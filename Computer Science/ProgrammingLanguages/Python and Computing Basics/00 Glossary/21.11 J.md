# 21.11 J

- **JIT compilation:** translation into executable code during a program’s run. *(Introduced §2.17.)*
- **Jitter:** deliberate random variation in timing used to reduce synchronised retries, starts, or other contention. *(Introduced §20.38.)*
- **Job:** finite workload whose controller seeks a specified number of successful completions. *(Introduced §20.38.)*
- **Join:** combination of records according to a relation between key values. *(Introduced §16.31.)*
- **JSON:** a text interchange format with objects, arrays, strings, numbers, Booleans, and null. *(Introduced §11.20.)*
