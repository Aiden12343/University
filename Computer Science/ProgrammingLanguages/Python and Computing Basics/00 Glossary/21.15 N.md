# 21.15 N

- **Name mangling:** class-definition transformation of selected double-leading-underscore names to reduce accidental subclass collision. *(Introduced §9.23.)*
- **Namespace:** a mapping from names to objects. *(Introduced §5.22, §20.37.)*
- **Namespace package:** a package whose portions can be contributed from multiple locations. *(Introduced §10.18.)*
- **NaN:** a special floating-point value meaning “not a number” with unordered comparison behaviour. *(Introduced §5.22.)*
- **Negative caching:** temporary caching of a name-resolution failure such as non-existence. *(Introduced §20.38.)*
- **Network address translation:** rewriting of packet addresses or ports between routing contexts. *(Introduced §20.38.)*
- **Network policy:** enforced rule set constraining permitted network communication between defined subjects and destinations. *(Introduced §20.38.)*
- **New reference:** C API result transferring a strong ownership obligation to the receiver. *(Introduced §15.23.)*
- **Node:** schedulable host supplying compute and runtime resources to orchestrated workloads. *(Introduced §20.38.)*
- **Noise margin:** tolerance separating valid physical signal ranges. *(Introduced §1.14.)*
- **Non-data descriptor:** a descriptor defining retrieval without setting/deletion and ordinarily shadowable by instance state. *(Introduced §9.23.)*
- **Nonce:** value required to be unique or otherwise constrained for a cryptographic operation under one key. *(Introduced §19.34.)*
- **None:** Python’s singleton object conventionally representing absence under an interface. *(Introduced §5.22.)*
- **Nonlocal:** a declaration targeting a binding in an enclosing function scope. *(Introduced §8.20.)*
- **Normal change:** non-emergency change following the ordinary risk, review, evidence, and rollout path. *(Introduced §20.38.)*
- **Normal form:** a chosen structural shape satisfying stated invariants. *(Introduced §7.18.)*
- **Numeral:** a written representation of a number. *(Introduced §1.14.)*
