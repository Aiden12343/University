# 21.16 O

- **Object:** a Python datum with identity, type, and value. *(Introduced §5.22.)*
- **Object file:** translated code/data plus metadata for later linking; unrelated here to a Python object. *(Introduced §2.17.)*
- **Observability:** ability to investigate internal system state from designed outputs and associated operational evidence. *(Introduced §20.38.)*
- **Observation:** recorded unit of analysis. *(Introduced §16.31.)*
- **Observed state:** controller's time-bounded and potentially stale view of actual resources and conditions. *(Introduced §20.38.)*
- **OCI:** Open Container Initiative specifications for container images, distribution, and runtime bundles and lifecycle. *(Introduced §20.38.)*
- **Opcode:** the portion of an instruction identifying its operation. *(Introduced §1.14.)*
- **Open-loop load:** workload model scheduling arrivals independently of prior response completion. *(Introduced §20.38.)*
- **Operand:** a value or location to which an operation applies. *(Introduced §1.14.)*
- **Operating system:** software managing hardware resources and providing protected abstractions and services. *(Introduced §2.17.)*
- **Operation identifier:** stable identifier correlating attempts and effects belonging to one logical operation. *(Introduced §20.38.)*
- **Optimisation:** a meaning-preserving transformation intended to improve a resource measure. *(Introduced §2.17.)*
- **Orchestration:** scheduling and lifecycle management of workloads and their supporting resources across hosts. *(Introduced §20.38.)*
- **ORM:** layer mapping object-oriented expressions and state to relational queries and rows. *(Introduced §18.36.)*
- **Out-of-memory termination:** process or container termination caused when memory demand cannot be satisfied under kernel and cgroup policy. *(Introduced §20.38.)*
- **Overfitting:** learning sample-specific variation that impairs relevant new-case performance. *(Introduced §17.37.)*
- **Overflow:** a result outside the representable range of a fixed representation. *(Introduced §1.14.)*
- **Override:** explicitly authorised, scoped, and preferably expiring departure from ordinary desired state or policy. *(Introduced §20.38.)*
