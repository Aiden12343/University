# 21.8 G

- **Game day:** organised exercise testing technical systems, people, authority, procedures, and communications under a scenario. *(Introduced §20.38.)*
- **Gauge:** metric representing sampled state that may increase or decrease, such as queue depth or temperature. *(Introduced §20.38.)*
- **Generalisation:** performance on relevant cases not used to choose the fitted model. *(Introduced §17.37.)*
- **Generation precondition:** requirement that a remote object still has an observed version before a mutation is accepted. *(Introduced §20.38.)*
- **Generational collection:** garbage-collection policy grouping objects by survival history or age. *(Introduced §15.23.)*
- **Generator:** a stateful iterator whose execution can suspend and resume around yielded values. *(Introduced §6.20.)*
- **Generator expression:** lazy expression syntax producing values through iteration. *(Introduced §6.20.)*
- **Generator function:** a function whose relevant body contains `yield` and whose call creates a generator. *(Introduced §6.20.)*
- **GIL:** conventional CPython global interpreter lock limiting simultaneous Python bytecode execution within one interpreter. *(Introduced §14.24.)*
- **Golden signal:** high-level service signal such as latency, traffic, errors, or saturation used to begin operational assessment. *(Introduced §20.38.)*
- **Good event:** eligible event satisfying the explicitly defined success criteria of an SLI. *(Introduced §20.38.)*
- **Graceful degradation:** deliberate reduction of optional behaviour while preserving explicitly selected correctness, security, and availability properties. *(Introduced §20.38.)*
- **Graceful shutdown:** bounded protocol for stopping admission, draining or checkpointing work, releasing authority, and terminating under supervisor coordination. *(Introduced §20.38.)*
- **Gradient:** vector of partial derivatives of a scalar function. *(Introduced §17.37.)*
- **Graph:** vertices and edges representing entities and connections. *(Introduced §13.22.)*
- **Grapheme cluster:** one or more code points commonly perceived as one written character. *(Introduced §5.22.)*
- **GraphQL:** typed query language and execution system for client-shaped application data. *(Introduced §18.36.)*
- **Greatest common divisor:** the greatest positive integer dividing each of two integers without remainder. *(Introduced §3.16.)*
- **Greedy algorithm:** algorithm committing to locally selected choices under a global-correctness proof. *(Introduced §13.22.)*
- **Guard:** a runtime check protecting an optimisation assumption. *(Introduced §2.17.)*
- **Guardrail:** monitored condition whose violation pauses, reverses, or limits a change or experiment. *(Introduced §20.38.)*
