# 21.9 H

- **Half-open interval:** an interval including its start and excluding its stop. *(Introduced §7.18.)*
- **Halting problem:** the undecidable general problem of determining whether an arbitrary program stops on an arbitrary input. *(Introduced §3.16.)*
- **Hash value:** an integer summary used to choose candidate locations in a hash structure. *(Introduced §5.22.)*
- **Hashable:** satisfying stable-hash and compatible-equality requirements for hashed collections. *(Introduced §5.22.)*
- **Head sampling:** trace-sampling decision made near operation start before its eventual outcome is known. *(Introduced §20.38.)*
- **Health check:** bounded observation used to decide a component's eligibility, restart, or operator attention under a specified meaning. *(Introduced §20.38.)*
- **Heap:** tree-shaped priority structure maintaining parent–child order, commonly array-backed. *(Introduced §13.22.)*
- **Hermetic build:** build constrained to read declared inputs and produce declared outputs under an isolated execution boundary. *(Introduced §20.38.)*
- **Hertz:** one cycle per second. *(Introduced §1.14.)*
- **Higher-order function:** a function accepting or returning callable behaviour. *(Introduced §8.20.)*
- **Histogram:** metric representation counting observations in defined buckets, usually with total count and sum. *(Introduced §20.38.)*
- **HMAC:** standard secret-key message-authentication construction built from a cryptographic hash. *(Introduced §19.34.)*
- **Horizontal scaling:** changing the number of replicas or workers serving a workload. *(Introduced §20.38.)*
- **Host:** operating-system instance or machine supplying kernel and resources to one or more processes or containers. *(Introduced §20.38.)*
- **Hot key:** disproportionately requested partition, cache, or object key that concentrates load despite broad aggregate capacity. *(Introduced §20.38.)*
- **HTTP:** application protocol defining request and response semantics for resources and representations. *(Introduced §18.36.)*
- **Hyperparameter:** configuration selected outside an individual parameter-fitting operation. *(Introduced §17.37.)*
- **Hysteresis:** use of different thresholds or delays for opposing control transitions to reduce oscillation. *(Introduced §20.38.)*
