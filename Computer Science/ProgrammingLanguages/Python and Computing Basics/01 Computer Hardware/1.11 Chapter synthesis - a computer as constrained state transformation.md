# 1.11 Chapter synthesis: a computer as constrained state transformation

The chapter’s parts can now be assembled into one model.

1. Physical devices provide controllable, distinguishable conditions.
2. Digital conventions classify ranges of those conditions as binary states.
3. Transistor networks realise gates and storage elements.
4. Gates compose Boolean and arithmetic functions.
5. Feedback and clocked storage make prior state available to later steps.
6. Registers and addressable memory retain instructions and data.
7. A CPU repeatedly fetches, decodes, and executes instruction representations.
8. Branches alter the next instruction address, enabling selection and repetition.
9. I/O mechanisms exchange represented information with the outside world.
10. Abstraction contracts permit each level to be reasoned about without reproducing every detail below it.

Under this model, computation is not mysterious intelligence. It is a controlled sequence of state transitions whose physical implementation is complex but whose architectural effects can be specified exactly. The machine’s usefulness arises from generality: instructions are represented in memory, so changing stored patterns changes the procedure without reconstructing the hardware.
