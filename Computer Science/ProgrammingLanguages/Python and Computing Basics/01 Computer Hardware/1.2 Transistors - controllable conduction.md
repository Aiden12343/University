# 1.2 Transistors: controllable conduction

A **transistor** is a semiconductor device whose electrical behaviour allows one signal to control the passage of another. A **semiconductor** is a material whose ability to conduct electrical current can be engineered and controlled. Modern processors predominantly use metal–oxide–semiconductor field-effect transistors, abbreviated **MOSFETs**. A detailed account of semiconductor physics is not required to understand computation, but the logical role must be stated accurately: a transistor can be arranged to behave approximately as a controlled switch.

A switch has an input that influences whether a conductive path is open or closed. In one region, current can pass sufficiently for the surrounding circuit to recognise an asserted output; in another, it cannot. The word “approximately” matters. A transistor is not an ideal mathematical switch. It has switching delay, leakage, heat production, capacitance, and operating limits. Digital logic is possible because circuits are designed so that these analogue imperfections remain inside the tolerances of the logical contract.

The most common logic family in general-purpose processors is **CMOS**, complementary metal–oxide–semiconductor. “Complementary” refers to the coordinated use of two kinds of MOSFET. In a basic CMOS inverter, one network connects the output towards the supply when the input is logically low, while the complementary network connects the output towards ground when the input is logically high. The circuit therefore produces the opposite logical state.

A **signal** is a varying physical quantity used to convey information. An **input** is a signal presented to a component; an **output** is the signal it produces. A **logic level** is one of the permitted signal ranges interpreted as a logical value. When an inverter receives logical 0 and settles, it produces logical 1. When it receives logical 1 and settles, it produces logical 0. The qualification “and settles” introduces **propagation delay**, the finite time between an input change and a corresponding valid output.

### Worked example 1.2 — From switch behaviour to inversion

Consider an abstract inverter with the rule (y = \operatorname{NOT}(x)), where (x) is the input and (y) the output.

| Input (x) | Output (y) |
|:---:|:---:|
| 0 | 1 |
| 1 | 0 |

This table is a **truth table**: an exhaustive listing of a Boolean operation’s output for every possible input combination. Because one binary input has two possible states, the table contains two rows. The logical table says nothing about transistor count, voltage thresholds, propagation time, power, or temperature. Those belong to the physical implementation. Conversely, a circuit diagram alone does not state which stable ranges the designer agrees to call 0 and 1. A complete engineering account connects both levels without confusing them.

Transistors become computationally important through scale and composition. One transistor supplies little useful behaviour. Networks of transistors implement logic gates; networks of gates implement arithmetic and storage; collections of arithmetic, storage, and control circuits implement a processor; a processor executing stored instructions supports software abstractions. Each layer constrains the layer above while allowing most lower-level details to be ignored during ordinary reasoning.

An **abstraction** is a model that exposes selected properties while deliberately hiding others. Hiding is justified only when the exposed contract remains true. Treating an inverter as NOT is sound while voltage, timing, fan-out, temperature, and fabrication conditions remain within its specified limits. Abstraction is therefore disciplined omission, not vagueness.

> **Common misconception — “A transistor literally stores a bit.”**  
> A lone transistor is a controllable electrical device, not a complete abstract storage cell. Stable storage requires a circuit arrangement—often involving several transistors—whose feedback preserves one of multiple states. Different memory technologies use different physical mechanisms.
