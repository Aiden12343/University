# 1.4 Binary positional representation

A **numeral** is a written representation of a number. A **radix**, or base, is the number of digit symbols used by a positional numeral system. Decimal notation has radix ten and uses the digits 0 through 9. Binary notation has radix two and uses 0 and 1.

The position of a digit determines its weight. Moving left through a radix-(b) numeral multiplies the positional weight by (b). In decimal, the numeral 347 denotes

\[
3\times 10^2 + 4\times 10^1 + 7\times 10^0
= 3\times 100 + 4\times 10 + 7\times 1.
\]

An **exponent** records repeated multiplication: (10^2 = 10\times10), while any non-zero number to exponent zero is 1. Binary follows the same rule with powers of two. The binary numeral `101101` denotes

\[
1\times2^5 + 0\times2^4 + 1\times2^3 + 1\times2^2 + 0\times2^1 + 1\times2^0
=32+0+8+4+0+1=45.
\]

A **bit**, short for binary digit, is one position holding 0 or 1. A group of eight bits is conventionally called a **byte**. A bit is a unit in an abstract representation; its physical realisation depends on the storage or signalling technology. The number of distinct patterns in (n) bits is (2^n), because every additional bit independently doubles the number of combinations. Eight bits therefore supply (2^8=256) patterns.

Unsigned binary represents non-negative integers. If an (n)-bit unsigned pattern is interpreted positionally, its smallest value is 0 and its largest is (2^n-1). The subtraction of one occurs because the count includes zero. An eight-bit unsigned integer therefore ranges from 0 through 255.

### Worked example 1.5 — Converting decimal 45 to binary

Repeated division by two exposes binary digits from right to left. At each step, divide the current quotient by two and record the remainder.

| Current value | Quotient after division by 2 | Remainder |
|---:|---:|:---:|
| 45 | 22 | 1 |
| 22 | 11 | 0 |
| 11 | 5 | 1 |
| 5 | 2 | 1 |
| 2 | 1 | 0 |
| 1 | 0 | 1 |

Reading the remainders from bottom to top gives `101101`. The reverse order is not a trick: the first remainder answers whether (2^0), the units position, is present; the next answers whether (2^1) is present; and so on.

Numbers below zero require an additional convention. Contemporary processors ordinarily use **two’s-complement representation** for signed integers. In an (n)-bit two’s-complement interpretation, the highest-position bit contributes (-2^{n-1}), while the remaining bits retain positive weights. For eight bits, `11111111` represents

\[
-128 + 64+32+16+8+4+2+1=-1.
\]

Fixed-width arithmetic can **overflow**: the mathematical result may require a pattern outside the available range. Eight-bit unsigned addition of 255 and 1 mathematically yields 256, but 256 requires nine bits. If only the low eight result bits are retained, the stored pattern becomes `00000000`. Whether a system wraps, traps, saturates, or records a carry belongs to its arithmetic contract.

Python integers will later appear not to have this fixed-width limit because their software representation grows to hold larger magnitudes, subject to available memory. This sentence is an explicitly flagged forward reference: **Python** is a programming language introduced formally in Chapter 4, and its integers are software objects implemented above finite machine words. The physical machine has not acquired infinitely wide registers.

Binary patterns also represent fractions, text, colour, sound, instructions, and addresses under other contracts. A widespread approximation for real-number arithmetic is **floating-point representation**, which divides a finite bit pattern into sign, exponent, and significand fields. It is introduced properly when Python numbers are examined. At this stage the essential rule is that a bit pattern has no type or meaning by itself; interpretation supplies both.

> **Common misconception — “Everything in a computer is a number.”**  
> Everything stored digitally is represented by finite patterns. Calling every pattern a number ignores the interpretation that makes a pattern an instruction, character, reference, colour, or encoded sound. Patterns can be *read as* numbers, but that is one interpretation among many.
