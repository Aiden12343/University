# 1.8 Memory hierarchy and the cost of distance

The phrase “memory” conceals several technologies and timescales. A **memory hierarchy** arranges storage by speed, capacity, cost, and persistence. Near the CPU are registers: extremely fast and scarce. One or more **cache** levels retain recently or nearby used memory contents so that the processor need not repeatedly wait for slower main memory. Main memory, commonly dynamic random-access memory (**DRAM**), holds active programs and data. Persistent devices such as solid-state drives retain information without continuous power but are slower than main memory. Remote storage adds network delay and independent failure modes.

**Latency** is the elapsed time between requesting an operation and receiving its result. **Bandwidth** is the quantity of data transferable per unit time. A system can have high bandwidth yet substantial latency: a freight train transports much material per hour once moving, but is a poor way to deliver one urgent page. Both measures matter to computer performance.

Caches exploit **locality**. **Temporal locality** is the tendency to use recently used data again. **Spatial locality** is the tendency to use data near recently used addresses. A cache transfers blocks containing more than the exact requested byte because nearby data is often needed soon. If the requested content is present, the access is a **cache hit**; otherwise it is a **cache miss**, and a slower level must supply it.

The hierarchy does not change a correctly written program’s intended abstract result, but it strongly influences time. Two procedures performing the same number of arithmetic operations may differ greatly if one accesses memory sequentially while the other repeatedly misses caches. This observation will later qualify simplistic performance claims based only on counting source-code lines or arithmetic operators.

Main memory is conventionally **volatile**, meaning its retained state requires continuing power. Persistent storage is **non-volatile**. These terms describe retention characteristics, not a moral hierarchy: volatile memory is selected because it offers properties useful for active computation; persistent storage is selected when information must survive termination or power loss.

> **Common misconception — “Memory and storage are synonyms.”**  
> Everyday usage sometimes merges them, but systems reasoning benefits from precision. Main memory normally supplies directly addressable working state to the CPU and is volatile. Persistent storage retains files and other data across power loss but is accessed through different mechanisms and at different costs.
