# 3.4 Data representation determines available operations

An abstract value must be represented before a machine can operate on it. A **data structure** is an organised representation together with operations and invariants that give the representation meaning. Selection of structure is selection of which operations will be direct, which will require traversal or reorganisation, and which invariants must be maintained.

Consider a collection of names. If represented as a contiguous sequence, preserving an order and visiting every name are direct, while determining membership may require comparison against many elements. If represented by a hash table, expected membership checks can be fast, while ordering is not the defining invariant. If represented as a sorted tree, ordered traversal and logarithmic search may be supported when balance is maintained. These structures are studied later; here they establish that an algorithm is not independent of representation.

The relationship can be stated in four questions:

1. What information must the computation preserve?
2. Which operations dominate the workload?
3. What invariants make those operations valid?
4. What time, memory, and complexity costs follow?

### Worked example 3.4 — Same abstract collection, different method

Problem: report whether identifier 73 occurs among (n) identifiers.

If the identifiers are stored in an unsorted sequence, a general correct method examines elements until 73 is found or the sequence is exhausted. In the worst case it examines all (n) elements.

If the identifiers are stored in sorted order, binary search can compare against a middle element and discard half the remaining interval after each comparison. This requires the sorted-order invariant and random access or an equivalent efficient navigation structure. Inserting arbitrary new identifiers may now require work to preserve that representation.

The abstract set of identifiers did not change. The representation changed the admissible proof and cost of the operation. “Choose the best data structure” is therefore incomplete; best must be measured against required operations and constraints.
