# 3.5 Computability and the informal meaning of Turing-completeness

Some questions cannot be answered by any algorithm, and some computational models cannot express every algorithm that another can. To discuss expressive power, computer science uses idealised mathematical machines.

A **Turing machine** is a formal model consisting, informally, of an unbounded tape divided into cells, a head that reads or writes one cell, a finite set of control states, and transition rules selecting an action from the current state and observed symbol. “Unbounded” is a mathematical allowance: any individual terminating computation uses only a finite portion, but no fixed finite limit is imposed on all possible inputs.

A system is **Turing-complete** when, given sufficient time and storage, it can simulate a universal Turing machine and therefore express every computation possible in that model. This is an equivalence of computability, not of efficiency, convenience, safety, or practical capacity. A Turing-complete language does not make infinite memory appear, guarantee termination, solve every mathematical question, or execute every expressible program within the age of the universe.

The phrase “given sufficient resources” also does not excuse physical limits. A real computer has finite memory and time. Turing-completeness classifies the language or abstract machine’s lack of a *fixed conceptual restriction* preventing universal computation as resources grow.

### Worked example 3.5 — Why selection and unbounded repetition matter

A notation that can only add a fixed list of constants and then stop expresses finitely many predetermined computations. A notation with mutable state, conditional selection, and repetition whose count depends on data can express arbitrarily extended procedures. These features are not by themselves a formal proof of Turing-completeness, but they expose the necessary shape: the next operation depends on retained state, and no fixed source-size bound limits the number of state transitions.

Many unexpectedly small systems are Turing-complete. This is usually a warning about expressive reach, not an endorsement as a programming medium. Conversely, deliberately restricted languages—configuration formats, query fragments, total functional languages, regular-expression subsets—can be more analysable precisely because they do not permit arbitrary computation.
