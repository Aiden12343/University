# 4.1 The workshop is part of the experiment

A program execution is determined not only by visible source text but also by the language implementation, implementation version, installed packages, operating system, working directory, environment, input, permissions, and external state. “It ran on my machine” records an observation while suppressing most of its conditions. A controlled programming workshop makes those conditions inspectable and reproducible.

This chapter uses **Python 3.12 or later**. A **version** identifies a particular release of software. Python release numbers use components such as `3.12.4`: the major version is 3, the minor version is 12, and the maintenance or micro release is 4. Exact compatibility is a contract, not a comparison in ordinary decimal arithmetic; version 3.12 is later than 3.9 even though the decimal number 3.12 is smaller than 3.9.

The name **Python** denotes a programming language and its standardised documentation, community, and ecosystem. A **Python implementation** is software that carries out Python-language semantics. **CPython** is the reference implementation and the implementation assumed for implementation-specific investigations in this work. Other implementations can preserve Python language behaviour while using different compilation, memory, and execution machinery.

The first diagnostic rule is therefore:

> Record the executable actually selected and ask that executable to report its version. Do not infer either fact from an installer window, a filename elsewhere, or a command that might resolve differently.
