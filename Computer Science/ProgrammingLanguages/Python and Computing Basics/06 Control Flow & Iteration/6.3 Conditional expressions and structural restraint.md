# 6.3 Conditional expressions and structural restraint

A **conditional expression** selects one of two expression values:

```python
label = "adult" if age >= 18 else "minor"
```

Python evaluates the condition first, then only the selected value expression. It does not evaluate both alternatives. This form is appropriate when one concise expression differs by condition. Multi-step effects, nested policy, or several conditions usually belong in an `if` statement or a named function.

```python
fee = standard_fee if member else guest_fee
```

This reads as a value selection. By contrast, nesting several conditional expressions can force the reader to reconstruct grouping and order. Concision is not density of meaning; a form is economical when it exposes the rule with the least interpretive work.
