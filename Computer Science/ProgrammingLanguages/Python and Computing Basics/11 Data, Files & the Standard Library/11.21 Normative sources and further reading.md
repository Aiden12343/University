# 11.21 Normative sources and further reading

This chapter crosses language, library, operating-system, filesystem, and interchange-format boundaries. Each source below governs only its own layer; none makes all filesystems or downstream consumers equivalent.

1. Python Software Foundation, [<code>io</code> — Core tools for working with streams](https://docs.python.org/3/library/io.html), *Python Standard Library*. Defines raw, buffered, and text I/O hierarchies, capabilities, buffering, encoding, newline behaviour, and stream lifecycle.
2. Python Software Foundation, [<code>open</code>](https://docs.python.org/3/library/functions.html#open), *Built-in Functions*. Specifies modes, buffering, encoding, error handling, newlines, descriptor ownership, and opener hooks.
3. Python Software Foundation, [<code>codecs</code> — Codec registry and base classes](https://docs.python.org/3/library/codecs.html), *Python Standard Library*. Defines codecs, incremental encoders/decoders, and registered error handlers.
4. M. von Löwis, [PEP 383 — Non-decodable Bytes in System Character Interfaces](https://peps.python.org/pep-0383/), 2009. Gives the rationale and limits of the surrogate-escape mechanism.
5. N. Inada, [PEP 597 — Add optional EncodingWarning](https://peps.python.org/pep-0597/), 2020. Documents detection of ambiguous default text encodings.
6. N. Inada, [PEP 686 — Make UTF-8 mode default](https://peps.python.org/pep-0686/), 2022. Specifies the later default change and its compatibility considerations; projects supporting 3.12 must account for the earlier behaviour.
7. Unicode Consortium, [The Unicode Standard](https://www.unicode.org/versions/latest/). Normative definition of Unicode characters, encoding forms, properties, and conformance.
8. Unicode Consortium, [Unicode Standard Annex #15 — Unicode Normalization Forms](https://www.unicode.org/reports/tr15/). Defines NFC, NFD, NFKC, and NFKD.
9. Unicode Consortium, [Unicode Standard Annex #29 — Unicode Text Segmentation](https://www.unicode.org/reports/tr29/). Defines default grapheme, word, and sentence boundaries and explains tailoring.
10. Python Software Foundation, [<code>contextlib</code> — Utilities for <code>with</code>-statement contexts](https://docs.python.org/3/library/contextlib.html), *Python Standard Library*. Specifies generator managers, suppression, closing, null contexts, exit stacks, redirection, and asynchronous variants.
11. Python Software Foundation, [The <code>with</code> statement](https://docs.python.org/3/reference/compound_stmts.html#the-with-statement), *Python Language Reference*. Normative control-flow semantics for the context-management protocol.
12. Python Software Foundation, [<code>pathlib</code> — Object-oriented filesystem paths](https://docs.python.org/3/library/pathlib.html), *Python Standard Library*. Defines pure/concrete paths and versioned filesystem operations.
13. Python Software Foundation, [<code>os</code> — Miscellaneous operating-system interfaces](https://docs.python.org/3/library/os.html), *Python Standard Library*. Defines descriptor, pathname, synchronisation, replacement, relative-directory, and filesystem-encoding interfaces with platform availability.
14. Python Software Foundation, [<code>shutil</code> — High-level file operations](https://docs.python.org/3/library/shutil.html), *Python Standard Library*. Specifies copying, moving, archive, and recursive filesystem operations and their metadata limitations.
15. Python Software Foundation, [<code>tempfile</code> — Generate temporary files and directories](https://docs.python.org/3/library/tempfile.html), *Python Standard Library*. Defines secure creation APIs, named/unnamed lifetimes, spooling, and platform qualifications.
16. The Open Group, [<code>open</code>](https://pubs.opengroup.org/onlinepubs/9699919799/functions/open.html), *The Open Group Base Specifications Issue 7*. POSIX contract for opening and creation flags.
17. The Open Group, [<code>fsync</code>](https://pubs.opengroup.org/onlinepubs/9699919799/functions/fsync.html), *The Open Group Base Specifications Issue 7*. POSIX synchronisation contract and error conditions.
18. The Open Group, [<code>rename</code>](https://pubs.opengroup.org/onlinepubs/9699919799/functions/rename.html), *The Open Group Base Specifications Issue 7*. POSIX namespace replacement semantics and constraints.
19. T. Bray, ed., [RFC 8259 — The JavaScript Object Notation (JSON) Data Interchange Format](https://www.rfc-editor.org/rfc/rfc8259.html), IETF Standards Track, 2017. Defines JSON grammar, values, UTF-8 interoperability, parser/generator latitude, and security considerations.
20. A. Rundgren, B. Jordan, and S. Erdtman, [RFC 8785 — JSON Canonicalization Scheme](https://www.rfc-editor.org/rfc/rfc8785.html), IETF Informational, 2020. Defines JCS for repeatable cryptographic representations.
21. N. Williams, [RFC 7464 — JavaScript Object Notation Text Sequences](https://www.rfc-editor.org/rfc/rfc7464.html), IETF Standards Track, 2015. Defines one framed sequence format for multiple JSON texts.
22. Python Software Foundation, [<code>json</code> — JSON encoder and decoder](https://docs.python.org/3/library/json.html), *Python Standard Library*. Specifies Python mappings, hooks, extensions, ordering, circular checks, and compliance caveats.
23. Y. Shafranovich, [RFC 4180 — Common Format and MIME Type for Comma-Separated Values Files](https://www.rfc-editor.org/rfc/rfc4180.html), IETF Informational, 2005. Documents one common CSV dialect and explicitly notes implementation variation.
24. D. Montanaro et al., [PEP 305 — CSV File API](https://peps.python.org/pep-0305/), 2003. Design and rationale for Python's CSV interfaces.
25. Python Software Foundation, [<code>csv</code> — CSV File Reading and Writing](https://docs.python.org/3/library/csv.html), *Python Standard Library*. Defines readers, writers, dialects, dictionary adapters, quoting, sniffing, limits, and newline guidance.
26. Python Software Foundation, [<code>pickle</code> — Python object serialisation](https://docs.python.org/3/library/pickle.html), *Python Standard Library*. Specifies protocols, object-graph preservation, reconstruction hooks, persistent IDs, and the prohibition on untrusted input.
27. Python Software Foundation, [<code>pickletools</code> — Tools for pickle developers](https://docs.python.org/3/library/pickletools.html), *Python Standard Library*. Documents pickle opcode analysis and optimisation utilities.
28. A. Pitrou, [PEP 574 — Pickle protocol 5 with out-of-band data](https://peps.python.org/pep-0574/), 2018. Defines buffer separation and zero-copy-oriented protocol extensions.
29. Python Software Foundation, [<code>struct</code> — Interpret bytes as packed binary data](https://docs.python.org/3/library/struct.html), *Python Standard Library*. Defines byte order, sizes, alignment, packing, and unpacking.
30. Python Software Foundation, [<code>collections</code> — Container datatypes](https://docs.python.org/3/library/collections.html), *Python Standard Library*. Specifies deque, Counter, defaultdict, ChainMap, named tuples, ordered mappings, and wrapper containers.
31. Python Software Foundation, [<code>itertools</code> — Functions creating iterators for efficient looping](https://docs.python.org/3/library/itertools.html), *Python Standard Library*. Defines iterator algebra, consumption, caching, grouping, and combinatorial generators.
32. Python Software Foundation, [<code>functools</code> — Higher-order functions and operations on callable objects](https://docs.python.org/3/library/functools.html), *Python Standard Library*. Specifies partial application, wrappers, caches, dispatch, reduction, and ordering helpers.
33. Python Software Foundation, [<code>dataclasses</code> — Data Classes](https://docs.python.org/3/library/dataclasses.html), *Python Standard Library*. Defines field discovery and generated construction, representation, equality, ordering, hashing, matching, freezing, and slots.
34. IEEE, *IEEE Standard for Floating-Point Arithmetic*, IEEE 754-2019. Normative arithmetic model relevant to JSON numeric interoperability and non-associative rounding.
35. J. Gray and A. Reuter, *Transaction Processing: Concepts and Techniques*, Morgan Kaufmann, 1992. Comprehensive treatment of atomicity, logging, recovery, concurrency, and commit protocols.
36. C. Mohan et al., “ARIES: A Transaction Recovery Method Supporting Fine-Granularity Locking and Partial Rollbacks Using Write-Ahead Logging,” *ACM Transactions on Database Systems* 17(1), 1992, pp. 94–162. Formalises influential WAL and recovery machinery.
37. J. H. Saltzer and M. D. Schroeder, “The Protection of Information in Computer Systems,” *Proceedings of the IEEE* 63(9), 1975, pp. 1278–1308. Establishes least privilege, complete mediation, and related protection principles used at trust boundaries.
