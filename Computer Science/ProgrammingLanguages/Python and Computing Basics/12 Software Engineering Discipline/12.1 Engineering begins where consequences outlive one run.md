# 12.1 Engineering begins where consequences outlive one run

**Software engineering** is the disciplined construction, evaluation, operation, and evolution of software under requirements, constraints, uncertainty, and change. Programming produces executable behaviour; engineering additionally establishes why that behaviour is wanted, how it is verified, how change is controlled, and how failure is detected and contained.

The central artefacts are not only source files. They include:

- requirements and acceptance criteria;
- architecture and interface contracts;
- tests and independent oracles;
- type and static-analysis evidence;
- version-control history;
- build and dependency declarations;
- documentation and operational procedures;
- measurements, logs, and incident records.

No artefact is proof by volume. A thousand assertions derived from the same false assumption remain false. Evidence must be selected by risk and linked to claims.
