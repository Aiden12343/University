# 16.25 Visualisation is an encoded argument

A **data visualisation** maps data properties to visual properties such as position, length, angle, area, colour, or shape. It is not an ornamental final step. Every axis limit, transformation, aggregation, ordering, bin, colour scale, and omission influences the represented claim.

Position along a common scale supports more precise comparisons than area or volume. Bar lengths should ordinarily share a meaningful zero when their length encodes magnitude. Lines imply ordered connection and are therefore suitable for many time series but misleading for unordered categories. A log scale represents multiplicative ratios more directly than additive differences and must be labelled.

### Worked example 16.15 — A reproducible distribution plot

~~~python
import matplotlib.pyplot as plt
import pandas as pd

latencies = pd.DataFrame(
    {
        "site": ["north", "north", "south", "south", "south"],
        "latency_ms": [83, 91, 107, 101, 98],
    }
)

figure, axis = plt.subplots(figsize=(7, 4))
for site, group in latencies.groupby("site"):
    axis.ecdf(
        group["latency_ms"],
        label=site,
    )

axis.set(
    xlabel="Latency (milliseconds)",
    ylabel="Cumulative proportion",
    title="Empirical latency distributions by site",
)
axis.legend(title="Site")
figure.tight_layout()
figure.savefig("latency-ecdf.png", dpi=180)
~~~

An **empirical cumulative distribution function**, abbreviated ECDF, gives for each horizontal value the observed proportion at or below it. It avoids a histogram’s arbitrary bin boundaries, though a small sample still yields a coarse staircase. Explicit labels include units; the output parameters make rendering repeatable. Accessibility additionally requires colour choices with adequate contrast and distinctions not carried by colour alone.

The plot does not show request volume over time, dependence, uncertainty about a population, or why sites differ. A caption should state the sample, exclusions, time range, and transformation. Visual honesty consists of making the encoding and limitations inspectable.

### 16.25.1 A grammar: data, transformations, marks, scales, and coordinates

A useful analytical grammar decomposes a graphic into components. **Marks** are geometric objects such as points, lines, bars, and areas. **Visual channels** are properties—position, length, angle, area, hue, lightness, shape—used to encode variables. A **scale** maps data values into a visual channel and provides an inverse interpretation through axes or legends. A **coordinate system** determines spatial geometry. **Faceting** repeats a design across subsets on comparable panels.

The data shown in a plot are often transformed: counted, binned, averaged, smoothed, normalised, ranked, or model-predicted. The transformation must be as visible in the specification as the mark. A bar chart of raw records, group means, percentages, and model-adjusted estimates can look similar while making different claims.

Choose encodings according to comparisons:

- aligned position on a common scale supports accurate magnitude comparison;
- non-aligned positions, angles, areas, and volumes are harder to compare precisely;
- hue distinguishes categories but gives weak intrinsic order;
- lightness can encode order but must remain legible and perceptually monotonic;
- shape supports a small number of categories and provides redundancy for colour;
- animation reveals change but burdens memory and is difficult to inspect exactly.

A bar encodes magnitude through length and normally requires a zero baseline. A point estimate on a truncated axis can legitimately focus on small differences if the mark is position rather than length and the scale is conspicuous. A line connects observations and implies an ordered continuum or trajectory. Connecting category means invents interpolation unless the categories possess meaningful order.

~~~python
import matplotlib.pyplot as plt
import numpy as np

x = np.arange(1, 7)
estimate = np.array([10.0, 10.8, 11.1, 11.7, 12.0, 12.4])
lower = estimate - np.array([0.8, 0.6, 0.7, 0.5, 0.6, 0.7])
upper = estimate + np.array([0.9, 0.7, 0.8, 0.6, 0.7, 0.8])

figure, axis = plt.subplots(figsize=(7, 4))
axis.plot(x, estimate, marker="o", color="#1b4f72", label="estimate")
axis.fill_between(x, lower, upper, color="#85c1e9", alpha=0.45,
                  label="95% interval")
axis.set(
    xlabel="Month after deployment",
    ylabel="Mean energy use (kWh per active device-day)",
    xticks=x,
)
axis.legend()
figure.tight_layout()
figure.savefig("energy-with-intervals.png", dpi=180)
plt.close(figure)
~~~

The ribbon’s meaning must be stated: confidence interval for a mean, prediction interval for new units, posterior credible interval, or merely between-unit quantiles. Smoothly joining discrete monthly estimates aids trajectory reading but must not imply observations between months if none exist.

> **Common misconception 16.69 — “A chart displays the data directly.”**  
> A chart displays a selected and transformed representation through marks, scales, coordinates, aggregation, ordering, and omission. Those choices form an argument and must be documented.

### 16.25.2 Distributions, uncertainty, density, and overplotting

Summary marks conceal distributions. Mean bars with error bars can hide skew, multimodality, outliers, unequal sample sizes, paired structure, and truncation. Prefer an ECDF, dot plot, interval plot, box plot, violin/density estimate, histogram, or raw-plus-summary design according to sample size and question. Every distribution graphic also has parameters: histogram bin edges, density bandwidth, box-plot whisker convention, and ECDF weighting.

Overplotting occurs when marks overlap so density and multiplicity disappear. Remedies include transparency, smaller marks, jitter for discrete axes, hexagonal or rectangular binning, contours, sampling with disclosure, and faceting. Transparency is not a precise count scale and interacts with rendering background; binned counts with a labelled scale are preferable when density magnitude matters.

Uncertainty should be encoded at the level where it exists. A confidence band around a fitted mean is narrower than a prediction band for individuals. Error bars must state their definition. Showing standard deviation bars as though they were uncertainty in the mean conflates outcome dispersion with estimator precision. For many groups, interval plots on a common axis enable comparison better than overlapping ribbons.

Colour requires both statistical and accessibility discipline. Use a sequential scale for ordered magnitude, a diverging scale around a meaningful reference, and a qualitative palette for unordered classes. Rainbow palettes introduce false boundaries and uneven perceptual change. Provide adequate contrast, ensure distinctions survive common colour-vision deficiencies and monochrome reproduction, and add labels, shapes, or line styles rather than making colour the sole carrier. Text alternatives should state the principal relationship and unusual features, not enumerate every pixel.

A **logarithmic scale** spaces equal ratios equally. It cannot ordinarily display zero or negative values on a standard log axis. Adding an arbitrary constant to make values positive changes ratios, especially near zero. If signed values matter, a symmetric log or another transformation may be used with explanation. Dual vertical axes can make unrelated series appear correlated through arbitrary scaling; small multiples or indexed values are usually more interpretable.

### 16.25.3 Graphical integrity and reproducible construction

Graphical distortion can arise from:

- truncated bar baselines that exaggerate length ratios;
- area or three-dimensional volume whose geometry grows faster than the encoded quantity;
- unequal bin widths shown through count heights rather than density area;
- omitted categories or time intervals;
- sorting chosen to dramatise a pattern without disclosure;
- aspect ratios that visually steepen or flatten trends;
- smoothing parameters selected after seeing the preferred story;
- axes whose units, transformations, or denominators are absent;
- maps that encode population counts by land area and thereby emphasise empty regions.

Integrity does not require one fixed aspect ratio or always-zero axes. It requires that visual ratios correspond to intended data ratios, transformations are legible, and reasonable design alternatives do not reverse the conclusion without notice.

The figure-generating program should be deterministic given data and environment. Set explicit figure size, scales, limits where substantively fixed, ordering, palette, labels, and output format. Close figures in automated loops. Vector formats preserve geometric marks for print; raster formats require sufficient pixel dimensions and font rendering. Embedding metadata and keeping the source data table or hash supports provenance.

~~~python
import matplotlib.pyplot as plt
import pandas as pd

counts = pd.DataFrame(
    {
        "category": ["complete", "incomplete", "invalid"],
        "records": [8_420, 730, 85],
    }
).sort_values("records")

figure, axis = plt.subplots(figsize=(7, 3.8))
bars = axis.barh(counts["category"], counts["records"], color="#4472c4")
axis.bar_label(bars, fmt="%d", padding=3)
axis.set(xlabel="Records", ylabel="Validation status", xlim=(0, 9_000))
axis.spines[["top", "right"]].set_visible(False)
figure.tight_layout()
figure.savefig("validation-status.svg")
plt.close(figure)
~~~

The zero baseline makes bar-length ratios interpretable. Direct labels reduce legend lookup. Yet this chart still needs a caption defining the validation run, date, source population, and whether categories are mutually exclusive.

> **Common misconception 16.70 — “Visual honesty is achieved by leaving plotting defaults unchanged.”**  
> Defaults know neither the estimand nor the audience. Honest construction requires deliberate denominators, scales, transformations, uncertainty definitions, accessibility, provenance, and captions; defaults are merely initial parameter values.
