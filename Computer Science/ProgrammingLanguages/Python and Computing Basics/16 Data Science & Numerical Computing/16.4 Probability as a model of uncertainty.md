# 16.4 Probability as a model of uncertainty

An **experiment** in probability is a repeatable or conceptually repeatable process with uncertain outcome. Its **sample space** is the set of possible outcomes under the model. An **event** is a subset of those outcomes. A **probability** assigns numbers between 0 and 1 to events consistently: impossible events receive 0, the whole sample space receives 1, and probabilities of mutually exclusive events add.

A **random variable** is a function assigning a numerical value to each outcome. The term does not mean a Python name changes at random. A **probability distribution** specifies how probability is allocated among possible values or intervals. For a discrete random variable \(X\), its expected value is

\[
\operatorname{E}[X] = \sum_x x\,P(X=x),
\]

provided the sum is well defined. Expected value is a probability-weighted long-run centre under the model, not necessarily a value that can occur. The expected value of a fair six-sided die is 3.5 although no roll produces 3.5.

Two events \(A\) and \(B\) are **independent** when \(P(A\cap B)=P(A)P(B)\). Independence is a model property, not a synonym for “different rows.” Repeated measurements from the same person, adjacent time-series values, and devices sharing a production batch commonly depend on one another.

The **conditional probability** \(P(A\mid B)\) is the probability assigned to \(A\) after restricting attention to cases where \(B\) occurs:

\[
P(A\mid B)=\frac{P(A\cap B)}{P(B)},\qquad P(B)>0.
\]

Reversing the condition changes the question. The probability of a positive test given disease is not the probability of disease given a positive test.

### Worked example 16.3 — Base rates and conditional probability

Suppose a model population contains 10,000 people. One percent, or 100 people, have a condition. A test is positive for 90% of affected people and 5% of unaffected people.

- True positives: \(0.90\times100=90\).
- False positives: \(0.05\times9{,}900=495\).
- All positives: \(90+495=585\).
- The modelled probability of disease given a positive result is \(90/585\), approximately 15.4%.

The calculation does not impugn the test’s sensitivity. It shows that a low base rate permits false positives from a large unaffected group to outnumber true positives. Real diagnostic interpretation additionally requires uncertainty, population applicability, consequences, and professional judgement.

### 16.4.1 Probability begins with a declared sample space

For a finite sample space (Omega), a probability function (P) assigns each event (A\subseteq\Omega) a value satisfying:

1. (P(A)\geq0);
2. (P(\Omega)=1);
3. for mutually exclusive events (A) and (B), (P(A\cup B)=P(A)+P(B)), extended to countable disjoint collections.

These **Kolmogorov axioms** constrain a model but do not tell the analyst which model describes the world. Declaring six die faces equally likely adds a symmetry/fairness assumption beyond the axioms. Historical frequency, physical reasoning or calibration supplies evidence for that assumption.

The **complement** (A^c) contains outcomes not in (A), so (P(A^c)=1-P(A)). The **union** (A\cup B) means at least one event occurs. The **intersection** (A\cap B) means both occur. When events can overlap,

\[
P(A\cup B)=P(A)+P(B)-P(A\cap B),
\]

because the intersection would otherwise be counted twice.

~~~python
from fractions import Fraction
from itertools import product


space = set(product(range(1, 7), repeat=2))
sum_is_seven = {outcome for outcome in space if sum(outcome) == 7}
first_is_six = {outcome for outcome in space if outcome[0] == 6}

def probability(event: set[tuple[int, int]]) -> Fraction:
    return Fraction(len(event), len(space))


union = sum_is_seven | first_is_six
intersection = sum_is_seven & first_is_six
assert probability(union) == (
    probability(sum_is_seven)
    + probability(first_is_six)
    - probability(intersection)
)
~~~

The counting calculation is valid only under the model that all 36 ordered pairs are equally likely. The set operations make event algebra explicit.

> **Common misconception 16.9 — “Probability is a property automatically contained in observed data.”**  
> Probability belongs to a model or design connecting possible outcomes. Data inform or test that model but do not select a unique probability assignment by themselves.

### 16.4.2 Discrete and continuous distributions allocate probability differently

A discrete random variable has countable possible values. Its **probability mass function** (p(x)=P(X=x)) assigns point probabilities summing to one. A continuous random variable is described through probabilities of intervals; a **probability density function** (f(x)) integrates over a region to give probability. Density can exceed one, while integrated probability remains between zero and one. For a truly continuous model, (P(X=x)=0) at each exact point even though some value occurs.

The **cumulative distribution function** is

\[
F(x)=P(X\leq x).
\]

It applies to discrete, continuous and mixed distributions. It is non-decreasing, approaches zero toward negative infinity, approaches one toward positive infinity, and determines the distribution.

For a Bernoulli random variable with success probability (p), (X) takes 1 with probability (p) and 0 otherwise. Its expectation is (p) and variance is (p(1-p)). A binomial variable counts successes in a fixed number of independent identically distributed Bernoulli trials under the model. Real repeated outcomes are not binomial merely because they are recorded as success/failure: changing probabilities or dependence violates assumptions.

The normal distribution is a continuous family specified by mean (mu) and positive standard deviation (sigma). Its symmetric bell-shaped density is a model, not a generic synonym for “ordinary”. Heavy-tailed, bounded, skewed, multimodal and discrete data can be entirely normal in the everyday sense while being non-normal statistically.

> **Common misconception 16.10 — “A density value is the probability of observing that exact continuous value.”**  
> Point probability is zero in a continuous model. Density is probability per unit near a point; probability is the integral over an interval.

### 16.4.3 Expectation is linear without requiring independence

For random variables with defined expectations and constants (a,b),

\[
\operatorname{E}[aX+bY]=a\operatorname{E}[X]+b\operatorname{E}[Y].
\]

This **linearity of expectation** does not require (X) and (Y) to be independent. Independence becomes relevant to products and variance simplifications. Variance is

\[
\operatorname{Var}(X)=\operatorname{E}[(X-\operatorname{E}X)^2].
\]

For two variables,

\[
\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)
+2\operatorname{Cov}(X,Y).
\]

Only when covariance is zero does the cross-term vanish. Independence with finite second moments implies zero covariance; zero covariance does not generally imply independence.

An expected value is not a prediction that every or most outcome lies near it. A lottery can have positive expected winnings dominated by a tiny chance of a huge prize while almost every ticket loses. Expected utility or a risk-sensitive decision criterion may be more relevant than expected money.

~~~python
from fractions import Fraction


outcomes = {
    -1: Fraction(999_999, 1_000_000),
    2_000_000: Fraction(1, 1_000_000),
}
expectation = sum(value * chance for value, chance in outcomes.items())

assert expectation == Fraction(1_000_001, 1_000_000)
assert outcomes[-1] > Fraction(999, 1_000)
~~~

The expected payoff is slightly greater than one unit even though loss occurs with probability 0.999999. The example excludes ticket price, utility, counterparty risk and repeated play; it isolates the distinction between expectation and typical outcome.

> **Common misconception 16.11 — “The expected value is the outcome one should expect to observe.”**  
> It is a probability-weighted centre. It may be impossible as a single outcome and can be dominated by rare extremes.

### 16.4.4 Bayes’ rule reverses a condition only with the base rate

From the definition of conditional probability,

\[
P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)},\qquad P(B)>0.
\]

This is **Bayes’ rule**. (P(A)) is the prior or base probability in the model; (P(B\mid A)) is the likelihood of evidence (B) given (A); (P(A\mid B)) is the updated conditional probability. The denominator sums evidence probability across mutually exclusive cases.

Odds provide another form. If prior odds for (A) are (P(A)/P(A^c)), then posterior odds equal prior odds times the likelihood ratio (P(B\mid A)/P(B\mid A^c)). A highly discriminative test can still yield modest posterior probability when prior odds are very small, as Worked Example 16.3 showed.

The word **prior** does not necessarily mean subjective guess; it can be a prevalence estimate, randomisation probability, previous posterior or explicitly chosen judgement. Its appropriateness to the target population must be defended.

### 16.4.5 Independence, identical distribution and exchangeability are distinct

Observations (X_1,\ldots,X_n) are **independent and identically distributed** (IID) when their joint distribution factors into independent components and each component has the same distribution. Independence concerns dependence; identical distribution concerns sameness of marginal distributions. Either can hold without the other.

**Exchangeability** means the joint probability is invariant under permutations of observation order. IID observations are exchangeable, but exchangeable sequences can share latent dependence. Time series are generally not exchangeable because order carries structure.

The **law of large numbers** states, under specified conditions, that an average converges toward an expectation as sample size grows. It does not state that short runs must balance or that bias vanishes. The **central limit theorem** states, under specified conditions and scaling, that sampling distributions of sums/means approach a normal distribution. It does not make the underlying observations normally distributed and can converge slowly or fail under dependence/heavy tails.

~~~python
from random import Random
from statistics import mean


rng = Random(314159)
running_means: list[float] = []
total = 0.0

for count in range(1, 10_001):
    total += rng.random()
    if count in {10, 100, 1_000, 10_000}:
        running_means.append(total / count)

print(running_means, mean(running_means))
~~~

The simulation illustrates one pseudorandom path from a uniform generator whose model expectation is 0.5. It does not prove convergence, independence of physical observations or generator quality.

> **Common misconception 16.12 — “The central limit theorem says every sufficiently large dataset is normally distributed.”**  
> It concerns the scaled sampling distribution of specified sums or means under conditions, not the shape of the raw observations, and “sufficiently large” depends on the distribution and dependence.

Probability supplies a language for uncertainty. NumPy supplies a representation allowing many numerical values to be manipulated under explicit shape, dtype and memory contracts.
