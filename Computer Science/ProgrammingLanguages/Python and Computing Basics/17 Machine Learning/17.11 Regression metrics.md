# 17.11 Regression metrics

For targets \(y_i\) and predictions \(\hat{y}_i\):

**Mean absolute error**

\[
\operatorname{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|.
\]

**Mean squared error**

\[
\operatorname{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2.
\]

**Root mean squared error**

\[
\operatorname{RMSE}=\sqrt{\operatorname{MSE}}.
\]

MAE and RMSE retain target units, but RMSE gives greater influence to large errors. A relative or percentage error is undefined or unstable near zero and can weight cases unexpectedly. The coefficient of determination \(R^2\) compares squared error with a reference based on target mean under its definition; it can be negative on evaluation data and is not “percent accuracy.”

Metrics must reflect use. If a ten-unit underprediction is worse than a ten-unit overprediction, symmetric metrics conceal the difference. Report error distributions and slices, not only a mean.

### 17.11.1 Metrics imply different target summaries

MAE estimates average absolute error and corresponds to conditional medians when optimised pointwise. MSE corresponds to conditional means and gives squared influence to large residuals. RMSE is the square root of an aggregate; it is not the mean absolute magnitude and cannot be decomposed additively across groups without returning to squared errors.

The coefficient \(R^2\) for ordinary evaluation is

\[
R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}
              {\sum_i(y_i-\bar y)^2}.
\]

It compares the model with predicting the evaluation target mean under this definition. Negative \(R^2\) means worse squared error than that reference. It is undefined when the denominator is zero under some library policies, and it is not a percentage of cases explained.

Percentage metrics have asymmetric and zero-denominator pathologies. Mean absolute percentage error heavily weights small targets; symmetric variants introduce other conventions. Log-scale losses imply multiplicative priorities and require policies for zero and negative outcomes.

~~~python
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

actual = np.array([1.0, 2.0, 10.0, 100.0])
predicted = np.array([2.0, 2.0, 8.0, 80.0])

mae = mean_absolute_error(actual, predicted)
rmse = mean_squared_error(actual, predicted) ** 0.5
r_squared = r2_score(actual, predicted)
print({"mae": mae, "rmse": rmse, "r2": r_squared})
~~~

The final case dominates squared loss. Whether that is desirable depends on the consequences of a 20-unit error at a target of 100.

> **Common misconception 17.27 — “A lower regression metric means every prediction improved.”**  
> Aggregate loss can improve while important cases, tails, directions, or groups worsen. Preserve residual distributions and case-level consequences.

### 17.11.2 Weights, intervals, and transformed targets

Sample-weighted metrics estimate a weighted population or priority. Report both weights and unweighted denominators. A model can improve a weighted average by sacrificing low-weight groups; that may be intended under a sampling design and unacceptable under a fairness objective.

For transformed targets, inverse transformation changes errors. Fitting squared error to \(\log Y\) targets conditional behaviour on the log scale; exponentiating the predicted log mean does not generally yield the conditional arithmetic mean because expectation does not commute with exponentiation. Bias correction requires distributional assumptions or direct modelling.

Point metrics omit predictive uncertainty. A **prediction interval** or quantile forecast can represent conditional dispersion. Interval evaluation should examine empirical coverage and width together; a trivially infinite interval covers everything. Coverage may fail by subgroup or target magnitude despite matching globally.

> **Common misconception 17.28 — “Transforming the target and transforming predictions back preserves the original loss objective.”**  
> Nonlinear transformations alter which errors and conditional functional are optimised. Inverse-transformed point predictions require an explicit interpretation.

### 17.11.3 Distributional prediction and conformal coverage

A point prediction suppresses conditional variation. **Distributional regression** estimates parameters or representations of an entire conditional distribution \(P(Y\mid X=x)\). A Gaussian model might predict both mean \(\mu(x)\) and standard deviation \(\sigma(x)>0\), then optimise negative log likelihood. Its intervals are only as valid as the distributional form and fitted parameters.

**Quantile regression** estimates a conditional quantile \(q_\tau(x)\), defined so that a proportion \(\tau\) of the conditional distribution lies at or below it under regularity conventions. It minimises pinball loss

\[
\rho_\tau(y-\hat q)
=
\begin{cases}
\tau(y-\hat q), & y\geq\hat q,\\
(1-\tau)(\hat q-y), & y<\hat q.
\end{cases}
\]

Separate lower and upper quantile models can cross, producing an invalid ordering unless the modelling procedure constrains or repairs them. Nominal conditional quantiles can also be miscalibrated under misspecification or shift.

**Conformal prediction** converts nonconformity scores into prediction sets. In split conformal regression:

1. fit a point model on a training partition;
2. compute absolute residual scores on a separate calibration partition;
3. select a finite-sample corrected score quantile;
4. place that radius around a future point prediction.

Under exchangeability of calibration and future examples, the construction gives marginal finite-sample coverage at least approximately \(1-\alpha\), with exact convention depending on ties and randomisation. It does not guarantee conditional coverage for every \(x\), group, or time.

~~~python
import math
import numpy as np
from sklearn.datasets import make_regression
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split

X, y = make_regression(
    n_samples=1_200,
    n_features=8,
    noise=18.0,
    random_state=9,
)
X_development, X_test, y_development, y_test = train_test_split(
    X,
    y,
    test_size=0.25,
    random_state=9,
)
X_train, X_calibration, y_train, y_calibration = train_test_split(
    X_development,
    y_development,
    test_size=0.25,
    random_state=10,
)

model = RandomForestRegressor(
    n_estimators=300,
    min_samples_leaf=4,
    n_jobs=-1,
    random_state=11,
).fit(X_train, y_train)

calibration_scores = np.abs(
    y_calibration - model.predict(X_calibration)
)
alpha = 0.10
count = len(calibration_scores)
level = min(
    1.0,
    math.ceil((count + 1) * (1.0 - alpha)) / count,
)
radius = np.quantile(
    calibration_scores,
    level,
    method="higher",
)

centre = model.predict(X_test)
lower = centre - radius
upper = centre + radius
coverage = np.mean((lower <= y_test) & (y_test <= upper))
print({"radius": radius, "test_coverage": coverage})
assert np.all(lower <= upper)
~~~

The observed test coverage is random and need not equal \(0.90\). Reusing calibration data to tune the base model or choose among interval constructions consumes the exchangeability-based guarantee unless the selection is itself accounted for.

Heteroskedastic data make a constant conformal radius inefficient: low-noise cases receive overly wide intervals and high-noise cases too narrow for useful conditional behaviour. Normalised scores based on a separately fitted scale model, conformalised quantile regression, group-conditional procedures, and local methods address aspects of this problem with additional data and assumptions.

Prediction intervals concern future outcomes. Confidence intervals for a mean function or model parameter answer different questions and are generally narrower. A system should state whether uncertainty refers to observation noise, parameter estimation, model choice, data shift, or all of these; no single interval automatically contains every source.
