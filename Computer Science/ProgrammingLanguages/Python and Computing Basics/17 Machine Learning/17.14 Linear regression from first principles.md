# 17.14 Linear regression from first principles

A linear regression model with \(p\) features has

\[
\hat{y}=\beta_0+\beta_1x_1+\cdots+\beta_px_p.
\]

The coefficients \(\beta_j\) are parameters. “Linear” means linear in the parameters; features can include transformations such as \(x^2\) while the model remains linear in its coefficients.

In matrix notation, predictions are \(X\beta\) after incorporating an intercept column if desired. Ordinary least squares chooses \(\beta\) to minimise

\[
\lVert X\beta-y\rVert_2^2
=\sum_{i=1}^{n}(\hat{y}_i-y_i)^2.
\]

The notation \(\lVert v\rVert_2\) is the Euclidean norm, the square root of summed squared components; squaring it gives summed squared error.

Coefficient interpretation is conditional on included features and units. If features are correlated, several coefficient combinations can predict similarly. Exact linear dependence makes parameters non-identifiable without additional convention. Numerical solvers usually avoid explicitly computing a matrix inverse because factorisation methods are more stable and efficient.

Prediction does not require that every classical inferential assumption hold, but uncertainty estimates and coefficient tests rely on assumptions about errors, sampling, specification, and dependence. A fitted line is not a causal law.

### 17.14.1 Geometry and solution of least squares

For a design matrix \(X\in\mathbb{R}^{n\times p}\), coefficient vector \(\beta\), and target \(y\), least squares minimises

\[
J(\beta)=\frac{1}{n}\|X\beta-y\|_2^2.
\]

Differentiating gives

\[
\nabla_\beta J=\frac{2}{n}X^\mathsf{T}(X\beta-y).
\]

At an unconstrained differentiable minimum the gradient is zero, producing the normal equations \(X^\mathsf{T}X\beta=X^\mathsf{T}y\). If \(X\) has full column rank, the solution is unique. One should not ordinarily compute \((X^\mathsf{T}X)^{-1}X^\mathsf{T}y\) explicitly: forming \(X^\mathsf{T}X\) squares the condition number, and factorisations such as QR or SVD are more stable.

Geometrically, fitted values \(\hat y=X\hat\beta\) are the orthogonal projection of \(y\) onto the column space of \(X\). The residual vector is orthogonal to each design column under unweighted least squares:

\[
X^\mathsf{T}(y-X\hat\beta)=0.
\]

~~~python
import numpy as np

x = np.array([0.0, 1.0, 2.0, 3.0])
y = np.array([1.1, 2.9, 5.2, 7.0])
X = np.column_stack([np.ones_like(x), x])

coefficient, _, rank, singular_values = np.linalg.lstsq(X, y, rcond=None)
residual = y - X @ coefficient

assert rank == 2
assert np.allclose(X.T @ residual, np.zeros(2), atol=1e-12)
print(coefficient, singular_values)
~~~

The orthogonality identity is an algebraic property of the fitted sample; it does not show that residuals are independent, normally distributed, homoskedastic, or causally unconfounded.

> **Common misconception 17.34 — “Least squares assumes the observed points lie close to a straight line.”**  
> Least squares is an optimisation criterion over represented features. Statistical interpretation adds assumptions about sampling, conditional mean, errors, dependence, and specification; transformed features can make the fitted surface nonlinear in raw inputs.

### 17.14.2 Coefficients, interactions, and uncertainty

In an additive linear model, \(\beta_j\) is the predicted change associated with a one-unit increase in feature \(j\) while represented other features are held fixed. If that combination is absent or impossible in the population, the conditional contrast is extrapolative. Units matter: changing metres to millimetres rescales the coefficient without changing fitted predictions.

An **interaction** permits one feature’s association to depend on another. A model

\[
\hat y=\beta_0+\beta_1x_1+\beta_2x_2+\beta_3x_1x_2
\]

has derivative with respect to \(x_1\) equal to \(\beta_1+\beta_3x_2\). The main-effect coefficient is therefore the \(x_1\) slope at \(x_2=0\), not an average universal effect. Centring can make the reference meaningful but changes coefficient interpretation.

Polynomial features remain linear in coefficients but can be highly collinear and unstable at large raw magnitudes. Orthogonal bases, splines, scaling, or regularisation can improve numerical and statistical behaviour. Extrapolation beyond the observed range can grow explosively.

Classical coefficient intervals require a sampling model. Heteroskedastic or clustered errors need corresponding variance estimators; correlated features inflate uncertainty; model selection invalidates naive post-selection intervals. Prediction can remain useful when individual coefficients are unstable because correlated combinations yield similar fitted values.

> **Common misconception 17.35 — “A positive linear coefficient means increasing that feature will increase the outcome.”**  
> It is a conditional association in a specified representation and fitted population. Intervention requires causal identification, feasible support, and attention to interactions and selection.
