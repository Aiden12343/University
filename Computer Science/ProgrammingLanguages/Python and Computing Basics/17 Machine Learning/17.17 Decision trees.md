# 17.17 Decision trees

A **decision tree** partitions feature space through a hierarchy of tests. An internal node asks a question such as \(x_j\le t\); branches represent outcomes; a leaf supplies a prediction. A tree can represent nonlinear interactions without scaling features.

Training commonly considers candidate splits and chooses one that most reduces an **impurity** or loss measure. For classification, Gini impurity for class proportions \(p_k\) is

\[
1-\sum_k p_k^2.
\]

It is zero when all samples at a node share one class. Entropy,

\[
-\sum_k p_k\log p_k,
\]

is another impurity. These are selection criteria, not moral quantities.

~~~python
import pandas as pd
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text

values, target = make_classification(
    n_samples=500,
    n_features=6,
    n_informative=4,
    random_state=7,
)
X = pd.DataFrame(
    values,
    columns=[f"feature_{index}" for index in range(values.shape[1])],
)
X_train, X_test, y_train, y_test = train_test_split(
    X,
    target,
    stratify=target,
    random_state=42,
)

tree = DecisionTreeClassifier(
    max_depth=3,
    min_samples_leaf=20,
    random_state=42,
)
tree.fit(X_train, y_train)

print(export_text(tree, feature_names=list(X_train.columns)))
~~~

Depth and minimum leaf size constrain complexity. An unconstrained tree can keep splitting until leaves encode a small training subset. Small data changes can produce different structures because greedy early splits redirect later choices. A printed tree is inspectable but not automatically interpretable in the substantive sense: derived or proxy features can make a simple rule socially or scientifically opaque.

### 17.17.1 Split search, leaves, and piecewise predictions

For each candidate feature and threshold, a greedy tree compares weighted child impurity with parent impurity. The **impurity decrease** depends on both purity and child sizes; splitting one unusual case into a pure leaf may be disallowed or penalised by minimum leaf rules.

A regression tree commonly predicts the mean target in each leaf under squared error, producing a piecewise-constant function. It does not extrapolate a linear trend beyond observed feature regions. A classification leaf’s class proportions are finite-sample estimates and may be poorly calibrated, especially in small leaves.

~~~python
import numpy as np
from sklearn.tree import DecisionTreeRegressor

X = np.arange(10, dtype=float).reshape(-1, 1)
y = 2.0 * X[:, 0]
tree = DecisionTreeRegressor(max_depth=2, random_state=3).fit(X, y)

inside = tree.predict(np.array([[8.5]]))[0]
outside = tree.predict(np.array([[100.0]]))[0]
print(inside, outside)
~~~

The out-of-range prediction remains a terminal-leaf constant rather than extending the slope.

Continuous split search considers order, not physical distance, so feature scaling ordinarily leaves a tree’s candidate partitions unchanged. Scaling can still matter through numerical precision, preprocessing, histogram binning, constraints, or combined pipelines.

> **Common misconception 17.40 — “Trees require no preprocessing.”**  
> They often do not require standardisation for split geometry, but still require valid missingness, categorical encoding or native support, schema control, leakage prevention, and stable feature availability.

### 17.17.2 Instability, pruning, and interpretation

Greedy trees make locally best splits. Several near-tied first splits can lead to very different subtrees, so small data perturbations can alter the visible rule set while predictions remain similar. This instability motivates bagging but weakens narrative interpretation of one fitted tree.

Complexity controls include maximum depth, minimum samples per split/leaf, maximum leaves, minimum impurity decrease, and cost-complexity pruning. A pruning parameter selects a subtree by trading empirical error against leaf count. It is a hyperparameter requiring validation.

Missing values can be rejected, imputed, or routed natively depending on algorithm and version. Categoricals can be one-hot encoded, ordinally misrepresented, or handled by specialised partition searches. High-cardinality identifiers let trees isolate tiny groups and overfit.

A path explanation states which stored thresholds produced a prediction. It does not establish that these conditions caused the outcome or that changing one feature alone is feasible. Correlated proxies and training artefacts remain.

> **Common misconception 17.41 — “A shallow decision tree is intrinsically interpretable.”**  
> Its computation is inspectable, but substantive interpretation depends on feature meaning, stability, proxy structure, population, and the decision context.
