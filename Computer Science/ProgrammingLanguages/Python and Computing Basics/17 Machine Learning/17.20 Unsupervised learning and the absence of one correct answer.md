# 17.20 Unsupervised learning and the absence of one correct answer

Without supplied targets, an algorithm’s objective defines what counts as structure. **Clustering** groups instances according to a similarity and objective. Different scalings, distances, numbers of clusters, initialisations, and algorithms can yield incompatible but internally valid partitions.

The \(k\)-means objective chooses \(k\) centres \(\mu_1,\ldots,\mu_k\) to minimise within-cluster squared Euclidean distance:

\[
\sum_{i=1}^{n}\min_{1\le j\le k}\lVert x_i-\mu_j\rVert_2^2.
\]

This favours roughly compact Euclidean clusters under the representation. It does not discover a natural taxonomy guaranteed to exist.

~~~python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, _ = make_blobs(
    n_samples=500,
    centers=4,
    cluster_std=1.2,
    random_state=7,
)

clusterer = make_pipeline(
    StandardScaler(),
    KMeans(
        n_clusters=4,
        n_init="auto",
        random_state=42,
    ),
)

cluster_ids = clusterer.fit_predict(X)
~~~

Cluster numbers are arbitrary labels. Cluster 0 is not less than cluster 1. External validation asks whether the partition supports an independently meaningful use; internal compactness alone can reward a mathematically convenient but substantively meaningless grouping.

**Dimensionality reduction** represents data using fewer coordinates. Principal component analysis, or PCA, finds orthogonal directions of maximal variance under centred linear geometry. A **principal component** is a direction, not an original variable. High variance does not imply predictive or causal importance, and scaling determines which variables dominate.

### 17.20.1 k-means is an objective and an algorithm family

Lloyd-style \(k\)-means alternates assignment to nearest centres and replacement of each centre by its assigned mean. Each step does not increase the within-cluster squared Euclidean objective, but the procedure can converge to a local optimum. Initialisation matters; \(k\)-means++ spreads initial centres probabilistically to improve expected starting quality.

Empty clusters, duplicate points, scale, outliers, and local minima require implementation policies. The objective assumes means are meaningful and favours convex, similarly scaled groups. Elongated, nested, unequal-density, categorical, or manifold structure can make its partition arbitrary.

Cluster stability across seeds or bootstrap samples is informative but not sufficient. A consistently recovered partition can still reflect a dominant nuisance variable. Silhouette scores compare within- and nearest-other-cluster distances under the chosen metric; optimising them does not establish external meaning.

~~~python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(18)
left = rng.normal(loc=(-2.0, 0.0), scale=(0.7, 3.0), size=(150, 2))
right = rng.normal(loc=(2.0, 0.0), scale=(0.7, 3.0), size=(150, 2))
X = np.vstack([left, right])
X_scaled = StandardScaler().fit_transform(X)

labels = KMeans(n_clusters=2, n_init=20, random_state=18).fit_predict(X_scaled)
print(silhouette_score(X_scaled, labels))
~~~

The score concerns compactness in standardised Euclidean space, not whether the groups correspond to real categories.

> **Common misconception 17.46 — “Choosing the number of clusters reveals how many kinds exist.”**  
> It selects granularity under an objective and representation. Elbow, silhouette, likelihood, stability, and domain utility can favour different values.

### 17.20.2 PCA, reconstruction, and latent coordinates

After centring \(X\), principal component analysis finds orthonormal directions maximising projected sample variance. Equivalently, the first \(q\) components minimise squared reconstruction error among rank-\(q\) linear projections. SVD computes

\[
X=U\Sigma V^\mathsf{T},
\]

and rows of \(V^\mathsf{T}\) give principal directions under conventional orientation. Component signs are arbitrary: multiplying one direction and its scores by \(-1\) changes no reconstruction.

Explained variance is not explained target variance or causal importance. Without scaling, high-unit or high-variance features dominate. With scaling, every feature receives equal variance weight even when some measurements are mostly noise. Missing-value handling and centring must be fitted within the training partition.

~~~python
import numpy as np
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(20)
latent = rng.normal(size=(300, 2))
mixing = np.array([[1.0, 0.2, 1.2, -0.5], [0.1, 2.0, -0.7, 1.0]])
X = latent @ mixing + 0.05 * rng.normal(size=(300, 4))

reducer = make_pipeline(StandardScaler(), PCA(n_components=2))
coordinates = reducer.fit_transform(X)
reconstructed = reducer.inverse_transform(coordinates)
assert coordinates.shape == (300, 2)
print(np.mean((X - reconstructed) ** 2))
~~~

The pipeline’s inverse includes reversal of standardisation. A low reconstruction error says the sample lies near a two-dimensional linear subspace under the scaling, not that two true causes exist.

Anomaly detection likewise requires a definition of normality, contamination, and consequence. Rare valid cases can be the most important observations; anomalies in input space need not cause prediction errors. Evaluate with labelled incidents, synthetic perturbations, expert review, or operational utility where possible.

> **Common misconception 17.47 — “Unsupervised learning removes subjective labels from analysis.”**  
> It replaces target labels with choices of representation, similarity, objective, complexity, and interpretation. Human judgement moves rather than disappears.

### 17.20.4 Density, mixtures, and manifold assumptions

A **density estimator** assigns relative probability density over represented space. Density is not point probability for continuous variables; it depends on coordinate units because a change of variables introduces a Jacobian factor. Comparing raw density values across differently transformed feature spaces can therefore be meaningless.

A Gaussian mixture model represents

\[
p(x)=\sum_{k=1}^{K}\pi_k\,
\mathcal N(x\mid\mu_k,\Sigma_k),
\]

where non-negative mixing weights sum to one. A latent component label yields soft posterior responsibilities rather than mandatory hard clusters. The expectation–maximisation algorithm alternates between computing responsibilities under current parameters and updating parameters from weighted sufficient statistics. It converges to a local stationary solution, so initialisation and covariance regularisation matter.

Mixture components need not correspond to real-world kinds. One skewed population may require several Gaussian components for approximation, while two substantively distinct populations can overlap within one component. Choosing \(K\) by likelihood on training data rewards added flexibility; held-out likelihood, information criteria, stability, and external utility answer different questions.

Density-based clustering such as DBSCAN defines clusters as connected high-density regions relative to neighbourhood radius and minimum support. It can find non-spherical shapes and mark noise, but one global radius struggles with unequal densities. Distances and scaling remain decisive.

**Manifold learning** assumes high-dimensional observations lie near a lower-dimensional structured surface. Local neighbour graphs, geodesic approximations, or reconstruction objectives can reveal coordinates useful for visualisation. Global distances and axes may have no stable meaning, and embeddings can change under seeds or parameter choices. Two-dimensional plots are especially persuasive and therefore require explicit stress tests.

Unsupervised validation should triangulate:

- objective value on held-out or resampled data where meaningful;
- stability under seeds, samples, scale, and reasonable hyperparameters;
- recovery of synthetic structures with known ground truth;
- external association with variables not used to construct the representation;
- usefulness and harms in the downstream task;
- inspection for artefacts driven by batches, missingness, or protected proxies.

External labels used repeatedly to select an “unsupervised” representation become supervision in the overall procedure. The term describes the local fitting objective, not the complete research process.
