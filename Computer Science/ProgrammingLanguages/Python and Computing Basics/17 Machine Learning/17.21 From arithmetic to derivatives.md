# 17.21 From arithmetic to derivatives

Gradient-based learning requires a new mathematical concept. This section introduces it without assuming prior calculus.

For a function \(f(x)\), the **average rate of change** from \(x\) to \(x+h\) is

\[
\frac{f(x+h)-f(x)}{h},
\qquad h\ne0.
\]

If these rates approach one value as \(h\) approaches zero, that value is the **derivative** \(f'(x)\). The derivative describes local sensitivity: the output change per very small input change in the limiting model. “Approaches zero” does not mean substituting zero into a division by \(h\); it means examining a limit.

For \(f(x)=x^2\),

\[
\frac{(x+h)^2-x^2}{h}
=\frac{x^2+2xh+h^2-x^2}{h}
=2x+h.
\]

As \(h\) approaches zero, this approaches \(2x\). Thus \(f'(x)=2x\).

For a function of several parameters \(\theta_1,\ldots,\theta_p\), a **partial derivative** measures sensitivity to one parameter while the others are held fixed. The **gradient** is the vector of all partial derivatives:

\[
\nabla J(\theta)
=
\begin{bmatrix}
\partial J/\partial\theta_1\\
\vdots\\
\partial J/\partial\theta_p
\end{bmatrix}.
\]

The gradient points in the direction of steepest local increase under ordinary Euclidean geometry. Moving a small distance in its negative direction tends to decrease the objective.

### 17.21.1 Limits, local linearity, and units

The derivative is defined by the limit

\[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h},
\]

provided that one finite limit exists. A **limit** specifies the value approached as an input is made arbitrarily close to a point; the expression need not be defined at the point reached by the limiting variable. This distinction is what permits the quotient to contain \(h\) while the limiting process considers \(h\) approaching zero. Both positive and negative values of \(h\) must approach the same result for the ordinary two-sided derivative to exist.

Differentiability is a local linear-approximation property. For sufficiently small \(h\),

\[
f(x+h)\approx f(x)+f'(x)h.
\]

The approximation error must become negligible relative to \(h\) as \(h\) shrinks. A derivative therefore has physical units: if \(x\) is measured in seconds and \(f(x)\) in metres, \(f'(x)\) is measured in metres per second. Optimisation gradients inherit the units and scales of their parameters. This is one reason that changing feature units can change numerical optimisation even when an equivalent statistical model exists.

The following familiar rules can be derived from the limit definition:

\[
\frac{d}{dx}c=0,\qquad
\frac{d}{dx}x^r=rx^{r-1},\qquad
\frac{d}{dx}(f+g)=f'+g',
\]

and, for a composition \(f(g(x))\),

\[
\frac{d}{dx}f(g(x))=f'(g(x))g'(x).
\]

The final identity is the chain rule used by automatic differentiation. It says that a small perturbation is first transformed by the local sensitivity of \(g\), then by that of \(f\).

Continuity does not imply differentiability. The absolute-value function \(f(x)=|x|\) is continuous at zero but its slope approaches \(-1\) from the left and \(1\) from the right. Optimisation can still use a **subgradient**, a permitted generalised slope for a convex non-differentiable function. At zero, every value in \([-1,1]\) is a subgradient of \(|x|\). Software chooses a convention for operations such as ReLU at a kink; that convention is part of the implemented optimisation procedure.

> **Common misconception 17.48 — “A derivative is the quotient obtained by setting an infinitesimal change equal to zero.”**  
> The derivative is a limit of quotients for non-zero changes. Ordinary real arithmetic never divides by zero; the limiting value records local linear sensitivity.

### 17.21.2 Multivariable derivatives

For \(f:\mathbb{R}^{p}\rightarrow\mathbb{R}\), the partial derivative

\[
\frac{\partial f}{\partial x_j}
\]

varies coordinate \(j\) while holding the represented values of all other coordinates fixed. The gradient collects these \(p\) partial derivatives. Its inner product with a unit direction \(u\) gives the **directional derivative**

\[
D_u f(x)=\nabla f(x)^\mathsf{T}u.
\]

Cauchy--Schwarz implies that this quantity is largest when \(u\) is parallel to the gradient. Thus the negative gradient is the steepest local descent direction under Euclidean distance. If distance is measured under another geometry or parameters have different units, a transformed direction may be more appropriate; preconditioning and adaptive optimisers exploit this fact.

A vector-valued function \(f:\mathbb{R}^{p}\rightarrow\mathbb{R}^{q}\) has a **Jacobian**, the \(q\times p\) matrix

\[
J_{ij}=\frac{\partial f_i}{\partial x_j}.
\]

A twice differentiable scalar-valued function has a **Hessian**, the \(p\times p\) matrix

\[
H_{ij}=\frac{\partial^2 f}{\partial x_i\partial x_j}.
\]

The Jacobian is the local linear map from input perturbations to output perturbations. The Hessian describes local curvature: positive eigenvalues indicate upward curvature in associated directions, negative eigenvalues downward curvature, and a mixture identifies a saddle geometry. Most large neural-network training does not materialise the full Hessian because its \(p^2\) entries are prohibitive.

### 17.21.3 Finite differences and numerical error

When an analytic or automatically differentiated gradient is available, a finite difference can test it. The central approximation

\[
f'(x)\approx\frac{f(x+h)-f(x-h)}{2h}
\]

has truncation error proportional to \(h^2\) for sufficiently smooth \(f\), but floating-point cancellation grows when \(h\) becomes too small. Accuracy therefore improves and then deteriorates as \(h\) shrinks.

~~~python
from collections.abc import Callable
import math


def central_difference(
    function: Callable[[float], float],
    point: float,
    step: float,
) -> float:
    if step <= 0.0:
        raise ValueError("step must be positive")
    return (
        function(point + step) - function(point - step)
    ) / (2.0 * step)


point = 1.3
exact = math.cos(point)  # derivative of sin
errors = []
for exponent in range(1, 17):
    step = 10.0 ** (-exponent)
    estimate = central_difference(math.sin, point, step)
    errors.append((step, abs(estimate - exact)))

best_step, best_error = min(errors, key=lambda pair: pair[1])
print(best_step, best_error)
assert best_error < 1e-7
~~~

The smallest tested step is not generally the best. Gradient checking should use floating-point tolerances, representative parameter directions, deterministic code, and points away from deliberate non-differentiabilities. It is a diagnostic, not a training algorithm.

> **Common misconception 17.49 — “Making the finite-difference step smaller always makes a numerical derivative more accurate.”**  
> Smaller steps reduce truncation error only until rounding and subtractive cancellation dominate. Scale, dtype, smoothness, and the chosen formula determine a useful range.
