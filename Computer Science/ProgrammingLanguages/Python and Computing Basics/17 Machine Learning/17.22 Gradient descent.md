# 17.22 Gradient descent

**Gradient descent** iteratively updates parameters:

\[
\theta_{t+1}=\theta_t-\eta\nabla J(\theta_t),
\]

where \(\eta>0\) is the **learning rate**. Too large a rate can overshoot or diverge; too small can make progress impractically slow. The gradient is local, so non-convex objectives can have multiple basins, flat regions, and saddle points.

### Worked example 17.7 — Fit one slope manually

Suppose predictions are \(\hat{y}_i=wx_i\), and the mean squared objective is

\[
J(w)=\frac{1}{n}\sum_i(wx_i-y_i)^2.
\]

Its derivative is

\[
J'(w)=\frac{2}{n}\sum_i x_i(wx_i-y_i).
\]

~~~python
from collections.abc import Sequence


def fit_slope(
    xs: Sequence[float],
    ys: Sequence[float],
    *,
    learning_rate: float = 0.01,
    steps: int = 1_000,
) -> float:
    if len(xs) != len(ys) or not xs:
        raise ValueError("xs and ys need equal non-zero length")

    weight = 0.0
    count = len(xs)

    for _ in range(steps):
        gradient = (
            2.0
            * sum(
                x * (weight * x - y)
                for x, y in zip(xs, ys, strict=True)
            )
            / count
        )
        weight -= learning_rate * gradient

    return weight


print(fit_slope([1.0, 2.0, 3.0], [2.0, 4.0, 6.0]))
~~~

The function starts with weight zero. Each iteration computes residual \(wx-y\), multiplies it by the feature according to the derivative, averages, and moves against the gradient. For these data and a suitable learning rate, the result approaches 2.

The example omits intercept, scaling, stopping criteria, overflow checks, and vectorisation. Its purpose is to expose the update, not to replace numerical libraries.

### 17.22.1 Why the negative gradient is a descent direction

The first-order Taylor approximation around \(\theta\) is

\[
J(\theta+\Delta)
\approx
J(\theta)+\nabla J(\theta)^\mathsf{T}\Delta.
\]

Under a Euclidean step constraint \(\|\Delta\|_2\leq\epsilon\), the inner product is minimised by moving opposite the gradient. Gradient descent selects \(\Delta=-\eta\nabla J(\theta)\). For a sufficiently small positive \(\eta\), this lowers a differentiable objective unless the gradient is zero. “Sufficiently small” depends on curvature; it is not a universal numeric constant.

A set is **convex** if the line segment between any two of its points remains in the set. A scalar function \(J\) is convex if

\[
J(\lambda x+(1-\lambda)y)
\leq
\lambda J(x)+(1-\lambda)J(y)
\quad\text{for }0\leq\lambda\leq1.
\]

Every local minimum of a convex function is global. If the function is **strictly convex**, its minimiser is unique when one exists. Convexity does not imply that an arbitrary step size converges, that computation is cheap, or that the fitted model generalises. Neural-network objectives are usually non-convex because parameters interact across layers.

A differentiable objective is \(L\)-**smooth** when its gradient cannot change faster than a constant \(L\):

\[
\|\nabla J(x)-\nabla J(y)\|_2
\leq L\|x-y\|_2.
\]

For an \(L\)-smooth convex objective, step sizes bounded relative to \(1/L\) support convergence guarantees. The unknown \(L\), finite precision, stochastic gradients, constraints, and non-convexity complicate practice.

> **Common misconception 17.50 — “A zero gradient proves that optimisation has found the desired minimum.”**  
> A zero gradient identifies a stationary point. It may be a local minimum, local maximum, saddle, or flat region; constrained optima can also occur with a non-zero unconstrained gradient.

### 17.22.2 Conditioning and scaling

Consider the quadratic objective

\[
J(\theta)=\tfrac12\theta^\mathsf{T}A\theta-b^\mathsf{T}\theta,
\]

where \(A\) is symmetric positive definite. Its gradient is \(A\theta-b\), and its unique minimiser solves \(A\theta=b\). The ratio of the largest to smallest eigenvalue of \(A\) is its spectral **condition number**. A large ratio produces narrow elongated contours: a step safe along the high-curvature direction makes slow progress along the low-curvature direction, while a larger step oscillates or diverges.

Feature standardisation can improve conditioning because differently scaled columns induce differently scaled curvature. It does not guarantee good conditioning: highly correlated columns can still make the problem nearly singular. A **preconditioner** changes coordinates so curvature is more balanced. Momentum and adaptive methods also alter update dynamics, though they do not literally solve every conditioning problem.

~~~python
import numpy as np


def minimise_quadratic(
    matrix: np.ndarray,
    vector: np.ndarray,
    *,
    learning_rate: float,
    steps: int,
) -> tuple[np.ndarray, list[float]]:
    parameter = np.zeros_like(vector, dtype=np.float64)
    history: list[float] = []
    for _ in range(steps):
        gradient = matrix @ parameter - vector
        parameter -= learning_rate * gradient
        objective = (
            0.5 * parameter @ matrix @ parameter
            - vector @ parameter
        )
        history.append(float(objective))
    return parameter, history


A = np.diag([1.0, 100.0])
b = np.array([1.0, 1.0])
estimate, history = minimise_quadratic(
    A,
    b,
    learning_rate=0.018,
    steps=700,
)
truth = np.linalg.solve(A, b)
assert np.allclose(estimate, truth, atol=1e-4)
assert history[-1] < history[0]
~~~

The largest eigenvalue is \(100\), making a step of \(0.018\) stable but causing the first coordinate to converge much more slowly than the second. Rescaling the coordinates changes the optimisation path while preserving an equivalent underlying problem.

### 17.22.3 Schedules, stopping, and convergence evidence

A **learning-rate schedule** changes \(\eta_t\) over updates. Step decay, exponential decay, cosine schedules, and warm-up phases express different assumptions about early exploration and late refinement. A schedule is a hyperparameterised policy and must be selected without consulting final test results.

Stopping after a fixed update budget is reproducible but may underfit or waste computation. A gradient-norm threshold tests local stationarity but is scale-dependent. An objective-change threshold can stop on a plateau caused by an excessively small rate. **Early stopping** selects a checkpoint using validation behaviour and is therefore both regularisation and model selection. The validation set remains unavailable for final unbiased assessment.

Optimisation evidence should include training-objective curves, validation curves, gradient or update norms where informative, elapsed computation, failed runs, and sensitivity to seeds and learning rates. A low objective relative to the starting point is not proof of proximity to a global optimum. For convex problems, duality gaps or problem-specific bounds can provide stronger certificates.

> **Common misconception 17.51 — “Gradient descent has converged when the training loss stops visibly changing.”**  
> A flat plot may result from scale, rounding, a poor learning rate, numerical saturation, noise, or a saddle. Convergence requires a stated criterion and evidence appropriate to the objective.
