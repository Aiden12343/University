# 17.25 Neural networks

An artificial **neuron** computes a weighted sum followed by an activation:

\[
z=w^\mathsf{T}x+b,\qquad a=\phi(z).
\]

An **activation function** \(\phi\) introduces nonlinearity. Without nonlinear activations, composing many linear layers still yields one linear transformation.

A **layer** applies many units in parallel. For input row vector \(x\), a dense layer can be written

\[
h=\phi(xW+b),
\]

where columns of \(W\) parameterise output units and \(b\) broadcasts across instances. A **neural network** composes such layers. Its depth is the number of sequential learned transformations under a convention; its width is units per layer.

The rectified linear unit, or ReLU, is

\[
\operatorname{ReLU}(z)=\max(0,z).
\]

It is simple and supports useful optimisation but has zero derivative on its negative region under the standard piecewise choice. Sigmoid and hyperbolic tangent activations saturate at large magnitudes, where gradients become small.

### Worked example 17.8 — A small network in a framework

~~~python
import torch
from torch import nn

network = nn.Sequential(
    nn.Linear(10, 32),
    nn.ReLU(),
    nn.Linear(32, 1),
)

features = torch.randn(64, 10)
targets = torch.randn(64, 1)

predictions = network(features)
loss = nn.functional.mse_loss(predictions, targets)
loss.backward()

for parameter in network.parameters():
    assert parameter.grad is not None
~~~

The batch contains 64 rows with 10 features. The first linear layer maps 10 features to 32 hidden values; ReLU transforms them; the second maps 32 to one prediction. The scalar loss records a computation graph. <code>backward</code> populates gradient buffers for trainable parameters.

No parameters change because no optimiser step occurs. Gradient calculation and parameter update are separate state transitions.

### 17.25.1 Expressivity, depth, and parameter symmetries

For a batch matrix \(X\in\mathbb{R}^{n\times d}\), a dense layer with \(m\) outputs computes

\[
Z=XW+\mathbf{1}b^\mathsf{T},
\qquad
W\in\mathbb{R}^{d\times m},
\quad b\in\mathbb{R}^{m}.
\]

The bias is broadcast to each row. Applying an activation elementwise gives \(H=\phi(Z)\). Shape annotations are part of the mathematical specification: accidental broadcasting can produce a valid array with the wrong semantics and still permit gradients.

Networks with sufficiently many units can approximate broad classes of continuous functions on compact domains under stated activation assumptions. Such **universal approximation** results are existence theorems. They do not state that finite data identify the desired function, that gradient optimisation finds the required parameters, that the necessary network is economical, or that extrapolation is reliable.

Parameterisation is non-identifiable in several ways. Permuting hidden units and applying the inverse permutation to the next layer leaves the represented function unchanged. With positively homogeneous activations such as ReLU, multiplying incoming weights by a positive constant and dividing outgoing weights by it can also preserve the function. A neural-network parameter vector is consequently not a unique semantic decomposition.

Depth can represent compositional structure efficiently: successive layers reuse intermediate features. Yet additional depth increases optimisation and systems complexity. Width, depth, connectivity, normalisation, activation, and data representation together define an **architecture**. Architecture choice is model selection, not a metaphysical discovery of the data’s true form.

> **Common misconception 17.56 — “A universal approximation theorem means a neural network can learn any relationship from available data.”**  
> It establishes representational existence under mathematical conditions, not finite-sample identification, computational attainability, generalisation, causality, or useful extrapolation.

### 17.25.2 Initialisation and signal propagation

If every unit in a layer begins with identical weights, symmetric units receive identical gradients and remain redundant. Random initialisation breaks this symmetry. Its scale matters: multiplying many transformations can make activations and gradients vanish or explode.

For approximately independent zero-mean inputs and weights, variance calculations motivate scaling weight variance inversely with fan-in, the number of incoming connections. Xavier or Glorot initialisation balances signal variance for approximately symmetric activations; He or Kaiming initialisation adjusts for rectifiers that discard much of the negative half. These derivations depend on simplifying assumptions and do not guarantee stable training for every architecture.

Bias initialisation is task-dependent. Output biases can encode an initial class prevalence, reducing a severe initial mismatch in rare-event classification. Recurrent gates sometimes use deliberate biases. Initialisation is therefore part of the algorithm and should be recorded.

**Normalisation layers** transform activations using computed statistics and learned affine parameters. Batch normalisation uses mini-batch statistics during training and maintained population estimates during evaluation; layer normalisation uses features within each represented example under its axis convention. Their train/evaluation semantics and axes must be understood rather than inferred from the word “normalisation.”

### 17.25.3 Output layers and losses form one contract

The final representation must match the target and loss:

| Task | Typical raw output | Training loss | Prediction interpretation |
|:---|:---|:---|:---|
| unconstrained regression | one or more real values | squared, absolute, Huber, or distributional loss | conditional location or distribution parameter under assumptions |
| binary classification | one logit | binary cross-entropy with logits | sigmoid of logit is a probability estimate |
| exclusive \(K\)-class classification | \(K\) logits | categorical cross-entropy | softmax probabilities sum to one |
| multilabel classification | one logit per label | independent binary cross-entropies or structured loss | labels need not be exclusive |
| positive-valued parameter | unconstrained raw value followed by positive link | likelihood-appropriate loss | positive distribution parameter |

A **logit** is an unconstrained score before sigmoid or softmax. Combining sigmoid with a separately implemented logarithmic loss can underflow; fused “with logits” losses use stable identities. Softmax is invariant to adding the same constant to every class logit, so stable implementations subtract a row maximum.

~~~python
import numpy as np


def stable_softmax(logits: np.ndarray) -> np.ndarray:
    values = np.asarray(logits, dtype=np.float64)
    if values.ndim != 2:
        raise ValueError("expected a batch-by-class matrix")
    shifted = values - values.max(axis=1, keepdims=True)
    exponentials = np.exp(shifted)
    return exponentials / exponentials.sum(axis=1, keepdims=True)


scores = np.array(
    [[1_000.0, 1_001.0, 999.0], [-1_000.0, -999.0, -998.0]]
)
probabilities = stable_softmax(scores)
assert np.allclose(probabilities.sum(axis=1), 1.0)
assert np.isfinite(probabilities).all()
~~~

Independent sigmoid outputs are not a replacement for softmax when exactly one class is possible: they represent a different factorisation and can assign high probability to several labels. Conversely, softmax wrongly imposes exclusivity on a multilabel problem.

### 17.25.4 Capacity control and representation regularity

Weight penalties, data augmentation, early stopping, stochastic depth, label smoothing, and dropout encode different assumptions. **Dropout** randomly masks activations during training and uses a corresponding scaling convention so evaluation computes a deterministic approximation. It is disabled during ordinary inference; failure to switch mode makes repeated predictions stochastic and changes expected activation scale under some conventions.

Data augmentation creates transformed training instances whose targets are assumed invariant or equivariant. Horizontal reflection may preserve an object category but reverse written text or clinical laterality. Augmentation is therefore a domain claim. Applying it to validation data estimates performance on the augmented evaluation distribution unless test-time augmentation is itself the declared prediction procedure.

Label smoothing moves one-hot targets away from probability endpoints. It can affect confidence and representation learning but changes the proper-scoring target and does not guarantee calibration. Weight decay constrains parameters, not functions uniformly, because parameter symmetries permit different norms for related representations.

> **Common misconception 17.57 — “More layers and parameters necessarily cause more overfitting.”**  
> Capacity, optimisation, implicit and explicit regularisation, architecture, data, and selection interact. Parameter count alone neither orders all function classes nor predicts generalisation monotonically.
