# 17.28 Convolution, sequence models, and attention

A **convolutional layer** applies shared local filters across positions. Weight sharing encodes the assumption that a learned local pattern can matter in multiple locations. It reduces parameters relative to an unstructured dense mapping and expresses translation-related structure. Boundary padding, stride, dilation, and channel layout determine output shape.

A **sequence model** processes ordered elements such as text tokens or time measurements. Recurrent networks update a hidden state step by step. Their sequential dependence can impede parallelism and suffer gradient degradation across long paths.

**Attention** computes data-dependent weighted combinations of represented elements. In a common scaled dot-product form:

\[
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^\mathsf{T}}{\sqrt{d}}
\right)V.
\]

Queries \(Q\) are compared with keys \(K\); softmax turns scores into non-negative row weights summing to one; weights combine values \(V\). The scale \(\sqrt d\) controls score magnitude under common assumptions. This equation describes a mechanism, not understanding, truth, or causal reasoning.

A **transformer** composes attention, feed-forward transformations, residual paths, normalisation, and positional information. Large language models are trained to model token sequences under objectives and datasets of considerable complexity. Their fluent output is generated prediction, not an intrinsic certificate of correctness.

### 17.28.1 Convolutional geometry

For a one-dimensional input of length \(L_{\text{in}}\), kernel size \(K\), total symmetric padding \(2P\), dilation \(D\), and stride \(S\), a conventional convolution output length is

\[
L_{\text{out}}
=
\left\lfloor
\frac{L_{\text{in}}+2P-D(K-1)-1}{S}
+1
\right\rfloor.
\]

The two-dimensional formula applies per spatial axis. Channels are mixed through a kernel tensor; **groups** can restrict which input channels connect to which outputs, and depthwise convolution uses one group per input channel under common conventions.

A unit’s **receptive field** is the region of original input that can affect it. Stacking local kernels enlarges the theoretical receptive field; stride and dilation enlarge its spacing. The effective empirical influence can be much smaller than the theoretical set. Padding introduces boundary values and therefore a boundary assumption.

Convolution is translation-equivariant away from boundary and sampling qualifications: shifting an input shifts the feature map. Pooling or striding can produce limited invariance but also aliasing and lost location information. Image rotation, scale, perspective, and illumination invariance do not follow automatically.

~~~python
import numpy as np


def valid_cross_correlation_1d(
    signal: np.ndarray,
    kernel: np.ndarray,
) -> np.ndarray:
    x = np.asarray(signal, dtype=np.float64)
    k = np.asarray(kernel, dtype=np.float64)
    if x.ndim != 1 or k.ndim != 1 or not 0 < len(k) <= len(x):
        raise ValueError("expected one-dimensional compatible inputs")
    return np.array(
        [x[start : start + len(k)] @ k
         for start in range(len(x) - len(k) + 1)]
    )


x = np.array([1.0, 3.0, 2.0, 0.0])
k = np.array([1.0, -1.0])
output = valid_cross_correlation_1d(x, k)
assert np.array_equal(output, np.array([-2.0, 1.0, 2.0]))
~~~

Many deep-learning APIs call this operation convolution although the kernel is not reversed, making it mathematically cross-correlation. Learned kernels make the naming difference operationally minor, but it matters when reproducing a fixed signal-processing filter.

> **Common misconception 17.62 — “A convolutional network is inherently invariant to position.”**  
> Convolution primarily shares a translation-equivariant local operation. Padding, stride, pooling, coordinates, later dense layers, and data determine what position information is preserved or suppressed.

### 17.28.2 Recurrent state and sequence boundaries

A simple recurrent update has

\[
h_t=\phi(W_xx_t+W_hh_{t-1}+b).
\]

The same parameters are reused over positions. Backpropagation through time unfolds this recurrence into a deep graph. Repeated multiplication by recurrent Jacobians can shrink or enlarge gradients exponentially. LSTM and gated recurrent units introduce gates and additive state paths that mitigate, but do not abolish, long-range optimisation problems.

Sequences in one batch often have unequal lengths. Padding supplies placeholder positions; a mask prevents them from contributing to attention, loss, or state under the intended convention. Packing or bucketing can reduce wasted computation. An off-by-one boundary can leak a future token into an autoregressive target or train on padding labels.

Time-series validation must respect information availability. A recurrent architecture does not license random splitting. State carried between batches can also leak across independent entities or validation boundaries unless deliberately reset.

### 17.28.3 Attention mechanics and masks

For a sequence length \(T\), queries and keys produce a \(T\times T\) score matrix in ordinary full self-attention. Row-wise softmax gives weights. Before softmax, disallowed positions receive a mask represented conceptually by negative infinity, producing zero probability. A **causal mask** permits position \(t\) to attend only to positions at or before \(t\); a padding mask excludes non-data positions.

Stable softmax subtracts each row maximum. If every position in a row is masked, the mathematical normalisation has zero denominator; APIs differ in whether they return NaN, zeros, or reject the row. Mask polarity, dtype, broadcasting, and axis conventions are recurrent sources of silent defects.

**Multi-head attention** applies several learned projections, allowing different representation subspaces and attention patterns, then concatenates and projects their outputs. It does not guarantee that heads acquire distinct human-interpretable roles. Attention weights are internal mixing coefficients and are not, without validation, faithful causal explanations of predictions.

Full attention has \(O(T^2)\) score storage and arithmetic in sequence length, aside from feature dimensions. Sparse, local, recurrent, low-rank, kernelised, and memory-efficient exact implementations trade generality, approximation, recomputation, or kernel design. “Linear attention” must specify what quantity is linear and under which dimensions.

### 17.28.4 Transformer blocks, tokens, and objectives

A transformer block combines attention with a position-wise feed-forward network, residual additions, and normalisation. **Residual connections** add a transformed branch to an earlier representation, creating short gradient paths. Pre-normalisation and post-normalisation arrange layer normalisation differently and have distinct optimisation behaviour.

Because bare attention does not encode sequence order, a model needs positional information. Fixed sinusoidal encodings, learned position embeddings, relative position biases, and rotary representations implement different inductive assumptions and extrapolation properties.

A **tokeniser** maps raw text or another input stream to a finite vocabulary of integer identifiers. Subword tokenisation balances word-level semantics against open vocabulary, but token boundaries are algorithmic artifacts: visually similar strings can map differently, and length in tokens differs across languages and scripts. The vocabulary, normalisation, special-token rules, and version are part of the model.

An autoregressive language model factorises a token-sequence probability:

\[
P(x_1,\ldots,x_T)
=
\prod_{t=1}^{T}P(x_t\mid x_1,\ldots,x_{t-1}).
\]

Teacher-forced training predicts each observed next token from the true prefix. Generation conditions on previously generated tokens, creating exposure to its own errors. Greedy decoding, beam search, temperature scaling, top-\(k\), and nucleus sampling are decision procedures over model scores; they change output distributions but do not change learned parameters.

The context window limits directly represented tokens under the architecture and serving system. Retrieval, summarisation, or recurrence can supply external information but introduce selection and provenance failures. Long context does not guarantee that every supplied fact influences an output correctly.

> **Common misconception 17.63 — “Attention weights show which input facts caused a model’s answer.”**  
> They are intermediate normalised coefficients within one computation. Causal influence includes values, projections, residual paths, later layers, and interventions; explanatory validity requires a purpose-specific test.
