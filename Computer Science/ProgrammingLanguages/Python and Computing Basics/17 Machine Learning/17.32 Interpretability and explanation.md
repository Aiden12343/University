# 17.32 Interpretability and explanation

**Interpretability** refers to how a person can understand model behaviour for a purpose. Global understanding of the model, local explanation of one prediction, debugging, scientific insight, and legal justification are different purposes.

A linear coefficient is transparent only when features, interactions, transformations, dependence, and units are understood. A shallow tree can still use incomprehensible proxies. Post-hoc explanation methods approximate or attribute behaviour according to their own assumptions. They do not reveal a model’s inner causal reasoning.

Perturbation explanations can create unrealistic feature combinations. Correlated features make attribution non-unique. An explanation faithful to model behaviour may still be an inadequate justification for the institutional decision. Validate explanation methods as models with failure modes.

### 17.32.1 Global behaviour and feature perturbation

**Permutation importance** measures the drop in a chosen evaluation score after a feature column is permuted. It estimates reliance under that perturbation and dataset, not intrinsic feature value. Correlated substitutes can make each appear unimportant because the other remains; permutation can also create implausible combinations. Importance must be computed on validation or test data if the question is generalisation reliance.

A **partial dependence plot** averages predictions while setting one feature to selected values:

\[
\operatorname{PD}_j(z)
=
\frac1n\sum_{i=1}^{n}
\hat f(z,x_{i,-j}).
\]

It describes the fitted model over a constructed distribution. When \(z\) conflicts with correlated \(x_{-j}\), it evaluates extrapolative combinations. **Individual conditional expectation** curves retain one curve per instance and can reveal heterogeneous effects hidden by the average. Neither is automatically causal.

Global surrogate models fit an interpretable approximation to a black-box model’s predictions. Their fidelity must be measured over a stated input distribution. A simple surrogate with poor fidelity explains itself, not the black box.

### 17.32.2 Local attributions and counterfactuals

A local linear surrogate samples perturbations near one instance, obtains black-box predictions, weights samples by a neighbourhood rule, and fits a sparse linear approximation. Every phrase—near, perturbation, weight, sparse—contains a modelling choice. Stability under small changes and fidelity within the declared neighbourhood are essential checks.

Shapley-value explanations borrow a cooperative-game allocation rule. For a specified value function, they distribute the difference between a prediction and a baseline among features while satisfying axioms such as efficiency and symmetry. Different choices of background population, conditional versus interventional feature removal, output scale, and feature grouping define different games and therefore different attributions.

A **counterfactual explanation** seeks a nearby feasible input \(x'\) yielding another decision. Distance must respect feature units and actionability; immutable properties cannot be edited, correlated features must remain coherent, and institutional action after the change must be stable. “Increase income by £5,000” may describe a model boundary without supplying feasible recourse.

Explanations can disclose sensitive features, enable gaming, or falsely legitimise a decision. Access and detail should follow audience and threat model. Debugging explanations, subject notices, regulator evidence, and scientific interpretation are separate products.

> **Common misconception 17.70 — “A feature attribution states how much that feature caused the outcome.”**  
> It allocates a model output under a particular explanation definition and reference distribution. Causal effect requires interventions, identification assumptions, and a causal estimand.
