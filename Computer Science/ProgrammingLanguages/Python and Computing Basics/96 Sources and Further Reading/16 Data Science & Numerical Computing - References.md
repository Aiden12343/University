# 16.32 References and further study

The software references describe documented interfaces rather than timeless implementation facts; consult the documentation for the supported release and record that release in reproducibility manifests. Standards and original methodological works establish terminology or results, while later textbooks provide fuller proofs and context. A citation does not transfer a method’s assumptions to a new dataset: the analytical design must still justify them.
