# 22.10 Bibliographic note to Chapters 10 and 11

Import semantics are specified by the Python Language Reference and implemented through <code>importlib</code>. A module is an executing object cached in <code>sys.modules</code>, not textual inclusion. Circular imports expose partial initialisation and should be treated as a dependency-design problem.

The I/O account relies on Python’s <code>io</code>, <code>pathlib</code>, <code>codecs</code>, <code>json</code>, <code>csv</code>, <code>pickle</code>, and context-management documentation, plus format standards. RFC 8259 specifies JSON. The Unicode Standard and character-encoding specifications govern text representation. Python pickle documentation explicitly warns that unpickling untrusted data is unsafe.

Context managers encode paired acquisition/release under exceptions. They do not guarantee process-level cleanup after forced termination, power loss, or kernel failure; durable protocols need transactional or recovery semantics.
