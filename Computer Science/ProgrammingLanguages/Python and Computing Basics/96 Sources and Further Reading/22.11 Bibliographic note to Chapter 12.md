# 22.11 Bibliographic note to Chapter 12

Software testing literature distinguishes example-based, property-based, stateful, integration, acceptance, mutation, and statistical testing. Meszaros catalogues test-automation patterns; Ammann and Offutt treat test criteria formally. Beck’s test-driven-development account is one workflow rather than a proof technique.

PEP 8 states the Python style guide; PEP 257 addresses docstrings. PEP 484 introduced type hints, and subsequent PEPs refine the type system. Type checkers implement related but not identical interpretations and extensions. An annotation is not automatically enforced at runtime.

Git’s object model is described in the official reference and Pro Git. A commit is a content-addressed snapshot node with parent links, not a mutable bag of line edits. Branches are movable references. Merge records graph history rather than merely combining files.
