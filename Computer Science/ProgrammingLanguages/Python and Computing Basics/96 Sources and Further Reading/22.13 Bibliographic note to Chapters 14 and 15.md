# 22.13 Bibliographic note to Chapters 14 and 15

Concurrency foundations include Hoare’s communicating sequential processes, Lamport’s work on logical clocks and distributed-system ordering, and Herlihy and Shavit’s treatment of multiprocessor programming. Python-specific interfaces are documented in <code>threading</code>, <code>multiprocessing</code>, <code>concurrent.futures</code>, and <code>asyncio</code>.

The Global Interpreter Lock is an implementation mechanism of conventional CPython builds, not a general Python language rule. PEP 703 specifies making the GIL optional in CPython and records the required implementation changes. Free-threaded operation removes one global exclusion but does not make compound application operations atomic or data-race-free.

The CPython source repository, developer guide, C API manual, <code>dis</code>, <code>ast</code>, <code>symtable</code>, <code>gc</code>, and <code>inspect</code> documentation are primary sources for Chapter 15. Opcode names and adaptive specialisation are version-specific. Extension authors must distinguish stable ABI, limited API, public full API, and private internals.
