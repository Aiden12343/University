# 22.15 Bibliographic note to Branch B

Mitchell supplies a classic definition and survey of machine learning. Hastie, Tibshirani, and Friedman connect statistical learning methods; Bishop and Murphy develop probabilistic treatments; Shalev-Shwartz and Ben-David present theoretical foundations. Goodfellow, Bengio, and Courville treat deep learning and optimisation.

The scikit-learn API and evaluation guidance are primary for current estimator, pipeline, preprocessing, cross-validation, and metric behaviour. Pedregosa and colleagues describe the project’s design in the *Journal of Machine Learning Research*. Framework documentation governs automatic differentiation, tensor semantics, devices, and determinism.

Model performance does not settle the legitimacy of a task. Work on dataset documentation, model cards, algorithmic accountability, fairness impossibility results, distribution shift, and socio-technical systems supplies necessary analysis beyond optimisation.
