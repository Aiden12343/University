# 22.16 Bibliographic note to Branch C

HTTP semantics are specified by RFC 9110; HTTP/1.1 messaging by RFC 9112; HTTP/2 by RFC 9113; HTTP/3 by RFC 9114; URI syntax by RFC 3986; TLS 1.3 by RFC 8446; cookies by RFC 6265 and subsequent updates. Fielding’s dissertation states REST’s architectural constraints. These sources distinguish protocol meaning from framework convention.

PEP 3333 specifies WSGI. The ASGI specification defines its asynchronous event interface. Flask and Django official documentation govern their current APIs and security guidance. PostgreSQL documentation provides an authoritative concrete account of relational transactions, isolation, constraints, indexing, and query planning; SQL standards govern broader portable semantics.

OWASP guidance is useful for web threat classes and verification requirements, but controls must be adapted to a concrete threat model. Browser behaviour requires current HTML, URL, Fetch, CSP, and related web-platform specifications.
