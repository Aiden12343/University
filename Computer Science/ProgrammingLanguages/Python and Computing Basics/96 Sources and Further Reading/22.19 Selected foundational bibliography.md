# 22.19 Selected foundational bibliography

The following bibliography is selective rather than decorative. Each work supplies a conceptual foundation, primary specification, or durable research result used by one or more chapters. Versioned online documentation is dated by access in the canonical production database; archival editions and persistent identifiers are preferred where available.
