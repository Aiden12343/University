# 22.20 Normative-reference discipline

Online documentation changes. A canonical release of this treatise therefore records:

- title;
- issuing organisation;
- document or PEP/RFC number;
- semantic version or release tag;
- publication or last-updated date;
- permanent URL;
- archived snapshot or commit identifier;
- exact section supporting each claim.

The prose does not reproduce large passages. It paraphrases concepts, derives examples independently, and directs readers to primary material. This preserves both intellectual traceability and copyright boundaries.
