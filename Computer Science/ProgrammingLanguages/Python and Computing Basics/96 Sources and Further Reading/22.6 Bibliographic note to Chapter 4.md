# 22.6 Bibliographic note to Chapter 4

Python installation and packaging are versioned operational topics. The primary sources are the Python documentation, the Python Packaging User Guide, pip documentation, virtual-environment documentation, PyPA specifications, and the metadata/build PEPs. A command copied from an old text can install from a different index, invoke a different interpreter, or rely on a deprecated build backend.

PEP 517 defines a build-system interface; PEP 518 specifies declaration of build-system requirements; PEP 621 standardises core project metadata in <code>pyproject.toml</code>. The packaging ecosystem continues to evolve, so the canonical edition records a tested toolchain snapshot while teaching concepts that outlive individual front ends.
