# 22.7 Bibliographic note to Chapters 5 and 6

The [Python Language Reference](https://docs.python.org/3/reference/) is the primary source for lexical analysis, the data model, execution model, expressions, simple statements, compound statements, and top-level components. The [Python Standard Library reference](https://docs.python.org/3/library/) specifies built-in types, exceptions, and supplied modules. The tutorial is pedagogical; the reference is the appropriate starting point for exact language questions.

The statement “everything is an object” is useful when constrained: Python values are represented by objects, and operations are mediated through types and protocols. Names are bindings established in namespaces. Assignments do not mutate arbitrary objects merely because a name previously referred to them. Identity, equality, mutability, and hashing remain distinct.

Python’s evaluation order, truth testing, iterator protocol, generator suspension, and exception propagation are language topics. Bytecode sequences are CPython implementation observations and belong to Chapter 15. This separation prevents a disassembly from being used as a substitute specification.
