# 22.8 Bibliographic note to Chapter 7

Data-structure theory and asymptotic analysis are developed by Cormen, Leiserson, Rivest, and Stein; Sedgewick and Wayne; and Knuth. Python’s documented semantics do not require every implementation to use CPython’s exact dynamic-array or compact-dictionary representation. Complexity tables in the standard documentation and implementation source must be version-scoped.

Hash-table expected performance depends on hash distribution, load policy, resizing, and adversarial conditions. Universal claims of constant time are wrong. “Average” must identify the distribution or implementation expectation, and amortised bounds must identify the operation sequence.

Unicode text requires the Unicode Standard rather than an ASCII mental model. A Python string is a sequence of Unicode code points under language semantics; user-perceived characters can comprise multiple code points. Normalisation, grapheme segmentation, collation, and case mapping are separate specifications.
