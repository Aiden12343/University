# algebraic denominator

The bottom part of an algebraic fraction, which may contain variables and determines when the expression is undefined.

First introduced in: [[2.11 Algebraic Fractions]]

Builds on: [[numerator and denominator]], [[2.1 Variables Expressions and Equations]]

Used in CS: Denominators define divide-by-zero guards in code for averages, rates, and ratios.
