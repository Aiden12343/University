# asymptote
A line a graph approaches but never reaches as x or y grows very large.
First introduced in: [[3.6 Exponential Functions]]
Builds on: [[3.3 Linear Functions and Gradient]]
Used in CS: Horizontal limits in probability and vertical caps in rendering behave like asymptotes.
