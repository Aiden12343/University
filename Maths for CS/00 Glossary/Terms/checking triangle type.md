# checking triangle type

Using Pythagoras' theorem to determine whether a triangle is right-angled by verifying if a² + b² = c² (the converse of Pythagoras). Also used to classify triangles as acute or obtuse.

First introduced in: [[4.4 Pythagoras Theorem]]
Builds on: [[4.1 Lines Angles and Triangles]], [[2.2 Simplifying Expressions]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - mesh validation, triangle classification
