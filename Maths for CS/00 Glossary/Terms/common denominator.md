# common denominator

A shared bottom expression used to rewrite algebraic fractions so they can be added or subtracted.

First introduced in: [[2.11 Algebraic Fractions]]

Builds on: [[1.6 Fractions]], [[algebraic denominator]]

Used in CS: Combining rates or partial metrics with different bases requires the same fractional structure as finding a common denominator.
