# component

One of the coordinate values that make up a vector. For v = (3, 4), the x-component is 3 and the y-component is 4.

First introduced in: [[4.8 Vectors Basics]]
Builds on: [[3.1 Coordinates and Axes]], [[1.3 Addition and Subtraction]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - accessing individual vector elements in code (v.x, v.y)
