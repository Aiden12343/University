# coordinate pair
An ordered pair (x, y) that names one point on a plane by horizontal then vertical position.
First introduced in: [[3.1 Coordinates and Axes]]
Builds on: [[x-axis]], [[y-axis]], [[origin]]
Used in CS: Pixel positions, mouse clicks, and GPS-style locations are stored as ordered pairs where order matters.
