# double bracket

Two bracketed expressions multiplied together, such as (x + 2)(x + 3).

First introduced in: [[2.3 Expanding Brackets]]
Builds on: [[single bracket]] and [[distributive law]]
Used in CS: Polynomial and matrix expressions in graphics and machine learning often use double-bracket forms that tools expand automatically.
