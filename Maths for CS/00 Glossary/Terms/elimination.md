# elimination

A method for solving a system by adding or subtracting equations so that one unknown disappears.

First introduced in: [[2.8 Simultaneous Equations]]

Builds on: [[2.5 Solving Linear Equations]], [[2.2 Simplifying Expressions]]

Used in CS: The same idea underlies solving paired constraints in layout engines and simple linear models before matrix methods.
