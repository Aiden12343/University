# exponent

The index in a power that tells how many times the base is multiplied by itself.

First introduced in: [[2.9 Indices and Powers]]

Builds on: [[base]], [[1.4 Multiplication and Times Tables]]

Used in CS: Exponents describe bit counts, memory scaling, and exponential algorithm growth such as `O(2^n)`.
