# formula

An equation that links two or more quantities using letters, constants, and operations.

First introduced in: [[2.6 Rearranging Formulae]]
Builds on: [[equation]], [[expression]]
Used in CS: Programs implement formulas directly (e.g. `area = length * width`) and often need them rearranged to compute a different output variable.
