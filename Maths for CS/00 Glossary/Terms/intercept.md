# intercept
The value where a graph crosses an axis, usually the y-value when x equals zero.
First introduced in: [[3.3 Linear Functions and Gradient]]
Builds on: [[3.1 Coordinates and Axes]]
Used in CS: Base fees, bias terms in ML, and y-axis crossing points are intercepts.
