# inverse operations

Operations that undo each other, such as addition with subtraction or multiplication with division.

First introduced in: [[2.5 Solving Linear Equations]]
Builds on: [[checking inverse operations]], [[1.3 Addition and Subtraction]]
Used in CS: Reversing a state update (e.g. undoing `score += 10` with `score -= 10`) mirrors using inverse operations to solve equations.
