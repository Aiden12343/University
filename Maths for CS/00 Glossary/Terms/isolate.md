# isolate

To get a chosen letter alone on one side of an equation or formula by undoing every other operation on it.

First introduced in: [[2.6 Rearranging Formulae]]
Builds on: [[inverse operation]], [[balancing]]
Used in CS: Deriving `x = (y - c) / m` from `y = m * x + c` isolates `x` so the program can compute horizontal position from a known vertical value.
