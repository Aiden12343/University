# line

A straight one-dimensional figure that extends infinitely in both directions, or a finite segment between two points. A line has no thickness and contains infinitely many points. In geometry notation, $\overleftrightarrow{AB}$ denotes the infinite line through points A and B.

First introduced in: [[4.1 Lines Angles and Triangles]]
Builds on: [[1.1 Counting and Number Sense]], [[1.2 Place Value and Number Lines]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - rays for rendering, line drawing algorithms like Bresenham's
