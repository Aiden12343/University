# magnitude

The length or size of a vector. For vector (x, y), magnitude = √(x² + y²). Always a non-negative scalar. Denoted |v|.

First introduced in: [[4.8 Vectors Basics]]
Builds on: [[4.4 Pythagoras Theorem]], [[2.9 Indices and Powers]]
