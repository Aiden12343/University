# model space

The local coordinate system of a 3D object, centred at its own origin. Model vertices are defined relative to this origin before being placed in the world.

First introduced in: [[4.10 Geometry for Computer Graphics]]
Builds on: [[3.1 Coordinates and Axes]], [[4.8 Vectors Basics]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - 3D modelling, object definition
