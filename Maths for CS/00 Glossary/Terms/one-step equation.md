# one-step equation

A linear equation that can be solved with a single inverse operation to isolate the unknown.

First introduced in: [[2.5 Solving Linear Equations]]
Builds on: [[equation]], [[inverse operations]]
Used in CS: Simple constraints like `used + buffer = limit` often reduce to one-step equations when one value is unknown.
