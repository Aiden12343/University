# one-to-one
A function where different inputs always give different outputs, required for a full inverse.
First introduced in: [[3.8 Inverse and Composite Functions]]
Builds on: [[3.2 Function Notation and Mapping]]
Used in CS: Injective hash functions and bijective encodings need one-to-one behaviour.
