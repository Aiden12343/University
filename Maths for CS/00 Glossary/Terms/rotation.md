# rotation

Turning an object around a fixed point or axis. In 2D, x' = x cos θ - y sin θ, y' = x sin θ + y cos θ. A rigid transformation preserving distance.

First introduced in: [[4.10 Geometry for Computer Graphics]]
Builds on: [[4.5 Trig Ratios SOHCAHTOA]], [[4.6 Unit Circle]], [[4.7 Radians and Degrees]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - object orientation, camera rotation
