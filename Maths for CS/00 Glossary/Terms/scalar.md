# scalar

A single number (not a vector). Scalars have magnitude only, no direction. Examples: temperature, mass, speed, the result of a dot product.

First introduced in: [[4.9 Dot Product and Projection]]
Builds on: [[1.1 Counting and Number Sense]]
Used in CS: [[10.8 Machine Learning Vectors and Matrices]] - scalar multiplication of vectors, scalar loss functions
