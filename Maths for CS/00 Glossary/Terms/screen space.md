# screen space

The 2D coordinate system of a display after 3D-to-2D projection. Coordinates in screen space correspond to pixel positions.

First introduced in: [[4.10 Geometry for Computer Graphics]]
Builds on: [[3.1 Coordinates and Axes]], [[4.8 Vectors Basics]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - rendering pipeline, pixel shaders

## Related Notes
- [[model space]] - starts from model space, ends in screen space
- [[translation]] - part of the transformation pipeline
- [[scaling]] - screen space may use different scaling than world space
