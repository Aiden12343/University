# single bracket

An expression with one multiplier outside one pair of brackets, such as 3(x + 2).

First introduced in: [[2.3 Expanding Brackets]]
Builds on: [[distributive law]] and [[term]]
Used in CS: Code like k * (a + b) is a single-bracket form that compilers may expand using the distributive law.
