# solution set

The collection of all values of a variable that make an inequality (or other condition) true.

First introduced in: [[2.7 Inequalities]]
Builds on: [[solution]], [[2.5 Solving Linear Equations]]
Used in CS: Valid inputs for a function form a solution set (e.g. all indexes `i` where `0 <= i < length`).
