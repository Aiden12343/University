# square root

A non-negative value that multiplied by itself gives the original number; written √a.

First introduced in: [[2.10 Surds and Roots]]

Builds on: [[square]], [[2.9 Indices and Powers]]

Used in CS: Distance formulas, vector lengths, and normalisation all rely on square roots.
