# strict vs inclusive

Whether an inequality boundary value is excluded (strict: `<`, `>`) or included (inclusive: `≤`, `≥`).

First introduced in: [[2.7 Inequalities]]
Builds on: [[inequality symbols]], [[1.1 Counting and Number Sense]]
Used in CS: Half-open array ranges like `0 <= i < n` use an inclusive lower bound and strict upper bound to match valid indexes.
