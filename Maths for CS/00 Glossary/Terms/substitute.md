# substitute

To replace a letter in an expression or formula with a number and calculate the result.

First introduced in: [[2.6 Rearranging Formulae]]
Builds on: [[variable]], [[1.9 Order of Operations]]
Used in CS: Function calls substitute argument values for parameter names, the same way numbers replace letters in a rearranged formula.
