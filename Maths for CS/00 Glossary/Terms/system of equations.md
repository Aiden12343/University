# system of equations

Two or more equations that share the same unknowns and must all be satisfied at the same time.

First introduced in: [[2.8 Simultaneous Equations]]

Builds on: [[2.5 Solving Linear Equations]]

Used in CS: Models multiple constraints that software must satisfy together, such as layout limits or resource balances.
