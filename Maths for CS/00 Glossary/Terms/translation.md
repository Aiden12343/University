# translation

Moving an object by adding a constant offset (a translation vector) to all its coordinates. A rigid transformation that preserves distance and orientation.

First introduced in: [[4.10 Geometry for Computer Graphics]]
Builds on: [[1.3 Addition and Subtraction]], [[4.8 Vectors Basics]]
Used in CS: [[10.4 Computer Graphics and Transformations]] - moving objects in a scene, camera movement
