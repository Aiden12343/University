# turning point
A point where a curve changes from increasing to decreasing, or from decreasing to increasing.
First introduced in: [[3.4 Quadratic Functions]]
Builds on: [[3.1 Coordinates and Axes]], [[3.3 Linear Functions and Gradient]]
Used in CS: Optimisation, animation easing, and ML loss curves all care about highest, lowest, or best points.
