# unknown on both sides

An equation where the variable appears on both the left-hand and right-hand sides, requiring term collection before isolating.

First introduced in: [[2.5 Solving Linear Equations]]

Used in CS: Resource-balance constraints (e.g. `allocated + free = total` rearranged with variables on both sides) appear when reconciling competing allocations in systems code.
