# x-axis
The horizontal number line on a coordinate plane where the first coordinate x is read.
First introduced in: [[3.1 Coordinates and Axes]]
Builds on: [[1.2 Place Value and Number Lines]], [[1.8 Negative Numbers]]
Used in CS: The horizontal axis in charts, game worlds, and pixel grids usually represents x position or an independent variable such as time.
