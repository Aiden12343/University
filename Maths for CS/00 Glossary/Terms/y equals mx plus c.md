# y equals mx plus c
The standard linear form y = mx + c where m is gradient and c is y-intercept.
First introduced in: [[3.3 Linear Functions and Gradient]]
Builds on: [[2.1 Variables Expressions and Equations]]
Used in CS: Affine pricing and timing formulas in code often match y = mx + c.
