# y-axis
The vertical number line on a coordinate plane where the second coordinate y is read.
First introduced in: [[3.1 Coordinates and Axes]]
Builds on: [[1.2 Place Value and Number Lines]], [[1.8 Negative Numbers]]
Used in CS: The vertical axis in plots and screen coordinates holds y position, though some graphics APIs increase y downward from the top.
