# Diagnostic Test - Absolute Basics

Take this before starting [[1.1 Counting and Number Sense]]. Do not use a calculator.

## Questions
1. Count from 1 to 30.
2. Write the number that comes after 49.
3. Which is larger: 83 or 38?
4. Calculate 7 + 5.
5. Calculate 15 - 8.
6. Calculate 6 x 4.
7. Calculate 20 / 5.
8. What is half of 10?
9. Write 25% as a fraction.
10. Put these in order: -2, 5, 0, -7.
11. Calculate 3 + 4 x 2.
12. Explain what an equals sign means.

## Decision
- If this felt hard, start at [[1.1 Counting and Number Sense]].
- If this was easy, still skim Folder 01 and take each mastery test.
