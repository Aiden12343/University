# How To Use This Course

This vault is a five-year mathematics path for Computer Science, starting from zero and moving toward master's-level study.

## Daily Study Loop
1. Open [[University/Maths for CS/Home]].
2. Pick the next unchecked topic in [[Progress Tracker]].
3. Read the topic note slowly.
4. Rewrite the Plain-English Idea in your own words.
5. Work through the linked worked examples.
6. Attempt practice questions on paper.
7. Take the mastery test without notes.
8. If you fail, create a correction note in [[University/Maths for CS/94 Review Sheets/94 Review Sheets MOC]] and retake later.

## Printing
Each topic is designed to print as a standalone handout. Print the theory note, worked examples, practice questions, and mastery test as one packet.

## Obsidian Links
Links show dependencies. If a later topic is confusing, follow the backward links and repair the earlier gap first.
