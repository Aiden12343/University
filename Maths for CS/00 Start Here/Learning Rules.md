# Learning Rules

## Progression Rule
You only move forward after passing the current topic's [[Mastery Test Template]].

## Default Pass Marks
- Arithmetic and algebra foundations: 90%.
- Later topics: 85%.
- Definitions and notation: 100%.

## Failure Rule
A failed question is useful evidence. For each failed question:

1. Create a note from [[Correction Note Template]].
2. Write the mistake in plain English.
3. Link the failed topic.
4. Solve a new version of the question.
5. Retake the test later.

## Explanation Rule
You do not know a topic until you can explain it without copying the note.
