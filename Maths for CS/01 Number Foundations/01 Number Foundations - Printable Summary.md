# 01 Number Foundations - Printable Summary

Build arithmetic fluency from zero: numbers, operations, fractions, ratios, and checking work.

## What You Must Be Able To Do
- [ ] [[1.1 Counting and Number Sense]] - Understand what numbers count, order, and compare.
- [ ] [[1.2 Place Value and Number Lines]] - Read and build whole numbers using units, tens, hundreds, and positions.
- [ ] [[1.3 Addition and Subtraction]] - Combine quantities and find differences reliably.
- [ ] [[1.4 Multiplication and Times Tables]] - See multiplication as repeated addition, scaling, and arrays.
- [ ] [[1.5 Division and Remainders]] - Split quantities into equal groups and understand what is left over.
- [ ] [[1.6 Fractions]] - Represent part of a whole and compare parts fairly.
- [ ] [[1.7 Decimals and Percentages]] - Use base-ten parts and percentages to describe quantities precisely.
- [ ] [[1.8 Negative Numbers]] - Work with numbers below zero and understand direction.
- [ ] [[1.9 Order of Operations]] - Decide the correct order for mixed calculations.
- [ ] [[1.10 Factors Multiples and Primes]] - Break whole numbers into building blocks and repeated patterns.
- [ ] [[1.11 HCF and LCM]] - Find the biggest shared factor and the smallest shared multiple.
- [ ] [[1.12 Ratio Proportion and Units]] - Compare quantities and scale them while keeping relationships fixed.
- [ ] [[1.13 Estimation and Error Checking]] - Predict reasonable answers and catch mistakes before they spread.
