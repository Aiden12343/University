# 01 Number Foundations - What This Unlocks in CS

Build arithmetic fluency from zero: numbers, operations, fractions, ratios, and checking work.

## CS Connections
- [[1.1 Counting and Number Sense]] - Loops, counters, indexes, and array positions all start with counting.
- [[1.2 Place Value and Number Lines]] - Memory addresses, binary numbers, and data sizes all rely on position giving meaning.
- [[1.3 Addition and Subtraction]] - Programs constantly update totals, balances, offsets, and differences.
- [[1.4 Multiplication and Times Tables]] - Nested loops, grid sizes, and runtime counts often multiply quantities.
- [[1.5 Division and Remainders]] - Division and remainders appear in pagination, hashing, and modular arithmetic.
- [[1.6 Fractions]] - Fractions model proportions, probabilities, rates, and precision.
- [[1.7 Decimals and Percentages]] - Progress bars, statistics, memory use, and probability outputs often use percentages.
- [[1.8 Negative Numbers]] - Offsets, signed integers, coordinates, and financial calculations use negatives.
- [[1.9 Order of Operations]] - Programming languages also need exact rules for expression evaluation.
- [[1.10 Factors Multiples and Primes]] - Primes and factors are central to cryptography, hashing, and optimisation.
- [[1.11 HCF and LCM]] - Scheduling, clocks, cycles, and simplifying ratios use HCF and LCM.
- [[1.12 Ratio Proportion and Units]] - Performance metrics, screen scaling, network rates, and algorithm benchmarks use ratios.
- [[1.13 Estimation and Error Checking]] - Debugging numerical output starts with asking whether the answer is reasonable.
