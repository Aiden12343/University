## Section A — Vocabulary and concepts (6 marks)

1. **(1 mark)** Define *variable* and give one example from programming.
2. **(1 mark)** What is the difference between an expression and an equation?
3. **(1 mark)** Define *simultaneous equations* in one sentence.
4. **(1 mark)** State the index law for `a^m × a^n`.
5. **(1 mark)** What is a *restriction* on an algebraic fraction?
6. **(1 mark)** What is *exact form* for a surd answer?

---

## Section B — Core algebra skills (12 marks)

7. **(2 marks)** Simplify: `5x - 2x + 7 - 3`.
8. **(2 marks)** Expand and simplify: `(x + 3)(x + 2)`.
9. **(2 marks)** Factorise: `x^2 + 7x + 12`.
10. **(2 marks)** Solve: `4x - 9 = 21`.
11. **(2 marks)** Make `x` the subject: `y = 3x - 4`.
12. **(2 marks)** Solve the inequality: `2x + 5 < 13`.

---

## Section C — Systems, powers, surds, fractions (8 marks)

13. **(2 marks)** Solve the system:
    ```text
    x + y = 10
    x - y = 4
    ```

14. **(2 marks)** Simplify: `2^4 × 2^3` and evaluate `2^7`.

15. **(2 marks)** Simplify √72 and rationalise `4/√2`.

16. **(2 marks)** Simplify `(x^2 - 16)/(x + 4)` and state the restriction.

---

## Section D — Computer science transfer (4 marks)

17. **(2 marks)** A UI panel must satisfy `width + height = 600` and `width = 2(height)`. Find both dimensions.

18. **(2 marks)** A cache logs 847 hits and 153 misses.
    - Write the hit rate as a simplified fraction.
    - If hits doubled but misses stayed the same, would the rate increase or decrease? Explain briefly.

**A**
1. A symbol standing for a value that can change; e.g. `count`, `score`, loop variable `i`.
2. Expression has no equals sign; equation states two things are equal.
3. Two or more equations with the same unknowns that must all be true together.
4. `a^m × a^n = a^(m+n)`.
5. A value of the variable that makes the denominator zero and must be excluded.
6. Answer kept as a surd such as `5√2`, not rounded to a decimal.

**B**
7. `3x + 4`
8. `x^2 + 5x + 6`
9. `(x + 3)(x + 4)`
10. `x = 7.5` or `15/2`
11. `x = (y + 4)/3`
12. `x < 4`

**C**
13. `x = 7`, `y = 3`
14. `2^7 = 128`
15. `6√2` and `2√2`
16. `x - 4`, `x ≠ -4`

**D**
17. Substitute `width = 2h` into `2h + h = 600` → `h = 200`, `width = 400`.
18. Hit rate = `847/1000` (or `0.847`). Doubling hits increases the rate because numerator grows while denominator grows by less than doubling.
