Turn arithmetic into general rules using symbols, expressions, equations, and rearrangement.

- [ ] [[2.1 Variables Expressions and Equations]] — Use letters for unknowns; tell expressions from equations.
- [ ] [[2.2 Simplifying Expressions]] — Collect like terms; simplify `3x + 2x`, `5a - a + 2`.
- [ ] [[2.3 Expanding Brackets]] — Expand single and double brackets: `3(x+2)`, `(x+1)(x+4)`.

- [ ] [[2.11 Algebraic Fractions]] — Simplify `(x^2-9)/(x+3)`; add with common denominator; state restrictions.

## Key Rules Cheat Sheet

### Index laws (same base)
```text
a^m × a^n = a^(m+n)
a^m ÷ a^n = a^(m-n)
(a^m)^n = a^(mn)
```

### Simultaneous equations
```text
Substitution — use when one variable is already isolated
Elimination   — use when coefficients match or can be matched
Always check both original equations
```

### Surds
```text
√(ab) = √a × √b
√a + √b only combines when the surd part matches
Rationalise: multiply top and bottom by the surd on the bottom
```

### Algebraic fractions
```text
Cancel factors, not added terms
State restrictions (denominator ≠ 0)
Common denominator to add/subtract
```
