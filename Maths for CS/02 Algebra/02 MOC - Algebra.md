# 02 MOC - Algebra

Turn arithmetic into general rules using symbols, expressions, equations, and rearrangement.

## Topics
- [ ] [[2.1 Variables Expressions and Equations]] - Use letters to stand for unknown or changing values.
- [ ] [[2.2 Simplifying Expressions]] - Collect like terms and remove unnecessary clutter.
- [ ] [[2.3 Expanding Brackets]] - Multiply into brackets correctly.
- [ ] [[2.4 Factorising]] - Reverse expanding by finding common structure.
- [ ] [[2.5 Solving Linear Equations]] - Find the unknown value that makes a statement true.
- [ ] [[2.6 Rearranging Formulae]] - Make any chosen variable the subject of a formula.
- [ ] [[2.7 Inequalities]] - Solve and graph statements involving greater than or less than.
- [ ] [[2.8 Simultaneous Equations]] - Solve two or more linked equations at once.
- [ ] [[2.9 Indices and Powers]] - Use powers to describe repeated multiplication.
- [ ] [[2.10 Surds and Roots]] - Work with square roots exactly instead of rounding too soon.
- [ ] [[2.11 Algebraic Fractions]] - Simplify and solve fractions containing algebra.
