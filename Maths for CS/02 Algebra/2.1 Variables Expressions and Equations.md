## Introduction

In all of Module 01, you worked with fixed numbers: `7 + 5 = 12`, `3 x 8 = 24`. Algebra makes this more powerful by letting letters stand in for numbers you do not know yet, or numbers that can change. A **variable** is that letter. An **expression** is a mathematical phrase built from variables, numbers, and operations. An **equation** claims two expressions are equal. The **solution** is the value of the variable that makes the equation true.

```text
x + 3 = 11
```

Here `x` is a variable, `3` and `11` are constants, `x + 3` and `11` are expressions, the `=` makes it an equation, and `x = 8` is the solution.

This topic introduces:
- [[variable]] — a letter or symbol that stands for an unknown or changeable number
- [[constant]] — a fixed number that does not change
- [[expression]] — a maths phrase without an equals sign
- [[equation]] — a statement that two expressions are equal
- [[solution]] — the value of the variable that makes an equation true

> [!example] Everyday idea
> "I have some coins in my pocket. After finding 3 more, I have 11." You do not know the starting number yet, so you call it `x`. The sentence becomes an equation: `x + 3 = 11`.

## New Words

- [[variable]] — a letter or symbol that stands for a number that is unknown or can change.
- [[constant]] — a fixed number that does not change, such as `3` or `-5`.
- [[expression]] — a maths phrase made from numbers, variables, and operations, without an equals sign.
- [[equation]] — a statement that two expressions are equal, using an equals sign.
- [[solution]] — the value of the variable that makes an equation true.

## Breadcrumbs

### Breadcrumb 1: Variables Hold the Place of a Number

**Builds on:** [[1.1 Breadcrumb 1|Numbers Can Name Quantity]] (a name for a quantity you have not counted yet)

A [[variable]] is not a special kind of number. It is a **name** for a number you will find later, or a number that can take different values.

Examples:

```text
x     means "some number, not fixed yet"
n     often means "a counting number"
t     often means "time"
```

You already used placeholders in arithmetic without calling them variables:

```text
? + 3 = 11
```

Replacing `?` with `x` is the start of algebra.

> [!important] A variable stands for one number at a time
> In `x + 3 = 11`, the letter `x` represents one specific unknown number. When you find `x = 8`, you have found that number.

#### Chunked Example
Question: A box holds `n` marbles. Write a sentence in words for "the box has n marbles."

Step 1: Identify what is unknown or changeable — the number of marbles.

Step 2: Use `n` as the variable name.

Step 3: The expression is simply `n`.

Answer: The box contains **n marbles**, where `n` is a variable representing the count.

### Breadcrumb 2: Constants Are Fixed Numbers

**Builds on:** [[1.3 Breadcrumb 1|Addition as Combining]] (constants are the fixed numbers in arithmetic), [[1.8 Breadcrumb 1|The Number Line Extends Below Zero]] (constants can be negative)

A [[constant]] is an ordinary number in an expression or equation. It does not change when the variable changes.

In:

```text
x + 3 = 11
```

- `x` is the variable (unknown)
- `3` and `11` are constants (fixed)

> [!warning] Common mistake
> Do not treat a letter as a variable if it always stands for one fixed value in the problem. In `π` (pi) or `e`, the letter names a constant, not something you solve for. At this level, focus on letters like `x` and `n`.

#### Chunked Example
Question: In `2x + 5 = 17`, list the variable and the constants.

Step 1: Find the letter — `x` is the variable.

Step 2: Find the fixed numbers — `2`, `5`, and `17` are constants.

Answer: Variable: **x**. Constants: **2, 5, 17**.

Note: `2x` means `2 x x`, using multiplication from [[1.4 Breadcrumb 1|Multiplication as Equal Groups]].

### Breadcrumb 3: Expressions Have No Equals Sign

**Builds on:** [[1.9 Breadcrumb 4|Multiplication and Division Before Addition and Subtraction]] (expressions follow order of operations), [[1.9 Breadcrumb 2|Brackets First]] (expressions can include brackets)

An [[expression]] is a maths **phrase**. It does not claim two things are equal.

Examples of expressions:

```text
x + 3
2n
7 - t
```

Not expressions (these are equations):

```text
x + 3 = 11
2n = 10
```

> [!example] Word analogy
> An expression is like a noun phrase ("three more than a number"). An equation is like a full sentence ("three more than a number equals eleven").

#### Chunked Example
Question: Which are expressions and which are equations?

```text
(a) 4x + 1
(b) 4x + 1 = 9
(c) 15
(d) y = y + 0
```

Step 1: Check for an equals sign. Items with `=` are equations.

Step 2: Items without `=` are expressions.

Answer:
- Expressions: **(a) 4x + 1**, **(c) 15**
- Equations: **(b) 4x + 1 = 9**, **(d) y = y + 0**

### Breadcrumb 4: Equations Make a Claim of Equality

**Builds on:** [[1.1 Breadcrumb 4|Bigger, Smaller, and Equal]] (the `=` symbol means the same value), [[1.3 Breadcrumb 10|Checking with Inverse Operations]] (balancing both sides)

An [[equation]] says two expressions have the **same value**. The equals sign `=` is a statement, not an instruction.

```text
x + 3 = 11
```

means: "Whatever number `x` is, adding 3 gives the same result as 11."

> [!important] Both sides must balance
> If you replace `x` with a value, both sides must give the same number. That test defines a [[solution]].

#### Chunked Example
Question: Is `x = 5` a solution to `x + 3 = 11`?

Step 1: Substitute `x = 5` into the left side.

```text
5 + 3 = 8
```

Step 2: Compare to the right side.

```text
8 ≠ 11
```

Step 3: The sides are not equal, so `5` is not a solution.

Answer: **No**, `x = 5` is not a solution.

---

### Breadcrumb 5: A Solution Makes the Equation True

**Builds on:** [[1.3 Breadcrumb 3|Subtraction as Difference]] (finding the missing amount), [[1.3 Breadcrumb 10|Checking with Inverse Operations]] (check by reversing)

A [[solution]] is the value of the variable that makes the equation true.

For `x + 3 = 11`:

```text
Try x = 8:  8 + 3 = 11  ✓
Try x = 4:  4 + 3 = 7   ✗
```

So **x = 8** is the solution.

Check with the inverse operation:

```text
11 - 3 = 8
```

#### Chunked Example
Question: Find the solution to `n + 7 = 15`.

Step 1: Estimate — `n` should be near `15 - 7`, roughly 8.

Step 2: Use subtraction as the inverse of addition.

```text
n = 15 - 7
n = 8
```

Step 3: Check by substitution.

```text
8 + 7 = 15  ✓
```

Answer: **n = 8**.

### Breadcrumb 6: Substituting a Value into an Expression

**Builds on:** [[1.9 Breadcrumb 1|BIDMAS]] (order of operations when evaluating with substitution), [[1.4 Breadcrumb 5|Times Tables Are Stored Facts]] (quick arithmetic with substituted values)

**Substitution** means replacing a variable with a number and calculating the result.

If `x = 4`, then:

```text
x + 3  →  4 + 3  →  7
```

#### Chunked Example
Question: If `x = 6`, find the value of `2x + 1`.

Step 1: Replace `x` with `6`.

```text
2(6) + 1
```

Step 2: Multiply first (order of operations).

```text
12 + 1 = 13
```

Answer: **13**.

## Why This Works

Variables let you describe **patterns once** instead of repeating arithmetic for every number.

If you know:

```text
total = starting + found
```

you can write:

```text
x + 3 = 11
```

The equals sign preserves balance — anything you do to one side must be matched on the other. That idea comes from [[1.3 Breadcrumb 10|Checking with Inverse Operations]]: addition and subtraction undo each other.

In symbols:

$$
x + 3 = 11 \implies x = 11 - 3 = 8
$$

You are not guessing. You are using the same number facts from Module 01, now with a placeholder.

## Common Mistakes

- Treating `x + 3` as an equation — it is an **expression** with no equals sign.
- Thinking `x` is always 1 because it is "one letter" — it stands for whatever value the problem requires.
- Forgetting to check a solution by substituting back.
- Confusing `2x` with `2 + x` — `2x` means `2 x x`.
- Writing `3x = 3 + x` — multiplication is not addition.

## Where This Shows Up in CS

Variables are the core of programming.

```python
score = 0          # variable
score = score + 10 # expression on the right, assignment with =
lives = 3          # constant value stored in a variable
```

In a function:

```python
def double(n):
    return 2 * n   # n is a variable parameter
```

Every time you call `double(5)` or `double(7)`, `n` stands for a different number — the same idea as substituting into an expression.

Equations model constraints: "memory used plus buffer equals limit" becomes `used + buffer = limit`.
