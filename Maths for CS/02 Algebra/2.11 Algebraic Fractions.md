## Introduction

An **algebraic fraction** has algebra in the numerator, the denominator, or both — for example `(x+2)/3` or `5/x`. The rules of numeric fractions still apply: simplify by cancelling **common factors**, add using a **common denominator**, and never divide by zero. Factorising helps you see those factors when `x` is involved.

The **algebraic numerator** is the top part, the **algebraic denominator** is the bottom. A **restriction** is any value of the variable that makes the denominator zero and must be excluded.

> [!example] Everyday idea
> If `x` notebooks cost £6 in total, one notebook costs `6/x` pounds. The expression makes sense only when `x ≠ 0`.

## New Words

- [[algebraic numerator]] — the top of an algebraic fraction, which may contain variables.
- [[algebraic denominator]] — the bottom of an algebraic fraction, which may contain variables.
- [[common denominator]] — a shared bottom expression used to add or subtract algebraic fractions.
- [[cancel common factors]] — divide numerator and denominator by the same non-zero factor to simplify.
- [[restriction]] — a value of the variable that must be excluded because it makes the denominator zero.

## Breadcrumbs

### Breadcrumb 1: Structure of an Algebraic Fraction

**Builds on:** [[1.6 Breadcrumb 1|What a Fraction Is]] (numerator over denominator), [[2.1 Breadcrumb 1|What a Variable Is]] (letters stand for numbers)

In `(x + 4) / (2x)`, the [[algebraic numerator]] is `x + 4` and the [[algebraic denominator]] is `2x`.

The fraction means:

```text
(x + 4) divided by (2x)
```

> [!important] Denominator cannot be zero
> Any value making the denominator 0 is excluded. Here, `x ≠ 0`.

#### Chunked Example
Question: State the restriction on `(3x - 1)/(x + 5)`.

Step 1: Set denominator equal to zero.

```text
x + 5 = 0
```

Step 2: Solve.

```text
x = -5
```

Answer: **x ≠ -5**.

### Breadcrumb 2: Simplifying by Cancelling Common Factors

**Builds on:** [[2.11 Breadcrumb 1|Structure of an Algebraic Fraction]] (knowing numerator and denominator), [[2.4 Breadcrumb 2|Taking Out a Common Factor]] (factorise first), [[1.6 Breadcrumb 4|Simplifying Fractions]] (cancel common factors)

[[cancel common factors]] only when the shared part is a **factor** of both top and bottom.

```text
(6x)/9 = (2x)/3
```

With algebra:

```text
(x^2 + 5x)/(x) = x + 5,   x ≠ 0
```

Factorise first.

> [!warning] Cannot cancel across addition
> `(x + 2)/2` does **not** simplify to `x`. The whole numerator is not a product.

#### Chunked Example
Question: Simplify `(x^2 - 9)/(x + 3)`.

Step 1: Factorise the numerator.

```text
x^2 - 9 = (x - 3)(x + 3)
```

Step 2: Cancel the common factor `(x + 3)`.

```text
(x - 3)(x + 3)/(x + 3) = x - 3
```

Step 3: State restriction.

```text
x ≠ -3
```

Answer: **x - 3**, with **x ≠ -3**.

### Breadcrumb 3: Adding and Subtracting

**Builds on:** [[2.11 Breadcrumb 2|Simplifying by Cancelling Common Factors]] (handle fraction form), [[1.6 Breadcrumb 5|Adding and Subtracting Fractions]] (common denominator method)

To add algebraic fractions, find a [[common denominator]].

```text
2/x + 3/x = 5/x
```

When denominators differ:

```text
1/x + 1/(x+1)
```

Common denominator: `x(x+1)`.

> [!tip] Same rule as numeric fractions
> This is identical to numeric fractions, except the denominators contain `x`.

#### Chunked Example
Question: Simplify `3/(2x) + 1/x`.

Step 1: Common denominator is `2x`.

Step 2: Rewrite the second fraction.

```text
1/x = 2/(2x)
```

Step 3: Add.

```text
3/(2x) + 2/(2x) = 5/(2x)
```

Answer: **5/(2x)**, with **x ≠ 0**.

---

### Breadcrumb 4: Multiplying and Dividing

**Builds on:** [[2.11 Breadcrumb 2|Simplifying by Cancelling Common Factors]] (cancel after multiply), [[1.6 Breadcrumb 6|Multiplying Fractions]] (multiply tops and bottoms), [[1.6 Breadcrumb 7|Dividing Fractions]] (multiply by reciprocal)

Multiply tops and bottoms:

```text
(2/x) × (3/x^2) = 6/x^3
```

To divide, multiply by the reciprocal:

```text
(4/x) ÷ (2/x) = (4/x) × (x/2) = 2
```

#### Chunked Example
Question: Simplify `(x/3) × (6/x^2)`.

Step 1: Multiply numerators and denominators.

```text
6x / (3x^2)
```

Step 2: Cancel common factors.

```text
6x / (3x^2) = 2/x
```

Step 3: Restriction from original denominators: `x ≠ 0`.

Answer: **2/x**, **x ≠ 0**.

---

### Breadcrumb 5: Solving Equations With Algebraic Fractions

**Builds on:** [[2.11 Breadcrumb 3|Adding and Subtracting]] (common denominator), [[2.5 Breadcrumb 4|Two-Step Equations]] (balancing both sides)

Clear fractions by multiplying both sides by the common denominator, using balancing from [[2.5 Solving Linear Equations]].

```text
1/x + 1/2 = 1
```

Multiply through by `2x`:

```text
2 + x = 2x
x = 2
```

Check restrictions: `x ≠ 0`. The solution `x = 2` is valid.

> [!failure] Always check restrictions
> A solution that makes any original denominator zero must be rejected.

#### Chunked Example
Question: Solve `(x + 1)/3 = 2`.

Step 1: Multiply both sides by 3.

```text
x + 1 = 6
```

Step 2: Solve.

```text
x = 5
```

Step 3: Denominator was constant 3 — no variable restriction issue.

Answer: **x = 5**.

### Breadcrumb 6: Rational Expressions as CS Models

**Builds on:** [[2.11 Breadcrumb 1|Structure of an Algebraic Fraction]] (rate as fraction), [[2.11 Breadcrumb 5|Solving Equations With Algebraic Fractions]] (restrictions matter in code)

Algebraic fractions model rates, probabilities, and formulas where the variable appears in the denominator.

Example: success rate `s/(s+f)` where `s` successes and `f` failures.

Simplify before coding when possible to reduce operations and avoid divide-by-zero bugs.

> [!example] CS connection
> A cache hit rate `h/(h+m)` must handle `h+m = 0`. The restriction `h + m ≠ 0` is exactly the guard clause a program needs.

#### Chunked Example
Question: Simplify `(2n + 4)/(n + 2)`.

Step 1: Factorise numerator.

```text
2(n + 2)/(n + 2)
```

Step 2: Cancel.

```text
2,   n ≠ -2
```

Answer: **2**, with **n ≠ -2**.

## Why This Works

Algebraic fractions follow the same structure as numeric fractions. Cancelling works because `(a×b)/a = b` when `a ≠ 0`.

Factorising reveals hidden common factors. A [[common denominator]] works because equivalent fractions name the same value with different partitions, just as with numbers.

## Common Mistakes

- Cancelling terms instead of factors: `(x+2)/2 ≠ x`.
- Forgetting to state [[restriction]] values.
- Using a common denominator without multiplying **every** numerator term.
- Dividing by an expression that could be zero.
- Adding numerators while keeping different denominators.
- Accepting a solution that breaks an original denominator.

> [!failure] Mistake pattern
> In `(x^2 - 1)/(x - 1)`, cancelling gives `x + 1` but **x ≠ 1** must be recorded.

## Where This Shows Up in CS

Algebraic fractions appear in:

- **probability** — favourable/total as `(x)/(x+y)`
- **performance metrics** — hits/(hits+misses)
- **average formulas** — totals divided by counts that may be variables
- **calculus limits** — rational expressions simplify before taking limits
- **algorithm formulas** — rates with variable workload size `n`

```python
def hit_rate(hits, misses):
    total = hits + misses
    if total == 0:
        return None   # restriction: total ≠ 0
    return hits / total
```

The guard clause enforces the mathematical restriction.
