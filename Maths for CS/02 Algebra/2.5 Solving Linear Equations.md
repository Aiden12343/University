## Introduction

A **linear equation** is a statement that two expressions are equal, and the unknown appears only to the first power (no squares, no cubes). **Solving** means finding the value of the unknown that makes the statement true.

Think of an equation as a balanced scale. Both sides weigh the same. To find the unknown, you undo what was done to it using **inverse operations** — addition undoes subtraction, multiplication undoes division — while keeping the scale balanced.

A **one-step equation** needs one inverse operation. A **two-step equation** needs two, applied in reverse order of operations. An equation with the **unknown on both sides** requires collecting terms first. **Balancing** is the discipline of keeping both sides equal through every step.

> [!example] Everyday idea
> "I had some money, spent £4, and now have £11." The unknown starting amount satisfies `x - 4 = 11`. Solving gives `x = 15`.

## New Words

- [[balancing]] — keeping both sides of an equation equal when you add, subtract, multiply, or divide.
- [[inverse operations]] — operations that undo each other, such as addition and subtraction, or multiplication and division.
- [[one-step equation]] — an equation that can be solved with a single inverse operation.
- [[two-step equation]] — an equation that needs two inverse operations in the correct order to solve.
- [[unknown on both sides]] — an equation where the variable appears on the left and the right, so terms must be collected before isolating.

## Breadcrumbs

### Breadcrumb 1: Equations Are Balanced Statements

**Builds on:** [[2.1 Breadcrumb 2|Expressions vs Equations]] (equations have an equals sign), [[2.1 Breadcrumb 1|What a Variable Is]] (unknown stands for a number), [[1.3 Breadcrumb 1|What Addition and Subtraction Mean]] (combining and separating quantities)

An equation says two sides have the **same value**. The equals sign `=` is not an instruction to calculate — it is a claim of balance.

```text
x + 3 = 11
```

means: "Whatever `x` is, adding 3 gives the same result as 11."

> [!important] Both sides must stay equal
> Every legal step must keep the equation true. If you change one side, you must make the same change to the other. That is [[balancing]].

#### Chunked Example
Question: Is `x = 8` a solution to `x + 3 = 11`?

Step 1: Substitute `x = 8` into the left side.

```text
8 + 3 = 11
```

Step 2: Compare to the right side.

```text
11 = 11  ✓
```

Answer: **Yes**, `x = 8` is a solution because both sides balance.

---

### Breadcrumb 2: Inverse Operations Undo What Was Done

**Builds on:** [[1.3 Breadcrumb 3|Inverse Operations]] (addition and subtraction undo each other), [[1.4 Breadcrumb 4|Multiplication and Division as Inverses]] (undoing multiplication)

[[inverse operations]] are pairs of operations that reverse each other:

```text
addition  ↔  subtraction
multiplication  ↔  division
```

If `7 + 5 = 12`, then `12 - 5 = 7`. If `3 × 4 = 12`, then `12 ÷ 4 = 3`.

When solving an equation, you work **backwards** through what was done to the unknown.

> [!tip] Ask: "What was done to x?"
> In `x + 3 = 11`, 3 was **added** to `x`. The inverse is **subtract 3**.

#### Chunked Example
Question: Solve `x + 3 = 11`.

Step 1: Identify what was done — 3 was added to `x`.

Step 2: Apply the inverse to **both sides** (balancing).

```text
x + 3 - 3 = 11 - 3
x = 8
```

Step 3: Check by substitution.

```text
8 + 3 = 11  ✓
```

Answer: **x = 8**.

---

### Breadcrumb 3: One-Step Equations

**Builds on:** [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (what equation means), [[2.5 Breadcrumb 2|Inverse Operations]] (how to undo)

A [[one-step equation]] needs only one inverse operation to isolate the unknown.

Common patterns:

```text
x + a = b     →  subtract a from both sides
x - a = b     →  add a to both sides
ax = b        →  divide both sides by a
x/a = b       →  multiply both sides by a
```

> [!warning] Do the same to both sides
> If you subtract 3 from the left, you must subtract 3 from the right. Changing only one side breaks the balance.

#### Chunked Example
Question: Solve `5x = 35`.

Step 1: Identify the operation — `x` was multiplied by 5.

Step 2: Divide both sides by 5.

```text
5x ÷ 5 = 35 ÷ 5
x = 7
```

Step 3: Check.

```text
5 × 7 = 35  ✓
```

Answer: **x = 7**.

---

### Breadcrumb 4: Two-Step Equations

**Builds on:** [[2.5 Breadcrumb 3|One-Step Equations]] (same idea, two inverses), [[1.9 Breadcrumb 8|Reverse Order of Operations]] (undo addition before multiplication)

A [[two-step equation]] needs two inverse operations. Order matters — undo addition/subtraction **before** multiplication/division, following the order of operations in reverse.

Example pattern:

```text
ax + b = c
```

Step 1: Remove the constant (subtract `b`).

Step 2: Remove the coefficient (divide by `a`).

> [!example] Undo in reverse order
> In `2x + 3 = 11`, the last thing done to `x` was adding 3, then before that multiplying by 2. Undo addition first, then division.

#### Chunked Example
Question: Solve `2x + 3 = 11`.

Step 1: Subtract 3 from both sides.

```text
2x + 3 - 3 = 11 - 3
2x = 8
```

Step 2: Divide both sides by 2.

```text
2x ÷ 2 = 8 ÷ 2
x = 4
```

Step 3: Check.

```text
2(4) + 3 = 8 + 3 = 11  ✓
```

Answer: **x = 4**.

### Breadcrumb 5: Unknown on Both Sides

**Builds on:** [[2.5 Breadcrumb 4|Two-Step Equations]] (extra collecting step first), [[2.2 Breadcrumb 4|Collecting Like Terms to Simplify]] (moving terms across the equals sign)

In an equation with [[unknown on both sides]], the variable appears on the left and the right. Collect like terms before isolating.

```text
3x + 2 = x + 10
```

Strategy: move all `x` terms to one side and all constants to the other, using [[balancing]].

> [!important] Move terms, do not "cancel" blindly
> Subtract `x` from both sides to gather the unknowns on the left. Then subtract constants from both sides.

#### Chunked Example
Question: Solve `3x + 2 = x + 10`.

Step 1: Subtract `x` from both sides.

```text
3x + 2 - x = x + 10 - x
2x + 2 = 10
```

Step 2: Subtract 2 from both sides.

```text
2x = 8
```

Step 3: Divide by 2.

```text
x = 4
```

Step 4: Check.

```text
Left:  3(4) + 2 = 14
Right: 4 + 10 = 14  ✓
```

Answer: **x = 4**.

---

### Breadcrumb 6: Always Check by Substitution

**Builds on:** [[2.5 Breadcrumb 3|One-Step Equations]] (check by substituting back), [[1.13 Breadcrumb 5|Inverse Checks]] (verifying by reversing the operation)

A solution must make **both sides equal** when you substitute back.

Quick check routine:

1. Substitute your answer into the **original** equation.
2. Simplify both sides.
3. Confirm they match.

> [!failure] Mistake pattern
> If your answer fails the check, the equation was not satisfied. Do not move on — find where the algebra went wrong.

#### Chunked Example
Question: Solve `4x - 1 = 15` and check.

Step 1: Add 1 to both sides.

```text
4x = 16
```

Step 2: Divide by 4.

```text
x = 4
```

Step 3: Check in the original equation.

```text
4(4) - 1 = 16 - 1 = 15  ✓
```

Answer: **x = 4**, verified.

## Why This Works

Solving works because every step preserves equality — the same truth, written differently.

If:

```text
x + 3 = 11
```

then subtracting 3 from both sides gives:

```text
x = 8
```

The second line is true **exactly when** the first is true. You are not guessing; you are applying [[inverse operations]] that undo what was done to the unknown.

This builds directly on [[1.3 Breadcrumb 3|Inverse Operations]]: addition and subtraction are inverses. [[1.4 Breadcrumb 4|Multiplication and Division as Inverses]] gives multiplication and division as inverses. [[1.9 Breadcrumb 8|Reverse Order of Operations]] tells you which inverse to apply first in multi-step equations.

## Worked Examples

For fully worked solutions, use [[2.5 Solving Linear Equations - Worked Examples]].

### Example 1 - One-step addition
Question: Solve `n + 7 = 15`.

Solution:

```text
n = 15 - 7 = 8
Check: 8 + 7 = 15  ✓
```

### Example 2 - Two-step
Question: Solve `3x - 5 = 16`.

Solution:

```text
3x = 21
x = 7
Check: 3(7) - 5 = 21 - 5 = 16  ✓
```

### Example 3 - Both sides
Question: Solve `5x - 3 = 2x + 9`.

Solution:

```text
3x - 3 = 9
3x = 12
x = 4
Check: Left 17, Right 17  ✓
```

## Common Mistakes

- Changing only one side of the equation — this breaks [[balancing]].
- Dividing before subtracting in `2x + 3 = 11` — undo addition first.
- Sign errors when moving terms: subtracting `x` from `3x + 2 = x + 10` gives `2x + 2 = 10`, not `4x + 2 = 10`.
- Forgetting to check by substitution.
- Treating `5x` as `5 + x` — `5x` means `5 × x`.
- Stopping early: `2x = 8` is not the final answer; divide to get `x = 4`.

> [!failure] Mistake pattern
> If you get `x = 17` from `x + 5 = 12`, you **added** 5 instead of subtracting. Inverse operations must undo, not repeat.

## Where This Shows Up in CS

Solving equations is solving **constraints** — conditions a program must satisfy.

**Debugging constraint violations:**

```python
used = 850
limit = 1024
buffer = limit - used   # solving used + buffer = limit
# buffer = 174
```

**Layout engines** solve for dimensions: "width plus margin equals container width" becomes `w + 2m = W`.

**Type inference** in some languages finds unknown types that satisfy constraints.

**Systems modelling:** "arrival rate times service time equals utilisation" rearranges to find unknown throughput.

When a bug report says "the total should be 100 but shows 97", you are debugging an equation: something in the chain did not balance.

```python
# Constraint: items * price + tax = total
items = 3
price = 10
tax = 2.50
total = items * price + tax   # must equal 32.50
assert total == 32.50         # check like substitution
```

Every `assert` in code is a balance check: does the left side equal the right side?
