## Introduction

A **formula** is an equation that links several quantities. The **subject** is the letter written alone on one side. **Rearranging** means rewriting the formula so a different letter becomes the subject — isolating it by undoing every operation applied to it using **inverse operations**. You can then **substitute** known values to calculate the unknown quantity.

> [!example] Everyday idea
> `distance = speed × time` tells you distance when you know speed and time. Rearranged as `time = distance ÷ speed`, it tells you time instead. Same relationship, different question.

## New Words

- [[subject]] — the single variable written alone on one side of a formula after rearranging.
- [[inverse operation]] — an operation that undoes another, used to move a term across the equals sign.
- [[formula]] — an equation that connects two or more quantities with letters and operations.
- [[isolate]] — to get the subject alone on one side by undoing every other operation on it.
- [[substitute]] — to replace a letter with a number and calculate the result.

## Breadcrumbs

### Breadcrumb 1: What a Formula Is

**Builds on:** [[2.1 Breadcrumb 1|What a Variable Is]] (letters stand for numbers), [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (formulas are equations)

A [[formula]] is an equation that describes a relationship between quantities. It uses letters as placeholders.

Examples:

```text
A = l × w          (area of a rectangle)
d = s × t          (distance = speed × time)
C = 2πr            (circumference of a circle)
```

Each letter can stand for a number you plug in. The formula does not pick one letter as "the answer" — that depends on what you need to find.

> [!important] A formula is still an equation
> The equals sign means balance. Rearranging preserves the relationship; it does not change the physics or the maths.

#### Chunked Example
Question: In `d = s × t`, what does each letter represent?

Step 1: Read the formula — distance equals speed times time.

Step 2: Label the letters.

```text
d = distance
s = speed
t = time
```

Answer: **d** is distance, **s** is speed, **t** is time.

### Breadcrumb 2: The Subject of a Formula

**Builds on:** [[2.6 Breadcrumb 1|What a Formula Is]] (formula links quantities), [[2.5 Breadcrumb 3|One-Step Equations]] (isolating the variable)

The [[subject]] is the letter written **alone** on one side of the formula, usually the left.

In:

```text
A = l × w
```

the subject is **A**.

If you rearrange to:

```text
w = A ÷ l
```

the subject is now **w**.

> [!tip] "Make w the subject" means "get w by itself"
> Every other letter and number must end up on the other side.

#### Chunked Example
Question: In `v = u + at`, which letter is the subject?

Step 1: Look at the left side of the equals sign.

Step 2: Only **v** appears there, not added to or multiplied by anything else.

Answer: The [[subject]] is **v**.

### Breadcrumb 3: Isolating with Inverse Operations

**Builds on:** [[2.6 Breadcrumb 2|The Subject of a Formula]] (know what to isolate), [[2.5 Breadcrumb 2|Inverse Operations]] (same method), [[1.3 Breadcrumb 3|Inverse Operations]] (addition/subtraction undo), [[1.4 Breadcrumb 4|Multiplication and Division as Inverses]] (multiply/divide undo)

To [[isolate]] a letter, undo every operation applied to it using an [[inverse operation]], while balancing both sides.

This is solving an equation — the method from [[2.5 Solving Linear Equations]].

Undo order follows [[1.9 Order of Operations]] in reverse:

1. Undo addition/subtraction
2. Undo multiplication/division
3. Undo brackets if needed

> [!warning] Treat the subject like x
> When making `t` the subject of `d = s × t`, you are solving for `t` exactly as you would solve for `x`.

#### Chunked Example
Question: Make `t` the subject of `d = s × t`.

Step 1: Identify the subject wanted — `t`.

Step 2: `t` is multiplied by `s`. Divide both sides by `s`.

```text
d ÷ s = t
```

Step 3: Rewrite with subject on the left.

```text
t = d/s
```

Step 4: Check with numbers: if `d = 60`, `s = 30`, then `t = 2`. Original: `60 = 30 × 2` ✓

Answer: **t = d/s**

---

### Breadcrumb 4: Rearranging with Addition and Subtraction

**Builds on:** [[2.6 Breadcrumb 3|Isolating with Inverse Operations]] (applying inverses), [[1.3 Breadcrumb 2|Adding and Subtracting with Negatives]] (sign handling)

When a letter is added or subtracted, use the inverse to move it.

From `v = u + at`:

```text
v - at = u
u = v - at
```

> [!example] Move terms, do not lose signs
> In `v = u + at`, subtract `at` from both sides. The `u` stays positive on the right, then swap sides.

#### Chunked Example
Question: Make `u` the subject of `v = u + at`.

Step 1: Subtract `at` from both sides.

```text
v - at = u
```

Step 2: Write with `u` as subject.

```text
u = v - at
```

Step 3: Check: if `v = 20`, `a = 2`, `t = 3`, then `u = 20 - 6 = 14`. Original: `20 = 14 + 6` ✓

Answer: **u = v - at**

---

### Breadcrumb 5: Order of Operations When Rearranging

**Builds on:** [[2.6 Breadcrumb 3|Isolating with Inverse Operations]] (multi-step isolating), [[1.9 Breadcrumb 8|Reverse Order of Operations]] (undo last operation first)

[[1.9 Order of Operations]] tells you which operation binds tighter. When isolating, undo the **last** operation first.

In `y = 2x + 3`:

- `x` is multiplied by 2, then 3 is added
- To isolate `x`: subtract 3, then divide by 2

```text
y - 3 = 2x
x = (y - 3)/2
```

If a formula has brackets, treat the bracket as one unit.

> [!failure] Mistake pattern
> Dividing before subtracting in `y = 2x + 3` gives `y/2 = x + 3`, which does not isolate `x`.

#### Chunked Example
Question: Make `x` the subject of `y = 2x + 3`.

Step 1: Subtract 3 from both sides.

```text
y - 3 = 2x
```

Step 2: Divide both sides by 2.

```text
(y - 3)/2 = x
```

Step 3: Write subject first.

```text
x = (y - 3)/2
```

Answer: **x = (y - 3)/2**

### Breadcrumb 6: Substituting into a Rearranged Formula

**Builds on:** [[2.6 Breadcrumb 3|Isolating with Inverse Operations]] (rearrange first), [[2.1 Breadcrumb 5|Substituting Values into Expressions]] (replace letters with numbers), [[1.9 Breadcrumb 1|Why Order Matters]] (calculate in correct order)

After rearranging, [[substitute]] known values to calculate the unknown quantity.

If `t = d/s` and `d = 100`, `s = 25`:

```text
t = 100/25 = 4
```

> [!tip] Check in the original formula
> Plug your answer back into the **original** formula, not only the rearranged one.

#### Chunked Example
Question: Given `d = s × t`, make `s` the subject. Then find `s` when `d = 120` and `t = 4`.

Step 1: Rearrange — divide both sides by `t`.

```text
s = d/t
```

Step 2: Substitute.

```text
s = 120/4 = 30
```

Step 3: Check in original.

```text
120 = 30 × 4  ✓
```

Answer: **s = d/t**, and when `d = 120`, `t = 4`, **s = 30**.

## Why This Works

Rearranging works because every step is a legal move on an equation — the same balancing rules as [[2.5 Solving Linear Equations]].

If:

```text
d = s × t
```

and `s ≠ 0`, dividing both sides by `s` gives:

```text
d/s = t
```

Both lines express the **same relationship**. You have not changed the physics — only which letter is isolated.

[[1.9 Order of Operations]] explains why you undo addition before division when the subject appears inside `2x + 3`. The order of undoing matches the reverse of the order of building.

### Example 1 - Simple multiplication
Question: Make `w` the subject of `A = l × w`.

Solution: `w = A/l`.

### Example 2 - With addition
Question: Make `u` the subject of `v = u + at`.

Solution: `u = v - at`.

### Example 3 - Two-step
Question: Make `x` the subject of `y = 3x - 5`.

Solution: `y + 5 = 3x`, so `x = (y + 5)/3`.

## Common Mistakes

- Dividing before undoing addition in `y = 2x + 3` — subtract first, then divide.
- Forgetting to apply the operation to **both** sides — breaks balancing.
- Losing a sign when moving terms: `v = u + at` becomes `u = v - at`, not `u = v + at`.
- Treating `d/s` as `d - s` — division is not subtraction.
- Rearranging correctly but substituting into the wrong version of the formula.
- Dividing by zero: `t = d/s` requires `s ≠ 0`.

> [!failure] Mistake pattern
> If your substituted values fail the original formula, the rearrangement or the arithmetic is wrong. Check both.

## Where This Shows Up in CS

Programs implement formulas constantly. You must rearrange them to compute the quantity you need.

**Graphics — convert screen coordinates:**

```python
# y = m * x + c  →  x = (y - c) / m
def x_from_y(y, m, c):
    return (y - c) / m
```

**Performance — find required bandwidth from transfer time:**

```python
# data = rate * time  →  rate = data / time
rate = data_size / elapsed_seconds
```

**Machine learning — learning rate from update rule:**

```python
# new_weight = old_weight - lr * gradient
# → lr = (old_weight - new_weight) / gradient
```

**Physics engines:**

```python
# v = u + a * t  →  t = (v - u) / a
time = (final_velocity - initial_velocity) / acceleration
```

If you code `y / 2 = x + 3` instead of `x = (y - 3) / 2`, the program computes the wrong variable. Rearranging is translating maths into correct assignment statements.
