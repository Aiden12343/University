## Introduction

A **simultaneous equation** problem asks you to find values that satisfy **two linked equations at the same time**. This is called a **system of equations** — the same letters appear in more than one statement, and you need one pair that makes both true. That pair is the **intersection point** of the two constraints.

You can solve using **substitution** (replace one unknown with an expression from the other equation) or **elimination** (add or subtract equations to remove an unknown). A **consistent system** has at least one solution.

> [!example] Everyday idea
> You buy 3 apples and 2 bananas for £2.70, and 1 apple and 4 bananas for £2.10. Each purchase gives one equation. Simultaneous equations find the price of one apple and one banana that fit both receipts.

## New Words

- [[system of equations]] — two or more equations that must all be true for the same unknown values.
- [[elimination]] — a method that adds or subtracts equations to remove one unknown.
- [[substitution]] — a method that writes one unknown in terms of another and plugs it into the second equation.
- [[intersection point]] — the values where two equations agree at the same time.
- [[consistent system]] — a system that has at least one solution that satisfies every equation.

## Breadcrumbs

### Breadcrumb 1: A System Has Shared Unknowns

**Builds on:** [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (each equation is a condition), [[2.1 Breadcrumb 1|What a Variable Is]] (the same variable has the same value everywhere)

A [[system of equations]] uses the same letters in more than one statement.

Example:

```text
x + y = 7
x - y = 1
```

Both equations use `x` and `y`. You are not solving them separately. You are looking for one ordered pair that works in both.

> [!important] Same unknowns, same meaning
> In a system, `x` in the first equation must mean the same `x` in the second equation.

#### Chunked Example
Question: Is `(3, 4)` a solution to the system `x + y = 7` and `x - y = 1`?

Step 1: Check the first equation.

```text
3 + 4 = 7   ✓
```

Step 2: Check the second equation.

```text
3 - 4 = -1   ✗
```

Answer: `(3, 4)` is **not** a solution because it fails the second equation.

---

### Breadcrumb 2: Substitution When One Variable Is Already Isolated

**Builds on:** [[2.8 Breadcrumb 1|A System Has Shared Unknowns]] (we need one pair), [[2.5 Breadcrumb 4|Two-Step Equations]] (solving for one variable), [[2.6 Breadcrumb 3|Isolating with Inverse Operations]] (rearranging to isolate)

[[substitution]] works well when one equation already says `y = ...` or `x = ...`.

Example system:

```text
y = 2x + 1
3x + y = 11
```

#### Chunked Example
Question: Solve by substitution.

```text
y = 2x + 1
3x + y = 11
```

Step 1: The first equation already gives `y`.

Step 2: Replace `y` in the second equation.

```text
3x + (2x + 1) = 11
```

Step 3: Simplify and solve.

```text
5x + 1 = 11
5x = 10
x = 2
```

Step 4: Substitute `x = 2` back into `y = 2x + 1`.

```text
y = 2(2) + 1 = 5
```

Step 5: Check both originals.

```text
5 = 2(2) + 1   ✓
3(2) + 5 = 11  ✓
```

Answer: `x = 2`, `y = 5`.

### Breadcrumb 3: Elimination by Adding or Subtracting Equations

**Builds on:** [[2.8 Breadcrumb 1|A System Has Shared Unknowns]] (combining equations), [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (adding equals to equals)

[[elimination]] removes one unknown by combining equations.

If coefficients of one variable are opposites, add the equations.

```text
2x + y = 8
2x - y = 2
```

Adding gives:

```text
4x = 10
x = 2.5
```

> [!tip] Match or create opposites
> If the coefficients are not already opposites, multiply one or both equations first.

#### Chunked Example
Question: Solve by elimination.

```text
3x + 2y = 16
x + 2y = 10
```

Step 1: Subtract the second equation from the first to eliminate `y`.

```text
(3x + 2y) - (x + 2y) = 16 - 10
2x = 6
x = 3
```

Step 2: Substitute `x = 3` into `x + 2y = 10`.

```text
3 + 2y = 10
2y = 7
y = 3.5
```

Step 3: Check in `3x + 2y = 16`.

```text
3(3) + 2(3.5) = 9 + 7 = 16   ✓
```

Answer: `x = 3`, `y = 3.5`.

### Breadcrumb 4: Multiply Before Eliminating

**Builds on:** [[2.8 Breadcrumb 3|Elimination by Adding or Subtracting Equations]] (need matching coefficients), [[2.2 Breadcrumb 4|Collecting Like Terms to Simplify]] (scaling expressions)

Sometimes you must scale an equation first.

System:

```text
2x + 3y = 13
4x - y = 5
```

To eliminate `x`, multiply the second equation by 2:

```text
4x + 6y = 26
4x -  y =  5
```

Now subtract.

> [!warning] Multiply every term
> When you multiply an equation by 2, multiply **both sides** and **every term**, including constants.

#### Chunked Example
Question: Solve.

```text
2x + 3y = 13
4x -  y =  5
```

Step 1: Multiply the second equation by 2.

```text
8x - 2y = 10
```

Step 2: Add to the first equation.

```text
2x + 3y = 13
8x - 2y = 10
-----------
10x + y = 23
```

Step 3: Solve for one variable, then back-substitute. Using elimination on `y` instead: multiply `4x - y = 5` by 3 to get `12x - 3y = 15`, then add to `2x + 3y = 13`:

```text
14x = 28
x = 2
```

Step 4: Substitute into `4x - y = 5`.

```text
8 - y = 5
y = 3
```

Answer: `x = 2`, `y = 3`.

### Breadcrumb 5: The Solution Is an Intersection Point

**Builds on:** [[2.8 Breadcrumb 3|Elimination by Adding or Subtracting Equations]] (algebraic solution), [[2.1 Breadcrumb 3|Using Variables for Unknown Numbers]] (x and y as coordinates)

Graphically, each linear equation is a line. The solution is where the lines cross.

For:

```text
x + y = 5
x - y = 1
```

the [[intersection point]] is `(3, 2)`.

```text
y
|
5|     /
 |    /
 |   /  x + y = 5
 |  * (3,2)
 | /
 +---------- x
```

This picture will matter again in [[7.1 Linear Equations in Two Variables]].

#### Chunked Example
Question: Solve and interpret as an intersection.

```text
y = x + 1
y = -x + 5
```

Step 1: Set the right-hand sides equal because both equal `y`.

```text
x + 1 = -x + 5
2x = 4
x = 2
```

Step 2: Find `y`.

```text
y = 2 + 1 = 3
```

Answer: Lines intersect at **(2, 3)**.

### Breadcrumb 6: Consistent and Inconsistent Systems

**Builds on:** [[2.8 Breadcrumb 5|The Solution Is an Intersection Point]] (lines either cross or they do not), [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (parallel lines mean constraints contradict)

A [[consistent system]] has at least one solution.

```text
x + y = 4
x - y = 0     → one solution: (2, 2)
```

If two equations describe the same line, there are infinitely many solutions. If they describe parallel lines with different constants, there is no solution.

> [!failure] No solution does not mean you failed
> Parallel lines mean the constraints contradict each other. In CS, that often signals impossible requirements in a specification.

#### Chunked Example
Question: How many solutions does this system have?

```text
2x + 4y = 10
x + 2y = 7
```

Step 1: Divide the first equation by 2.

```text
x + 2y = 5
x + 2y = 7
```

Step 2: Both left sides match, but constants differ.

Step 3: These are parallel lines.

Answer: **No solution** — an inconsistent system.

## Why This Works

Each equation is a condition. Solving a system finds values that satisfy every condition at once.

[[substitution]] works because if `y = 2x + 1` is true, you may replace `y` anywhere else without changing meaning. [[elimination]] works because adding equal amounts to equal amounts keeps balance, just like balancing a single equation.

If both methods give the same `(x, y)` and that pair checks in both originals, the system is [[consistent system|consistent]].

## Worked Examples

For fully worked solutions, use [[2.8 Simultaneous Equations - Worked Examples]].

### Example 1 - Substitution
Question: Solve `y = 3x - 2` and `2x + y = 13`.

Solution:

```text
2x + (3x - 2) = 13
5x = 15
x = 3
y = 3(3) - 2 = 7
```

Answer: `x = 3`, `y = 7`.

### Example 2 - Elimination
Question: Solve `4x + y = 14` and `2x - y = 4`.

Solution: Add the equations.

```text
6x = 18
x = 3
2(3) - y = 4
y = 2
```

Answer: `x = 3`, `y = 2`.

### Example 3 - CS constraint system
Question: A program needs `width + height = 100` and `width - height = 20`. Find both values.

Solution:

```text
width + height = 100
width - height =  20
-----------------------
2(width) = 120
width = 60
height = 40
```

Answer: `width = 60`, `height = 40`.

## Common Mistakes

- Solving each equation separately and stopping with two different answers.
- Substituting into the same equation you rearranged, which gives no new information.
- Forgetting to multiply **every term** when scaling an equation for elimination.
- Sign errors when subtracting one entire equation from another.
- Checking only one original equation after finding values.
- Assuming every system has exactly one solution.

> [!failure] Mistake pattern
> If you get `0 = 0`, the equations represent the same line. If you get `0 = 5`, the system is inconsistent.

## Where This Shows Up in CS

Simultaneous equations appear in:

- **layout engines** — solving width and height under fixed total area
- **graphics** — finding where two lines or rays intersect
- **linear algebra** — systems become matrices later in the course ([[10.3 Matrix Methods]])
- **resource allocation** — budgets and capacity limits that must both hold
- **network routing** — flow balance equations at junction nodes

```python
# Two constraints: total = 100, difference = 20
# width + height = 100
# width - height = 20
width = (100 + 20) / 2   # 60
height = width - 20      # 40
```

The code is doing elimination in plain arithmetic.
