## Introduction

An **index** (or **exponent**) counts how many times the **base** is multiplied by itself. `2^4 = 2 × 2 × 2 × 2 = 16`. Powers are a compact way to write repeated multiplication.

A **square** is exponent 2 (a grid of side × side). A **cube** is exponent 3. The **index laws** are rules for combining powers: add exponents when multiplying with the same base, subtract when dividing, multiply when raising a power to another power.

> [!example] Everyday idea
> If one sheet of paper is folded in half repeatedly, the number of layers doubles each fold. After 4 folds there are `2^4 = 16` layers.

## New Words

- [[base]] — the number (or expression) being multiplied repeatedly.
- [[exponent]] — the index that tells how many times the base is used in the multiplication.
- [[square]] — a power with exponent 2; the base multiplied by itself once.
- [[cube]] — a power with exponent 3; the base multiplied by itself twice more.
- [[index laws]] — rules for simplifying expressions with powers, such as multiplying and dividing with the same base.

## Breadcrumbs

### Breadcrumb 1: Repeated Multiplication as a Power

**Builds on:** [[1.4 Breadcrumb 1|Multiplication as Equal Groups]] (multiplying the same number repeatedly)

The expression `a^n` means multiply `a` by itself `n` times.

```text
5^3 = 5 × 5 × 5 = 125
```

Here:

```text
base = 5
exponent = 3
```

> [!important] Exponent counts factors
> In `2^5`, there are five factors of 2, not two factors of 5.

#### Chunked Example
Question: Evaluate `4^3`.

Step 1: Identify base and exponent.

```text
base = 4, exponent = 3
```

Step 2: Expand.

```text
4^3 = 4 × 4 × 4
```

Step 3: Multiply.

```text
16 × 4 = 64
```

Answer: **64**.

---

### Breadcrumb 2: Squares and Cubes

**Builds on:** [[2.9 Breadcrumb 1|Repeated Multiplication as a Power]] (special cases), [[1.4 Breadcrumb 3|Multiplication as Arrays]] (area = side²)

A [[square]] uses exponent 2:

```text
7^2 = 49   "seven squared"
```

A [[cube]] uses exponent 3:

```text
3^3 = 27   "three cubed"
```

Square numbers appear in grid sizes and pixel areas. Cubes appear in 3D volume scaling.

#### Chunked Example
Question: A game tile grid is 8 × 8. Write the area using a square.

Step 1: Area = side × side.

```text
8 × 8 = 8^2
```

Step 2: Evaluate.

```text
8^2 = 64
```

Answer: The grid has **64** cells, written as **8²**.

---

### Breadcrumb 3: Multiplying Powers With the Same Base

**Builds on:** [[2.9 Breadcrumb 1|Repeated Multiplication as a Power]] (combining factor counts)

One [[index laws|index law]] says:

```text
a^m × a^n = a^(m+n)
```

You are combining the factor counts.

Example:

```text
2^3 × 2^4 = 2^(3+4) = 2^7 = 128
```

> [!tip] Same base required
> You may add exponents only when the bases match.

#### Chunked Example
Question: Simplify `3^2 × 3^5`.

Step 1: Same base 3.

Step 2: Add exponents.

```text
3^(2+5) = 3^7
```

Step 3: Evaluate if needed.

```text
3^7 = 2187
```

Answer: **3^7** or **2187**.

---

### Breadcrumb 4: Dividing Powers With the Same Base

**Builds on:** [[2.9 Breadcrumb 3|Multiplying Powers With the Same Base]] (inverse operation)

Another index law:

```text
a^m ÷ a^n = a^(m-n)
```

Example:

```text
5^6 ÷ 5^2 = 5^4 = 625
```

#### Chunked Example
Question: Simplify `2^8 ÷ 2^3`.

Step 1: Same base 2.

Step 2: Subtract exponents.

```text
2^(8-3) = 2^5
```

Step 3: Evaluate.

```text
2^5 = 32
```

Answer: **32**.

---

### Breadcrumb 5: Power of a Power

**Builds on:** [[2.9 Breadcrumb 3|Multiplying Powers With the Same Base]] (multiplying exponents extends the rule)

When a power is raised to another power, multiply the exponents:

```text
(a^m)^n = a^(mn)
```

Example:

```text
(2^3)^2 = 2^6 = 64
```

#### Chunked Example
Question: Simplify `(5^2)^3`.

Step 1: Multiply exponents.

```text
5^(2×3) = 5^6
```

Step 2: Evaluate.

```text
5^6 = 15625
```

Answer: **5^6** or **15625**.

---

### Breadcrumb 6: Powers of 2 and Binary Sizes

**Builds on:** [[2.9 Breadcrumb 1|Repeated Multiplication as a Power]] (2^n as repeated doubling)

Computers use powers constantly.

Memory sizes follow powers of 2:

```text
2^10 = 1024   (often called 1 KB in CS contexts)
2^20 ≈ 1 million bytes scale step
```

Powers of 10 help with place value:

```text
10^3 = 1000
10^6 = 1 000 000
```

> [!example] CS connection
> If each additional bit doubles the number of patterns, `n` bits can represent `2^n` distinct values.

```text
3 bits → 2^3 = 8 patterns
8 bits → 2^8 = 256 patterns
```

#### Chunked Example
Question: How many distinct values can 4 bits represent?

Step 1: Each bit doubles the count.

```text
2 × 2 × 2 × 2 = 2^4
```

Step 2: Evaluate.

```text
2^4 = 16
```

Answer: **16** distinct values.

## Why This Works

Powers count repeated multiplication. The [[index laws]] work because multiplying adds more copies of the base, and dividing removes copies.

For example:

```text
2^3 × 2^4 = (2×2×2) × (2×2×2×2) = 2^7
```

Seven factors of 2 appear in total. This is the same counting idea as equal groups, but written compactly.

## Common Mistakes

- Multiplying the base and exponent: `2^3 ≠ 6`.
- Adding exponents when bases differ: `2^3 × 3^2` cannot become `6^5`.
- Forgetting that `a^1 = a` and `a^0 = 1` for `a ≠ 0`.
- Confusing `(2^3)^2` with `2^3^2` — use brackets.
- Treating `2^10` as 20 instead of 1024.
- Evaluating too early when the question asks for simplified index form.

> [!failure] Mistake pattern
> `(2^3)^2 = 2^6 = 64`, but `2^3^2 = 2^9 = 512` because exponentiation binds differently without brackets.

## Where This Shows Up in CS

Indices and powers appear in:

- **binary representation** — `n` bits give `2^n` patterns
- **memory and storage** — kilo/mega/giga as powers of 2 or 10
- **algorithm analysis** — doubling loops, exponential search spaces
- **exponential growth** — user counts, compound updates
- **scientific notation** — very large or small numbers

```python
# 32-bit unsigned max value
max_value = 2**32 - 1   # 4294967295
```
