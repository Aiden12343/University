## Introduction

A **quadratic function** has a squared term as its highest power, written `y = ax² + bx + c`. The graph is a **parabola** — a U-shaped curve. The **quadratic coefficient** `a` controls direction (up or down) and width. The **roots** are where the graph crosses the x-axis (y = 0). The **turning point** is the curve's minimum or maximum, and the **axis of symmetry** is the vertical line through it.

Linear graphs are straight because each step in x adds the same amount to y. Quadratic graphs curve because the squared term makes the change itself change.

> [!example] Everyday idea
> If a ball is thrown upward, its height rises, slows down, turns, then falls. A simple model for that path is quadratic: the graph has a highest point and bends smoothly.

## New Words

- [[parabola]] — the U-shaped curve made by a quadratic function.
- [[turning point]] — the point where the curve changes from going down to going up, or from going up to going down.
- [[roots]] — the x-values where the function equals zero.
- [[axis of symmetry]] — the vertical line through the turning point that splits the parabola into two matching halves.
- [[quadratic coefficient]] — the number multiplying x squared in a quadratic expression.

## Breadcrumbs

### Breadcrumb 1: Recognising a Quadratic

**Builds on:** [[2.9 Breadcrumb 2|Squares and Cubes]] (x² means x × x), [[3.3 Breadcrumb 1|The Form y = mx + c]] (linear extends to quadratic)

A quadratic function has a squared term as its highest power of x:

```text
y = ax² + bx + c
```

- **a** is the [[quadratic coefficient]]
- **b** multiplies x
- **c** is the y-intercept (x = 0 gives y = c)
- a must not be 0, otherwise the x² term disappears

> [!important] Highest power decides the family
> If the highest power is x², it is quadratic. If the highest power is x, it is linear.

#### Chunked Example
Question: Which of these are quadratic?

```text
A: y = 3x² - 2x + 1
B: y = 5x - 8
C: y = 4 - x²
D: y = x³ + x
```

Step 1: Look for x². A and C have x².

Step 2: D has highest power 3, not quadratic. B has highest power 1, linear.

Answer: **A and C are quadratic**.

### Breadcrumb 2: The Parabola Shape

**Builds on:** [[3.4 Breadcrumb 1|Recognising a Quadratic]] (a determines shape), [[3.1 Breadcrumb 3|Negative Coordinates]] (negative x² opens down)

The graph of a quadratic function is a [[parabola]].

If `a > 0`, the parabola opens upward:

```mermaid
xychart-beta
  x-axis "x" [-3, -2, -1, 0, 1, 2, 3]
  y-axis "y" 0 --> 10
  line [9, 4, 1, 0, 1, 4, 9]
```

If `a < 0`, the parabola opens downward:

```mermaid
xychart-beta
  x-axis "x" [-3, -2, -1, 0, 1, 2, 3]
  y-axis "y" -10 --> 0
  line [-9, -4, -1, 0, -1, -4, -9]
```

The [[quadratic coefficient]] controls direction and width:

- larger absolute value of a → narrower
- smaller absolute value of a → wider
- positive a → opens upward
- negative a → opens downward

> [!warning] Do not read a as "the height"
> The value of a controls shape. It is not the y-intercept and not the turning point.

#### Chunked Example
Question: Describe the shape of `y = -2x² + 3x + 4`.

Step 1: a = -2. Negative → opens downward.

Step 2: |a| = 2, narrower than y = -x².

Answer: **Downward-opening parabola**, narrower than `y = -x²`.

### Breadcrumb 3: Roots and x-Intercepts

**Builds on:** [[3.4 Breadcrumb 1|Recognising a Quadratic]] (finding roots), [[2.4 Breadcrumb 3|Factor Pairs for Quadratics]] (factorise to find roots), [[2.5 Breadcrumb 1|Equations Are Balanced Statements]] (set y = 0)

The [[roots]] of a quadratic are the x-values that make y equal 0. On the graph, roots are where the parabola crosses the x-axis.

For `y = (x - 2)(x + 3)`, the product is zero when either bracket is zero:

```text
x - 2 = 0  or  x + 3 = 0
x = 2      or  x = -3
```

> [!important] Zero product rule
> If two factors multiply to 0, at least one factor must be 0.

#### Chunked Example
Question: Find the roots of `y = (x + 4)(x - 1)`.

Step 1: Set y = 0 → (x + 4)(x - 1) = 0.

Step 2: Set each bracket to zero: x + 4 = 0, x - 1 = 0.

Answer: The roots are **x = -4** and **x = 1**.

### Breadcrumb 4: Expanding and Factorising Forms

**Builds on:** [[3.4 Breadcrumb 1|Recognising a Quadratic]] (two forms of the same function), [[2.3 Breadcrumb 5|Expanding Double Brackets]] (brackets → expanded), [[2.4 Breadcrumb 3|Factor Pairs for Quadratics]] (expanded → brackets)

The same quadratic can be written in different forms.

Expanded form:

```text
y = x² + 3x + 2
```

Factorised form:

```text
y = (x + 1)(x + 2)
```

They are equivalent — expanding the factorised form gives the expanded form:

```text
(x + 1)(x + 2) = x² + 2x + x + 2 = x² + 3x + 2
```

Factorised form is useful for roots. Expanded form is useful for reading the y-intercept.

#### Chunked Example
Question: Factorise `x² + 5x + 6`, then find the roots.

Step 1: Two numbers that multiply to 6 and add to 5: 2 and 3.

```text
x² + 5x + 6 = (x + 2)(x + 3)
```

Step 2: Set each bracket to zero: x = -2, x = -3.

Answer: `(x + 2)(x + 3)`, roots **-2** and **-3**.

### Breadcrumb 5: Turning Point and Axis of Symmetry

**Builds on:** [[3.4 Breadcrumb 3|Roots and x-Intercepts]] (roots give the axis), [[3.1 Breadcrumb 2|Reading a Coordinate Pair]] (midpoint of two x-values)

The [[turning point]] is the lowest point of an upward-opening parabola or the highest point of a downward-opening parabola.

The [[axis of symmetry]] is the vertical line through that turning point.

If the roots are r₁ and r₂, the axis of symmetry is halfway between them:

```text
axis x = (r₁ + r₂) / 2
```

> [!important] The axis is a line, not a point
> Write the axis as `x = number`, not just the number.

#### Chunked Example
Question: `y = (x - 2)(x - 6)`. Find the axis of symmetry and turning point.

Step 1: Roots: x = 2 and x = 6.

Step 2: Halfway x = (2 + 6) / 2 = 4.

Step 3: Substitute x = 4: y = (4 - 2)(4 - 6) = 2(-2) = -4.

Answer: Axis of symmetry **x = 4**. Turning point **(4, -4)**.

### Breadcrumb 6: Solving Quadratics by Factorising

**Builds on:** [[3.4 Breadcrumb 4|Expanding and Factorising Forms]] (factorise first), [[2.5 Breadcrumb 3|One-Step Equations]] (solving linear equations)

To solve a quadratic equation by factorising:

1. Put everything on one side, other side 0.
2. Factorise.
3. Use the zero product rule.
4. Check by substitution.

> [!warning] Do not divide by x unless you know x ≠ 0
> Dividing by x can lose the solution x = 0. Factorise instead.

#### Chunked Example
Question: Solve `x² - 7x = 0`.

Step 1: Factor out x: `x(x - 7) = 0`.

Step 2: Zero product rule: x = 0 or x - 7 = 0.

Answer: **x = 0** or **x = 7**.

### Breadcrumb 7: Quadratics in CS Models

**Builds on:** [[3.4 Breadcrumb 1|Recognising a Quadratic]] (shape models), [[3.3 Breadcrumb 2|Gradient as Rate of Change]] (quadratic growth is faster than linear)

Quadratics appear when a quantity depends on a square, a pairwise interaction, or a curved cost:

- physics simulation: height over time under gravity
- animation: easing curves for smooth motion
- optimisation: simple loss curves with a best value
- algorithms: nested loops produce quadratic growth

```python
# Nested loop: roughly n² comparisons
for i in range(n):
    for j in range(n):
        compare(items[i], items[j])
```

#### Chunked Example
Question: A simple animation uses `h(t) = -t² + 4t` for height. When is the height 0?

Step 1: Set height = 0: `-t² + 4t = 0`.

Step 2: Factorise: `t(-t + 4) = 0`.

Step 3: t = 0 or -t + 4 = 0 → t = 4.

Answer: Height 0 at **t = 0** and **t = 4**.

## Why This Works

A quadratic bends because the squared input changes faster as the input moves away from zero. When x gets larger, x² grows more quickly than x.

The graph is symmetrical because equal distances to the left and right of the axis give matching squared distances. For `y = x²`, both x = 3 and x = -3 give 9.

The root method works because of the zero product rule: if `(x - 2)(x + 3) = 0`, then one bracket must be zero.

The turning point calculation from two roots works because the axis of symmetry lies halfway between the roots.

## Common Mistakes

- Calling `y = 4x + 2` quadratic (highest power is 1, so it is linear).
- Thinking roots are y-intercepts (roots are where y = 0; intercept is where x = 0).
- Forgetting the zero product rule and solving only one bracket.
- Writing the axis of symmetry as a point instead of a line (`x = ...`).
- Dividing `x² - 7x = 0` by x and losing x = 0.

> [!failure] Mistake pattern
> If your sketch and algebra disagree, check the sign of a, the roots, and one substituted point.

## Where This Shows Up in CS

Quadratics appear in optimisation, physics, animation, graphics, and algorithm analysis.

In machine learning, a simple squared-error loss has a bowl shape. Gradient descent tries to move toward the bottom of such a curve.
