## Introduction

A **polynomial** is an expression made by adding powers of a variable with non-negative whole-number exponents, such as `4x³ - 2x² + x - 9`. The **degree** is the highest power. The **leading term** is the term with that highest power. The **coefficient** is the number multiplying each variable term. A **root** is an input that makes the polynomial zero.

Quadratics are polynomials of degree 2. This topic widens the view to cubic, quartic, and higher-degree expressions.

> [!example] Everyday idea
> A straight line has one kind of change, a quadratic curve bends once, and higher-degree polynomials can create richer curves.

## New Words

- [[polynomial]] — a sum of terms with non-negative whole-number powers of a variable.
- [[degree]] — the highest power of the variable in a polynomial.
- [[coefficient]] — the number multiplying a variable or power.
- [[root]] — a value of the variable that makes the polynomial equal zero.
- [[leading term]] — the highest-degree term when the polynomial is written in standard order.

## Breadcrumbs

### Breadcrumb 1: What Counts as a Polynomial

**Builds on:** [[3.4 Breadcrumb 1|Recognising a Quadratic]] (quadratic is a degree-2 polynomial), [[2.9 Breadcrumb 1|Repeated Multiplication as a Power]] (powers must be whole)

A polynomial is built from terms like:

```text
7, 3x, -2x², x⁵
```

These terms are allowed because the powers of x are non-negative whole numbers: 0, 1, 2, 3, ...

**Polynomials:**

```text
4x³ - 2x² + x - 9
x² + 5
8
```

**Not polynomials:**

```text
1/x       (x⁻¹, negative power)
√x        (x¹/², fractional power)
2^x       (variable in the exponent)
```

> [!important] Polynomial powers must be whole and non-negative

#### Chunked Example
Question: Which of these are polynomials? A: 5x⁴ - 3x + 2, B: 6/x + 1, C: 4x² + √x, D: 9.

Step 1: A has powers 4, 1, 0 — polynomial.

Step 2: B has 6/x = 6x⁻¹ — not polynomial.

Step 3: C has √x = x¹/² — not polynomial.

Step 4: D = 9x⁰ — constant polynomial.

Answer: **A and D** are polynomials.

### Breadcrumb 2: Terms and Coefficients

**Builds on:** [[3.5 Breadcrumb 1|What Counts as a Polynomial]] (recognise terms), [[2.1 Breadcrumb 2|Expressions vs Equations]] (variables with coefficients)

A polynomial is a sum of terms.

In `4x³ - 2x² + 7x - 5`, the terms are: 4x³, -2x², 7x, -5.

The [[coefficient]] is the number multiplying the variable part:

- 4 is the coefficient of x³
- -2 is the coefficient of x²
- 7 is the coefficient of x
- -5 is the constant term

> [!warning] Keep the sign with the coefficient
> In `4x³ - 2x²`, the coefficient of x² is **-2**, not 2.

#### Chunked Example
Question: List the terms and coefficients of `-3x⁴ + x² - 8x + 6`.

Step 1: Terms: -3x⁴, x², -8x, 6. Coefficients: -3, 1, -8, 6. Missing x³ coefficient is 0.

Answer: Terms: **-3x⁴, x², -8x, 6**. Coefficients: **-3, 1, -8, 6**.

---

### Breadcrumb 3: Degree and Leading Term

**Builds on:** [[3.5 Breadcrumb 2|Terms and Coefficients]] (identify highest power), [[3.4 Breadcrumb 1|Recognising a Quadratic]] (quadratic has degree 2)

The [[degree]] of a polynomial is the highest power of x with a non-zero coefficient. The [[leading term]] is the term with that highest power.

```text
2x⁵ - 4x³ + x - 1
```

Degree: 5. Leading term: 2x⁵.

> [!important] Zero coefficients do not count
> `0x⁷ + 3x⁴ + 2` has degree 4, not 7.

#### Chunked Example
Question: Find the degree and leading term of `-6x + 2x⁴ - x² + 11`.

Step 1: Rewrite: 2x⁴ - x² - 6x + 11.

Step 2: Highest power = 4.

Answer: Degree **4**, leading term **2x⁴**.

### Breadcrumb 4: Adding and Subtracting Polynomials

**Builds on:** [[3.5 Breadcrumb 2|Terms and Coefficients]] (like terms have same power), [[2.2 Breadcrumb 4|Collecting Like Terms to Simplify]] (same rule, more powers)

To add or subtract polynomials, combine like terms. Like terms have the same variable to the same power.

> [!example] Column method
> Line up powers like place-value columns. x³ terms go with x³, x² with x², constants with constants.

#### Chunked Example
Question: Simplify `(3x³ - 2x² + x - 4) + (x³ + 5x² - 7x + 9)`.

Group like terms: (3x³ + x³) + (-2x² + 5x²) + (x - 7x) + (-4 + 9).

Answer: **4x³ + 3x² - 6x + 5**.

---

### Breadcrumb 5: Multiplying Polynomials

**Builds on:** [[3.5 Breadcrumb 4|Adding and Subtracting Polynomials]] (combine results), [[2.3 Breadcrumb 5|Expanding Double Brackets]] (every term × every term), [[2.9 Breadcrumb 3|Multiplying Powers With the Same Base]] (x × x² = x³)

To multiply polynomials, every term in one must multiply every term in the other.

```text
(x + 2)(x² + 3x + 4) = x(x² + 3x + 4) + 2(x² + 3x + 4)
```

> [!warning] Every term must meet every term

#### Chunked Example
Question: Expand `(x - 3)(x² + 2x + 5)`.

Step 1: x(x² + 2x + 5) = x³ + 2x² + 5x.

Step 2: -3(x² + 2x + 5) = -3x² - 6x - 15.

Step 3: Combine: x³ - x² - x - 15.

Answer: **x³ - x² - x - 15**.

---

### Breadcrumb 6: Roots of Polynomials

**Builds on:** [[3.5 Breadcrumb 1|What Counts as a Polynomial]] (factorise to find roots), [[3.4 Breadcrumb 3|Roots and x-Intercepts]] (zero product rule)

A [[root]] of a polynomial is an input value that makes the output zero.

For `p(x) = x³ - 4x`:

```text
p(x) = x(x² - 4) = x(x - 2)(x + 2)
```

Roots: x = 0, x = 2, x = -2.

> [!important] Roots are inputs, not points. The graph point is (root, 0).

#### Chunked Example
Question: Find the roots of `p(x) = x³ + 3x²`.

Step 1: Factor: x²(x + 3).

Step 2: x² = 0 → x = 0. x + 3 = 0 → x = -3.

Answer: Roots are **x = 0** and **x = -3**.

### Breadcrumb 7: Leading-Term Behaviour

**Builds on:** [[3.5 Breadcrumb 3|Degree and Leading Term]] (highest power dominates), [[3.4 Breadcrumb 7|Quadratics in CS Models]] (leading term controls growth)

For large values of x, the [[leading term]] dominates the shape.

For `p(x) = 2x⁵ - 100x + 3`, when x is large, `2x⁵` dwarfs `-100x + 3`.

This prepares for [[10.1 Big O Theta and Omega]]:

```text
3n² + 20n + 100 behaves like n² for large n
```

#### Chunked Example
Question: Which term dominates `7n⁴ - 1000n² + 6n + 12` for large n?

Highest power: n⁴. Leading term: 7n⁴. Growth: quartic.

Answer: **7n⁴** dominates.

### Breadcrumb 8: Polynomials in CS

**Builds on:** [[3.5 Breadcrumb 7|Leading-Term Behaviour]] (growth modelling), [[2.3 Breadcrumb 6|Loop Unrolling in CS]] (expressions in code)

Polynomials appear in interpolation, error correction, graphics Bezier curves, and algorithm complexity.

```text
T(n) = 3n² + 5n + 20
```

This might model a program with one nested-loop part, one single-loop part, and fixed setup cost.

#### Chunked Example
Question: A program's operation count is `T(n) = 2n³ + 5n² + 9`. What is its leading-term growth?

Degree = 3. Leading term = 2n³. Cubic growth.

Answer: **Cubic**, controlled by **2n³**.

## Why This Works

Polynomials work because each term is a scaled power of the same variable. Powers must be whole numbers — fractional exponents break the structure.

The degree matters because higher powers grow faster for large inputs. That is why `x⁵` eventually becomes larger than `1000x`.

Multiplication works by distribution. Roots work by the zero product rule.

## Common Mistakes

- Calling `1/x + 2` a polynomial (x⁻¹ is not allowed).
- Forgetting invisible coefficients: `x⁴` has coefficient 1.
- Dropping negative signs when listing terms.
- Combining unlike terms: `x³ + x²` cannot become `x⁵`.
- Multiplying only matching positions in brackets.
- Thinking the largest coefficient controls long-term growth (the highest power does).

> [!failure] Mistake pattern
> If a polynomial simplification changes degree unexpectedly, check whether you combined unlike powers.

## Where This Shows Up in CS

Polynomials appear in algorithms, graphics, numerical computing, and reliable storage.

In QR codes and storage systems, polynomial arithmetic adds redundancy so damaged data can be reconstructed.
