- [[5.8 Boolean Algebra and De Morgan Laws]] - Boolean algebra optimises conditions, circuits, and search queries.
- [[5.9 Direct Proof and Counterexample]] - Algorithm correctness begins with proof habits.
- [[5.10 Proof by Contradiction and Contrapositive]] - Many CS impossibility and security arguments use these proof styles.
- [[5.11 Proof by Induction]] - Induction proves loops, recursion, data structures, and algorithms correct.
