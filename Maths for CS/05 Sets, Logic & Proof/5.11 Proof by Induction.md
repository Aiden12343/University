## Introduction

Proof by induction is the standard method for proving statements about all natural numbers (or any well-ordered set). It has two parts: the **base case** (prove the statement for the smallest number) and the **inductive step** (prove that if it holds for k, it holds for k+1).

Induction is the proof twin of **recursion**: recursive algorithms are defined in terms of smaller instances of themselves, and induction proves those definitions correct. Every computer scientist needs induction to analyse loops, recurrence relations, tree algorithms, and recursive functions.

## New Words

- [[induction]] — a proof method: prove base case and inductive step to show a statement for all natural numbers.
- [[induction hypothesis]] — the assumption that the statement holds for n = k in the inductive step.
- [[inductive step]] — the proof that if the statement holds for k, it holds for k+1.
- [[base case]] — the smallest case (usually n = 1) proven directly.
- [[recursive definition]] — defining something in terms of itself, the counterpart to induction.
- [[strong induction]] — induction where the hypothesis assumes the statement for all smaller values, not just k.

## Breadcrumbs

### Breadcrumb 1: The Principle of Mathematical Induction

**Builds on:** [[1.1 Breadcrumb 5|Counting by Powers of 2]] (natural numbers ℕ), [[5.9 Breadcrumb 2|Direct Proof Structure]] (proof format), [[5.7 Breadcrumb 5|Modus Ponens and Modus Tollens]] (P(k) → P(k+1))

If P(n) is a statement about natural numbers, and:
1. P(1) is true (base case)
2. For all k ≥ 1, P(k) → P(k+1) (inductive step)

Then P(n) is true for all n ∈ ℕ.

> [!important] Induction requires both steps
> Without the base case, the inductive step proves nothing (you have nothing to start from). Without the inductive step, only the base case is proven.

### Chunked Example
Question: Prove the sum of the first n natural numbers equals n(n+1)/2.

Base case (n=1): Sum = 1. Formula: 1(1+1)/2 = 1. ✓

Inductive step: Assume sum up to k = k(k+1)/2.
Prove sum up to k+1 = (k+1)(k+2)/2.

Step 1: Sum up to k+1 = (sum up to k) + (k+1).
Step 2: = k(k+1)/2 + (k+1).
Step 3: = (k+1)[k/2 + 1] = (k+1)(k+2)/2. ✓

Answer: By induction, the formula holds for all n.

### Breadcrumb 2: Summation Formulas

**Builds on:** [[5.11 Breadcrumb 1|The Principle of Mathematical Induction]] (technique), [[2.2 Breadcrumb 1|Collecting Like Terms]] (algebraic manipulation)

Induction proves summation formulas elegantly. Structure:
1. Base case: n = 1 (or n = 0).
2. Inductive hypothesis: assume formula true for n = k.
3. Inductive step: add the (k+1)-th term to both sides.

### Chunked Example
Question: Prove that 1 + 3 + 5 + ... + (2n-1) = n² (sum of first n odd numbers).

Base (n=1): 1 = 1². ✓

Inductive hypothesis: 1+3+...+(2k-1) = k².

Inductive step: Add (2(k+1)-1) = 2k+1 to both sides:
Left: 1+3+...+(2k-1)+(2k+1).
Right: k² + (2k+1) = (k+1)². ✓

Answer: By induction, sum of first n odd numbers = **n²**.

### Breadcrumb 3: Divisibility Proofs

**Builds on:** [[5.11 Breadcrumb 1|The Principle of Mathematical Induction]] (technique), [[1.4 Breadcrumb 1|What Are Factors?]] (divisibility concept)

Induction can prove divisibility statements.

### Chunked Example
Question: Prove that 7ⁿ - 2ⁿ is divisible by 5 for all n ≥ 1.

Base (n=1): 7¹ - 2¹ = 5. Divisible by 5. ✓

Inductive hypothesis: 7^k - 2^k = 5m (divisible by 5).

Inductive step: Show 7^{k+1} - 2^{k+1} is divisible by 5.
Step 1: 7^{k+1} - 2^{k+1} = 7·7^k - 2·2^k.
Step 2: = 5·7^k + 2·7^k - 2·2^k.
Step 3: = 5·7^k + 2(7^k - 2^k).
Step 4: = 5·7^k + 2(5m) = 5(7^k + 2m).
Step 5: This is a multiple of 5. ✓

Answer: By induction, 7ⁿ - 2ⁿ is **divisible by 5** for all n.

### Breadcrumb 4: Inequality Proofs

**Builds on:** [[5.11 Breadcrumb 2|Summation Formulas]] (algebraic manipulation), [[2.4 Breadcrumb 1|Inequality Notation]] (inequalities)

Induction handles inequalities, often used in algorithm complexity analysis.

### Chunked Example
Question: Prove 2ⁿ > n for all n ≥ 1.

Base (n=1): 2¹ = 2 > 1. ✓

Inductive hypothesis: 2^k > k.

Inductive step: Show 2^{k+1} > k+1.
Step 1: 2^{k+1} = 2·2^k > 2k (by inductive hypothesis).
Step 2: 2k = k + k ≥ k + 1 (since k ≥ 1).
Step 3: So 2^{k+1} > k + 1. ✓

Answer: By induction, 2ⁿ > n for all n ≥ 1.

### Breadcrumb 5: Induction on Recursive Definitions

**Builds on:** [[5.11 Breadcrumb 1|The Principle of Mathematical Induction]] (technique), [[5.11 Breadcrumb 4|Inequality Proofs]] (calculations with induction)

Many CS concepts (factorials, Fibonacci, tree data structures) are defined recursively. Induction is the natural proof method for them.

**Factorial**: 0! = 1, n! = n × (n-1)!
**Fibonacci**: F₀ = 0, F₁ = 1, F_n = F_{n-1} + F_{n-2}

### Chunked Example
Question: Prove that n! ≥ 2^{n-1} for all n ≥ 1.

Base (n=1): 1! = 1 ≥ 2^{0} = 1. ✓

Inductive hypothesis: k! ≥ 2^{k-1}.

Inductive step: (k+1)! = (k+1)·k! ≥ (k+1)·2^{k-1} ≥ 2·2^{k-1} = 2^k. ✓

Answer: By induction, n! ≥ **2^{n-1}** for all n ≥ 1.

### Breadcrumb 6: Strong Induction

**Builds on:** [[5.11 Breadcrumb 1|The Principle of Mathematical Induction]] (weak induction foundation), [[5.9 Breadcrumb 3|Proving Universal Statements]] (arbitrary element reasoning)

Strong induction allows the inductive hypothesis to assume the statement for ALL smaller values, not just k.

To prove P(n) for all n:
1. Base case(s): prove P(1), P(2), ..., P(b).
2. Inductive step: assume P(1), P(2), ..., P(k) all true, then prove P(k+1).

This is used when P(k+1) depends on values before k (not just k itself).

### Chunked Example
Question: Prove that every integer n ≥ 2 can be written as a product of primes.

Base (n=2): 2 is prime. ✓

Strong inductive hypothesis: Assume true for all 2 ≤ m ≤ k.

Inductive step (n = k+1):
- If k+1 is prime, done.
- If k+1 is composite: k+1 = a·b where 2 ≤ a,b ≤ k.
- By strong hypothesis, a and b are products of primes.
- So k+1 = (product of primes) × (product of primes) = product of primes. ✓

Answer: By strong induction, every integer n ≥ 2 has a **prime factorisation**.

## Worked Examples

### Example 1 — Summation Formula

Question: Prove by induction that for all n ≥ 1, 1 + 4 + 7 + ... + (3n − 2) = n(3n − 1)/2.

Step 1 (Base case n = 1): LHS = 3(1) − 2 = 1. RHS = 1(3·1 − 1)/2 = 2/2 = 1. ✓

Step 2 (Inductive hypothesis): Assume for n = k: 1 + 4 + ... + (3k − 2) = k(3k − 1)/2.

Step 3 (Inductive step — prove for n = k+1):
LHS_{k+1} = [1 + 4 + ... + (3k − 2)] + (3(k+1) − 2)
= k(3k − 1)/2 + (3k + 1)
= [k(3k − 1) + 2(3k + 1)] / 2
= [3k² − k + 6k + 2] / 2
= [3k² + 5k + 2] / 2
= (k+1)(3k + 2) / 2
= (k+1)(3(k+1) − 1) / 2 = RHS_{k+1}. ✓

Answer: By induction, the formula holds for all n ≥ 1.

### Example 2 — Sum of Odd Numbers

Question: Prove by induction that the sum of the first n odd numbers equals n²: 1 + 3 + 5 + ... + (2n − 1) = n².

Step 1 (Base n = 1): 1 = 1². ✓

Step 2 (Inductive hypothesis): Assume 1 + 3 + ... + (2k − 1) = k².

Step 3 (Inductive step): Add the (k+1)-th odd number, which is 2(k+1) − 1 = 2k + 1:
LHS_{k+1} = k² + (2k + 1) = (k² + 2k + 1) = (k + 1)² = RHS_{k+1}. ✓

Answer: By induction, 1 + 3 + ... + (2n − 1) = **n²** for all n ≥ 1.

### Example 3 — Divisibility Proof

Question: Prove by induction that 6ⁿ − 1 is divisible by 5 for all n ≥ 1.

Step 1 (Base n = 1): 6¹ − 1 = 5, which is divisible by 5. ✓

Step 2 (Inductive hypothesis): Assume 6^k − 1 = 5m for some integer m (i.e., divisible by 5).

Step 3 (Inductive step): Show 6^{k+1} − 1 is divisible by 5.
6^{k+1} − 1 = 6·6^k − 1
= 6·(6^k − 1) + 6 − 1
= 6·(5m) + 5
= 5(6m + 1).
This is a multiple of 5. ✓

Answer: By induction, **6ⁿ − 1 is divisible by 5** for all n ≥ 1.

### Example 4 — Inequality Proof

Question: Prove by induction that 2ⁿ ≥ n + 1 for all n ≥ 1.

Step 1 (Base n = 1): 2¹ = 2 ≥ 1 + 1 = 2. ✓ (Equality holds.)

Step 2 (Inductive hypothesis): Assume 2^k ≥ k + 1 for some k ≥ 1.

Step 3 (Inductive step): Show 2^{k+1} ≥ (k+1) + 1 = k + 2.
2^{k+1} = 2·2^k ≥ 2·(k + 1) (by inductive hypothesis)
= 2k + 2
= (k + 2) + k.
Since k ≥ 1, (k + 2) + k ≥ k + 2. Therefore 2^{k+1} ≥ k + 2. ✓

Answer: By induction, **2ⁿ ≥ n + 1** for all n ≥ 1.

## Why This Works
Induction works because the natural numbers are well-ordered (every non-empty subset has a least element). If the statement failed for some n, there would be a smallest counterexample m. By the inductive step, since P(m-1) is true, P(m) must also be true — contradiction. So no counterexample exists.

This connects back to [[1.1 Counting and Number Sense]] — induction is like counting with a guarantee — and to [[5.9 Direct Proof and Counterexample]], since induction is a special case of direct proof (from P(k) prove P(k+1)).

## Common Mistakes
1. Forgetting the base case (inductive step needs somewhere to start).
2. Using the wrong base case (n = 0 vs n = 1 — check the domain).
3. Assuming P(k+1) before proving it (circular).
4. Using the inductive hypothesis incorrectly (applying it to the wrong expression).
5. Proving only the inductive step and forgetting the base.
6. Applying induction to non-integer sequences.

> [!failure] Mistake pattern
> "To prove P(k+1), I just need to add the next term. P(k) is true, so P(k+1) is automatically true" — this skips the algebraic manipulation that connects P(k) to P(k+1). Write out the steps.

## Where This Shows Up in CS
- **Algorithm analysis**: proving loop invariants, recurrence relations
- **Data structures**: proving tree properties (height, size, balance) by induction on structure
- **Recursive functions**: proving correctness of recursive programs
- **Formal verification**: Hoare logic, loop invariants
- **Complexity theory**: proving properties of Turing machine computations

Example — proving a recursive function correct:
```python
def factorial(n):
    if n == 0:
        return 1                        # Base case
    return n * factorial(n - 1)          # Inductive step

# Proof by induction that factorial(n) = n!
# Base: n=0 → returns 1 = 0! ✓
# Inductive: assume factorial(k) = k!
# Then factorial(k+1) = (k+1) × factorial(k) = (k+1) × k! = (k+1)! ✓
```
