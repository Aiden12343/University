## Introduction

Set operations let us combine, compare, and select elements from sets. A **subset** is a set contained inside another. **Union** combines elements from two sets. **Intersection** finds elements common to both. **Complement** finds elements NOT in a set. These operations are the foundation of database queries, search algorithms, and type systems.

> [!example] Everyday idea
> Two playlists: "Rock songs" and "90s songs." The union is all songs that are either rock OR from the 90s. The intersection is songs that are BOTH rock AND from the 90s. The complement of "Rock songs" (within all songs) is every non-rock song.

## New Words

- [[subset]] — A is a subset of B if every element of A is also in B; denoted A ⊆ B.
- [[union]] — the set of all elements in A OR in B (or both); denoted A ∪ B.
- [[intersection]] — the set of all elements in both A AND B; denoted A ∩ B.
- [[complement]] — the set of all elements NOT in A (within the universal set); denoted A' or A̅.
- [[disjoint]] — two sets are disjoint if they share no elements; their intersection is empty.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Subsets

**Builds on:** [[5.1 Breadcrumb 1|What Is a Set?]] (set membership), [[5.1 Breadcrumb 2|Elements and Membership]] (∈ vs ⊆)

A is a **subset** of B (A ⊆ B) if every element of A is also in B.

```text
B = {1, 2, 3, 4, 5, 6}
A = {2, 4, 6}
Every element of A is in B, so A ⊆ B.
```

Every set is a subset of itself (A ⊆ A). The empty set is a subset of every set (∅ ⊆ A).

> [!important] Subset vs element
> A ⊆ B means A is a subset of B. A ∈ B means A is an element of B. `{2} ⊆ {1, 2, 3}` is true. `2 ∈ {1, 2, 3}` is true. But `{2} ∈ {1, 2, 3}` is FALSE — {2} is not an element.

#### Chunked Example
Question: A = {1, 2}, B = {1, 2, 3, 4}, C = {5, 6}. Which are true? (a) A ⊆ B (b) B ⊆ A (c) C ⊆ B (d) ∅ ⊆ A

(a) All of A (1, 2) are in B → True. (b) B has 3, 4 not in A → False. (c) C has 5, 6 not in B → False. (d) ∅ is subset of every set → True.

Answer: (a) and (d) are true.

---

### Breadcrumb 2: Union (∪)

**Builds on:** [[5.1 Breadcrumb 2|Elements and Membership]] (elements), [[5.1 Breadcrumb 3|Roster and Set-Builder Notation]] (building new sets)

The **union** of A and B is all elements in A OR B (or both):

$$ A \cup B = \{x \mid x \in A \text{ or } x \in B\} $$

```text
A = {1, 2, 3}
B = {3, 4, 5}
A ∪ B = {1, 2, 3, 4, 5}
```

> [!example] CS analogy
> Python: `set_a | set_b`. SQL: `SELECT * FROM A UNION SELECT * FROM B`.

#### Chunked Example
Question: A = {2, 4, 6, 8}, B = {6, 7, 8, 9}. Find A ∪ B.

All elements in A: 2, 4, 6, 8. Add elements in B not already listed: 7, 9. Combine: {2, 4, 6, 7, 8, 9}.

Answer: A ∪ B = **{2, 4, 6, 7, 8, 9}**.

---

### Breadcrumb 3: Intersection (∩)

**Builds on:** [[5.2 Breadcrumb 2|Union (∪)]] (similar operation but AND), [[5.1 Breadcrumb 2|Elements and Membership]] (checking membership in both)

The **intersection** of A and B is elements in A AND B:

$$ A \cap B = \{x \mid x \in A \text{ and } x \in B\} $$

```text
A = {1, 2, 3}
B = {3, 4, 5}
A ∩ B = {3}
```

> [!tip] ∪ is OR, ∩ is AND
> The U in ∪ is like a cup that catches everything. The ∩ is like a hat covering only the overlap.

#### Chunked Example
Question: A = {1, 3, 5, 7, 9}, B = {5, 6, 7, 8, 9}. Find A ∩ B.

Check each element of A: 1 ∉ B, 3 ∉ B, 5 ∈ B, 7 ∈ B, 9 ∈ B. Common: {5, 7, 9}.

Answer: A ∩ B = **{5, 7, 9}**.

---

### Breadcrumb 4: Complement (')

**Builds on:** [[5.1 Breadcrumb 4|The Empty Set and Universal Set]] (U and what's outside), [[5.2 Breadcrumb 2|Union (∪)]] and [[5.2 Breadcrumb 3|Intersection (∩)]] (set operations relative to U)

The **complement** of A (relative to U) is everything in U that is NOT in A:

$$ A' = \{x \in U \mid x \notin A\} $$

```text
U = {1, 2, 3, 4, 5, 6}
A = {2, 4, 6}
A' = {1, 3, 5}
```

> [!important] Complement depends on U
> If U changes, the complement changes.

#### Chunked Example
Question: U = {a, b, c, d, e, f, g, h}, A = {a, e}. Find A'.

Everything in U except a, e: b, c, d, f, g, h.

Answer: A' = **{b, c, d, f, g, h}**.

---

### Breadcrumb 5: Disjoint Sets

**Builds on:** [[5.2 Breadcrumb 3|Intersection (∩)]] (empty intersection), [[5.1 Breadcrumb 4|The Empty Set and Universal Set]] (∅ as result)

Two sets are **disjoint** if they share no elements: A ∩ B = ∅.

```text
A = {1, 2, 3}
B = {4, 5, 6}
A ∩ B = ∅  → disjoint
```

> [!warning] Disjoint ≠ complement
> Disjoint means no overlap. Complement means everything outside. Two disjoint sets do NOT necessarily cover U.

#### Chunked Example
Question: A = {2, 4, 6}, B = {1, 3, 5}, U = {1, 2, 3, 4, 5, 6}. Are A and B disjoint?

A ∩ B = ∅ → yes, they are disjoint. They also partition U in this case.

Answer: Yes, **A and B are disjoint**.

## Worked Examples

### Example 1 — Subset Testing

Question: Let A = {2, 4, 6}, B = {1, 2, 3, 4, 5, 6, 7}, C = {4, 6, 8}, D = ∅.
Which of the following are true? (a) A ⊆ B (b) C ⊆ B (c) D ⊆ A (d) B ⊆ A (e) {2, 4} ⊆ A

Step 1: (a) Every element of A (2, 4, 6) is in B → A ⊆ B is **true**.

Step 2: (b) C contains 8, which is not in B → C ⊆ B is **false**.

Step 3: (c) The empty set is a subset of every set → D ⊆ A is **true**.

Step 4: (d) B contains 1, 3, 5, 7 which are not in A → B ⊆ A is **false**.

Step 5: (e) {2, 4} is a subset of A because 2 ∈ A and 4 ∈ A → **true**.

Answer: (a) **true**, (b) **false**, (c) **true**, (d) **false**, (e) **true**.

### Example 2 — Union and Intersection

Question: Given A = {1, 3, 5, 7, 9}, B = {5, 6, 7, 8, 9}, C = {2, 4, 6, 8}, find:
(a) A ∪ B (b) A ∩ B (c) B ∩ C (d) (A ∪ B) ∩ C

Step 1: (a) A ∪ B = {1, 3, 5, 7, 9} ∪ {5, 6, 7, 8, 9} = {1, 3, 5, 6, 7, 8, 9}.

Step 2: (b) A ∩ B = elements in both A and B = {5, 7, 9}.

Step 3: (c) B ∩ C = elements in both B and C = {6, 8}.

Step 4: (d) (A ∪ B) ∩ C = {1, 3, 5, 6, 7, 8, 9} ∩ {2, 4, 6, 8} = {6, 8}.

Answer: (a) **{1, 3, 5, 6, 7, 8, 9}**, (b) **{5, 7, 9}**, (c) **{6, 8}**, (d) **{6, 8}**.

### Example 3 — Complement

Question: Let U = {a, b, c, d, e, f, g, h, i, j}, A = {a, c, e, g, i}, B = {b, d, f, h, j}.
Find: (a) A' (b) B' (c) (A ∪ B)' (d) A' ∩ B'

Step 1: (a) A' = U − A = {b, d, f, h, j}.

Step 2: (b) B' = U − B = {a, c, e, g, i} = A.

Step 3: (c) A ∪ B = U, so (A ∪ B)' = ∅.

Step 4: (d) A' ∩ B' = {b, d, f, h, j} ∩ {a, c, e, g, i} = ∅. (This illustrates De Morgan: (A ∪ B)' = A' ∩ B'.)

Answer: (a) **{b, d, f, h, j}**, (b) **{a, c, e, g, i}**, (c) **∅**, (d) **∅**.

### Example 4 — Disjoint Sets and Combined Operations

Question: Let A = {1, 2, 3, 4}, B = {5, 6, 7, 8}, C = {4, 5, 9}.
(a) Are A and B disjoint? (b) Are A and C disjoint? (c) Find (A ∪ B) ∩ C.

Step 1: (a) A ∩ B = {1, 2, 3, 4} ∩ {5, 6, 7, 8} = ∅. Yes, A and B are disjoint.

Step 2: (b) A ∩ C = {1, 2, 3, 4} ∩ {4, 5, 9} = {4} ≠ ∅. No, A and C are not disjoint.

Step 3: (c) A ∪ B = {1, 2, 3, 4, 5, 6, 7, 8}. (A ∪ B) ∩ C = {1, 2, 3, 4, 5, 6, 7, 8} ∩ {4, 5, 9} = {4, 5}.

Answer: (a) **Yes**, (b) **No**, (c) **{4, 5}**.

## Why This Works

Set operations are built from counting and classifying. Union counts elements from either group. Intersection counts elements in both groups. Complement counts elements not in the group. Every operation answers "how many?" with a condition on membership.

This connects to [[1.1 Counting and Number Sense]] — counting elements in categories.

## Common Mistakes

1. Confusing ∪ (union, everything) with ∩ (intersection, overlap).
2. Thinking A' depends only on A (it depends on U too).
3. Writing `{2} ∈ {1, 2, 3}` instead of `{2} ⊆ {1, 2, 3}`.
4. Forgetting that ∅ is a subset of every set.
5. Thinking disjoint sets cover the whole universe.
6. Using ∪ when the context requires AND (intersection).

> [!failure] Mistake pattern
> "A ∪ B means elements that are in both A and B" — wrong! ∪ means OR. ∩ means AND. ∪ is like a cup that catches everything; ∩ is like a hat covering only the overlap.

## Where This Shows Up in CS

- **SQL**: `UNION` = ∪, `INTERSECT` = ∩, `EXCEPT` = complement.
- **Python sets**: `a | b` (union), `a & b` (intersection), `a - b` (difference).
- **TypeScript types**: `A | B` (union type), `A & B` (intersection type).
- **Search engines**: "cats AND dogs" (intersection), "cats OR dogs" (union).
- **Access control**: permissions as sets; unions grant more access.

Example — Python:
```python
rock = {"Stairway", "Bohemian", "Hotel"}
nineties = {"Bohemian", "Smells", "Creep"}
all_songs = rock | nineties          # Union
overlap = rock & nineties            # Intersection: {"Bohemian"}
rock_only = rock - nineties          # Difference
```
