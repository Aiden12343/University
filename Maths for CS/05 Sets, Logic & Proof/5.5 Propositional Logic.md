## Introduction

Propositional logic studies statements that are either **true** or **false** (propositions) and how to combine them with operators like **AND**, **OR**, and **NOT**. It is algebra for true/false values: just as arithmetic computes `3 + 5 × 2`, propositional logic computes `(true AND false) OR NOT true`.

This is the foundation of: boolean conditions in code (`if`, `while`), digital circuits (logic gates), SQL `WHERE` clauses, search queries, and formal proof systems. If you have written `if (loggedIn && !banned)`, you have used it.

## New Words

- [[proposition]] — a declarative statement that is either true or false (not both).
- [[truth value]] — true (T, 1, ⊤) or false (F, 0, ⊥).
- [[and]] (∧, conjunction) — true only when both operands are true.
- [[or]] (∨, disjunction) — true when at least one operand is true (inclusive).
- [[not]] (¬, negation) — inverts the truth value.
- [[compound proposition]] — a proposition formed from simpler ones via connectives.
- [[truth table]] — a table listing truth values for every assignment to atomic propositions.
- [[logical equivalence]] — two propositions with identical truth tables, written P ≡ Q.
- [[tautology]] — true under every assignment, e.g. P ∨ ¬P.
- [[contradiction]] — false under every assignment, e.g. P ∧ ¬P.
- [[De Morgan's laws]] — ¬(P ∧ Q) ≡ ¬P ∨ ¬Q and ¬(P ∨ Q) ≡ ¬P ∧ ¬Q.

> [!important] You pass this topic only when you can define all eleven terms without looking.

## Breadcrumbs

### Breadcrumb 1: What Is a Proposition?

**Builds on:** [[1.1 Breadcrumb 1|Counting and Whole Numbers]] (statements about numbers have definite truth), [[5.1 Breadcrumb 2|Elements and Membership]] (membership as true/false)

A **proposition** must be declarative with a definite truth value. Questions, commands, exclamations, and vague statements are not propositions.

| Type | Example | Proposition? |
|------|---------|-------------|
| Declarative | Mars has two moons. | ✅ (false) |
| Question | Is Mars bigger? | ❌ |
| Command | Calculate the orbit. | ❌ |
| Vague | This planet is large. | ❌ |
| Paradox | This statement is false. | ❌ |

`x > 5` is not a proposition until the variable is bound (substitute x = 7 or quantify ∀x ∈ ℕ). This distinction leads to predicate logic.

#### Chunked Example
Question: Which are propositions? (a) `7 + 5 = 12` (b) `x + 3 = 10` (c) `Please close the door.`

(a) Definite truth value → proposition (true). (b) Variable not bound → not yet a proposition. (c) Command → not a proposition.

Answer: Only (a).

### Breadcrumb 2: Logical Connectives — NOT, AND, OR

**Builds on:** [[5.5 Breadcrumb 1|What Is a Proposition?]] (input propositions), [[5.1 Breadcrumb 2|Elements and Membership]] (∈/∉ as true/false)

The three fundamental connectives build new propositions from existing ones.

**NOT (¬)** — flips the truth value:
```
P    ¬P
────────
T     F
F     T
```

**AND (∧)** — true only when both are true:
```
P    Q    P ∧ Q
───────────────
T    T      T
T    F      F
F    T      F
F    F      F
```

**OR (∨)** — true when at least one is true (inclusive — unlike English "either/or"):
```
P    Q    P ∨ Q
───────────────
T    T      T
T    F      T
F    T      T
F    F      F
```

> [!tip] Circuit analogy
> ∧ = AND gate, ∨ = OR gate, ¬ = NOT gate (inverter).

#### Chunked Example
Question: P = "It is cold", Q = "It is raining". Translate `P ∧ ¬Q`.

P ∧ ¬Q = "It is cold and it is NOT raining."

### Breadcrumb 3: Compound Propositions

**Builds on:** [[5.5 Breadcrumb 2|Logical Connectives — NOT, AND, OR]] (operators), [[1.3 Breadcrumb 1|Adding Numbers on the Number Line]] (step-by-step evaluation)

Evaluate step-by-step from innermost outward.

Evaluate `(P ∧ Q) ∨ ¬R` with P=T, Q=F, R=T:
```
Step 1: P ∧ Q = T ∧ F = F
Step 2: ¬R    = ¬T    = F
Step 3: F ∨ F = F
```

**Order of operations (precedence):**
- Highest: ¬ (NOT) — like unary minus
- Middle: ∧ (AND) — like multiplication
- Lowest: ∨ (OR) — like addition

`¬P ∧ Q` means `(¬P) ∧ Q`, NOT `¬(P ∧ Q)`.

> [!warning] Use parentheses when in doubt
> `P ∨ Q ∧ R` means `P ∨ (Q ∧ R)` due to precedence. Always group explicitly in code.

#### Chunked Example
Question: P=T, Q=F, R=T. Evaluate `¬(P ∧ ¬Q) ∨ (R ∧ ¬P)`.

¬Q = T. P∧¬Q = T∧T = T. ¬(P∧¬Q) = F. ¬P = F. R∧¬P = T∧F = F. F ∨ F = F.

Answer: **False**.

### Breadcrumb 4: Translating English to Logic

**Builds on:** [[5.5 Breadcrumb 2|Logical Connectives — NOT, AND, OR]] (operators), [[5.5 Breadcrumb 1|What Is a Proposition?]] (identifying propositions)

| English | Logic |
|---------|-------|
| "It's warm and sunny." | `W ∧ S` |
| "I'll have coffee or tea." | `C ∨ T` |
| "I'm not going." | `¬G` |
| "The file exists and is readable." | `E ∧ R` |

#### Chunked Example
Question: P = "hasTicket", Q = "isStudent". Translate "Enter if you have a ticket or are a student."

Answer: `P ∨ Q` (if either condition is true, enter).

### Breadcrumb 5: Truth Tables for Complex Expressions

**Builds on:** [[5.5 Breadcrumb 3|Compound Propositions]] (evaluating step by step), [[1.1 Breadcrumb 3|Comparison Vocabulary]] (2ⁿ rows from n variables)

For n atomic propositions, a truth table has 2ⁿ rows. Build column by column.

Two-variable example: `(P ∧ Q) ∨ ¬P`
```
P    Q    P∧Q    ¬P    (P∧Q) ∨ ¬P
──────────────────────────────────
T    T     T      F         T
T    F     F      F         F
F    T     F      T         T
F    F     F      T         T
```

True in 3/4 cases; false only when P=T, Q=F.

> [!important] Reading the result
> All T → tautology. All F → contradiction. Mixed → contingent (depends on inputs).

---

### Breadcrumb 6: Logical Equivalence

**Builds on:** [[5.5 Breadcrumb 5|Truth Tables for Complex Expressions]] (comparing columns), [[5.5 Breadcrumb 2|Logical Connectives — NOT, AND, OR]] (connectives)

P ≡ Q means P and Q have identical truth tables.

**De Morgan's laws** (verify via truth table):
- `¬(P ∧ Q) ≡ ¬P ∨ ¬Q`
- `¬(P ∨ Q) ≡ ¬P ∧ ¬Q`

**Memory aid:** break the line, flip the sign.

**Other key equivalences:**
- Double negation: `¬(¬P) ≡ P`
- Commutativity: `P ∧ Q ≡ Q ∧ P`, `P ∨ Q ≡ Q ∨ P`
- Associativity: `(P∧Q)∧R ≡ P∧(Q∧R)`
- Distributivity: `P ∧ (Q ∨ R) ≡ (P∧Q) ∨ (P∧R)`
- Absorption: `P ∨ (P ∧ Q) ≡ P`, `P ∧ (P ∨ Q) ≡ P`

#### Chunked Example
Question: Simplify `(P ∧ Q) ∨ (P ∧ ¬Q)`.

Factor P: `P ∧ (Q ∨ ¬Q)`. `Q ∨ ¬Q ≡ T`. `P ∧ T ≡ P`.

Answer: **(P ∧ Q) ∨ (P ∧ ¬Q) ≡ P**.

## Worked Examples

### Example 1 — Identifying Propositions

Question: Which of the following are propositions? For those that are, state their truth value.
(a) 2 + 3 = 6
(b) x + 5 = 12
(c) Every integer is either even or odd.
(d) Close the door!

Step 1: (a) Declarative with definite truth value (false). Yes — **proposition**, false.

Step 2: (b) Contains a free variable x. Not a proposition until x is bound. **Not a proposition**.

Step 3: (c) Declarative, definite truth value. Every integer is either even or odd — true. Yes — **proposition**, true.

Step 4: (d) Command. No truth value. **Not a proposition**.

Answer: (a) **proposition, false**, (b) **not a proposition**, (c) **proposition, true**, (d) **not a proposition**.

### Example 2 — Evaluating Compound Propositions

Question: Let P = T, Q = F, R = T. Evaluate (¬P ∨ Q) ∧ (R ∨ ¬Q).

Step 1: ¬P = F, ¬Q = T.

Step 2: ¬P ∨ Q = F ∨ F = F.

Step 3: R ∨ ¬Q = T ∨ T = T.

Step 4: (¬P ∨ Q) ∧ (R ∨ ¬Q) = F ∧ T = F.

Answer: **False**.

### Example 3 — Translating English to Propositional Logic

Question: Let P = "the file is open", Q = "the system is locked", R = "the user is admin". Translate:
(a) The file is open and the system is not locked.
(b) If the user is admin, then the file is open.
(c) The file is open or the system is locked, but not both.

Step 1: (a) P ∧ ¬Q.

Step 2: (b) R → P (implication).

Step 3: (c) Exclusive OR: (P ∨ Q) ∧ ¬(P ∧ Q).

Answer: (a) **P ∧ ¬Q**, (b) **R → P**, (c) **(P ∨ Q) ∧ ¬(P ∧ Q)**.

### Example 4 — Simplifying Using Logical Equivalences

Question: Simplify ¬(P ∧ (Q ∨ ¬P)) using De Morgan's laws and other equivalences.

Step 1: Apply De Morgan: ¬(P ∧ (Q ∨ ¬P)) ≡ ¬P ∨ ¬(Q ∨ ¬P).

Step 2: De Morgan again on ¬(Q ∨ ¬P): ¬P ∨ (¬Q ∧ ¬(¬P)).

Step 3: Double negation: ¬P ∨ (¬Q ∧ P).

Step 4: Distributive (this is equivalent to (¬P ∨ ¬Q) ∧ (¬P ∨ P)). But ¬P ∨ P ≡ T, so: (¬P ∨ ¬Q) ∧ T ≡ ¬P ∨ ¬Q.

Step 5: Alternatively, note ¬P ∨ (¬Q ∧ P) ≡ (¬P ∨ ¬Q) ∧ (¬P ∨ P) ≡ (¬P ∨ ¬Q) ∧ T ≡ ¬P ∨ ¬Q.

Answer: ¬(P ∧ (Q ∨ ¬P)) ≡ **¬P ∨ ¬Q**.

## Why This Works

n variables → 2ⁿ truth assignments. Each assignment is a binary number from 0 to 2ⁿ−1. Exhaustive enumeration guarantees certainty.

Connectives map to set operations: ∧ → ∩, ∨ → ∪, ¬ → complement. De Morgan's laws for logic are the same as for sets: `(A ∩ B)' = A' ∪ B'`.

Because every proposition has exactly one truth value and every connective has a fixed truth table, the truth value of any compound proposition is completely determined by its atomic parts — no randomness, no ambiguity. This is what makes propositional logic suitable as the foundation for digital computers.

## Common Mistakes

1. Inclusive vs exclusive OR — P ∨ Q allows both true. For exclusive OR, use `(P ∨ Q) ∧ ¬(P ∧ Q)`.
2. Misapplying De Morgan — `¬(P ∧ Q) ≡ ¬P ∨ ¬Q`, not `¬P ∧ ¬Q`.
3. Ignoring precedence — `P ∨ Q ∧ R` means `P ∨ (Q ∧ R)`. Use parentheses.
4. Temporal "and" — English "and" can imply sequence; logical ∧ does not.
5. Non-propositions — Questions, commands, and paradoxes are not propositions.
6. Missing truth table rows — Use binary counting to guarantee all 2ⁿ rows.

## Where This Shows Up in CS

- **Boolean conditionals**: every `if`, `while`, `for` evaluates a proposition. Short-circuit evaluation (&&/||) mirrors truth tables.
- **SQL WHERE clauses**: compound propositions filter rows: `WHERE status = 'shipped' AND (total > 100 OR priority = 'high')`.
- **Digital circuits**: AND gate → ∧, OR gate → ∨, NOT gate → ¬. Every processor is built from billions of these gates.
- **Search queries**: "cats AND dogs" → intersection, "cats OR dogs" → union.
- **SAT solvers**: determine if a propositional formula has a satisfying assignment. Used for hardware verification, scheduling, automated theorem proving.
- **Static analysis**: linters detect contradictions: `if x > 0 and x < 0:` is unreachable.

## Mini-Quiz

1. Which connective is true only when both inputs are true? (a) AND (b) OR (c) NOT
2. Rows in a truth table for 5 variables? (a) 5 (b) 10 (c) 32
3. Negation of `P ∧ Q`? (a) ¬P∧¬Q (b) ¬P∨¬Q (c) ¬(P∨Q)
4. Which is a tautology? (a) P∧¬P (b) P∨¬P (c) P∧Q
5. Correct precedence order? (a) AND > OR > NOT (b) OR > AND > NOT (c) NOT > AND > OR
6. P=T, Q=F: `(P ∨ ¬Q) ∧ ¬P`? (a) T (b) F
7. `¬(P ∨ Q)` ≡ ? (a) P∧Q (b) ¬P∧¬Q (c) ¬P∨¬Q
8. How many distinct compound propositions with 2 atoms? (a) 4 (b) 8 (c) 16
9. Which gate implements conjunction? (a) OR (b) NOT (c) AND
10. `P ∨ (P ∧ Q)` simplifies to? (a) P (b) Q (c) P∧Q

Answers: 1-a, 2-c, 3-b, 4-b, 5-c, 6-b, 7-b, 8-c, 9-c, 10-a.
