# 06 Discrete Mathematics - What This Unlocks in CS

Study countable structures used throughout algorithms, data structures, cryptography, and theory.

## CS Connections
- [[6.1 Sequences and Series]] - Sequences model loops, recursive calls, and generated data.
- [[6.2 Summation and Product Notation]] - Algorithm analysis uses summations to count work.
- [[6.3 Modular Arithmetic]] - Hashing, checksums, cryptography, and circular buffers use modular arithmetic.
- [[6.4 Counting Rules]] - Counting rules estimate search spaces and brute-force difficulty.
- [[6.5 Permutations and Combinations]] - Passwords, scheduling, testing combinations, and probability use these counts.
- [[6.6 Recurrence Relations]] - Recursive algorithms are described by recurrence relations.
- [[6.7 Graph Theory Basics]] - Networks, maps, dependency graphs, and social graphs are graph structures.
- [[6.8 Trees and Traversal]] - File systems, syntax trees, DOM trees, and search structures are trees.
- [[6.9 Graph Algorithms BFS DFS Dijkstra]] - Routing, dependency resolution, and AI search rely on graph algorithms.
- [[6.10 Relations and Functions on Sets]] - Databases, type relations, ordering, and program semantics use relations.
- [[6.11 Formal Languages and Automata]] - Compilers, parsers, regex engines, and protocol checkers use automata.
- [[6.12 Computability and Decidability]] - Computability explains hard limits of software verification and automation.
