# 06 MOC - Discrete Maths

Study countable structures used throughout algorithms, data structures, cryptography, and theory.

## Topics
- [ ] [[6.1 Sequences and Series]] - Describe ordered lists of numbers and their sums.
- [ ] [[6.2 Summation and Product Notation]] - Write repeated addition and multiplication compactly.
- [ ] [[6.3 Modular Arithmetic]] - Calculate with remainders and cycles.
- [ ] [[6.4 Counting Rules]] - Count choices without listing every case.
- [ ] [[6.5 Permutations and Combinations]] - Count arrangements and selections.
- [ ] [[6.6 Recurrence Relations]] - Define values using previous values.
- [ ] [[6.7 Graph Theory Basics]] - Represent connected objects using vertices and edges.
- [ ] [[6.8 Trees and Traversal]] - Study connected acyclic graphs and ways to visit them.
- [ ] [[6.9 Graph Algorithms BFS DFS Dijkstra]] - Use algorithms to explore and solve graph problems.
- [ ] [[6.10 Relations and Functions on Sets]] - Describe links between elements and special relation properties.
- [ ] [[6.11 Formal Languages and Automata]] - Model patterns and machines that recognise strings.
- [ ] [[6.12 Computability and Decidability]] - Understand what algorithms can and cannot decide.
