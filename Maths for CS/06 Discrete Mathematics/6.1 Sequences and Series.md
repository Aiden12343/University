## Introduction

A **sequence** is an ordered list of numbers: `2, 4, 6, 8, 10, ...`. Each number is called a **term**. A **series** is the sum of a sequence's terms: `2 + 4 + 6 + 8 + 10 = 30`.

Sequences and series are the discrete analogue of functions. Where a function f(x) accepts any real x, a sequence aₙ accepts only integer positions n (1, 2, 3, ...). This makes them the natural model for step-by-step processes: loop iterations, algorithm running times, binary search steps, and compound interest growth.

The two most common patterns — arithmetic (constant difference) and geometric (constant ratio) — appear everywhere in programming and mathematics. Understanding them is essential for algorithm complexity analysis, recurrence relations, and financial modelling.

## New Words

- [[sequence]] — an ordered list of numbers where each number has a position. The number at position n is called aₙ.
- [[series]] — the sum of the terms of a sequence, written as Σaₙ.
- [[arithmetic sequence]] — a sequence where each term is obtained by adding a constant d to the previous term.
- [[geometric sequence]] — a sequence where each term is obtained by multiplying the previous term by a constant r.
- [[term]] — an individual element in a sequence. a₁ is the first term, a₂ the second, and aₙ the n-th term.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Sequences Are Ordered Lists

**Builds on:** [[1.1 Counting and Number Sense]] (natural numbers as positions), [[3.2 Function Notation and Mapping]] (aₙ = f(n) — sequence as function from ℕ to ℝ)

A sequence is written as:

```text
a₁, a₂, a₃, ..., aₙ
```

The **position number** n tells you which term you are looking at. a₁ is the first term, a₂ the second term, and aₙ is the term at position n.

> [!important] Position matters
> A sequence is not the same as a set. In a set, {1, 2, 3} and {3, 2, 1} are the same. In a sequence, 1, 2, 3 is different from 3, 2, 1.

### Chunked Example

Question: Find the next term in the sequence: 3, 7, 11, 15, ___

Step 1: Find the difference between consecutive terms.

```text
 3    7    11   15
   +4    +4    +4
```

Step 2: The pattern adds 4 each time.

Step 3: Add 4 to the last term: 15 + 4 = 19.

Answer: The next term is **19**.

### Breadcrumb 2: Arithmetic Sequences (Constant Difference)

**Builds on:** [[6.1 Sequences and Series]] (indexing terms), [[1.3 Addition and Subtraction]] (repeated addition)

An **arithmetic sequence** has the same difference d between every pair of consecutive terms.

```text
a₁, a₁+d, a₁+2d, a₁+3d, ...
```

Closed formula for term n:

```text
aₙ = a₁ + (n-1)d
```

> [!tip] Why (n-1)?
> You add d once to go from a₁ to a₂ (that is 1 addition), twice to go to a₃ (2 additions), and (n-1) times to go to aₙ.

### Chunked Example

Question: a₁ = 5, d = 3. Find a₁₀.

Step 1: Write the formula.

```text
aₙ = a₁ + (n-1)d
```

Step 2: Substitute n = 10, a₁ = 5, d = 3.

```text
a₁₀ = 5 + (10-1) × 3
```

Step 3: Compute.

```text
a₁₀ = 5 + 9 × 3 = 5 + 27 = 32
```

Answer: a₁₀ = **32**.

### Chunked Example

Question: The first 3 terms of a sequence are 100, 88, 76. Is it arithmetic? If so, find a₁₂.

Step 1: Check differences: 88 - 100 = -12, 76 - 88 = -12.

```text
Constant difference d = -12, so yes it is arithmetic.
```

Step 2: a₁ = 100, d = -12, n = 12.

```text
a₁₂ = 100 + (12-1) × (-12) = 100 + 11 × (-12) = 100 - 132 = -32
```

Answer: **Yes, arithmetic. a₁₂ = -32**.

### Breadcrumb 3: Geometric Sequences (Constant Ratio)

**Builds on:** [[6.1 Sequences and Series]] (arithmetic sequences — contrasting pattern), [[1.4 Multiplication and Times Tables]] (repeated multiplication), [[2.9 Indices and Powers]] (rⁿ⁻¹ for term n)

A **geometric sequence** has the same ratio r between every pair of consecutive terms.

```text
a₁, a₁r, a₁r², a₁r³, ...
```

Closed formula for term n:

```text
aₙ = a₁ × rⁿ⁻¹
```

### Chunked Example

Question: a₁ = 2, r = 3. Find a₅.

Step 1: Write the formula.

```text
aₙ = a₁ × rⁿ⁻¹
```

Step 2: Substitute n = 5, a₁ = 2, r = 3.

```text
a₅ = 2 × 3⁵⁻¹ = 2 × 3⁴ = 2 × 81 = 162
```

Answer: a₅ = **162**.

### Chunked Example

Question: The first 3 terms of a sequence are 160, 80, 40. Is it geometric? If so, find a₁₀.

Step 1: Check ratios: 80 ÷ 160 = 0.5, 40 ÷ 80 = 0.5.

```text
Constant ratio r = 0.5, so yes it is geometric.
```

Step 2: a₁ = 160, r = 0.5, n = 10.

```text
a₁₀ = 160 × 0.5⁹ = 160 × 1/512 = 160/512 = 5/16 = 0.3125
```

Answer: **Yes, geometric. a₁₀ = 0.3125**.

### Breadcrumb 4: Series (Sum of a Sequence)

**Builds on:** [[6.1 Sequences and Series]] (arithmetic and geometric sequences), [[2.2 Simplifying Expressions]] (simplifying sums)

A **series** is the sum of the terms of a sequence. If you have the sequence a₁, a₂, a₃, ..., aₙ, the series is:

```text
Sₙ = a₁ + a₂ + a₃ + ... + aₙ
```

### Arithmetic Series Formula

```text
Sₙ = n/2 × (2a₁ + (n-1)d)
```

which is the same as:

```text
Sₙ = n/2 × (first term + last term) = n/2 × (a₁ + aₙ)
```

### Chunked Example (Gauss's Trick)

Question: Add the numbers from 1 to 100: 1 + 2 + 3 + ... + 100.

Step 1: Pair first with last, second with second-last, etc.

```text
1 + 100 = 101
2 + 99  = 101
3 + 98  = 101
...
```

Step 2: There are 100 ÷ 2 = 50 pairs, each summing to 101.

Step 3: Total = 50 × 101 = 5050.

```text
Using the formula: S = 100/2 × (1 + 100) = 50 × 101 = 5050
```

Answer: **5050**.

> [!example] CS connection
> This is exactly the running time of a loop that does i operations for i=1..n. The total is n(n+1)/2 which is O(n²).

### Geometric Series Formula

```text
Sₙ = a₁(1 - rⁿ) / (1 - r)   for r ≠ 1
```

For an infinite geometric series with |r| < 1:

```text
S∞ = a₁ / (1 - r)
```

### Chunked Example

Question: Sum the first 5 terms of the geometric sequence starting a₁=3, r=2.

Step 1: Write the series: 3 + 6 + 12 + 24 + 48.

Step 2: Use the formula: S₅ = 3(1-2⁵)/(1-2) = 3(1-32)/(-1) = 3(-31)/(-1) = 93.

Step 3: Check by adding: 3+6=9, 9+12=21, 21+24=45, 45+48=93. ✓

Answer: **93**.

## Worked Examples

### Example 1 — Arithmetic Sequence: Finding the 20th Term

Question: Find the 20th term of the arithmetic sequence: 7, 11, 15, 19, ...

Step 1: Identify a₁ and d.
a₁ = 7, d = 11 − 7 = 4.

Step 2: Use the arithmetic sequence formula aₙ = a₁ + (n−1)d.
a₂₀ = 7 + (20−1) × 4 = 7 + 19 × 4 = 7 + 76 = 83.

Answer: **a₂₀ = 83**.

### Example 2 — Geometric Sequence: Finding the 8th Term

Question: Find the 8th term of the geometric sequence: 3, 6, 12, 24, ...

Step 1: Identify a₁ and r.
a₁ = 3, r = 6 ÷ 3 = 2.

Step 2: Use the geometric sequence formula aₙ = a₁ × rⁿ⁻¹.
a₈ = 3 × 2⁸⁻¹ = 3 × 2⁷ = 3 × 128 = 384.

Answer: **a₈ = 384**.

### Example 3 — Arithmetic Series: Sum of First 15 Terms

Question: Sum the first 15 terms of the arithmetic sequence with a₁ = 10, d = 4.

Step 1: Find the last term a₁₅ using aₙ = a₁ + (n−1)d.
a₁₅ = 10 + (15−1) × 4 = 10 + 14 × 4 = 10 + 56 = 66.

Step 2: Use the arithmetic series formula Sₙ = n/2 × (a₁ + aₙ).
S₁₅ = 15/2 × (10 + 66) = 15/2 × 76 = 15 × 38 = 570.

Answer: **570**.

### Example 4 — Infinite Geometric Series

Question: Sum the infinite geometric series: 8 + 4 + 2 + 1 + ...

Step 1: Identify a₁ and r.
a₁ = 8, r = 4 ÷ 8 = 1/2.

Step 2: Check convergence. |r| = ½ < 1, so the series converges.

Step 3: Use the infinite geometric series formula S∞ = a₁ / (1−r).
S∞ = 8 / (1 − 1/2) = 8 / (1/2) = 16.

Answer: **16**.

## Why This Works

Sequences are the discrete version of functions: aₙ = f(n) where n ∈ ℕ. Counting (from [[1.1 Counting and Number Sense]]) is the simplest sequence: 1, 2, 3, ... Every counting situation produces a sequence, and summing terms produces a series.

The closed-form formulas for arithmetic and geometric sequences work because the position n determines the value deterministically — just like an array index determines the value at that position. The series formulas derive from clever pairing (Gauss's trick) or algebraic manipulation of geometric sums.

The key insight: sequences model **step-by-step discrete processes**, which is what algorithms are. Every loop iterates over a sequence of values.

## Common Mistakes

> [!failure] Mistake pattern: Off-by-one in term numbering
> aₙ = a₁ + (n-1)d, NOT a₁ + nd. Term 10 needs 9 steps, not 10.
> Example: For a₁=5,d=3, a₁₀=5+9×3=32, not 5+10×3=35.

> [!failure] Mistake pattern: Confusing arithmetic and geometric
> Arithmetic: same difference (add/subtract).
> Geometric: same ratio (multiply/divide).
> Check by looking at consecutive terms. If you are adding/subtracting, think arithmetic. If you are multiplying/dividing, think geometric.

> [!failure] Mistake pattern: Geometric series denominator
> The formula Sₙ = a₁(1-rⁿ)/(1-r). If r > 1, use Sₙ = a₁(rⁿ-1)/(r-1) to keep denominators positive.

## Where This Shows Up in CS

### Loop Analysis
```python
for i in range(n):       # 1, 2, 3, ..., n  (arithmetic sequence)
    print(i)
```

### Binary Search
Each step halves the search space (geometric with r=1/2).

### Algorithm Complexity
```text
Loop inside a loop: i=1..n, j=1..i → total operations = 1+2+...+n = n(n+1)/2
This is an arithmetic series sum.
```

### Other applications
- **Pagination**: page numbers form a sequence
- **Frames in animation**: frame numbers
- **Network packets**: packet sequence numbers
- **CPU scheduling**: time slices form a sequence
- **Compound interest**: account balance follows a geometric sequence
