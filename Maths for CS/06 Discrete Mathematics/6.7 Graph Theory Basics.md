## Plain-English Idea

A **graph** is a collection of **vertices** (nodes, points) connected by **edges** (lines, connections). Graphs model almost everything in CS:

```text
Social network:  people = vertices, friendships = edges
Road map:        cities = vertices, roads = edges
Web:             pages = vertices, links = edges
Computer network: computers = vertices, cables = edges
```

> [!example] Everyday idea
> A graph is like a map of cities connected by roads. The cities are vertices, the roads are edges. You might want the shortest route (shortest path), whether every city is reachable (connectivity), or how many direct neighbours a city has (degree).

## New Words

- **[[graph]]** - an ordered pair G = (V, E) where V is a set of vertices and E is a set of edges.
- **[[vertex]]** - a node or point in a graph (plural: vertices).
- **[[edge]]** - a connection between two vertices, written (u, v).
- **[[directed graph]]** - edges have direction (one-way streets, Twitter follows).
- **[[weighted graph]]** - edges have weights (distances, costs, capacities).

You pass this topic only when you can define all five terms without looking.

## Concept 1 - Graph Terminology

A graph G = (V, E) consists of:

- **V**: a set of vertices (also called nodes)
- **E**: a set of edges, each connecting two vertices

### Chunked Example

Question: A graph has V = {A, B, C, D} and E = {A-B, B-C, C-D, A-C}. How many vertices and edges?

Step 1: Count V: {A, B, C, D} = 4 vertices.

Step 2: Count E: A-B, B-C, C-D, A-C = 4 edges.

Answer: **|V|=4, |E|=4**.

```text
Graph drawing:
    A --- B
    |     |
    |     |
    C --- D
```

## Concept 2 - Undirected vs Directed Graphs

### Undirected Graph
Edges have no direction: (A, B) = (B, A). Friendship is undirected.

```text
A --- B    means A and B are connected, no direction
```

### Directed Graph (Digraph)
Edges have direction: A→B is different from B→A. Twitter follow is directed.

```text
A → B    means A follows B, but B may not follow A
```

### Chunked Example

Question: In a directed graph with edges A→B, B→C, A→C, list all edges.

Step 1: Each edge has a direction.

```text
(A,B): from A to B
(B,C): from B to C
(A,C): from A to C
```

Step 2: Note: B→A is NOT an edge (no edge from B to A).

Answer: **Edges: (A,B), (B,C), (A,C)**.

## Concept 3 - Degree of a Vertex

In an **undirected graph**, the degree of a vertex is the number of edges incident to it.

In a **directed graph**:
- **Indegree**: number of incoming edges.
- **Outdegree**: number of outgoing edges.

### Chunked Example

Question: For V={A,B,C,D}, E={A-B, A-C, B-C, B-D}, find degree of each vertex.

Step 1: Count edges for each vertex.

```text
A: connected to B, C    → degree 2
B: connected to A, C, D → degree 3
C: connected to A, B    → degree 2
D: connected to B       → degree 1
```

Answer: **deg(A)=2, deg(B)=3, deg(C)=2, deg(D)=1**.

> [!tip] Handshaking Lemma
> In any graph, the sum of all vertex degrees = 2|E| (each edge contributes 2 to the degree sum). For the example above: 2+3+2+1=8=2×4. ✓

## Concept 4 - Paths, Cycles, and Connectivity

### Path
A sequence of edges connecting vertices. A-B-C-D is a path from A to D.

### Cycle
A path that starts and ends at the same vertex with no repeated edges. A-B-C-A is a cycle.

### Connected Graph
A graph is **connected** if there is a path between every pair of vertices.

### Chunked Example

Question: In {A-B, B-C, C-D}, is there a path from A to D? Is there a cycle?

Step 1: Path A→B→C→D connects A to D. Yes, there is a path.

Step 2: For a cycle, we need a path that returns to the start without revisiting edges. A-B-C-D has no edge back to A → no cycle.

Answer: **Path exists (A-B-C-D), no cycle**.

## Concept 5 - Representing Graphs

### Adjacency List
Each vertex stores its neighbours.

```text
A: [B, C]
B: [A, C, D]
C: [A, B]
D: [B]
```

### Adjacency Matrix
An n×n matrix where entry (i,j) = 1 if there is an edge from i to j, 0 otherwise.

```text
  A B C D
A 0 1 1 0
B 1 0 1 1
C 1 1 0 0
D 0 1 0 0
```

### Chunked Example

Question: Convert the adjacency list to an adjacency matrix.

Step 1: For each pair (i,j), check if j is in i's neighbour list.

```text
A has B, C  → row A: [0,1,1,0]
B has A, C, D → row B: [1,0,1,1]
C has A, B  → row C: [1,1,0,0]
D has B     → row D: [0,1,0,0]
```

Answer: **See matrix above**.

> [!example] CS connection
> Adjacency lists use O(V+E) memory (good for sparse graphs). Adjacency matrices use O(V²) memory (good for dense graphs with many edges).

## Concept 6 - Special Graphs

### Complete Graph Kₙ
Every pair of distinct vertices is connected. K₃ is a triangle.

```text
K₃: A --- B
     \   /
       C
```

### Bipartite Graph
Vertices can be split into two sets with all edges going between sets (no edges within a set).

## Why This Works

Graphs are a general-purpose modelling tool because they abstract away everything except connections. A graph can represent a social network, a circuit board, a molecule, or a dependency tree — the same algorithms work on all of them.

[[5.1 Set Theory Basics]] gave us sets. Graphs add structure: they say not just "these things exist" but "these things are connected in these ways."

## Worked Examples

### Example 1 - Degree Sum

Question: In a directed graph with edges A→B, A→C, B→C, C→A, compute indegree and outdegree of each vertex.

Step 1: Count outgoing edges.

```text
A→B, A→C   → outdegree(A)=2
B→C        → outdegree(B)=1
C→A        → outdegree(C)=1
```

Step 2: Count incoming edges.

```text
A gets from C     → indegree(A)=1
B gets from A     → indegree(B)=1
C gets from A, B  → indegree(C)=2
```

Answer:
```text
Vertex  outdeg  indeg
A       2       1
B       1       1
C       1       2
```

### Example 2 - Graph from Description

Question: 5 cities. Roads: London-Paris, London-Berlin, Paris-Berlin, Paris-Rome, Berlin-Rome. Draw the graph, find degrees.

Step 1: V = {London, Paris, Berlin, Rome, Milan}. (Milan has no roads.)

Step 2: Edges: L-P, L-B, P-B, P-R, B-R.

Step 3: Degrees: L=2, P=3, B=3, R=2, M=0.

Answer: **Milan is isolated (degree 0)**.

### Example 3 - CS Application: Web Graph

Question: 4 web pages: A links to B and C, B links to C, C links to A, D links to no one. Draw the directed graph.

Step 1: Vertices: A, B, C, D.

Step 2: Directed edges: A→B, A→C, B→C, C→A.

Step 3: D has no outgoing or incoming edges (isolated).

```text
A ←--- C
|     /|
|    / |
v   /  v
B  /  (D)
```

### Example 4 - Path Existence

Question: Can you travel from D to A in the undirected graph with edges A-B, B-C, C-D, A-C?

Step 1: Path: D-C-A. Yes.

Step 2: Alternative: D-C-B-A. Also yes.

Answer: **Yes (D-C-A or D-C-B-A)**.

## Common Mistakes

> [!failure] Mistake pattern: Confusing vertices and edges
> Vertices are the objects (people, cities). Edges are the connections (friendships, roads). A graph with no edges still has vertices.

> [!failure] Mistake pattern: Forgetting direction in directed graphs
> A→B is not the same as B→A. When reading a directed graph problem, always check which direction edges go.

> [!failure] Mistake pattern: Double-counting edges in undirected degree sum
> Each undirected edge (A,B) contributes 1 to deg(A) and 1 to deg(B). The sum of all degrees = 2|E|, not |E|.

## Where This Shows Up in CS

### Social Network Analysis
```text
Facebook: undirected graph (friendship is mutual)
Twitter:  directed graph (follows are one-way)
```

### Web Search (PageRank)
Google models the web as a directed graph. PageRank computes importance from the link structure.

### Other applications
- **Computer networks**: routers = vertices, cables = edges
- **Dependency graphs**: package managers resolve dependencies as a directed graph
- **Knowledge graphs**: Wikidata, Freebase
- **Neural networks**: computational graphs
- **Compilers**: control flow graphs
