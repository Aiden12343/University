# 07 MOC - Linear Algebra

Build vector and matrix reasoning for graphics, ML, numerical computing, and systems.

## Topics
- [ ] [[7.1 Matrix Notation and Shape]] - Read matrices by rows, columns, and dimensions.
- [ ] [[7.2 Matrix Addition and Scalar Multiplication]] - Combine matrices and scale every entry.
- [ ] [[7.3 Matrix Multiplication]] - Multiply matrices as composed linear operations.
- [ ] [[7.4 Identity and Inverse Matrices]] - Understand matrices that do nothing and matrices that undo.
- [ ] [[7.5 Determinants]] - Measure scaling and invertibility for square matrices.
- [ ] [[7.6 Solving Linear Systems with Matrices]] - Use matrix methods to solve many equations at once.
- [ ] [[7.7 Vector Spaces Span and Basis]] - Describe spaces made from vectors and their building blocks.
- [ ] [[7.8 Linear Transformations]] - Treat matrices as operations that move vectors.
- [ ] [[7.9 Eigenvalues and Eigenvectors]] - Find directions that a transformation only scales.
- [ ] [[7.10 Orthogonality and Least Squares]] - Use right-angle ideas to find best approximate solutions.
- [ ] [[7.11 Matrix Decompositions LU QR SVD]] - Break matrices into useful simpler pieces.
- [ ] [[7.12 Numerical Stability in Linear Algebra]] - Understand rounding error and stable computation.
