## Introduction

A **matrix** is a rectangular grid of numbers arranged in rows and columns. Think of it as a spreadsheet where every cell has a row number and a column number.

```
     [ 1  2  3 ]   ← row 1
A =  [ 4  5  6 ]   ← row 2

          ↑  ↑  ↑
        col1 col2 col3
```

This matrix has 2 rows and 3 columns. We say its **shape** is 2×3 (read "two by three").

You already know about **vectors** from [[4.8 Vectors Basics]] — an ordered list of numbers. A matrix is the natural next step: a 2-dimensional array instead of a 1-dimensional one. If a vector is a single row or column of numbers, a matrix is the full rectangular grid.

Matrices are the language of:
- **Machine learning**: every dataset is a matrix (rows = samples, columns = features)
- **Computer graphics**: 3D transformations use 4×4 matrices
- **Neural networks**: every layer is a matrix multiplication
- **Linear systems**: solving many equations at once

## New Words

- **[[matrix]]** — a rectangular array of numbers with m rows and n columns. Denoted by a capital letter: A, B, M.
- **[[element]]** — a single entry in a matrix, written Aᵢⱼ (row i, column j).
- **[[shape]]** — the dimensions of a matrix: m × n (rows × columns).
- **[[row vector]]** — a matrix with exactly one row, shape 1×n.
- **[[column vector]]** — a matrix with exactly one column, shape m×1.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: What Is a Matrix?

**Builds on:** [[1.1 Counting and Number Sense]] (natural numbers count positions), [[1.4 Multiplication and Times Tables]] (shape = rows × columns), [[5.1 Set Theory Basics]] (entries belong to a set, usually ℝ)

A matrix A of size m × n is a rectangular arrangement:

```
     [ a₁₁  a₁₂  ...  a₁ₙ ]
     [ a₂₁  a₂₂  ...  a₂ₙ ]
A =  [  ⋮    ⋮    ⋱    ⋮  ]
     [ aₘ₁  aₘ₂  ...  aₘₙ ]
```

The **shape** tells you the size: m rows and n columns. Always say "rows × columns".

#### Chunked Example

Question: Matrix A = [[7, 2, 5], [3, 8, 1]]. How many rows? How many columns? What is its shape?

Step 1: Count rows: the matrix has 2 rows of numbers.

Step 2: Count columns: each row has 3 numbers → 3 columns.

Step 3: Shape = 2 rows × 3 columns = 2×3.

Answer: **Shape 2×3 (2 rows, 3 columns)**.

```
Row 1: [7, 2, 5]
Row 2: [3, 8, 1]
```

#### Pattern Recognition Drill

For the matrix B = [[4, 9, 2, 7], [6, 1, 0, 3], [5, 8, 3, 2]]:

```
Shape: 3×4  (3 rows, 4 columns)
```

### Breadcrumb 2: Matrix Notation and Element Indexing

**Builds on:** [[2.1 Variables Expressions and Equations]] (subscript notation aᵢⱼ), [[3.1 Coordinates and Axes]] (i for row, j for column like x,y coordinates), Breadcrumb 1

Every element in a matrix has an address: **row first, column second**.

```
Aᵢⱼ = element at row i, column j
```

This is the same convention as coordinates (x, y) but with the row (vertical position) stated first. It matches how nested loops iterate: the outer loop runs over rows, the inner loop over columns.

```
for i = 1 to m:          # row
    for j = 1 to n:      # column
        process A[i][j]
```

#### Chunked Example

Question: In matrix C = [[10, 20, 30], [40, 50, 60]], find C₁₂, C₂₁, and C₂₃.

Step 1: C₁₂ means row 1, column 2. Row 1 = [10, 20, 30], column 2 = 20.

Step 2: C₂₁ means row 2, column 1. Row 2 = [40, 50, 60], column 1 = 40.

Step 3: C₂₃ means row 2, column 3. Row 2 = [40, 50, 60], column 3 = 60.

Answer: **C₁₂ = 20, C₂₁ = 40, C₂₃ = 60**.

```
C = [ 10  20  30 ]
    [ 40  50  60 ]
        ↑   ↑   ↑
       C₁₂ C₂₂ C₂₃
       =20 =50 =60
```

### Breadcrumb 3: Row Vectors and Column Vectors

**Builds on:** [[4.8 Vectors Basics]] (ordered list of numbers), Breadcrumb 1

Vectors are matrices with only one row or one column:

- **Row vector**: exactly 1 row. Shape 1×n.
- **Column vector**: exactly 1 column. Shape m×1.
- **Scalar**: a single number. Shape 1×1.

```
Row vector:    v = [1  2  3]          shape 1×3

Column vector: v = [1]                shape 3×1
                   [2]
                   [3]

Scalar:        c = 5                  shape 1×1
```

The **transpose** (written Aᵀ) flips rows and columns. Transposing a row vector gives a column vector and vice versa:

```
[1  2  3]ᵀ = [1]          [4]ᵀ = [4  7  2]
              [2]
              [3]
```

#### Chunked Example

Question: Classify each as row vector, column vector, or scalar:
(a) [4, 7, 2]
(b) [[4], [7], [2]]
(c) 5

Step 1: (a) 1 row, 3 columns → row vector, shape 1×3.

Step 2: (b) 3 rows, 1 column → column vector, shape 3×1.

Step 3: (c) Single number → scalar, shape 1×1.

Answer: **(a) Row vector 1×3, (b) Column vector 3×1, (c) Scalar 1×1**.

### Breadcrumb 4: Special Matrices

**Builds on:** Breadcrumb 1

Certain matrix shapes and patterns appear so often they have their own names.

#### Square Matrix

Rows = columns. Shape n×n.

```
3×3 square:  [ 1  2  3 ]
             [ 4  5  6 ]
             [ 7  8  9 ]
```

#### Diagonal Matrix

A square matrix where only the diagonal entries (row i = column j) are non-zero. All other entries are zero.

```
D = [ 5  0  0 ]
    [ 0  3  0 ]
    [ 0  0  8 ]
```

#### Identity Matrix Iₙ

A diagonal matrix where every diagonal entry is 1. This is the multiplicative identity — the matrix equivalent of the number 1.

```
I₃ = [ 1  0  0 ]
     [ 0  1  0 ]
     [ 0  0  1 ]
```

#### Zero Matrix

Every entry is 0. Can be any shape.

```
0₂ₓ₃ = [ 0  0  0 ]
       [ 0  0  0 ]
```

#### Chunked Example

Question: Classify each matrix:
(a) [[1, 0], [0, 1]]
(b) [[2, 0, 0], [0, 2, 0], [0, 0, 2]]
(c) [[1, 2], [3, 4]]

Step 1: (a) 2×2, diagonal entries are 1 → identity matrix I₂.

Step 2: (b) 3×3, only diagonal entries are non-zero (all 2) → diagonal matrix.

Step 3: (c) 2×2, no special pattern → square matrix (general).

Answer: **(a) Identity I₂, (b) Diagonal matrix, (c) Square matrix**.

### Breadcrumb 5: Why Shape Matters

**Builds on:** Breadcrumbs 1, 3, 4

The shape of a matrix determines which operations are valid:

| Operation | Shape Requirement | Result Shape |
|-----------|------------------|--------------|
| Addition A + B | A and B must have the **same** shape | Same shape |
| Multiplication AB | Columns of A = rows of B | (A rows) × (B columns) |
| Transpose Aᵀ | Any shape | Flips: m×n → n×m |

This is not a rule invented to be difficult — it follows from how these operations are defined. If shapes do not match, the operation simply has no meaning (just as you cannot add 3 apples to 5 oranges without reinterpreting what you are counting).

#### Chunked Example

Question: Can you add a 2×3 matrix to a 3×2 matrix?

Step 1: Addition requires identical shapes.

Step 2: 2×3 ≠ 3×2.

Answer: **No. Shapes must match exactly for addition**.

Question: Can you multiply a 2×3 matrix by a 3×4 matrix?

Step 1: Inner dimensions must match: (2×**3**) × (**3**×4).

Step 2: The 3s match → multiplication is possible.

Step 3: Result shape = 2×4.

Answer: **Yes. Result is 2×4**.

## Worked Examples

### Example 1 — Identifying Shape and Elements

Question: For the matrix A = [[5, -2, 3], [0, 7, 1], [-4, 8, 9]], state its shape, find a₂₁ and a₁₃.

Step 1: Count rows: 3 rows. Count columns: 3 columns. Shape = 3×3.

Step 2: a₂₁ means row 2, column 1. Row 2 = [0, 7, 1], column 1 entry = 0.

Step 3: a₁₃ means row 1, column 3. Row 1 = [5, -2, 3], column 3 entry = 3.

Answer: **Shape 3×3. a₂₁ = 0. a₁₃ = 3**.

### Example 2 — Classifying Matrices by Shape

Question: Classify each as a row vector, column vector, scalar, or general matrix:
(a) [[1, 2, 3, 4]]
(b) [[1], [2], [3]]
(c) 5
(d) [[1, 0], [0, 1]]

Step 1: (a) 1 row, 4 columns → row vector, shape 1×4.

Step 2: (b) 3 rows, 1 column → column vector, shape 3×1.

Step 3: (c) Single number → scalar, shape 1×1.

Step 4: (d) 2 rows, 2 columns → square matrix, specifically identity I₂.

Answer: **(a) Row vector 1×4, (b) Column vector 3×1, (c) Scalar 1×1, (d) Square identity matrix I₂**.

### Example 3 — Element Indexing and Transpose

Question: For D = [[2, 4, 6, 8], [1, 3, 5, 7], [0, 1, 0, 1]], find D₂₃, D₁₄, and write Dᵀ.

Step 1: D₂₃ = row 2, column 3 = 5.

Step 2: D₁₄ = row 1, column 4 = 8.

Step 3: Transpose flips rows and columns. D is 3×4, so Dᵀ is 4×3:
Dᵀ = [[2, 1, 0], [4, 3, 1], [6, 5, 0], [8, 7, 1]].

Answer: **D₂₃ = 5, D₁₄ = 8. Dᵀ = [[2, 1, 0], [4, 3, 1], [6, 5, 0], [8, 7, 1]]**.

### Example 4 — Shape Compatibility for Operations

Question: (a) Can you multiply a 3×4 matrix by a 5×4 matrix? (b) Can you multiply a 2×5 matrix by a 5×3 matrix? If yes, give the result shape.

Step 1: (a) Inner dimensions: 3×**4** and 5×**4** → 4 ≠ 5. Cannot multiply.

Step 2: (b) Inner dimensions: 2×**5** and **5**×3 → 5 = 5. Can multiply. Result uses outer dimensions: 2×3.

Answer: **(a) No — inner dimensions 4 and 5 do not match. (b) Yes — result shape is 2×3**.

## Why This Works

A matrix is a natural extension of a vector. A vector stores one row (or column) of numbers with a single index. A matrix stores a rectangular block with two indices: row and column.

The double subscript aᵢⱼ works like a coordinate system. From [[3.1 Coordinates and Axes]] you already know how to locate a point by (x, y). Matrix indexing is the same — (row, column) — just with a different naming convention.

The row-first convention (i = row, j = column) mirrors how nested loops iterate in programming: the outer loop runs over rows (i), the inner loop runs over columns (j). This is not accidental — matrix notation and computing co-evolved to use the same convention.

## Common Mistakes

> [!failure] Mistake pattern: Confusing rows and columns in shape
> A 3×4 matrix has 3 **rows** and 4 **columns**, not the other way around. Think "rows × columns" — the first number is always the row count.

> [!failure] Mistake pattern: Off-by-one in element indexing
> In mathematical notation, matrix indices start at 1 (unlike Python and C which start at 0). a₁ is the first row, not the zeroth.

> [!failure] Mistake pattern: Writing column vectors as row vectors
> A column vector [1, 2, 3]ᵀ is 3×1. A row vector [1, 2, 3] is 1×3. They are different shapes. The transpose symbol ᵀ distinguishes them.

> [!failure] Mistake pattern: Forgetting that shape restricts operations
> Two matrices can only be added if they have exactly the same shape. You cannot "force" a 2×3 and a 3×2 to add by rearranging entries.

## Where This Shows Up in CS

### Machine Learning Datasets

Every dataset is a matrix:
- Rows = individual data samples (observations)
- Columns = features (measurements)
- Shape: n_samples × n_features

```text
Iris dataset:     150 × 4   (150 flowers, 4 measurements each)
MNIST images:     60000 × 784  (60000 images, 28×28 pixels flattened)
```

### Neural Network Weights

Each layer of a neural network is a matrix multiplication:
- Weight matrix W: rows = output neurons, columns = input neurons
- Shape: n_outputs × n_inputs
- Input vector x (column) → output = Wx

### Computer Graphics

3D transformations use 4×4 matrices:
- Rotation, scaling, translation are all matrix operations
- Each vertex is a column vector [x, y, z, 1]ᵀ
- A transformation matrix applied to every vertex produces the rendered scene

### Other Applications

- **Image processing**: each colour channel (R, G, B) is a matrix of pixel values
- **PageRank**: the web is an adjacency matrix with billions of columns
- **Social networks**: friendship connections form an adjacency matrix
- **Linear systems**: solving n equations with n unknowns using matrix methods
