## Introduction

Matrix addition and scalar multiplication extend the arithmetic you already know to entire grids of numbers. Adding two matrices means adding every pair of elements in matching positions. Multiplying a matrix by a scalar (a single number) means multiplying every element by that number.

These two operations are the foundations for everything that follows: linear combinations, matrix multiplication, and every machine learning or graphics algorithm that uses matrices.

If you can add 3 + 5 = 8 and multiply 3 × 7 = 21, you already know how to do these operations — the only new skill is applying them systematically to every position in a grid.

## New Words

- **[[matrix addition]]** — element-wise addition of matrices with identical shape.
- **[[scalar multiplication]]** — multiplying every element of a matrix by a constant.
- **[[compatible dimensions]]** — matrices must have the same shape (same number of rows and columns) for addition.
- **[[element-wise operation]]** — an operation applied independently to each (i,j) position.
- **[[linear combination]]** — c₁A₁ + c₂A₂ + ... + cₖAₖ (sum of scalar multiples).

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Matrix Addition — Element by Element

**Builds on:** [[7.1 Matrix Notation and Shape]] (element indexing Aᵢⱼ, shape m×n), [[1.3 Addition and Subtraction]] (adding numbers)

To add two matrices, add the elements in the same position:

```
(A + B)ᵢⱼ = Aᵢⱼ + Bᵢⱼ   for every row i, column j
```

Both matrices must have the **same shape**. A 2×3 matrix can only be added to another 2×3 matrix.

#### Chunked Example

Question: A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]]. Find A + B.

Step 1: Add position by position.

```
(1,1): 1+5 = 6     (1,2): 2+6 = 8
(2,1): 3+7 = 10    (2,2): 4+8 = 12
```

Answer: **[[6, 8], [10, 12]]**.

#### Chunked Example

Question: A = [[1, 2, 3], [4, 5, 6]], B = [[0, -1, 2], [3, -2, 1]]. Find A + B.

Step 1: Same shape (2×3). Add each position:

```
Row 1: [1+0=1, 2+(-1)=1, 3+2=5]
Row 2: [4+3=7, 5+(-2)=3, 6+1=7]
```

Answer: **[[1, 1, 5], [7, 3, 7]]**.

> [!warning] Shape must match exactly
> A 2×3 matrix cannot be added to a 3×2 matrix. Always check shapes first.

### Breadcrumb 2: Scalar Multiplication — Scale Every Element

**Builds on:** [[1.4 Multiplication and Times Tables]] (multiplying numbers), Breadcrumb 1

Multiplying a matrix by a scalar c means multiplying every element by c:

```
(cA)ᵢⱼ = c × Aᵢⱼ   for every row i, column j
```

The shape does not change. Every single element gets multiplied — no exceptions.

#### Chunked Example

Question: A = [[1, 2], [3, 4]], c = 3. Find 3A.

Step 1: Multiply every element by 3.

```
Row 1: [3×1=3, 3×2=6]
Row 2: [3×3=9, 3×4=12]
```

Answer: **[[3, 6], [9, 12]]**.

#### Chunked Example

Question: A = [[-2, 0], [5, -3]], compute -2A.

Step 1: Multiply every element by -2.

```
Row 1: [-2×(-2)=4, -2×0=0]
Row 2: [-2×5=-10, -2×(-3)=6]
```

Answer: **[[4, 0], [-10, 6]]**.

### Breadcrumb 3: Properties of Addition and Scalar Multiplication

**Builds on:** Breadcrumbs 1, 2

These properties make matrices behave like ordinary numbers in many ways:

```
Commutative:     A + B = B + A
Associative:     (A + B) + C = A + (B + C)
Zero matrix:     A + 0 = A
Scalar identity: 1·A = A
Distributive:    c(A+B) = cA + cB
                 (c+d)A = cA + dA
```

#### Chunked Example

Question: Verify commutativity for A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]].

Step 1: A + B = [[1, 3], [4, 4]].

Step 2: B + A = [[1, 3], [4, 4]].

Answer: **A + B = B + A. Matrix addition is commutative**.

### Breadcrumb 4: Linear Combinations

**Builds on:** Breadcrumbs 1, 2, 3

A **linear combination** of matrices is any sum of scalar multiples:

```
c₁A₁ + c₂A₂ + ... + cₖAₖ
```

This is the most general operation using only addition and scalar multiplication. It appears throughout linear algebra — every vector space concept, every neural network layer, and every graphics transformation builds on linear combinations.

#### Chunked Example

Question: Compute 2A + 3B where A = [[1, 0], [0, 1]], B = [[0, 1], [1, 0]].

Step 1: 2A = [[2, 0], [0, 2]]. 3B = [[0, 3], [3, 0]].

Step 2: 2A + 3B = [[2, 3], [3, 2]].

Answer: **[[2, 3], [3, 2]]**.

## Worked Examples

### Example 1 — Adding Two Matrices

Question: A = [[4, -3], [1, 6], [0, 2]], B = [[2, 5], [-1, 0], [3, -4]]. Find A + B.

Step 1: Check shapes — both are 3×2, compatible for addition.

Step 2: Add element-wise:
Row 1: [4+2=6, -3+5=2]
Row 2: [1+(-1)=0, 6+0=6]
Row 3: [0+3=3, 2+(-4)=-2]

Answer: **[[6, 2], [0, 6], [3, -2]]**.

### Example 2 — Scalar Multiplication

Question: A = [[1, 2, 3], [4, 0, -2]]. Compute -3A.

Step 1: Multiply every element by -3.

Row 1: [-3×1=-3, -3×2=-6, -3×3=-9]
Row 2: [-3×4=-12, -3×0=0, -3×(-2)=6]

Answer: **[[-3, -6, -9], [-12, 0, 6]]**.

### Example 3 — Linear Combination

Question: Compute 2A + 3B where A = [[2, -1], [0, 3]], B = [[1, 2], [-3, 4]].

Step 1: 2A = [[4, -2], [0, 6]].

Step 2: 3B = [[3, 6], [-9, 12]].

Step 3: 2A + 3B = [[4+3=7, -2+6=4], [0+(-9)=-9, 6+12=18]].

Answer: **[[7, 4], [-9, 18]]**.

### Example 4 — Combination of Addition and Scalar Multiplication

Question: Given A = [[4, 2], [1, 3]], B = [[0, -1], [2, 4]], C = [[-2, 3], [1, -2]], compute A - 2B + 3C.

Step 1: -2B = [[0, 2], [-4, -8]].

Step 2: 3C = [[-6, 9], [3, -6]].

Step 3: A - 2B + 3C = [[4+0+(-6)= -2, 2+2+9=13], [1+(-4)+3=0, 3+(-8)+(-6)= -11]].

Answer: **[[-2, 13], [0, -11]]**.

## Why This Works

Adding matrices element-wise and scaling every element by a constant are the simplest possible extensions of ordinary arithmetic to grids of numbers. The properties (commutative, associative, distributive) carry over from real numbers because each element operation is independent.

This consistency is what makes matrices useful: the operations behave predictably, so we can build complex transformations (rotation, scaling, neural network layers) from simple building blocks.

## Common Mistakes

> [!failure] Mistake pattern: Adding matrices of different shapes
> A + B requires A and B to have exactly the same number of rows AND columns. Always check shape first: "Are they both m×n?"

> [!failure] Mistake pattern: Forgetting that scalar multiplication affects ALL elements
> 3 × A means every single element is multiplied by 3. Not just the first row, not just the diagonal — every element.

> [!failure] Mistake pattern: Confusing scalar multiplication with matrix multiplication
> 2 × A (scalar) multiplies every element by 2. A × B (matrix multiply, covered in 7.3) is a completely different operation using dot products.

> [!failure] Mistake pattern: Subtracting as if it were different
> Matrix subtraction is just A + (-1)B. There is no separate "matrix subtraction" operation — it is a linear combination with c = -1.

## Where This Shows Up in CS

### Image Processing
```python
brightness = 1.2 * image       # scalar multiplication: every pixel × 1.2
blend = 0.3 * image1 + 0.7 * image2  # linear combination: cross-fade
```

### Neural Networks
```python
z = W @ x + b   # matrix-vector product + bias vector
# The bias b is added element-wise (linear combination of W@x and b)
```

### Gradient Descent
```
θ_new = θ - η · ∇θ   # scalar multiplication (η=learning rate) + subtraction
```

### Data Normalisation
```
X_centered = X - μ    # subtracting mean vector from each row (broadcasting)
```
