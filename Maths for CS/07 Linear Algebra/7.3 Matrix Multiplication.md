## Introduction

Matrix multiplication is NOT element-wise. It follows a special rule: the element at position (i,j) of the product AB is the **dot product** of row i of A with column j of B.

You already know dot products from [[4.9 Dot Product and Projection]]: multiply corresponding entries and sum them. Matrix multiplication applies this pattern across every combination of rows (from A) and columns (from B).

This definition is not arbitrary — it is designed so that matrix multiplication corresponds to **composition of transformations**. When A represents transformation T₁ and B represents T₂, the product AB represents "apply T₂ first, then T₁."

## New Words

- **[[matrix multiplication]]** — C = AB where Cᵢⱼ = rowᵢ(A) · colⱼ(B).
- **[[dot product]]** — the sum of element-wise products of two equal-length vectors: a · b = Σaᵢbᵢ.
- **[[inner dimension]]** — the matching dimension p in (m×p) × (p×n).
- **[[non-commutative]]** — AB ≠ BA in general (order matters).
- **[[associative]]** — (AB)C = A(BC).

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Shape Compatibility — The Inner Dimension Rule

**Builds on:** [[7.1 Matrix Notation and Shape]] (shape m×n), [[7.2 Matrix Addition and Scalar Multiplication]] (element indexing)

A matrix of size m×p can be multiplied by a matrix of size p×n **if and only if** the inner dimensions (p) match:

```
A(m×p)  ×  B(p×n)  =  C(m×n)
   ↑         ↑
   p  must equal  p
```

The result shape uses the outer dimensions: (m×p) × (p×n) → (m×n).

#### Chunked Example

Question: Which pairs can be multiplied?
(a) A(2×3), B(3×4)
(b) A(2×3), B(2×4)
(c) A(4×2), B(2×3)

Step 1: (a) Inner: 3=3 → result 2×4. ✓

Step 2: (b) Inner: 3≠2 → cannot multiply. ✗

Step 3: (c) Inner: 2=2 → result 4×3. ✓

Answer: **(a) and (c) can be multiplied. (b) cannot**.

### Breadcrumb 2: The Dot Product Rule

**Builds on:** [[4.9 Dot Product and Projection]] (a·b = Σaᵢbᵢ), Breadcrumb 1

Each element Cᵢⱼ is the dot product of row i of A with column j of B:

```
Cᵢⱼ = Aᵢ₁B₁ⱼ + Aᵢ₂B₂ⱼ + ... + AᵢₚBₚⱼ
```

Operationally: slide across row i of A, slide down column j of B, multiply each pair, sum them all.

#### Chunked Example

Question: A = [[1, 2], [3, 4]] (2×2), B = [[5, 6], [7, 8]] (2×2). Compute AB.

Step 1: C₁₁ = row₁·col₁ = 1×5 + 2×7 = 5 + 14 = 19.

Step 2: C₁₂ = row₁·col₂ = 1×6 + 2×8 = 6 + 16 = 22.

Step 3: C₂₁ = row₂·col₁ = 3×5 + 4×7 = 15 + 28 = 43.

Step 4: C₂₂ = row₂·col₂ = 3×6 + 4×8 = 18 + 32 = 50.

Answer: **[[19, 22], [43, 50]]**.

#### Chunked Example (3×2 × 2×3)

Question: A(3×2) = [[1, 2], [3, 4], [5, 6]], B(2×3) = [[7, 8, 9], [10, 11, 12]]. Compute AB.

Step 1: Result shape: 3×3.

Step 2: Compute each element:

```
C₁₁ = 1×7+2×10 = 27    C₁₂ = 1×8+2×11 = 30    C₁₃ = 1×9+2×12 = 33
C₂₁ = 3×7+4×10 = 61    C₂₂ = 3×8+4×11 = 68    C₂₃ = 3×9+4×12 = 75
C₃₁ = 5×7+6×10 = 95    C₃₂ = 5×8+6×11 = 106   C₃₃ = 5×9+6×12 = 117
```

Answer: **[[27, 30, 33], [61, 68, 75], [95, 106, 117]]**.

### Breadcrumb 3: Matrix-Vector Multiplication

**Builds on:** Breadcrumb 2, [[4.8 Vectors Basics]] (vectors as columns)

A special case: multiplying a matrix by a column vector.

```
A(m×n) × v(n×1) → result(m×1)
```

Each element of the result is the dot product of one row of A with v.

#### Chunked Example

Question: A = [[1, 2], [3, 4], [5, 6]], v = [7, 8]ᵀ. Compute Av.

Step 1: Shape check: 3×2 × 2×1 → 3×1.

```
Row 1: 1×7 + 2×8 = 7 + 16 = 23
Row 2: 3×7 + 4×8 = 21 + 32 = 53
Row 3: 5×7 + 6×8 = 35 + 48 = 83
```

Answer: **[23, 53, 83]ᵀ**.

> [!example] CS connection
> This is exactly how a neural network layer works: y = Wx + b. W is the weight matrix, x is the input vector. Each output neuron is the dot product of its weight row with the input.

### Breadcrumb 4: Non-Commutativity — Order Matters

**Builds on:** Breadcrumbs 1, 2

In general, **AB ≠ BA**. Matrix multiplication is not commutative. Reversing the order gives a different result (and often cannot even be computed due to shape mismatch).

#### Chunked Example

Question: Show AB ≠ BA for A = [[1, 2], [3, 4]], B = [[0, 1], [1, 0]].

Step 1: Compute AB:

```
AB = [[1×0+2×1, 1×1+2×0], [3×0+4×1, 3×1+4×0]]
   = [[2, 1], [4, 3]]
```

Step 2: Compute BA:

```
BA = [[0×1+1×3, 0×2+1×4], [1×1+0×3, 1×2+0×4]]
   = [[3, 4], [1, 2]]
```

Step 3: [[2, 1], [4, 3]] ≠ [[3, 4], [1, 2]].

Answer: **AB ≠ BA. Order matters**.

### Breadcrumb 5: Properties of Matrix Multiplication

**Builds on:** Breadcrumbs 1-4

```
Associative:    (AB)C = A(BC)
Distributive:   A(B+C) = AB + AC
                (A+B)C = AC + BC
Not commutative: AB ≠ BA (usually)
Identity:       A·I = A, I·A = A
```

#### Chunked Example

Question: Verify AI = A for A = [[1, 2], [3, 4]].

Step 1: I₂ = [[1, 0], [0, 1]].

Step 2: AI = [[1×1+2×0, 1×0+2×1], [3×1+4×0, 3×0+4×1]] = [[1, 2], [3, 4]] = A.

Answer: **AI = A. The identity matrix acts like the number 1**.

## Worked Examples

### Example 1 — 2×2 Matrix Multiplication

Question: A = [[2, -1], [3, 4]], B = [[1, 0], [-2, 3]]. Compute AB.

Step 1: Shape check: 2×2 × 2×2 → 2×2.

Step 2: C₁₁ = row₁·col₁ = 2×1 + (-1)×(-2) = 2 + 2 = 4.

Step 3: C₁₂ = row₁·col₂ = 2×0 + (-1)×3 = 0 - 3 = -3.

Step 4: C₂₁ = row₂·col₁ = 3×1 + 4×(-2) = 3 - 8 = -5.

Step 5: C₂₂ = row₂·col₂ = 3×0 + 4×3 = 0 + 12 = 12.

Answer: **[[4, -3], [-5, 12]]**.

### Example 2 — Rectangular Matrix Multiplication

Question: A = [[1, 3, 2], [0, -1, 4]], B = [[2, 1], [-1, 3], [0, 5]]. Compute AB.

Step 1: Shape check: 2×3 × 3×2 → 2×2.

Step 2: C₁₁ = 1×2 + 3×(-1) + 2×0 = 2 - 3 + 0 = -1.

Step 3: C₁₂ = 1×1 + 3×3 + 2×5 = 1 + 9 + 10 = 20.

Step 4: C₂₁ = 0×2 + (-1)×(-1) + 4×0 = 0 + 1 + 0 = 1.

Step 5: C₂₂ = 0×1 + (-1)×3 + 4×5 = 0 - 3 + 20 = 17.

Answer: **[[-1, 20], [1, 17]]**.

### Example 3 — Matrix-Vector Product

Question: A = [[2, -1], [0, 3], [1, 4]], v = [2, -3]ᵀ. Compute Av.

Step 1: Shape check: 3×2 × 2×1 → 3×1.

Step 2: Row 1: 2×2 + (-1)×(-3) = 4 + 3 = 7.

Step 3: Row 2: 0×2 + 3×(-3) = 0 - 9 = -9.

Step 4: Row 3: 1×2 + 4×(-3) = 2 - 12 = -10.

Answer: **[7, -9, -10]ᵀ**.

### Example 4 — Non-Commutativity

Question: A = [[0, 1], [1, 0]], B = [[1, 2], [3, 4]]. Compute AB and BA and compare.

Step 1: AB = [[0×1+1×3, 0×2+1×4], [1×1+0×3, 1×2+0×4]] = [[3, 4], [1, 2]].

Step 2: BA = [[1×0+2×1, 1×1+2×0], [3×0+4×1, 3×1+4×0]] = [[2, 1], [4, 3]].

Step 3: [[3, 4], [1, 2]] ≠ [[2, 1], [4, 3]].

Answer: **AB ≠ BA. Matrix multiplication is not commutative**.

## Why This Works

Matrix multiplication is defined as row-dot-column specifically to represent **composition of linear transformations**. If A represents transformation T₁ and B represents T₂, then AB represents "first T₂, then T₁." The dot product captures how each input component contributes to each output component.

This is why the inner dimensions must match: the output of T₂ (p-dimensional) must be a valid input for T₁ (which expects p-dimensional inputs).

## Common Mistakes

> [!failure] Mistake pattern: Trying to multiply with mismatched inner dimensions
> If A is m×p and B is q×n, p must equal q. Check: "are the inner numbers the same?"

> [!failure] Mistake pattern: Multiplying element-wise
> Matrix multiplication is NOT [[1, 2], [3, 4]] × [[5, 6], [7, 8]] = [[1×5, 2×6], [3×7, 4×8]]. That is the Hadamard (element-wise) product, a different operation.

> [!failure] Mistake pattern: Forgetting that order matters
> AB and BA are different. Swapping them changes the result (if it is even computable).

> [!failure] Mistake pattern: Confusing result shape
> (m×p) × (p×n) gives (m×n). The middle dimension disappears, the outer ones remain.
