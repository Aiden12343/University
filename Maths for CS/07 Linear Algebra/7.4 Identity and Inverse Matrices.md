## Introduction

In ordinary arithmetic, multiplying by 1 leaves a number unchanged. Multiplying by the reciprocal (1/3) undoes the multiplication (3 × 1/3 = 1).

Matrices have the same concepts. The **identity matrix** Iₙ is the "1" of matrix multiplication — multiplying any compatible matrix by I leaves it unchanged. The **inverse** A⁻¹ is the "reciprocal" — A × A⁻¹ = I. If A represents a transformation (like a rotation), then A⁻¹ represents the reverse transformation (rotate back).

Not every matrix has an inverse. Those that do are **invertible** (or **non-singular**). Those that do not are **singular**. The determinant (covered in 7.5) tells you which is which.

## New Words

- **[[identity matrix]]** — Iₙ: n×n matrix with 1s on the diagonal and 0s elsewhere.
- **[[inverse matrix]]** — A⁻¹ such that AA⁻¹ = A⁻¹A = I.
- **[[singular matrix]]** — a matrix with no inverse (determinant = 0).
- **[[invertible]]** — a matrix that has an inverse (non-singular).
- **[[orthogonal matrix]]** — a square matrix where Q⁻¹ = Qᵀ (inverse equals transpose).

## Breadcrumbs

### Breadcrumb 1: The Identity Matrix Iₙ

**Builds on:** [[7.1 Matrix Notation and Shape]] (square matrix, diagonal), [[7.3 Matrix Multiplication]] (AI = A)

The identity matrix Iₙ is an n×n square matrix with 1s on the main diagonal and 0s everywhere else:

```
I₂ = [1  0]      I₃ = [1  0  0]
     [0  1]           [0  1  0]
                      [0  0  1]
```

For any matrix A where the shapes are compatible:

```
A × I = A     and     I × A = A
```

#### Chunked Example

Question: Verify AI = A for A = [[1, 2, 3], [4, 5, 6]] and the correct identity matrix.

Step 1: A is 2×3. The identity must be 3×3 (I₃).

Step 2: A × I₃ = [[1, 2, 3], [4, 5, 6]] × [[1, 0, 0], [0, 1, 0], [0, 0, 1]].

```
Row 1: [1×1+2×0+3×0, 1×0+2×1+3×0, 1×0+2×0+3×1] = [1, 2, 3]
Row 2: [4×1+5×0+6×0, 4×0+5×1+6×0, 4×0+5×0+6×1] = [4, 5, 6]
```

Answer: **AI = A. The identity leaves A unchanged**.

### Breadcrumb 2: What Is an Inverse?

**Builds on:** Breadcrumb 1, [[7.3 Matrix Multiplication]] (product of matrices)

The inverse of a square matrix A is written A⁻¹. It satisfies:

```
A × A⁻¹ = A⁻¹ × A = I
```

Only square matrices can have inverses. If A represents a transformation, A⁻¹ undoes it.

#### Chunked Example

Question: Verify that [[2, 1], [5, 3]]⁻¹ = [[3, -1], [-5, 2]].

Step 1: Multiply the matrix by its claimed inverse:

```
[[2, 1], [5, 3]] × [[3, -1], [-5, 2]]
= [[2×3+1×(-5), 2×(-1)+1×2], [5×3+3×(-5), 5×(-1)+3×2]]
= [[6-5, -2+2], [15-15, -5+6]]
= [[1, 0], [0, 1]] = I₂
```

Answer: **[[3, -1], [-5, 2]] is indeed the inverse**.

### Breadcrumb 3: The 2×2 Inverse Formula

**Builds on:** Breadcrumb 2, [[7.1 Matrix Notation and Shape]] (element indexing)

For a 2×2 matrix A = [[a, b], [c, d]]:

```
A⁻¹ = (1 / (ad - bc)) × [[d, -b], [-c, a]]
```

The quantity ad - bc is called the **determinant** (covered in depth in 7.5). If ad - bc = 0, the matrix is singular and has no inverse.

#### Chunked Example

Question: Find the inverse of A = [[4, 3], [2, 5]].

Step 1: Compute the determinant: ad - bc = 4×5 - 3×2 = 20 - 6 = 14.

Step 2: Apply the formula:

```
A⁻¹ = (1/14) × [[5, -3], [-2, 4]]
    = [[5/14, -3/14], [-2/14, 4/14]]
    = [[0.357, -0.214], [-0.143, 0.286]]
```

Step 3: Verify: A × A⁻¹ should give I₂.

Answer: **A⁻¹ = [[5/14, -3/14], [-1/7, 2/7]]**.

#### Chunked Example

Question: Find the inverse of B = [[2, 4], [1, 2]].

Step 1: Compute the determinant: ad - bc = 2×2 - 4×1 = 4 - 4 = 0.

Step 2: Cannot divide by zero → no inverse exists.

Answer: **B is singular. No inverse exists**.

### Breadcrumb 4: Singular Matrices — When Inverses Fail

**Builds on:** Breadcrumb 3

A matrix is **singular** (non-invertible) when its determinant is zero. Geometrically, a singular matrix collapses space — it maps multiple input vectors to the same output, so there is no way to uniquely undo the transformation.

In 2D, a singular matrix maps the entire plane onto a line (or a point). Information is lost, and no inverse can recover it.

Common causes of singularity:
- One row is a multiple of another row
- One column is a multiple of another column
- A row or column is all zeros

### Breadcrumb 5: Properties of Inverses

**Builds on:** Breadcrumbs 2, 3

```
(AB)⁻¹ = B⁻¹A⁻¹          (reverse order)
(A⁻¹)⁻¹ = A              (inverse of inverse)
(kA)⁻¹ = (1/k) A⁻¹       (scalar factor)
(Aᵀ)⁻¹ = (A⁻¹)ᵀ          (transpose and inverse commute)
```

#### Chunked Example

Question: If A = [[1, 2], [3, 4]] (known inverse A⁻¹ = [[-2, 1], [1.5, -0.5]]) and B = [[0, 1], [1, 0]] (B⁻¹ = B since B is its own inverse), verify (AB)⁻¹ = B⁻¹A⁻¹.

Step 1: Compute AB = [[1, 2], [3, 4]] × [[0, 1], [1, 0]] = [[2, 1], [4, 3]].

Step 2: Find (AB)⁻¹ using the 2×2 formula:
det = 2×3 - 1×4 = 6 - 4 = 2.
(AB)⁻¹ = (1/2) × [[3, -1], [-4, 2]] = [[1.5, -0.5], [-2, 1]].

Step 3: Compute B⁻¹A⁻¹ = [[0, 1], [1, 0]] × [[-2, 1], [1.5, -0.5]] = [[1.5, -0.5], [-2, 1]].

Step 4: They match. ✓

Answer: **(AB)⁻¹ = B⁻¹A⁻¹ is verified**.

## Worked Examples

### Example 1 — Multiplying by the Identity

Question: A = [[3, -1, 2], [0, 4, 1]]. Verify that AI = A using the correct identity matrix.

Step 1: A is 2×3, so the identity must be I₃ (3×3).

Step 2: AI₃ = [[3, -1, 2], [0, 4, 1]] × [[1, 0, 0], [0, 1, 0], [0, 0, 1]].

Row 1: [3×1+(-1)×0+2×0, 3×0+(-1)×1+2×0, 3×0+(-1)×0+2×1] = [3, -1, 2].
Row 2: [0×1+4×0+1×0, 0×0+4×1+1×0, 0×0+4×0+1×1] = [0, 4, 1].

Answer: **AI₃ = [[3, -1, 2], [0, 4, 1]] = A. Verified**.

### Example 2 — Finding a 2×2 Inverse

Question: Find the inverse of A = [[3, 2], [5, 4]].

Step 1: Compute the determinant: ad - bc = 3×4 - 2×5 = 12 - 10 = 2. det ≠ 0 → invertible.

Step 2: Apply the 2×2 formula: A⁻¹ = (1/2) × [[4, -2], [-5, 3]] = [[2, -1], [-2.5, 1.5]].

Step 3: Verify: A × A⁻¹ = [[3, 2], [5, 4]] × [[2, -1], [-2.5, 1.5]] = [[6-5, -3+3], [10-10, -5+6]] = [[1, 0], [0, 1]] = I₂.

Answer: **A⁻¹ = [[2, -1], [-2.5, 1.5]]**.

### Example 3 — Singular Matrix

Question: Find the inverse of B = [[6, 3], [2, 1]].

Step 1: Compute the determinant: ad - bc = 6×1 - 3×2 = 6 - 6 = 0.

Step 2: Cannot divide by zero → no inverse exists.

Answer: **B is singular. No inverse exists** (the rows are multiples: row 2 = (1/3) × row 1).

### Example 4 — Recovering a Matrix from Its Inverse

Question: Given A⁻¹ = [[2, 1], [5, 3]], find A (hint: A = (A⁻¹)⁻¹).

Step 1: Let B = A⁻¹ = [[2, 1], [5, 3]]. Compute det(B) = 2×3 - 1×5 = 6 - 5 = 1.

Step 2: A = B⁻¹ = (1/1) × [[3, -1], [-5, 2]] = [[3, -1], [-5, 2]].

Step 3: Verify: A × A⁻¹ = [[3, -1], [-5, 2]] × [[2, 1], [5, 3]] = [[6-5, 3-3], [-10+10, -5+6]] = [[1, 0], [0, 1]].

Answer: **A = [[3, -1], [-5, 2]]**.

## Why This Works

The inverse undoes the effect of a matrix. If A rotates 90° counterclockwise, A⁻¹ rotates 90° clockwise. If A scales by factor 2, A⁻¹ scales by factor 1/2.

The formula for the 2×2 inverse (swap diagonal, negate off-diagonal, divide by determinant) follows from solving the equation AX = I for the unknown matrix X. The determinant tells you whether a unique solution exists.

The reverse-order property (AB)⁻¹ = B⁻¹A⁻¹ makes intuitive sense: to undo "first put on socks, then put on shoes," you must first remove shoes, then remove socks — reverse order.

## Common Mistakes

> [!failure] Mistake pattern: Forgetting that only square matrices can have inverses
> Non-square matrices do not have inverses. A 2×3 matrix cannot be inverted.

> [!failure] Mistake pattern: Confusing the inverse with the transpose
> A⁻¹ is not the same as Aᵀ. They are equal only for orthogonal matrices (Q⁻¹ = Qᵀ).

> [!failure] Mistake pattern: Getting the 2×2 formula wrong
> A⁻¹ = (1/det) × [[d, -b], [-c, a]]. Notice: a and d swap, b and c get negated, NOT [[a, -b], [-c, d]].

> [!failure] Mistake pattern: Forgetting to check the determinant first
> Always check det ≠ 0 before computing an inverse. If det = 0, stop — the matrix is singular.

## Where This Shows Up in CS

### Solving Linear Systems
```python
x = inv(A) @ b   # solve Ax = b (though Gaussian elimination is preferred numerically)
```

### 3D Graphics
```python
camera_matrix = inv(view_matrix)  # camera position from view transform
```

### Least Squares Regression
```python
beta = inv(X.T @ X) @ X.T @ y   # normal equation
```
