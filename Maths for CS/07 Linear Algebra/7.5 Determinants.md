## Introduction

The **determinant** is a single number computed from a square matrix. It answers three crucial questions at once:

1. **Is the matrix invertible?** det ≠ 0 means yes. det = 0 means no.
2. **How does the transformation scale area?** |det| is the factor by which areas (2D) or volumes (3D) are scaled.
3. **Is the orientation preserved?** det > 0 means yes. det < 0 means the transformation flips orientation.

For a 2×2 matrix A = [[a, b], [c, d]], the determinant is ad - bc. This is the same quantity that appeared in the 2×2 inverse formula in [[7.4 Identity and Inverse Matrices]].

## New Words

- **[[determinant]]** — det(A) or |A|: a scalar computed from a square matrix. det = 0 means singular.
- **[[Sarrus rule]]** — a visual method for computing the determinant of a 3×3 matrix.
- **[[area scaling factor]]** — |det(A)| = how much the transformation A multiplies area by.
- **[[orientation]]** — det(A) > 0 preserves orientation; det(A) < 0 flips it.
- **[[cofactor expansion]]** — a general method for computing determinants of any size.

## Breadcrumbs

### Breadcrumb 1: Determinant of a 2×2 Matrix

**Builds on:** [[7.4 Identity and Inverse Matrices]] (det appears in inverse formula), [[7.1 Matrix Notation and Shape]] (element indexing)

For A = [[a, b], [c, d]]:

```
det(A) = ad - bc
```

This is also written as |A| or | a  b |
                            | c  d |.

#### Chunked Example

Question: Compute det(A) for A = [[4, 3], [2, 5]].

Step 1: a = 4, b = 3, c = 2, d = 5.

Step 2: det = ad - bc = 4×5 - 3×2 = 20 - 6 = 14.

Answer: **det(A) = 14. Since det ≠ 0, A is invertible**.

#### Chunked Example

Question: Compute det(B) for B = [[2, 4], [1, 2]].

Step 1: a = 2, b = 4, c = 1, d = 2.

Step 2: det = 2×2 - 4×1 = 4 - 4 = 0.

Answer: **det(B) = 0. B is singular — no inverse exists**.

### Breadcrumb 2: Determinant of a 3×3 Matrix (Sarrus Rule)

**Builds on:** Breadcrumb 1

For a 3×3 matrix, Sarrus rule is a visual shortcut. Write the matrix and repeat the first two columns to the right:

```
| a  b  c |
| d  e  f |
| g  h  i |

det = (aei + bfg + cdh) - (ceg + afh + bdi)
```

Forward diagonals (top-left to bottom-right): aei + bfg + cdh
Backward diagonals (bottom-left to top-right): ceg + afh + bdi
Subtract backward from forward.

#### Chunked Example

Question: Compute det(A) for A = [[1, 2, 3], [4, 5, 6], [7, 8, 10]].

Step 1: Write with repeated columns:

```
[1  2  3 | 1  2]
[4  5  6 | 4  5]
[7  8 10 | 7  8]
```

Step 2: Forward diagonals:
1×5×10 = 50
2×6×7 = 84
3×4×8 = 96
Sum = 50 + 84 + 96 = 230

Step 3: Backward diagonals:
3×5×7 = 105
1×6×8 = 48
2×4×10 = 80
Sum = 105 + 48 + 80 = 233

Step 4: det = 230 - 233 = -3.

Answer: **det(A) = -3. A is invertible (det ≠ 0) and orientation is flipped (det < 0)**.

### Breadcrumb 3: What the Determinant Tells Us

**Builds on:** Breadcrumbs 1, 2, [[7.4 Identity and Inverse Matrices]]

#### Invertibility

det = 0 ⇔ matrix is singular (no inverse).
det ≠ 0 ⇔ matrix is invertible.

This is the most important single use of the determinant.

#### Area and Volume Scaling

In 2D, |det(A)| is the factor by which the area of any shape changes when transformed by A. A unit square maps to a parallelogram of area |det|.

In 3D, |det(A)| is the volume scaling factor.

#### Orientation

det(A) > 0: the transformation preserves orientation (right-handed stays right-handed).
det(A) < 0: the transformation flips orientation (right-handed becomes left-handed).

#### Chunked Example

Question: A transformation has matrix [[2, 0], [0, 3]]. What does it do to a unit square?

Step 1: det = 2×3 - 0×0 = 6.

Step 2: Area scaling factor = |6| = 6. A unit square (area 1) becomes a 2×3 rectangle (area 6).

Step 3: Orientation: det = 6 > 0, orientation preserved.

Answer: **Scales width by 2, height by 3. Area multiplies by 6**.

### Breadcrumb 4: Properties of Determinants

**Builds on:** Breadcrumbs 1-3, [[7.3 Matrix Multiplication]]

```
det(AB) = det(A) × det(B)          (product rule)
det(A⁻¹) = 1 / det(A)              (inverse)
det(Aᵀ) = det(A)                   (transpose)
det(cA) = cⁿ × det(A)              (scalar, for n×n matrix)
det(I) = 1
det(0) = 0
```

The product rule is especially powerful: the area scaling of a composition is the product of the individual scalings.

#### Chunked Example

Question: If det(A) = 2 and det(B) = 3, what is det(AB)? What is det(A⁻¹)?

Step 1: det(AB) = det(A) × det(B) = 2 × 3 = 6.

Step 2: det(A⁻¹) = 1 / det(A) = 1/2.

Answer: **det(AB) = 6, det(A⁻¹) = 0.5**.

## Worked Examples

### Example 1 — 2×2 Determinant

Question: Compute det(A) for A = [[2, -3], [1, 5]].

Step 1: a = 2, b = -3, c = 1, d = 5.

Step 2: det = ad - bc = 2×5 - (-3)×1 = 10 + 3 = 13.

Answer: **det(A) = 13. Since det ≠ 0, A is invertible**.

### Example 2 — 3×3 Determinant Using Sarrus Rule

Question: Compute det(B) for B = [[2, 1, 0], [3, -1, 2], [1, 0, 3]].

Step 1: Write with repeated columns:
[[2, 1, 0 | 2, 1], [3, -1, 2 | 3, -1], [1, 0, 3 | 1, 0]]

Step 2: Forward diagonals (top-left to bottom-right):
2×(-1)×3 = -6
1×2×1 = 2
0×3×0 = 0
Sum = -6 + 2 + 0 = -4

Step 3: Backward diagonals (bottom-left to top-right):
0×(-1)×1 = 0
2×2×1 = 4
3×3×0 = 0
Sum = 0 + 4 + 0 = 4

Step 4: det = forward - backward = -4 - 4 = -8.

Answer: **det(B) = -8. B is invertible with orientation flipped**.

### Example 3 — Product and Inverse Properties

Question: If det(A) = 4 and det(B) = 0.5, find det(AB) and det(A⁻¹).

Step 1: det(AB) = det(A) × det(B) = 4 × 0.5 = 2.

Step 2: det(A⁻¹) = 1 / det(A) = 1/4 = 0.25.

Answer: **det(AB) = 2, det(A⁻¹) = 0.25**.

### Example 4 — Finding an Unknown Entry from det = 0

Question: For A = [[2, 4], [3, d]], det(A) = 0. Find d.

Step 1: det(A) = ad - bc = 2d - 4×3 = 2d - 12.

Step 2: Set det = 0: 2d - 12 = 0 → 2d = 12 → d = 6.

Step 3: Verify: [[2, 4], [3, 6]] → det = 2×6 - 4×3 = 12 - 12 = 0. ✓

Answer: **d = 6. The matrix is singular with det = 0**.

## Why This Works

The determinant measures how a linear transformation scales areas (or volumes). This geometric interpretation explains the product rule: applying A scales area by |det(A)|, then applying B scales it by |det(B)|, so the combined scaling is |det(A)| × |det(B)|.

The formula ad - bc for a 2×2 matrix is the area of the parallelogram formed by the column vectors (or row vectors) of the matrix. When the columns are linearly dependent (one is a multiple of the other), the parallelogram collapses to a line with zero area — det = 0.

## Common Mistakes

> [!failure] Mistake pattern: Forgetting the minus sign in 2×2
> det([[a, b], [c, d]]) = ad - bc, not ad + bc or ad - cb. The off-diagonal product b×c is subtracted.

> [!failure] Mistake pattern: Applying Sarrus to non-3×3 matrices
> Sarrus works only for 3×3. For larger matrices, use cofactor expansion or row reduction.

> [!failure] Mistake pattern: Thinking det = 0 means "matrix is bad"
> det = 0 is not a bug — it tells you the matrix collapses space. Many useful transformations are singular (projections, for example).

> [!failure] Mistake pattern: Mixing up forward and backward diagonals in Sarrus
> Forward = top-left to bottom-right (add). Backward = bottom-left to top-right (subtract).
