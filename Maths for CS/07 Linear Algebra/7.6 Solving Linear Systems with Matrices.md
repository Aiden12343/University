## Introduction

A system of linear equations like:

```
2x + 3y = 7
4x -  y = 1
```

can be written as a single matrix equation:

```
[[2, 3], [4, -1]] × [x, y]ᵀ = [7, 1]ᵀ
```

Or compactly: **Ax = b**, where A is the coefficient matrix, x is the vector of unknowns, and b is the vector of constants.

From [[3.5 Systems of Linear Equations]], you already know how to solve small systems by substitution or elimination. Matrix methods extend this to any size — solving 1000 equations in 1000 unknowns is routine in scientific computing.

## New Words

- **[[augmented matrix]]** — [A | b]: the coefficient matrix A with the constant vector b appended.
- **[[elementary row operations]]** — three allowed operations: swap rows, scale a row, add a multiple of one row to another.
- **[[row echelon form]]** — a triangular form where each leading entry is to the right of the one above.
- **[[Gaussian elimination]]** — the algorithm that reduces [A | b] to row echelon form.
- **[[back substitution]]** — solving for variables starting from the last row upward.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Writing a Linear System as Ax = b

**Builds on:** [[3.5 Systems of Linear Equations]] (solving small systems), [[7.3 Matrix Multiplication]] (matrix-vector product), [[7.1 Matrix Notation and Shape]] (column vectors)

Given a system of m equations in n unknowns:

```
A₁₁x₁ + A₁₂x₂ + ... + A₁ₙxₙ = b₁
A₂₁x₁ + A₂₂x₂ + ... + A₂ₙxₙ = b₂
...
Aₘ₁x₁ + Aₘ₂x₂ + ... + Aₘₙxₙ = bₘ
```

Write it as Ax = b, where A is m×n, x is n×1, and b is m×1.

#### Chunked Example

Question: Write the system 3x - 2y + z = 5, x + y - z = 0, 2x + 3y + 4z = 10 as Ax = b.

Step 1: Extract coefficients into A:

```
A = [[3, -2, 1], [1, 1, -1], [2, 3, 4]]
```

Step 2: x = [x, y, z]ᵀ, b = [5, 0, 10]ᵀ.

Answer: **[[3, -2, 1], [1, 1, -1], [2, 3, 4]] × [x, y, z]ᵀ = [5, 0, 10]ᵀ**.

### Breadcrumb 2: Solving with the Inverse

**Builds on:** [[7.4 Identity and Inverse Matrices]] (A⁻¹), Breadcrumb 1

If A is square and invertible (det ≠ 0), multiply both sides by A⁻¹:

```
Ax = b
A⁻¹Ax = A⁻¹b
Ix = A⁻¹b
x = A⁻¹b
```

The solution is **x = A⁻¹b**. This is mathematically elegant, but numerically, Gaussian elimination is preferred (it is faster and more stable).

#### Chunked Example

Question: Solve 2x + y = 5, 5x + 3y = 11 using the inverse method.

Step 1: A = [[2, 1], [5, 3]], b = [5, 11]ᵀ.

Step 2: Compute A⁻¹: det = 2×3 - 1×5 = 6 - 5 = 1.
A⁻¹ = (1/1) × [[3, -1], [-5, 2]] = [[3, -1], [-5, 2]].

Step 3: x = A⁻¹b = [[3, -1], [-5, 2]] × [5, 11]ᵀ = [3×5-1×11, -5×5+2×11] = [4, -3]ᵀ.

Answer: **x = 4, y = -3**.

### Breadcrumb 3: Gaussian Elimination

**Builds on:** Breadcrumbs 1, 2, [[7.5 Determinants]] (det ≠ 0 ensures unique solution)

Gaussian elimination is the workhorse method. It uses three **elementary row operations**:

1. **Swap** two rows.
2. **Multiply** a row by a non-zero constant.
3. **Add** a multiple of one row to another row.

These operations preserve the solution set of the system. The goal is to reach **row echelon form**:

```
[1  a  b | c]
[0  1  d | e]
[0  0  1 | f]
```

Then solve by **back substitution** (starting from the last row).

#### Chunked Example

Question: Solve using Gaussian elimination:
x + y + z = 6
2x - y + z = 3
x + 2y - z = 2

Step 1: Write the augmented matrix:

```
[1   1   1 | 6]
[2  -1   1 | 3]
[1   2  -1 | 2]
```

Step 2: Eliminate x from row 2: R₂ = R₂ - 2R₁.

```
[1   1   1 |  6]
[0  -3  -1 | -9]
[1   2  -1 |  2]
```

Step 3: Eliminate x from row 3: R₃ = R₃ - R₁.

```
[1   1   1 |  6]
[0  -3  -1 | -9]
[0   1  -2 | -4]
```

Step 4: Swap R₂ and R₃ to get a better pivot:

```
[1   1   1 |  6]
[0   1  -2 | -4]
[0  -3  -1 | -9]
```

Step 5: Eliminate y from row 3: R₃ = R₃ + 3R₂.

```
[1   1   1 |  6]
[0   1  -2 | -4]
[0   0  -7 | -21]
```

Step 6: Row 3: -7z = -21 → z = 3.

Step 7: Back substitute: Row 2: y - 2(3) = -4 → y = 2.

Step 8: Row 1: x + 2 + 3 = 6 → x = 1.

Answer: **x = 1, y = 2, z = 3**.

### Breadcrumb 4: Row Echelon Form and Rank

**Builds on:** Breadcrumb 3

A matrix is in **row echelon form** when:
- All zero rows are at the bottom.
- The leading entry (first non-zero) of each non-zero row is to the right of the one above.
- The leading entry in each non-zero row is 1 (optional, but standard).

The **rank** of a matrix is the number of non-zero rows in row echelon form. It tells you how many equations are genuinely independent.

- rank(A) = number of unknowns → unique solution (if A is square and det ≠ 0)
- rank(A) < number of unknowns → infinite solutions or no solution
- rank(A) < rank([A | b]) → no solution (inconsistent)

## Worked Examples

### Example 1 — Writing a System as Ax = b

Question: Write the system 4x - y = 9, 2x + 5y = -3 as a matrix equation.

Step 1: Extract coefficients: A = [[4, -1], [2, 5]].

Step 2: Unknown vector: x = [x, y]ᵀ. Constant vector: b = [9, -3]ᵀ.

Answer: **[[4, -1], [2, 5]] × [x, y]ᵀ = [9, -3]ᵀ**.

### Example 2 — Solving with the Inverse

Question: Solve 3x + 5y = 1, 2x + 4y = 0 using the inverse method.

Step 1: A = [[3, 5], [2, 4]], b = [1, 0]ᵀ.

Step 2: det(A) = 3×4 - 5×2 = 12 - 10 = 2.

Step 3: A⁻¹ = (1/2) × [[4, -5], [-2, 3]] = [[2, -2.5], [-1, 1.5]].

Step 4: x = A⁻¹b = [[2, -2.5], [-1, 1.5]] × [1, 0]ᵀ = [2, -1]ᵀ.

Answer: **x = 2, y = -1**.

### Example 3 — Solving via Gaussian Elimination

Question: Solve using Gaussian elimination:
2x + y - z = 3
x - y + z = 0
x + 2y + z = 6

Step 1: Write the augmented matrix:
[[2, 1, -1 | 3], [1, -1, 1 | 0], [1, 2, 1 | 6]]

Step 2: Swap R₁ and R₂ to get a 1 as pivot (optional but convenient):
[[1, -1, 1 | 0], [2, 1, -1 | 3], [1, 2, 1 | 6]]

Step 3: Eliminate x from R₂: R₂ = R₂ - 2R₁.
[[1, -1, 1 | 0], [0, 3, -3 | 3], [1, 2, 1 | 6]]

Step 4: Eliminate x from R₃: R₃ = R₃ - R₁.
[[1, -1, 1 | 0], [0, 3, -3 | 3], [0, 3, 0 | 6]]

Step 5: Eliminate y from R₃: R₃ = R₃ - R₂.
[[1, -1, 1 | 0], [0, 3, -3 | 3], [0, 0, 3 | 3]]

Step 6: Back substitution — Row 3: 3z = 3 → z = 1.
Row 2: 3y - 3(1) = 3 → 3y = 6 → y = 2.
Row 1: x - 2 + 1 = 0 → x = 1.

Answer: **x = 1, y = 2, z = 1**.

### Example 4 — Augmented Matrix and System Conversion

Question: Write the system 2x + 3y - z = 5, x - 2y + 4z = -1, 3x + y - 2z = 7 as Ax = b and give the augmented matrix.

Step 1: A = [[2, 3, -1], [1, -2, 4], [3, 1, -2]], x = [x, y, z]ᵀ, b = [5, -1, 7]ᵀ.

Step 2: Augmented matrix [A | b] = [[2, 3, -1 | 5], [1, -2, 4 | -1], [3, 1, -2 | 7]].

Answer: **Ax = b with A = [[2, 3, -1], [1, -2, 4], [3, 1, -2]]. Augmented matrix = [[2, 3, -1 | 5], [1, -2, 4 | -1], [3, 1, -2 | 7]]**.

## Why This Works

Gaussian elimination systematically eliminates variables one at a time by combining equations. The three elementary row operations correspond exactly to legitimate algebraic manipulations: swapping equations, multiplying both sides by a constant, and adding two equations together.

The augmented matrix [A | b] is just a compact notation for the system. Every row operation applied to [A | b] produces a new system with the same solution set — so the solution of the triangular system at the end is also the solution of the original system.

## Common Mistakes

> [!failure] Mistake pattern: Row operations that change the solution
> Only the three elementary operations are allowed. You cannot multiply a row by 0 (loses information) or add a non-constant multiple.

> [!failure] Mistake pattern: Arithmetic errors in back substitution
> Work from the bottom up. After finding z, substitute into the row above for y, then into the row above that for x.

> [!failure] Mistake pattern: Forgetting to apply row operations to the b column
> Every operation on the coefficient side must also be applied to the augmented b column.

> [!failure] Mistake pattern: Using the inverse method for large systems
> Computing A⁻¹ for a 1000×1000 matrix is slow and numerically unstable. Gaussian elimination (or LU decomposition) is preferred.
