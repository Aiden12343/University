## Introduction

A **vector space** is a set of vectors that is closed under addition and scalar multiplication — adding any two vectors in the space keeps you in the space, and scaling any vector keeps you in the space.

You already work in vector spaces every day. ℝ² (the 2D plane) is a vector space. ℝ³ (3D space) is a vector space. The set of all 2×3 matrices is a vector space. The set of all polynomials of degree ≤ 2 is a vector space.

The **span** of a set of vectors is all vectors you can reach by taking linear combinations (scaling and adding). A **basis** is the smallest set of vectors needed to reach the entire space — like the directions "forward, right, up" that span ℝ³.

## New Words

- **[[vector space]]** — a set of vectors closed under addition and scalar multiplication.
- **[[subspace]]** — a subset of a vector space that is itself a vector space.
- **[[span]]** — the set of all linear combinations of a given set of vectors.
- **[[linear independence]]** — a set of vectors where no vector can be written as a combination of the others.
- **[[basis]]** — a linearly independent spanning set (the minimal set of directions).
- **[[dimension]]** — the number of vectors in any basis for the space.

## Breadcrumbs

### Breadcrumb 1: What Is a Vector Space?

**Builds on:** [[4.8 Vectors Basics]] (vectors as directed quantities), [[5.1 Set Theory Basics]] (sets, elements, closure), [[7.1 Matrix Notation and Shape]] (vectors as matrices)

A vector space V is a set of vectors with two operations (addition and scalar multiplication) that satisfy:

- **Closure under addition**: u + v ∈ V for all u, v ∈ V
- **Closure under scalar multiplication**: cv ∈ V for all c ∈ ℝ, v ∈ V
- Plus the usual properties (commutative, associative, distributive, etc.)

The most familiar vector space is ℝⁿ — all n-dimensional vectors of real numbers.

### Chunked Example

Question: Is the set of all vectors of the form [x, y]ᵀ where x ≥ 0 a vector space?

Step 1: Check closure under scalar multiplication: v = [1, 0]ᵀ is in the set (x = 1 ≥ 0).

Step 2: c = -1 gives -1 × [1, 0]ᵀ = [-1, 0]ᵀ. But x = -1 < 0 → not in the set.

Answer: **No. Not closed under scalar multiplication (negative scalars break the rule)**.

### Breadcrumb 2: Subspaces

**Builds on:** Breadcrumb 1

A **subspace** is a subset of a vector space that is itself a vector space. To check if a subset is a subspace, verify:

1. The zero vector is in the subset.
2. The subset is closed under addition.
3. The subset is closed under scalar multiplication.

If all three hold, it is a subspace.

Examples of subspaces of ℝ³:
- Lines through the origin
- Planes through the origin
- The origin itself ({0})

Non-examples:
- A line NOT through the origin (fails zero vector check)
- The first quadrant x ≥ 0, y ≥ 0, z ≥ 0 (fails scalar multiplication with negative scalars)

### Chunked Example

Question: Is the set of all vectors [x, y, 0]ᵀ (the xy-plane) a subspace of ℝ³?

Step 1: Contains zero: [0, 0, 0]ᵀ ✓.

Step 2: Closed under addition: [x₁, y₁, 0] + [x₂, y₂, 0] = [x₁+x₂, y₁+y₂, 0] ✓.

Step 3: Closed under scalar multiplication: c[x, y, 0] = [cx, cy, 0] ✓.

Answer: **Yes. The xy-plane is a subspace of ℝ³**.

### Breadcrumb 3: Linear Combinations and Span

**Builds on:** [[7.2 Matrix Addition and Scalar Multiplication]] (linear combinations), Breadcrumb 1

A **linear combination** of vectors v₁, v₂, ..., vₖ is any expression:

```
c₁v₁ + c₂v₂ + ... + cₖvₖ    where c₁, ..., cₖ are scalars
```

The **span** of a set of vectors is the set of all possible linear combinations:

```
span{v₁, v₂, ..., vₖ} = {c₁v₁ + c₂v₂ + ... + cₖvₖ | cᵢ ∈ ℝ}
```

#### Chunked Example

Question: What is span{[1, 0]ᵀ, [0, 1]ᵀ}?

Step 1: Any vector [x, y]ᵀ in ℝ² can be written as x[1, 0] + y[0, 1].

Step 2: Therefore span = all of ℝ².

Answer: **span{[1, 0]ᵀ, [0, 1]ᵀ} = ℝ²**.

#### Chunked Example

Question: What is span{[1, 1]ᵀ, [2, 2]ᵀ}?

Step 1: [2, 2] = 2 × [1, 1], so both vectors point in the same direction.

Step 2: All linear combinations give vectors of the form [c, c]ᵀ — the line y = x.

Answer: **span = the line y = x (a 1-dimensional subspace of ℝ²)**.

### Breadcrumb 4: Linear Independence

**Builds on:** Breadcrumb 3

A set of vectors {v₁, v₂, ..., vₖ} is **linearly independent** if:

```
c₁v₁ + c₂v₂ + ... + cₖvₖ = 0   implies   c₁ = c₂ = ... = cₖ = 0
```

In other words, no vector in the set can be written as a combination of the others. If some vector can, the set is **linearly dependent**.

Geometrically: independent vectors point in distinct directions. Dependent vectors lie on the same line or plane.

#### Chunked Example

Question: Are [1, 0], [0, 1], [2, 3] linearly independent?

Step 1: Try to write [2, 3] as a combination of [1, 0] and [0, 1]: 2[1, 0] + 3[0, 1] = [2, 3].

Step 2: Since [2, 3] can be written as a combination of the others, the set is dependent.

Answer: **No. The set is linearly dependent. The maximum independent subset has size 2**.

### Breadcrumb 5: Basis and Dimension

**Builds on:** Breadcrumbs 3, 4

A **basis** for a vector space V is a set of vectors that:
1. **Spans** V (every vector in V can be reached).
2. Is **linearly independent** (no redundant vectors).

The **dimension** of V is the number of vectors in any basis.

| Space | Standard Basis | Dimension |
|-------|---------------|-----------|
| ℝ² | {[1,0], [0,1]} | 2 |
| ℝ³ | {[1,0,0], [0,1,0], [0,0,1]} | 3 |
| ℝⁿ | {e₁, e₂, ..., eₙ} | n |
| m×n matrices | {Eᵢⱼ (1 at (i,j), 0 elsewhere)} | m×n |
| Polynomials degree ≤ 2 | {1, x, x²} | 3 |

#### Chunked Example

Question: Is {[1, 0, 0], [1, 1, 0], [1, 1, 1]} a basis for ℝ³?

Step 1: Check span: can we get any [a, b, c]ᵀ? 
c × [1, 1, 1] gives [c, c, c]. (b-c) × [1, 1, 0] gives [b-c, b-c, 0].
(a-b) × [1, 0, 0] gives [a-b, 0, 0].
Sum: [a, b, c]ᵀ. ✓ Any vector can be reached.

Step 2: Check independence: c₁[1,0,0] + c₂[1,1,0] + c₃[1,1,1] = [0,0,0] gives:
c₁ + c₂ + c₃ = 0, c₂ + c₃ = 0, c₃ = 0 → c₃ = 0, c₂ = 0, c₁ = 0. ✓ Independent.

Answer: **Yes. It is a basis for ℝ³ (3 vectors, linearly independent, span ℝ³)**.

## Worked Examples

### Example 1 — Checking if a Subset Is a Subspace

Question: Is the set S = {[x, y, z]ᵀ | x + y - z = 0} a subspace of ℝ³?

Step 1: Check the zero vector: [0, 0, 0]ᵀ satisfies 0 + 0 - 0 = 0. ✓

Step 2: Check closure under addition: Let u = [x₁, y₁, z₁]ᵀ and v = [x₂, y₂, z₂]ᵀ be in S. Then (x₁+x₂) + (y₁+y₂) - (z₁+z₂) = (x₁+y₁-z₁) + (x₂+y₂-z₂) = 0 + 0 = 0. So u + v ∈ S. ✓

Step 3: Check closure under scalar multiplication: Let c ∈ ℝ. Then cx + cy - cz = c(x + y - z) = c×0 = 0. So cv ∈ S. ✓

Answer: **Yes. S is a subspace of ℝ³ (a plane through the origin)**.

### Example 2 — Finding the Span of a Set

Question: What is span{[1, -1]ᵀ, [-2, 2]ᵀ}?

Step 1: Note that [-2, 2] = -2 × [1, -1]. The two vectors are linearly dependent — they point in the same direction.

Step 2: All linear combinations give vectors of the form c[1, -1] = [c, -c]ᵀ.

Step 3: This is the line y = -x in ℝ².

Answer: **span = {[c, -c]ᵀ | c ∈ ℝ} = the line y = -x (a 1-dimensional subspace of ℝ²)**.

### Example 3 — Testing Linear Independence

Question: Are [1, 2, 1], [2, 1, 0], [0, 3, 2] linearly independent?

Step 1: Set up c₁[1,2,1] + c₂[2,1,0] + c₃[0,3,2] = [0,0,0]:
c₁ + 2c₂ = 0,  2c₁ + c₂ + 3c₃ = 0,  c₁ + 2c₃ = 0.

Step 2: From first equation: c₁ = -2c₂. From third: -2c₂ + 2c₃ = 0 → c₃ = c₂.

Step 3: Substitute into second: 2(-2c₂) + c₂ + 3c₂ = -4c₂ + c₂ + 3c₂ = 0. This holds for any c₂.

Step 4: Choose c₂ = 1, then c₁ = -2, c₃ = 1 gives a non-trivial solution.

Answer: **No. The set is linearly dependent. One vector can be expressed as a combination of the others**.

### Example 4 — Checking for a Basis of ℝ²

Question: Is {[2, 1], [1, 3]} a basis for ℝ²?

Step 1: Check linear independence: c₁[2,1] + c₂[1,3] = [0,0] → 2c₁ + c₂ = 0, c₁ + 3c₂ = 0.

Step 2: From first: c₂ = -2c₁. Substitute into second: c₁ + 3(-2c₁) = c₁ - 6c₁ = -5c₁ = 0 → c₁ = 0, c₂ = 0. The only solution is trivial → linearly independent. ✓

Step 3: Two linearly independent vectors in ℝ² span all of ℝ².

Answer: **Yes. {[2, 1], [1, 3]} is a basis for ℝ²**.

## Why This Works

Vector spaces abstract the essential properties of ℝⁿ to any set that behaves like vectors. The key insight: if a set is closed under addition and scalar multiplication, all the machinery of linear algebra (span, basis, dimension, linear transformations) applies.

The concept of **basis** answers the question: "What is the smallest set of building blocks I need to construct everything in this space?" The **dimension** tells you how many degrees of freedom the space has — how many independent directions exist.

## Common Mistakes

> [!failure] Mistake pattern: Thinking a subspace must be "smaller"
> A subspace can be the whole space itself (every vector space is a subspace of itself). The only subspace that is always smaller is a proper subspace.

> [!failure] Mistake pattern: Forgetting the zero vector
> Every subspace must contain the zero vector. If a subset does not contain 0, it cannot be a subspace, even if it is closed under addition and scalar multiplication.

> [!failure] Mistake pattern: Confusing span with the vectors themselves
> span{v₁, ..., vₖ} is a set (usually infinite) of all linear combinations. It is not the list of vectors.

> [!failure] Mistake pattern: Thinking every set of n vectors in ℝⁿ is a basis
> They must also be linearly independent. Two vectors in ℝ² that point in the same direction span a line, not the whole plane.
