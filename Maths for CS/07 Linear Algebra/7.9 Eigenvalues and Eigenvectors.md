## Introduction

An **eigenvector** v of a matrix A is a non-zero vector that, when transformed by A, does not change direction — it only gets scaled:

```
Av = λv
```

The **eigenvalue** λ is the scaling factor. If λ = 2, the eigenvector stretches to twice its length. If λ = -1, it flips direction.

From [[7.8 Linear Transformations]], every matrix represents a transformation. Most vectors change direction when transformed. Eigenvectors are the special directions that are only stretched or compressed — the transformation's "pure" directions. The eigenvalue tells you how much.

## New Words

- **[[eigenvector]]** — a non-zero vector v such that Av = λv (direction preserved).
- **[[eigenvalue]]** — the scalar λ in Av = λv (the scaling factor).
- **[[characteristic polynomial]]** — det(A - λI) = 0, whose roots are the eigenvalues.
- **[[eigenspace]]** — the set of all eigenvectors for a given eigenvalue (plus the zero vector).
- **[[diagonalization]]** — factoring A = PDP⁻¹ where D is diagonal with eigenvalues on the diagonal.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: What Are Eigenvalues and Eigenvectors?

**Builds on:** [[7.8 Linear Transformations]] (Av = T(v)), [[7.1 Matrix Notation and Shape]] (square matrices)

For a square matrix A, an eigenvector v satisfies:

```
Av = λv
```

- v ≠ 0 (eigenvectors are never the zero vector)
- λ is the eigenvalue — it can be any real (or complex) number

Geometrically: applying A to v is the same as just scaling v by λ. The direction of v is unchanged.

#### Chunked Example

Question: Given A = [[3, 0], [0, 5]], verify that [1, 0]ᵀ and [0, 1]ᵀ are eigenvectors and find their eigenvalues.

Step 1: A × [1, 0]ᵀ = [[3, 0], [0, 5]] × [1, 0]ᵀ = [3, 0]ᵀ = 3 × [1, 0]ᵀ.
So λ = 3.

Step 2: A × [0, 1]ᵀ = [[3, 0], [0, 5]] × [0, 1]ᵀ = [0, 5]ᵀ = 5 × [0, 1]ᵀ.
So λ = 5.

Answer: **[1, 0] is eigenvector with λ=3. [0, 1] is eigenvector with λ=5**.

### Breadcrumb 2: Finding Eigenvalues

**Builds on:** [[7.5 Determinants]] (det(A - λI)), [[7.1 Matrix Notation and Shape]] (identity matrix I)

Rearrange Av = λv:

```
Av - λv = 0
(A - λI)v = 0
```

For a non-zero v to exist, the matrix (A - λI) must be singular (determinant = 0):

```
det(A - λI) = 0
```

This is the **characteristic equation**. Expanding det(A - λI) gives a polynomial in λ of degree n (for an n×n matrix). The roots are the eigenvalues.

#### Chunked Example

Question: Find the eigenvalues of A = [[4, 1], [2, 3]].

Step 1: Form A - λI:

```
A - λI = [[4-λ, 1], [2, 3-λ]]
```

Step 2: Compute the determinant:

```
det(A - λI) = (4-λ)(3-λ) - 1×2
            = 12 - 4λ - 3λ + λ² - 2
            = λ² - 7λ + 10
```

Step 3: Solve λ² - 7λ + 10 = 0:
(λ - 5)(λ - 2) = 0 → λ = 5 or λ = 2.

Answer: **Eigenvalues: λ = 5 and λ = 2**.

### Breadcrumb 3: Finding Eigenvectors

**Builds on:** Breadcrumbs 1, 2, [[7.6 Solving Linear Systems with Matrices]] (solving (A-λI)v = 0)

For each eigenvalue λ, solve (A - λI)v = 0 to find the eigenvectors.

#### Chunked Example

Question: For A = [[4, 1], [2, 3]], find eigenvectors for λ = 5 and λ = 2.

Step 1: For λ = 5, solve (A - 5I)v = 0:

```
A - 5I = [[-1, 1], [2, -2]]
[-1, 1; 2, -2] × [x, y]ᵀ = [0, 0]ᵀ
-x + y = 0 → y = x
```

So v = [1, 1]ᵀ is an eigenvector (any scalar multiple works).

Step 2: For λ = 2, solve (A - 2I)v = 0:

```
A - 2I = [[2, 1], [2, 1]]
[2, 1; 2, 1] × [x, y]ᵀ = [0, 0]ᵀ
2x + y = 0 → y = -2x
```

So v = [1, -2]ᵀ is an eigenvector.

Answer: **λ=5 → [1, 1]ᵀ. λ=2 → [1, -2]ᵀ**.

### Breadcrumb 4: Geometric Interpretation

**Builds on:** [[7.8 Linear Transformations]] (transformation geometry), Breadcrumb 1

Eigenvalues and eigenvectors reveal the fundamental action of a transformation:

- **Positive eigenvalue**: stretch/compress in the eigenvector's direction.
- **Negative eigenvalue**: flip direction.
- **Zero eigenvalue**: the transformation collapses the eigenvector direction to zero.
- **Complex eigenvalues**: rotation (no real eigenvector).

The **eigenspace** for λ is the set of all eigenvectors with that eigenvalue (including zero). Its dimension is the number of linearly independent eigenvectors for that λ.

#### Chunked Example

Question: Interpret A = [[2, 0], [0, -1]] geometrically.

Step 1: Eigenvectors are [1, 0] with λ = 2 and [0, 1] with λ = -1.

Step 2: Along the x-axis, vectors stretch by factor 2. Along the y-axis, vectors flip (multiply by -1).

Answer: **A stretches horizontally by 2× and flips vertically**.

### Breadcrumb 5: Diagonalization

**Builds on:** [[7.4 Identity and Inverse Matrices]] (inverse), [[7.3 Matrix Multiplication]] (matrix product), Breadcrumbs 1-3

If an n×n matrix A has n linearly independent eigenvectors, it can be **diagonalized**:

```
A = PDP⁻¹
```

Where:
- P has the eigenvectors as columns.
- D is a diagonal matrix with the eigenvalues on the diagonal.

The powers of A are then easy to compute: Aᵏ = PDᵏP⁻¹ (just raise each eigenvalue to the k-th power).

#### Chunked Example

Question: Diagonalize A = [[4, 1], [2, 3]] using the eigenvectors found earlier.

Step 1: P = [[1, 1], [1, -2]] (eigenvectors as columns: [1,1] for λ=5, [1,-2] for λ=2).

Step 2: D = [[5, 0], [0, 2]] (eigenvalues on diagonal in matching order).

Step 3: Compute P⁻¹: det(P) = 1×(-2) - 1×1 = -3.
P⁻¹ = (-1/3) × [[-2, -1], [-1, 1]] = [[2/3, 1/3], [1/3, -1/3]].

Step 4: Verify A = PDP⁻¹ (optional, but confirms correctness).

Answer: **A = [[1, 1], [1, -2]] × [[5, 0], [0, 2]] × [[2/3, 1/3], [1/3, -1/3]]**.

## Worked Examples

### Example 1 — Verifying an Eigenvector

Question: Given A = [[1, 2], [2, 1]] and v = [1, 1]ᵀ, verify that v is an eigenvector and find its eigenvalue.

Step 1: Compute Av = [[1, 2], [2, 1]] × [1, 1]ᵀ = [1×1+2×1, 2×1+1×1] = [3, 3]ᵀ.

Step 2: [3, 3] = 3 × [1, 1] = 3v. So Av = 3v.

Answer: **v = [1, 1]ᵀ is an eigenvector with eigenvalue λ = 3**.

### Example 2 — Finding Eigenvalues

Question: Find the eigenvalues of A = [[2, -1], [-1, 2]].

Step 1: Form A - λI = [[2-λ, -1], [-1, 2-λ]].

Step 2: Compute det(A - λI) = (2-λ)(2-λ) - (-1)(-1) = (2-λ)² - 1.

Step 3: Expand: (4 - 4λ + λ²) - 1 = λ² - 4λ + 3.

Step 4: Solve λ² - 4λ + 3 = 0 → (λ - 3)(λ - 1) = 0 → λ = 3 or λ = 1.

Answer: **Eigenvalues: λ = 3 and λ = 1**.

### Example 3 — Finding Eigenvectors

Question: For A = [[2, -1], [-1, 2]], find eigenvectors for each eigenvalue.

Step 1: For λ = 3, solve (A - 3I)v = 0:
A - 3I = [[-1, -1], [-1, -1]]. So -x - y = 0 → y = -x.
An eigenvector is v = [1, -1]ᵀ (any scalar multiple works).

Step 2: For λ = 1, solve (A - I)v = 0:
A - I = [[1, -1], [-1, 1]]. So x - y = 0 → y = x.
An eigenvector is v = [1, 1]ᵀ.

Answer: **λ=3 → [1, -1]ᵀ. λ=1 → [1, 1]ᵀ**.

### Example 4 — Diagonalizing a 2×2 Matrix

Question: Diagonalize A = [[2, -1], [-1, 2]] using its eigenvectors.

Step 1: From Examples 2 and 3, eigenvectors are [1, -1]ᵀ (λ=3) and [1, 1]ᵀ (λ=1).

Step 2: Form P = [[1, 1], [-1, 1]] (eigenvectors as columns). D = [[3, 0], [0, 1]].

Step 3: Compute P⁻¹: det(P) = 1×1 - 1×(-1) = 2. P⁻¹ = (1/2) × [[1, -1], [1, 1]] = [[0.5, -0.5], [0.5, 0.5]].

Step 4: Verify: PDP⁻¹ = [[1, 1], [-1, 1]] × [[3, 0], [0, 1]] × [[0.5, -0.5], [0.5, 0.5]] = [[2, -1], [-1, 2]] = A. ✓

Answer: **A = [[1, 1], [-1, 1]] × [[3, 0], [0, 1]] × [[0.5, -0.5], [0.5, 0.5]]**.

## Why This Works

The eigenvalue equation Av = λv says: for certain special directions, the matrix A acts like a simple scalar. This is the closest analogy to "diagonalising" a matrix — turning it into a simple scaling operation along each eigen-direction.

Diagonalization A = PDP⁻¹ separates the matrix into three parts:
- P⁻¹ changes to the eigenvector basis.
- D applies the simple scalings.
- P changes back to the original basis.

## Common Mistakes

> [!failure] Mistake pattern: Thinking the zero vector is an eigenvector
> Eigenvectors are defined as non-zero. v = 0 trivially satisfies A·0 = λ·0 for any λ, which is useless.

> [!failure] Mistake pattern: Forgetting the identity matrix in det(A - λI)
> It is det(A - λI), not det(A - λ). You cannot subtract a scalar from a matrix — multiply λ by I first.

> [!failure] Mistake pattern: Confusing eigenvectors with eigenvalues
> Eigenvalues are scalars (λ). Eigenvectors are vectors (v). Av = λv involves both but they are different types of objects.

> [!failure] Mistake pattern: Assuming all matrices are diagonalizable
> A matrix with repeated eigenvalues may not have enough independent eigenvectors. Such matrices are called defective.
