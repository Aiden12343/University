## CS Connections
- [[8.1 Probability Basics]] - Reliability, ML predictions, simulations, and randomised algorithms use probability.
- [[8.2 Conditional Probability]] - Spam filters, risk models, and diagnostics use conditional probability.
- [[8.3 Bayes Theorem]] - Bayesian systems update beliefs from data.
- [[8.4 Random Variables and Expected Value]] - Expected runtime and ML loss use random variables.
- [[8.5 Discrete Distributions]] - Discrete distributions model clicks, failures, packets, and events.
- [[8.6 Continuous Distributions]] - Noise, measurement error, and ML assumptions often use continuous distributions.
- [[8.7 Descriptive Statistics]] - Dashboards, experiments, and logs need descriptive summaries.
- [[8.8 Correlation and Regression]] - Regression is a first model for prediction and data analysis.
- [[8.9 Hypothesis Testing]] - A/B testing and performance comparisons need hypothesis testing.
- [[8.10 Bayesian Inference]] - Probabilistic AI and uncertain decision-making use Bayesian inference.
- [[8.11 Information Theory]] - Compression, cryptography, and ML loss functions use information theory.
