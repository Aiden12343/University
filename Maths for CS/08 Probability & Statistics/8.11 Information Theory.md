## Introduction

**Information theory** quantifies information. It was developed by Claude Shannon in the 1940s to solve a fundamental engineering problem: how much can you compress a message, and how fast can you transmit it reliably over a noisy channel?

From [[8.4 Random Variables and Expected Value]], you know how to take expectations over probability distributions. Information theory applies expectation to log-probabilities. From [[3.7 Logarithms]], you know log₂ converts probabilities to bits: an event with probability p carries log₂(1/p) bits of information.

Why is information theory crucial for CS? Every time you:
- **Compress a file** (ZIP, MP3, JPEG): you are getting close to the entropy limit
- **Train a classifier** (cross-entropy loss): you are minimising KL divergence between the true and predicted distributions
- **Build a decision tree**: you choose splits by maximising information gain (mutual information)
- **Design a communication protocol**: Shannon's theorems tell you the maximum reliable data rate
- **Do feature selection**: you keep features with high mutual information with the target

Shannon's work is the foundation of the digital age. Before information theory, "information" was a vague concept. After Shannon, it is a precise mathematical quantity measured in bits.

## New Words

- **[[information content (self-information)]]** — I(x) = log₂(1/P(x)), bits of surprise when x occurs.
- **[[entropy]]** — H(X) = E[log₂(1/P(X))] = -Σ P(x) log₂ P(x), average information.
- **[[cross-entropy]]** — H(P, Q) = -Σ P(x) log₂ Q(x), average bits needed with wrong distribution Q.
- **[[KL divergence]]** — D_KL(P‖Q) = Σ P(x) log₂(P(x)/Q(x)), extra bits from using Q instead of P.
- **[[mutual information]]** — I(X;Y) = H(X) - H(X|Y), how much Y tells you about X.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Information Content — Surprise and Bits

**Builds on:** [[3.7 Logarithms]] (log₂), [[8.4 Random Variables and Expected Value]] (probability of an outcome)

The **information content** (self-information) of an event x with probability P(x) is:

```
I(x) = log₂(1 / P(x)) = -log₂ P(x)   bits
```

Key intuition:
- Certain event (P(x) = 1): I(x) = log₂(1) = 0 bits (no surprise)
- Rare event (P(x) = 0.125): I(x) = log₂(8) = 3 bits (very surprising)
- The unit is **bits** (binary digits) because log₂ is used.

The log scale has a natural additive property: the information of two independent events is the sum of their individual informations. If P(A∩B) = P(A)P(B), then I(A,B) = I(A) + I(B).

#### Chunked Example 1 — Coin Flip

Question: A fair coin flip comes up heads. What is the information content?

Step 1: P(heads) = 0.5. I(heads) = log₂(1/0.5) = log₂(2) = 1 bit.

Answer: **1 bit — one yes/no question reveals the outcome**.

#### Chunked Example 2 — Die Roll

Question: A fair die shows a 6. What is the information content?

Step 1: P(6) = 1/6. I(6) = log₂(1/(1/6)) = log₂(6) ≈ 2.585 bits.

Answer: **≈ 2.585 bits — more surprising than a coin flip**.

#### Chunked Example 3 — Certain Event

Question: The sun rises tomorrow (approximately P(sunrise) ≈ 1). What is the information content?

Step 1: I(sunrise) = log₂(1/1) = log₂(1) = 0 bits.

Answer: **0 bits — no surprise, no information**.

### Breadcrumb 2: Entropy — Average Information

**Builds on:** [[8.4 Random Variables and Expected Value]] (expected value), Breadcrumb 1

**Entropy** H(X) is the expected (average) information content of a random variable X:

```
H(X) = E[I(X)] = Σ P(x) × log₂(1 / P(x)) = -Σ P(x) log₂ P(x)
```

Entropy answers: "On average, how many bits do I need to encode one outcome of X?"

- H(X) ≥ 0
- H(X) = 0 if one outcome has probability 1 (certainty — no information)
- H(X) is maximised when all outcomes are equally likely (maximum uncertainty)

For a distribution over n outcomes, maximum entropy = log₂(n) bits.

#### Chunked Example 1 — Fair vs Biased Coin

Question: Compute H(X) for a fair coin. Compare to a biased coin with P(H)=0.9.

Step 1: Fair coin: P(H)=P(T)=0.5.
H = -(0.5 × log₂ 0.5 + 0.5 × log₂ 0.5) = -(0.5 × -1 + 0.5 × -1) = -(-0.5 - 0.5) = 1 bit.

Step 2: Biased coin: P(H)=0.9, P(T)=0.1.
H = -(0.9 × log₂ 0.9 + 0.1 × log₂ 0.1) = -(0.9 × -0.152 + 0.1 × -3.322)
  = -(-0.137 - 0.332) = -(-0.469) = 0.469 bits.

Answer: **Fair coin: 1 bit (maximum uncertainty). Biased coin: 0.469 bits (less uncertainty because heads is almost certain)**.

#### Chunked Example 2 — Fair Die

Question: Compute the entropy of a fair six-sided die.

Step 1: Each face has P = 1/6. H = 6 × (-(1/6) × log₂(1/6)) = -log₂(1/6) = log₂(6) ≈ 2.585 bits.

Answer: **H(die) ≈ 2.585 bits**.

### Breadcrumb 3: Cross-Entropy — When You Use the Wrong Distribution

**Builds on:** Breadcrumb 2

**Cross-entropy** measures the average number of bits needed to encode outcomes from true distribution P when you use distribution Q.

```
H(P, Q) = -Σ P(x) log₂ Q(x)
```

Key relationship:
- H(P, Q) ≥ H(P) for all Q (you always need at least as many bits)
- H(P, P) = H(P) (if Q = P, cross-entropy = entropy)
- H(P, Q) - H(P) = D_KL(P‖Q) (the extra bits are KL divergence)

In machine learning, minimising cross-entropy loss is equivalent to minimising KL divergence between the true distribution and the predicted distribution.

#### Chunked Example

Question: True distribution: P(H)=0.9, P(T)=0.1. Your model: Q(H)=0.5, Q(T)=0.5. Find H(P, Q).

Step 1: H(P, Q) = -(0.9 × log₂ 0.5 + 0.1 × log₂ 0.5) = -(0.9 × -1 + 0.1 × -1) = -(-0.9 - 0.1) = 1 bit.

Step 2: Compare to H(P) = 0.469 bits. Cross-entropy (1 bit) > entropy (0.469 bits).

Answer: **H(P, Q) = 1 bit. Using the wrong model costs 0.531 extra bits per outcome**.

### Breadcrumb 4: KL Divergence — The Information Distance

**Builds on:** Breadcrumb 2, Breadcrumb 3

**KL divergence** measures how much information is lost when using Q to approximate P:

```
D_KL(P‖Q) = Σ P(x) log₂(P(x) / Q(x)) = H(P, Q) - H(P)
```

Properties:
- D_KL(P‖Q) ≥ 0 (always non-negative)
- D_KL(P‖Q) = 0 if and only if P = Q
- NOT symmetric: D_KL(P‖Q) ≠ D_KL(Q‖P) in general
- NOT a true distance metric

The asymmetry is intuitive: D_KL(P‖Q) penalises Q for assigning low probability to events that P thinks are likely.

#### Chunked Example — Rain Probability

Question: P(rain)=0.5. Q(rain)=0.25. Compute D_KL(P‖Q) for this binary case.

Step 1: D_KL = P(rain) × log₂(P/Q) + P(no rain) × log₂(P(no rain)/Q(no rain))
         = 0.5 × log₂(0.5/0.25) + 0.5 × log₂(0.5/0.75)
         = 0.5 × log₂(2) + 0.5 × log₂(0.667)
         = 0.5 × 1 + 0.5 × (-0.585)
         = 0.5 - 0.293 = 0.207 bits.

Answer: **D_KL(P‖Q) ≈ 0.207 bits**.

### Breadcrumb 5: Mutual Information — How Much One Variable Tells You About Another

**Builds on:** Breadcrumb 2

**Mutual information** measures how much knowing Y reduces uncertainty about X:

```
I(X;Y) = H(X) - H(X|Y) = D_KL(P(X,Y)‖P(X)P(Y))
```

- I(X;Y) = 0 if X and Y are independent (knowing Y tells you nothing about X)
- I(X;Y) = H(X) if Y completely determines X

Mutual information is symmetric: I(X;Y) = I(Y;X).

#### Chunked Example 1 — Perfect Dependence

Question: Two fair coins. X = first coin (H/T), Y = X (Y always equals X). What is I(X;Y)?

Step 1: H(X) = 1 bit. H(X|Y) = 0 bits (knowing Y tells you X exactly).

Step 2: I(X;Y) = 1 - 0 = 1 bit.

Answer: **I(X;Y) = 1 bit. Y gives all the information about X**.

#### Chunked Example 2 — Independence

Question: Two fair, independent coins. X = first coin, Y = second coin. What is I(X;Y)?

Step 1: H(X) = 1 bit. H(X|Y) = 1 bit (Y tells you nothing about X).

Step 2: I(X;Y) = 1 - 1 = 0 bits.

Answer: **I(X;Y) = 0 bits. Independent variables share no information**.

## Worked Examples

### Example 1 — Entropy of a Three-outcome Distribution

Question: A random variable X has outcomes: P(a)=0.5, P(b)=0.25, P(c)=0.25. Compute H(X).

Step 1: H = -[0.5 × log₂(0.5) + 0.25 × log₂(0.25) + 0.25 × log₂(0.25)]

Step 2: = -[0.5 × (-1) + 0.25 × (-2) + 0.25 × (-2)]
       = -[-0.5 - 0.5 - 0.5]
       = -[-1.5] = 1.5 bits.

Answer: **H(X) = 1.5 bits**.

This means: optimally encoded, you need 1.5 bits per symbol on average to transmit outcomes from this distribution.

### Example 2 — Cross-Entropy in Binary Classification

Question: A true label is 1 (P(class=1)=1, P(class=0)=0). A model predicts Q(1)=0.7, Q(0)=0.3. What is the cross-entropy loss for this example?

Step 1: The true distribution P is [1, 0]. The predicted Q is [0.7, 0.3].

Step 2: H(P, Q) = -[1 × log₂(0.7) + 0 × log₂(0.3)] = -log₂(0.7) = -(-0.515) = 0.515 bits.

Answer: **Cross-entropy loss = 0.515 bits**. If the model had predicted Q(1)=1.0 perfectly, the loss would be 0.

### Example 3 — Information Gain in Decision Trees

Question: A dataset has 10 examples: 5 positive, 5 negative. Splitting on feature A gives child nodes: left (4 pos, 1 neg), right (1 pos, 4 neg). What is the information gain?

Step 1: Parent entropy: H_parent = -(0.5×log₂0.5 + 0.5×log₂0.5) = 1 bit.

Step 2: Left child entropy = -(0.8×log₂0.8 + 0.2×log₂0.2) = -(0.8×-0.322 + 0.2×-2.322) = -(-0.258 - 0.464) = 0.722 bits.
Right child entropy = same (symmetric): 0.722 bits.

Step 3: Weighted child entropy = (5/10)×0.722 + (5/10)×0.722 = 0.722 bits.

Step 4: Information gain = H_parent - H_weighted_children = 1 - 0.722 = 0.278 bits.

Answer: **Information gain = 0.278 bits**. This is how much knowing feature A reduces uncertainty about the class.

## Why This Works

Information theory rests on a beautiful insight: information = reduction in uncertainty. The log₂ scale means information is measured in the same unit as binary data. Shannon proved that entropy is the fundamental limit on lossless compression — you cannot compress below H(X) bits per symbol on average.

KL divergence naturally appears in Bayesian inference (from [[8.10 Bayesian Inference]]): when you update a prior to a posterior, the information gained is D_KL(posterior‖prior).

Mutual information extends this to two variables: it measures how much dependence there is beyond independence. It generalises correlation to any kind of relationship (not just linear).

## Common Mistakes

> [!failure] Mistake pattern: Confusing cross-entropy and KL divergence
> Cross-entropy = H(P, Q). KL divergence = H(P, Q) - H(P). Cross-entropy includes the entropy of P; KL divergence measures only the extra cost of using Q.

> [!failure] Mistake pattern: Using natural log instead of log₂
> Information theory typically uses log₂ (bits). Machine learning often uses natural log (nats). Be clear which base you are using.

> [!failure] Mistake pattern: Thinking KL divergence is symmetric
> D_KL(P‖Q) ≠ D_KL(Q‖P). If P is the true distribution and Q is the model, D_KL(P‖Q) penalises Q for not covering P's support (forward KL).

> [!failure] Mistake pattern: Forgetting that log₂(0) is undefined
> If Q(x) = 0 for some x where P(x) > 0, the KL divergence is infinite. This is why models must assign some probability to all possible outcomes.
