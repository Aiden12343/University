## Introduction

A **random variable** X assigns a number to each outcome of a random process. Unlike a regular variable (like x = 5), the value of X is uncertain until the experiment happens.

From [[3.2 Function Notation and Mapping]], you know functions map inputs to outputs. A random variable is exactly that: a function from the sample space to real numbers. X = "sum of two dice" maps each pair (1,1), (1,2), ..., (6,6) to a number between 2 and 12.

The **expected value** E[X] is the long-run average — roll two dice 1000 times, and the average sum will be about 7. The **variance** Var(X) measures how spread out the values are around the mean.

Why do random variables matter in CS? Almost every practical algorithm must handle uncertainty:
- **Randomised algorithms** deliberately use randomness to achieve good average-case performance. Quicksort with a random pivot has expected O(n log n) time.
- **Machine learning** models predict probability distributions over outcomes, not single values.
- **Reinforcement learning** agents maximise expected future reward.
- **Networking** protocols must handle random packet loss and delays.
- **Monte Carlo methods** use random sampling to estimate quantities that are too complex to compute exactly.

Without random variables and expected values, we could not analyse any of these systems.

## New Words

- **[[random variable]]** — a function from sample space to real numbers.
- **[[expected value]]** — E[X] = Σx·P(X=x) (discrete), the long-run average.
- **[[variance]]** — Var(X) = E[(X-μ)²] = E[X²] - μ², measures spread.
- **[[standard deviation]]** — σ = √Var(X), in the same units as X.
- **[[linearity of expectation]]** — E[aX + bY] = aE[X] + bE[Y] (always true, even for dependent variables).

## Breadcrumbs

### Breadcrumb 1: What Is a Random Variable?

**Builds on:** [[8.1 Probability Basics]] (sample space, probability), [[3.2 Function Notation and Mapping]] (X: S → ℝ)

A random variable X maps outcomes to numbers. For a coin flip:

```
X(H) = 1, X(T) = 0    (Bernoulli: 1 for success, 0 for failure)
```

We write P(X = x) to mean "the probability that X takes value x."

#### Chunked Example 1 — Sum of Two Dice

Question: Two dice are rolled. X = sum of the two dice. What outcomes give X = 7? What is P(X = 7)?

Step 1: X = 7 from (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) — 6 outcomes.

Step 2: Total outcomes = 36. P(X = 7) = 6/36 = 1/6.

Answer: **P(X = 7) = 1/6**.

#### Chunked Example 2 — Indicator Variable

Question: Roll a die. Let I = 1 if roll ≥ 4, 0 otherwise. What type of variable is I? What is P(I = 1)?

Step 1: I is called an **indicator variable** — it is 1 when an event occurs, 0 otherwise.

Step 2: P(roll ≥ 4) = P(4,5,6) = 3/6 = 1/2. So P(I = 1) = 1/2.

Answer: **P(I = 1) = 1/2. I is a Bernoulli indicator variable**.

### Breadcrumb 2: Expected Value

**Builds on:** [[6.2 Summation and Product Notation]] (Σ notation), Breadcrumb 1

The expected value is the probability-weighted average:

```
E[X] = Σ xᵢ × P(X = xᵢ)
```

#### Chunked Example 1 — Fair Die

Question: X = value from a fair six-sided die. Find E[X].

Step 1: Each value 1, 2, 3, 4, 5, 6 has probability 1/6.

Step 2: E[X] = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
         = (1+2+3+4+5+6)/6 = 21/6 = 3.5.

Answer: **E[X] = 3.5**.

#### Chunked Example 2 — Fair Coin

Question: A fair coin: X = 1 if heads, X = 0 if tails. Find E[X].

Step 1: P(X=1)=0.5, P(X=0)=0.5.

Step 2: E[X] = 1×0.5 + 0×0.5 = 0.5.

Answer: **E[X] = 0.5**.

This means: if you flip a coin many times and average the 1s and 0s, you get approximately 0.5.

#### Chunked Example 3 — Expected Value of a Bet

Question: A lottery ticket costs $5. You win $100 with P=0.02, $10 with P=0.10, and nothing otherwise. What is the expected winnings? Is the ticket worth buying?

Step 1: X = winnings. P(X=100)=0.02, P(X=10)=0.10, P(X=0)=0.88.

Step 2: E[X] = 100×0.02 + 10×0.10 + 0×0.88 = 2 + 1 + 0 = 3.

Step 3: The ticket costs $5 but expected winnings are only $3. Expected net = -$2.

Answer: **E[X] = $3. The ticket is a bad deal (expected loss of $2)**.

### Breadcrumb 3: Linearity of Expectation

**Builds on:** Breadcrumb 2

For any random variables X, Y and constants a, b:

```
E[aX + bY] = aE[X] + bE[Y]
```

This is always true — even when X and Y are dependent. This makes expectation the most useful tool in probability.

#### Chunked Example 1 — Linear Transformation

Question: Roll one die. Let X = the value. Find E[2X + 3].

Step 1: E[X] = 3.5.

Step 2: E[2X + 3] = 2×3.5 + 3 = 7 + 3 = 10.

Answer: **E[2X + 3] = 10**.

#### Chunked Example 2 — Sum of Two Dice

Question: Roll two dice. Let X = value of die 1, Y = value of die 2. Find E[X + Y].

Step 1: E[X] = E[Y] = 3.5.

Step 2: E[X + Y] = 3.5 + 3.5 = 7.

Answer: **E[X + Y] = 7** (matches our intuition that average sum of two dice is 7).

#### Chunked Example 3 — Number of Heads in n Coin Flips

Question: Flip a fair coin n times. Let X = total number of heads. Compute E[X] using linearity.

Step 1: Let Xᵢ = 1 if flip i is heads, 0 otherwise. Then X = X₁ + X₂ + ... + Xₙ.

Step 2: E[Xᵢ] = 1×0.5 + 0×0.5 = 0.5 for each i.

Step 3: E[X] = E[X₁] + E[X₂] + ... + E[Xₙ] = 0.5 + 0.5 + ... + 0.5 = n×0.5 = n/2.

Answer: **E[X] = n/2**. This is obvious (expected half are heads), but the method generalises to problems where direct calculation would be impossible.

### Breadcrumb 4: Variance and Standard Deviation

**Builds on:** Breadcrumb 2

Variance measures spread around the mean:

```
Var(X) = E[(X - μ)²] = E[X²] - μ²    where μ = E[X]
```

Standard deviation σ = √Var(X) is in the same units as X.

The two formulas for variance are equivalent. The second (E[X²] - μ²) is usually easier to compute.

#### Chunked Example 1 — Fair Die Variance

Question: Find Var(X) and σ for a fair six-sided die.

Step 1: μ = 3.5. E[X²] = (1²+2²+3²+4²+5²+6²)/6 = (1+4+9+16+25+36)/6 = 91/6 ≈ 15.167.

Step 2: Var(X) = E[X²] - μ² = 15.167 - 12.25 = 2.917.

Step 3: σ = √2.917 ≈ 1.708.

Answer: **Var(X) ≈ 2.917, σ ≈ 1.708**.

#### Chunked Example 2 — Coin vs Die Variance

Question: Which has higher variance: a fair coin (X=0 or 1) or a fair die (1 to 6)?

Step 1: Coin: μ=0.5. E[X²]=1×0.5+0×0.5=0.5. Var=0.5-0.25=0.25.

Step 2: Die: Var=2.917.

Answer: **The die has higher variance (more spread out values)**.

#### Chunked Example 3 — Variance of a Constant

Question: Let X = c (a constant). What is Var(X)?

Step 1: μ = c. E[X²] = c². Var(X) = c² - c² = 0.

Answer: **Var(X) = 0. A constant has no spread**.

## Worked Examples

### Example 1 — Expected Value of a Randomised Algorithm

Question: A randomised algorithm solves a problem. With probability 0.7 it runs in O(n) time, with probability 0.2 it runs in O(n²) time, and with probability 0.1 it crashes (returning no answer). Let the time cost be: T = n with probability 0.7, T = n² with probability 0.2, and T = ∞ (we assign cost 10⁶ as penalty) with probability 0.1. For n = 100, what is E[T]?

Step 1: When n = 100: T takes values 100 (P=0.7), 10000 (P=0.2), 10⁶ (P=0.1).

Step 2: E[T] = 100×0.7 + 10000×0.2 + 10⁶×0.1 = 70 + 2000 + 100000 = 102070.

Answer: **E[T] ≈ 102,070**. The crash probability dominates the expectation — this is why randomised algorithms should not crash!

### Example 2 — Linearity with Dependent Variables

Question: Let X be the number on a fair die. Let Y = X (same die). Compute E[X + Y] two ways: (1) directly from the distribution, (2) using linearity.

Step 1 (linearity): E[X + Y] = E[X] + E[Y] = 3.5 + 3.5 = 7.

Step 2 (direct): X + Y = 2X. E[2X] = 2×3.5 = 7.

Answer: **E[X + Y] = 7 both ways**. Notice: X and Y are perfectly dependent (Y = X), yet linearity still holds. This proves the "no independence required" property.

### Example 3 — Variance of Transformed Variables

Question: Let X be the value from a fair six-sided die. Compute Var(2X) and compare it to 2 × Var(X).

Step 1: E[X] = 3.5. E[X²] = (1+4+9+16+25+36)/6 = 91/6 ≈ 15.167. Var(X) = 15.167 − 12.25 = 2.917.

Step 2: Let Y = 2X. Y takes values 2, 4, 6, 8, 10, 12, each with probability 1/6.

Step 3: E[Y] = (2+4+6+8+10+12)/6 = 42/6 = 7. (Alternatively: 2 × E[X] = 7. ✓)

Step 4: E[Y²] = (4+16+36+64+100+144)/6 = 364/6 ≈ 60.667.
Var(Y) = 60.667 − 49 = 11.667.

Step 5: Compare: Var(X) = 2.917. Var(2X) = 11.667 = 4 × 2.917 = 2² × Var(X).

Answer: **Var(2X) = 11.667 = 4 × Var(X)**. Multiplying a random variable by a constant multiplies the variance by the constant squared: Var(cX) = c² Var(X). This is why scaling data changes its spread quadratically.

### Example 4 — Expected Value of a Function

Question: X = value from a fair die. Find E[X²] and compare to (E[X])².

Step 1: E[X] = 3.5. E[X²] = 91/6 ≈ 15.167.

Step 2: (E[X])² = 3.5² = 12.25.

Answer: **E[X²] ≈ 15.167 > (E[X])² = 12.25**. This inequality is always true (except for constants) and is the reason Var(X) = E[X²] - μ² ≥ 0.

## Why This Works

Expected value is the probability-weighted average. It represents the "centre of mass" of the probability distribution. The law of large numbers says that the average of many independent samples converges to E[X] — which is why casinos always win (they design games with E[X] < cost to play).

Linearity of expectation holds because expectation is a sum, and sums distribute over addition. This simple property makes it possible to analyse complex systems by breaking them into simpler components. There is no corresponding "linearity of variance" — variance only adds cleanly for independent variables.

Variance measures risk and uncertainty. In finance, a high-variance stock is riskier. In machine learning, a high-variance model overfits (memorises noise). In engineering, high-variance measurements indicate low precision.

## Common Mistakes

> [!failure] Mistake pattern: Thinking E[X] is the most likely value
> For a die, E[X]=3.5, but you can never roll 3.5. The expected value is the long-run average, not the mode.

> [!failure] Mistake pattern: Forgetting to square before averaging for variance
> Var(X) = E[(X-μ)²], not E[X-μ]. The latter is always 0 (positive and negative deviations cancel).

> [!failure] Mistake pattern: Assuming linearity of variance
> Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y). Linearity does NOT hold for variance (unless X and Y are independent).

> [!failure] Mistake pattern: Confusing E[f(X)] with f(E[X])
> E[X²] ≠ (E[X])² in general. The only exception is when f is linear.
