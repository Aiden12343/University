## Introduction

A **discrete distribution** gives the probability for each possible value of a discrete random variable (one that takes on countable values).

From [[8.4 Random Variables and Expected Value]], you know how to compute E[X] and Var(X) given a distribution. Now we study the three most important discrete distributions — Bernoulli, Binomial, and Poisson — each modelling a different type of random process.

Think of them as templates: once you recognise which distribution fits your problem, you get the mean, variance, and probability formulas for free. Instead of deriving everything from scratch every time, you can say "this is Binomial(100, 0.3)" and immediately know E[X] = 30, Var(X) = 21.

Why are these distributions so important in CS?
- **Bernoulli** models any binary outcome: click/no-click, spam/not-spam, correct/wrong.
- **Binomial** models the total from n independent Bernoulli trials: how many clicks out of 100 visitors, how many correct answers out of 50 test questions.
- **Poisson** models the count of rare events over time: number of server requests per second, number of bugs in a code module, number of packets arriving at a router.

Recognising these patterns lets you analyse real systems without reinventing probability every time.

## New Words

- **[[Bernoulli distribution]]** — X∼Bern(p), P(X=1)=p, P(X=0)=1-p. For a single trial.
- **[[binomial distribution]]** — X∼Bin(n,p), P(X=k)=C(n,k)pᵏ(1-p)ⁿ⁻ᵏ. For n independent trials.
- **[[Poisson distribution]]** — X∼Pois(λ), P(X=k)=e⁻λ λᵏ/k!. For rare events over a fixed interval.
- **[[probability mass function (PMF)]]** — P(X=k), gives the probability for each value k.
- **[[cumulative distribution function (CDF)]]** — F(k)=P(X≤k).

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Bernoulli Distribution

**Builds on:** [[8.4 Random Variables and Expected Value]] (E[X], Var(X)), [[8.1 Probability Basics]] (single trial)

A Bernoulli random variable models a single trial with two outcomes: success (1) or failure (0).

```
X ∼ Bern(p)
P(X=1) = p,  P(X=0) = 1-p
E[X] = p
Var(X) = p(1-p)
```

The Bernoulli is the simplest possible non-trivial random variable. Despite its simplicity, it is the building block of the Binomial, Geometric, and Negative Binomial distributions.

#### Chunked Example 1 — Fair Coin

Question: A fair coin flip. X=1 for heads, 0 for tails. What is the distribution? E[X]? Var(X)?

Step 1: p = 0.5. X ∼ Bern(0.5).

Step 2: E[X] = 0.5. Var(X) = 0.5 × 0.5 = 0.25.

Answer: **Bern(0.5). Mean = 0.5, Variance = 0.25**.

#### Chunked Example 2 — Click-through Rate

Question: A web ad has a click-through rate of 2%. X = 1 if a visitor clicks, 0 otherwise. What is the distribution? What is the variance?

Step 1: p = 0.02. X ∼ Bern(0.02).

Step 2: Var(X) = 0.02 × 0.98 = 0.0196.

Answer: **Bern(0.02). Mean = 0.02, Variance = 0.0196**.

### Breadcrumb 2: Binomial Distribution

**Builds on:** [[6.5 Permutations and Combinations]] (C(n,k) for number of ways to get k successes), Breadcrumb 1

The Binomial distribution models the number of successes in n independent Bernoulli trials, each with the same success probability p.

```
X ∼ Bin(n, p)
P(X=k) = C(n,k) × pᵏ × (1-p)ⁿ⁻ᵏ   for k = 0, 1, ..., n
E[X] = np
Var(X) = np(1-p)
```

C(n,k) = n! / (k!(n-k)!) counts the number of ways to arrange k successes among n trials.

The Binomial PMF has three parts:
- **pᵏ**: probability of k successes
- **(1-p)ⁿ⁻ᵏ**: probability of n-k failures
- **C(n,k)**: number of ways to order the k successes among n positions

#### Chunked Example 1 — Coin Flips

Question: Flip a fair coin 5 times. X = number of heads. Find P(X=3).

Step 1: n=5, p=0.5, k=3.

Step 2: C(5,3)=10. P(X=3) = 10 × 0.5³ × 0.5² = 10 × 0.125 × 0.25 = 10 × 0.03125 = 0.3125.

Answer: **P(3 heads in 5 flips) = 0.3125**.

#### Chunked Example 2 — Multiple-choice Test

Question: A test has 10 multiple-choice questions, each with 4 options. You guess every answer. X = number correct. Find E[X] and P(X ≥ 7).

Step 1: n=10, p=0.25. E[X]=10×0.25=2.5. Expected correct by guessing: 2.5.

Step 2: P(X≥7) = P(X=7)+P(X=8)+P(X=9)+P(X=10).

```
P(X=7) = C(10,7)×0.25⁷×0.75³ = 120×0.000061×0.422 = 0.0031
```

(Similarly for k=8,9,10. The total is about 0.0035.)

Answer: **E[X] = 2.5. P(X ≥ 7) ≈ 0.0035 (0.35%) — very unlikely**.

#### Chunked Example 3 — Quality Control

Question: A factory produces chips with a 5% defect rate. You sample 20 chips. What is P(≤ 1 defective)?

Step 1: n=20, p=0.05. P(X ≤ 1) = P(X=0) + P(X=1).

Step 2: P(X=0) = C(20,0) × 0.05⁰ × 0.95²⁰ = 1 × 1 × 0.95²⁰ ≈ 0.358.

Step 3: P(X=1) = C(20,1) × 0.05¹ × 0.95¹⁹ = 20 × 0.05 × 0.95¹⁹ ≈ 20 × 0.05 × 0.377 = 0.377.

Step 4: P(X ≤ 1) = 0.358 + 0.377 = 0.735.

Answer: **P(≤ 1 defective) ≈ 0.735 (73.5%)**.

### Breadcrumb 3: Poisson Distribution

**Builds on:** Breadcrumb 1 (single event rate)

The Poisson distribution models the number of rare events occurring in a fixed interval of time or space.

```
X ∼ Pois(λ)
P(X=k) = e⁻λ × λᵏ / k!   for k = 0, 1, 2, ...
E[X] = λ
Var(X) = λ
```

The parameter λ is the average rate (expected number of events per interval). The variance equals the mean — a hallmark of the Poisson. If Var >> Mean in real data, it suggests the events are not independent (overdispersion).

The Poisson is the limit of Binomial(n, p) when n → ∞, p → 0, and np = λ stays constant. This is why it works well for rare events.

#### Chunked Example 1 — Website Visits

Question: A website gets an average of 3 visits per minute. X = number of visits in a minute. Find P(X=0) and P(X ≥ 1).

Step 1: λ=3. P(X=0) = e⁻³ × 3⁰ / 0! = e⁻³ = 0.0498.

Step 2: P(X ≥ 1) = 1 - P(X=0) = 1 - 0.0498 = 0.9502.

Answer: **P(0 visits) ≈ 0.05. P(≥1 visit) ≈ 0.95**.

#### Chunked Example 2 — Poisson Probability

Question: Same website. Find P(X=5) in one minute.

Step 1: P(X=5) = e⁻³ × 3⁵ / 5! = 0.0498 × 243 / 120 = 0.0498 × 2.025 = 0.1008.

Answer: **P(5 visits) ≈ 0.101**.

#### Chunked Example 3 — Bugs in Code

Question: A software module has an average of 0.5 bugs per 1000 lines of code. What is the probability the next 1000-line module has exactly 0 bugs?

Step 1: λ = 0.5. P(X=0) = e⁻⁰·⁵ × 0.5⁰ / 0! = e⁻⁰·⁵ ≈ 0.6065.

Answer: **P(0 bugs) ≈ 0.607 (60.7%)**.

### Breadcrumb 4: PMF vs CDF

**Builds on:** [[8.4 Random Variables and Expected Value]] (P(X=x)), Breadcrumbs 1-3

The **probability mass function (PMF)** gives P(X=k) — the probability at a single point.

The **cumulative distribution function (CDF)** gives F(k) = P(X ≤ k) — the probability up to and including k.

```
PMF: P(X=k) = ...
CDF: F(k) = P(X ≤ k) = Σᵢ₌₀ᵏ P(X=i)
```

The CDF is useful for computing probabilities of ranges: P(a < X ≤ b) = F(b) - F(a).

#### Chunked Example — Binomial CDF

Question: X ∼ Bin(5, 0.5). Find P(X ≤ 2) using the CDF.

Step 1: P(X=0)=C(5,0)×0.5⁵=1×0.03125=0.03125.
P(X=1)=C(5,1)×0.5⁵=5×0.03125=0.15625.
P(X=2)=C(5,2)×0.5⁵=10×0.03125=0.3125.

Step 2: F(2) = P(X=0)+P(X=1)+P(X=2)=0.03125+0.15625+0.3125=0.5.

Answer: **P(X ≤ 2) = 0.5**.

This means: exactly half the time, you get 0, 1, or 2 heads; the other half, you get 3, 4, or 5 heads.

## Worked Examples

### Example 1 — Binomial vs Poisson: When to Use Which

Question: You observe 15,000 visitors to a website. Each visitor independently clicks a specific button with probability p = 0.001. Let X = number of visitors who click. Compute P(X = 20) using (a) the Binomial distribution, (b) the Poisson approximation.

Step 1 (Binomial): n=15000, p=0.001. P(X=20) = C(15000,20) × 0.001²⁰ × 0.999¹⁴⁹⁸⁰.
This is numerically tricky to compute directly (C(15000,20) is enormous, 0.999¹⁴⁹⁸⁰ is tiny).

Step 2 (Poisson): λ = np = 15000 × 0.001 = 15. P(X=20) = e⁻¹⁵ × 15²⁰ / 20!

Step 3: Compute: e⁻¹⁵ ≈ 3.06 × 10⁻⁷. 15²⁰ ≈ 3.33 × 10²³. 20! ≈ 2.43 × 10¹⁸.
P(X=20) = (3.06 × 10⁻⁷) × (3.33 × 10²³) / (2.43 × 10¹⁸) = 0.0419.

Answer: **P(X=20) ≈ 0.0419 using Poisson**. The Binomial would give the same answer (within rounding), but the Poisson is vastly easier to compute.

### Example 2 — Expected Number of Events in a System

Question: A server averages 100 requests per second (Poisson). What is the probability of 110 or fewer requests in a given second? What does the mean-variance relationship imply?

Step 1: λ = 100. For Poisson, Var(X) = λ = 100, so σ = 10.

Step 2: 110 is 1σ above the mean (z = (110-100)/10 = 1). Using the empirical rule, about 84% of the Poisson mass is below 1σ above the mean.

Answer: **P(X ≤ 110) ≈ 0.84 (roughly)**. The mean=variance property tells us: for large λ, the distribution is approximately normal.

### Example 3 — Sum of Independent Binomials

Question: Two servers each handle requests independently. Server 1 processes n₁ = 100 requests with success rate p₁ = 0.9 (respond within 1s). Server 2 processes n₂ = 200 requests with p₂ = 0.95. Let X = total number of fast responses across both servers. What is the distribution of X?

Step 1: Each server's count is Binomial: X₁ ∼ Bin(100, 0.9), X₂ ∼ Bin(200, 0.95).

Step 2: Since they are independent, X = X₁ + X₂ ∼ Bin(100+200, p_weighted) ... wait — Binomial only sums to Binomial when the p values are the same.

Step 3: Since p₁ ≠ p₂, X does NOT have a Binomial distribution. But we can use linearity:
E[X] = 100×0.9 + 200×0.95 = 90 + 190 = 280.
Var(X) = 100×0.9×0.1 + 200×0.95×0.05 = 9 + 9.5 = 18.5.

Answer: **E[X] = 280, Var(X) = 18.5. X is the sum of two independent Binomials with different p, so it is not itself Binomial**.

## Why This Works

Each distribution answers a specific type of question:

- **Bernoulli**: did a single event happen? (one trial, two outcomes)
- **Binomial**: how many times did it happen? (n independent trials with same p)
- **Poisson**: how many rare events occur in a fixed interval? (n large, p small, λ = np)

The formulas come from counting arguments (Binomial: C(n,k) ways to arrange k successes) or from limits (Poisson: the limit of Binomial when n → ∞ and p → 0 with λ fixed).

The PMF vs CDF distinction is crucial: the PMF gives exact probability at a point, the CDF gives cumulative probability up to a point. Most probability tables and statistical functions provide the CDF because it is more useful for computing tail probabilities and confidence intervals.

## Common Mistakes

> [!failure] Mistake pattern: Using Binomial when trials are not independent
> Drawing cards without replacement is NOT Binomial (probability changes each draw). Use the hypergeometric distribution instead.

> [!failure] Mistake pattern: Confusing Poisson λ with probability
> λ is the average COUNT, not a probability. λ can be any positive number (e.g., 3.7 visits per minute).

> [!failure] Mistake pattern: Forgetting that Binomial needs fixed n
> If the number of trials is not fixed in advance (e.g., "flip until heads"), use the geometric distribution, not Binomial.

> [!failure] Mistake pattern: Applying Poisson when events are not independent
> Poisson assumes independent events. If arrivals cluster (like rush-hour traffic), use a different model.
