## Introduction

**Hypothesis testing** is a formal procedure for deciding whether an observed effect is statistically significant or due to chance.

From [[8.6 Continuous Distributions]], you know how the normal distribution and z-scores work. From [[8.7 Descriptive Statistics]], you can summarise data with mean and standard deviation. Hypothesis testing combines these: if the observed mean is far enough from the null hypothesis mean (measured in standard errors), we reject the null.

Why is hypothesis testing central to CS? Every time you run an A/B test, you use hypothesis testing to decide whether the new feature actually improves the metric. Every time you compare two ML algorithms, you test whether the accuracy difference is real or just random variation. Every scientific paper that claims a result uses hypothesis testing. Without it, you could not distinguish genuine improvements from noise.

The core logic is simple: assume the null (nothing happened), compute a test statistic, calculate the probability of seeing such an extreme result by chance (p-value), and if that probability is small enough (p < α), reject the null in favour of the alternative.

## New Words

- **[[null hypothesis (H₀)]]** — the default assumption: no effect, no difference.
- **[[alternative hypothesis (H₁)]]** — what you want to show: there is an effect.
- **[[p-value]]** — probability of observing data at least as extreme as yours, assuming H₀ is true.
- **[[significance level (α)]]** — threshold for rejecting H₀ (commonly α = 0.05).
- **[[Type I error]]** — rejecting a true H₀ (false positive). Probability = α.
- **[[Type II error]]** — failing to reject a false H₀ (false negative). Probability = β.
- **[[test statistic]]** — a number computed from the data (e.g., z-score, t-statistic).
- **[[critical region]]** — values of the test statistic that lead to rejecting H₀.
- **[[statistical significance]]** — result is unlikely under H₀ (p < α).
- **[[confidence interval]]** — range of plausible values for a parameter (e.g., 95% CI).

## Breadcrumbs

### Breadcrumb 1: The Logic of Hypothesis Testing

**Builds on:** [[8.7 Descriptive Statistics]] (sample mean, standard deviation)

The hypothesis testing recipe:

1. State H₀ and H₁
2. Choose significance level α (usually 0.05)
3. Compute the test statistic from your data
4. Compute the p-value (probability of this result under H₀)
5. Decision: if p < α, reject H₀. Otherwise, fail to reject H₀.

> [!warning] We never "accept" H₀ — we either reject it or fail to reject it.

#### Chunked Example — Biased Coin

Question: A coin is flipped 20 times and lands heads 15 times. Is the coin biased towards heads? (α = 0.05)

Step 1: H₀: P(heads) = 0.5 (fair coin). H₁: P(heads) > 0.5 (biased towards heads).

Step 2: Test statistic: number of heads = 15. Under H₀, X ∼ Bin(20, 0.5).

Step 3: P(X ≥ 15 | H₀ is true). P(X=15)=C(20,15)×0.5²⁰=15504×0.000000954≈0.0148. P(X=16)=0.0046. P(X=17)=0.0011. P(X=18)=0.0002. P(X=19)≈0.00002. P(X=20)≈0.000001.

Sum ≈ 0.0148+0.0046+0.0011+0.0002+0.00000 ≈ 0.0207.

Step 4: p-value ≈ 0.021.

Step 5: Since p < α (0.021 < 0.05), reject H₀.

Answer: **We reject H₀. There is evidence the coin is biased towards heads (p ≈ 0.021)**.

#### Chunked Example 2 — Interpreting Non-significance

Question: Same coin flipped 20 times, lands heads 12 times. What is the conclusion at α = 0.05?

Step 1: P(X ≥ 12 | H₀) = P(12)+P(13)+...+P(20) ≈ 0.252.

Step 2: p = 0.252 > 0.05 → fail to reject H₀.

Answer: **Not enough evidence to conclude the coin is biased. 12 heads in 20 flips is consistent with a fair coin**.

### Breadcrumb 2: Z-Test (One Sample)

**Builds on:** [[8.6 Continuous Distributions]] (z-scores, standard normal)

When you know the population standard deviation (or have a large enough sample), use a z-test.

Test statistic:
```
z = (x̄ - μ₀) / (σ/√n)
```

where x̄ is the sample mean, μ₀ is the null hypothesis mean, σ is the population SD, and n is the sample size.

The denominator σ/√n is the **standard error** — the standard deviation of the sample mean. As n increases, the standard error shrinks, making it easier to detect small effects.

#### Chunked Example — Light Bulbs

Question: A manufacturer claims their light bulbs last μ₀ = 1000 hours (σ = 50). A sample of 40 bulbs has mean x̄ = 985 hours. Is there evidence that the bulbs fall short? (α = 0.05)

Step 1: H₀: μ = 1000. H₁: μ < 1000 (one-tailed).

Step 2: z = (985 - 1000) / (50/√40) = -15 / (50/6.325) = -15 / 7.906 = -1.897.

Step 3: P(Z < -1.897) ≈ 0.0289 (from z-table).

Step 4: Since p < α (0.0289 < 0.05), reject H₀.

Answer: **There is evidence that the bulbs fall short (p ≈ 0.029)**.

### Breadcrumb 3: Type I and Type II Errors

**Builds on:** Breadcrumb 1

| Decision | H₀ is true | H₀ is false |
|---|---|---|
| Reject H₀ | Type I error (α) | Correct |
| Fail to reject H₀ | Correct | Type II error (β) |

**Type I error (α)**: False positive — concluding there is an effect when there is none. α is set by the researcher (usually 0.05).

**Type II error (β)**: False negative — missing a real effect. 1-β is called **statistical power**.

- Lower α (e.g., 0.01) reduces Type I errors but increases Type II errors.
- Larger sample size reduces both types of errors.
- Power analysis helps you choose the right sample size before running an experiment.

#### Chunked Example — Medical Test

Question: A medical test for a disease: H₀ = patient is healthy. What are Type I and Type II errors in this context?

Step 1: Type I error: Test says patient HAS disease when they are healthy (false positive). Consequence: unnecessary worry, further testing.

Step 2: Type II error: Test says patient is HEALTHY when they have the disease (false negative). Consequence: missed diagnosis, delayed treatment.

Answer: **Type I = false positive, Type II = false negative**.

### Breadcrumb 4: Confidence Intervals

**Builds on:** [[8.6 Continuous Distributions]] (z-scores, empirical rule)

A 95% confidence interval gives the range of plausible values for the population mean:

```
95% CI = x̄ ± z* × (σ/√n)
```

where z* = 1.96 (the z-score that captures 95% of the standard normal).

Interpretation: If you repeated the sampling procedure many times, 95% of the computed intervals would contain the true population mean.

A confidence interval provides more information than a p-value: it shows not just whether an effect exists, but also its possible magnitude.

#### Chunked Example — Light Bulbs CI

Question: Light bulb example: x̄ = 985, σ = 50, n = 40. Compute the 95% CI.

Step 1: SE = σ/√n = 50/6.325 = 7.906.

Step 2: Margin of error = 1.96 × 7.906 ≈ 15.5.

Step 3: 95% CI = 985 ± 15.5 = [969.5, 1000.5].

Answer: **95% CI = [969.5, 1000.5]. Note: μ₀ = 1000 is just inside the interval**.

### Breadcrumb 5: One-Tailed vs Two-Tailed Tests

**Builds on:** Breadcrumb 2

**One-tailed test**: H₁ specifies a direction (μ < μ₀ or μ > μ₀). All the α is in one tail.

**Two-tailed test**: H₁ says μ ≠ μ₀ (no direction). α is split across both tails.

Two-tailed tests are more conservative (harder to reject H₀) and are the default in most scientific contexts. Use a one-tailed test only when you have a strong directional prediction.

## Worked Examples

### Example 1 — A/B Testing (Two-Sample)

Question: Variant A (control) gets 120 conversions out of 1000 visitors. Variant B gets 150 conversions out of 1000 visitors. Is B significantly better than A at α = 0.05?

Step 1: p̂ₐ = 120/1000 = 0.12. p̂ᵦ = 150/1000 = 0.15. Difference = 0.03.

Step 2: H₀: pᵦ - pₐ = 0. H₁: pᵦ - pₐ > 0.

Step 3: Standard error of difference = √(p̂(1-p̂)(1/nₐ + 1/nᵦ)) where p̂ = (120+150)/(1000+1000) = 270/2000 = 0.135.
SE = √(0.135 × 0.865 × (1/1000 + 1/1000)) = √(0.1168 × 0.002) = √0.000234 ≈ 0.0153.

Step 4: z = 0.03 / 0.0153 ≈ 1.96. P(Z > 1.96) ≈ 0.025.

Step 5: p = 0.025 < 0.05 → reject H₀.

Answer: **Variant B is significantly better (p ≈ 0.025). The 3 percentage point lift is unlikely due to chance**.

### Example 2 — Relationship Between Sample Size and Significance

Question: Two experiments measure the same effect (difference = 2 units, σ = 10). Experiment A uses n=100, experiment B uses n=400. Which one finds significance at α = 0.05?

Step 1 (A): z = 2 / (10/√100) = 2 / 1 = 2. p ≈ 0.046 (significant at α=0.05, just barely).

Step 2 (B): z = 2 / (10/√400) = 2 / 0.5 = 4. p ≈ 0.00003 (highly significant).

Answer: **Both find significance, but the larger sample gives much stronger evidence. The same effect size is easier to detect with more data**.

### Example 3 — The Multiple Testing Problem

Question: You test 100 features for correlation with a target at α = 0.05. All 100 features are actually noise (no real correlation). How many false positives do you expect?

Step 1: With α = 0.05 and 100 tests, expected false positives = 100 × 0.05 = 5.

Step 2: If you apply Bonferroni correction: α' = 0.05/100 = 0.0005. Now the expected false positives = 100 × 0.0005 = 0.05.

Answer: **Without correction: ~5 false positives. With Bonferroni: < 1 expected**. Always correct for multiple testing when running many tests.

## Why This Works

Hypothesis testing formalises the scientific method: assume the null (no effect), collect data, and ask "how surprising is this data under the null?" If very surprising (p < α), we conclude the null is unlikely.

The p-value is not the probability that H₀ is true. It is P(data | H₀), not P(H₀ | data). This distinction is subtle but critical. A p-value of 0.03 does not mean "3% chance H₀ is true" — it means "if H₀ were true, there is a 3% chance of seeing data this extreme."

Confidence intervals provide complementary information: they show the range of plausible effect sizes, not just whether the effect is non-zero.

## Common Mistakes

> [!failure] Mistake pattern: p-value > 0.05 means H₀ is true
> No. It means there is insufficient evidence to reject H₀. The data is consistent with both H₀ and many other hypotheses.

> [!failure] Mistake pattern: p-value is the probability H₀ is true
> p-value = P(data or more extreme | H₀). Not P(H₀ | data). That would require Bayesian methods.

> [!failure] Mistake pattern: Multiple testing without correction
> If you run 20 tests at α = 0.05, you expect 1 false positive by chance. Use Bonferroni correction: α/m (m = number of tests).

> [!failure] Mistake pattern: Choosing a one-tailed test after seeing the data
> If you see a result and then decide to use a one-tailed test to get p < 0.05, that is p-hacking. The test should be chosen before collecting data.
