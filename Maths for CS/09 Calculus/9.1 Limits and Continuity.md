## Introduction

A **limit** describes the behaviour of a function near a point. As x gets closer and closer to a (without ever reaching it), what value does f(x) get closer and closer to?

```
lim_{x→a} f(x) = L
```

This is read as "the limit of f(x) as x approaches a equals L."

Why do we need limits? Because many important mathematical ideas involve "approaching" without ever reaching:
- **Instantaneous velocity**: your speedometer shows how fast you are going at an exact moment. But speed is distance / time, and at a single moment, both distance and time are zero. Limits resolve this 0/0 problem.
- **Derivatives**: the slope of a tangent line requires two points, but at the point of tangency you only have one. Limits let you bring the second point arbitrarily close.
- **Area under a curve**: you can approximate it with rectangles, but the exact area requires making the rectangles infinitely thin — a limit.

From [[2.2 Simplifying Expressions]], you know how to factor polynomials and rationalise numerators. From [[2.7 Inequalities]], you can reason about how close values get. These skills are essential for working with limits.

## New Words

- **[[limit]]** — the value f(x) approaches as x→a, written lim_{x→a} f(x) = L. The function need not be defined at x=a.
- **[[continuity]]** — f is continuous at a if lim_{x→a} f(x) = f(a). The graph has no holes, jumps, or breaks at a.
- **[[one-sided limit]]** — limit from the left (x→a⁻) or right (x→a⁺). Written lim_{x→a⁻} f(x) or lim_{x→a⁺} f(x).
- **[[limit at infinity]]** — behaviour of f(x) as x→∞ or x→-∞.
- **[[Intermediate Value Theorem (IVT)]]** — if f is continuous on [a,b] and k is between f(a) and f(b), there exists c∈[a,b] such that f(c)=k.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: What Is a Limit? — The Intuitive Idea

**Builds on:** [[2.2 Simplifying Expressions]] (evaluating expressions), [[2.7 Inequalities]] (|x-a| < δ, values getting close)

The notation lim_{x→a} f(x) = L means: as x gets arbitrarily close to a (but not equal to a), f(x) gets arbitrarily close to L.

The key difference from simply evaluating f(a): the limit cares about what happens **near** a, not **at** a. The function might not even be defined at a, yet the limit can still exist.

#### Chunked Example — Seeing the Pattern

Question: Guess lim_{x→2} (x²-4)/(x-2) by plugging numbers progressively closer to 2.

Step 1: The function is undefined at x=2 (division by zero). But what happens near 2?

```
x      x²-4   x-2   (x²-4)/(x-2)
──────────────────────────────
1.9   -0.39  -0.1    3.9
1.99  -0.0399 -0.01  3.99
1.999 -0.003999 -0.001 3.999
2     undefined     undefined
2.001  0.004001 0.001  4.001
2.01   0.0401   0.01   4.01
2.1    0.41     0.1    4.1
```

Step 2: As x→2 from either side, the expression approaches 4.

Answer: **The limit appears to be 4**. Even though f(2) is undefined, the values get closer and closer to 4.

The epsilon-delta definition makes this precise: for any error tolerance ε > 0, there exists a distance δ > 0 such that whenever x is within δ of a (but x ≠ a), f(x) is within ε of L. In practice, you rarely use the ε-δ definition directly — you use algebraic techniques — but it is the theoretical foundation.

### Breadcrumb 2: Evaluating Limits by Direct Substitution

**Builds on:** Breadcrumb 1

If f is continuous at a, the limit equals the function value. Simply substitute x=a.

#### Chunked Example

Question: Compute lim_{x→3} (2x+1) and lim_{x→-1} (x²+3x-2).

Step 1: f(x)=2x+1 is a polynomial, continuous everywhere. Substitute x=3: 2×3+1 = 7.

Step 2: f(x)=x²+3x-2 is also continuous everywhere. Substitute x=-1: (-1)²+3(-1)-2 = 1-3-2 = -4.

Answer: **lim_{x→3} (2x+1) = 7. lim_{x→-1} (x²+3x-2) = -4**.

#### Chunked Example — When Substitution Fails

Question: lim_{x→0} sin x / x. Substitution gives 0/0.

Step 1: Substitute x=0: sin(0)/0 = 0/0. This is an indeterminate form — we cannot tell from substitution alone whether the limit exists or what it is.

Step 2: As x→0, sin x behaves approximately like x (for small x). So sin x / x ≈ x/x = 1. The limit is actually 1 (we will prove this later with L'Hôpital's rule in [[9.3 Differentiation Rules]]).

Answer: **Substitution gives 0/0, which is indeterminate. The actual limit is 1**.

### Breadcrumb 3: Indeterminate Forms (0/0) — Algebraic Manipulation

**Builds on:** [[2.2 Simplifying Expressions]] (factoring, rationalising), Breadcrumb 1

When substitution gives 0/0, the limit is an **indeterminate form**. The limit may exist, but we need to simplify the expression to find it. The three main techniques are:

1. **Factoring** — cancel common factors that cause the 0/0.
2. **Rationalising** — multiply by the conjugate to eliminate radicals.
3. **Algebraic expansion** — expand and simplify.

#### Chunked Example — Factoring

Question: Compute lim_{x→2} (x²-4)/(x-2).

Step 1: Substitute x=2: 0/0. Indeterminate.

Step 2: Factor the numerator: x²-4 = (x-2)(x+2).

Step 3: Rewrite: (x-2)(x+2)/(x-2) = x+2 (for x≠2).

Step 4: Take the limit: lim_{x→2} x+2 = 4.

Answer: **4**.

#### Chunked Example — The Derivative Limit

Question: Compute lim_{h→0} ((x+h)² - x²)/h. This is the definition of the derivative of x².

Step 1: Substitute h=0: (x² - x²)/0 = 0/0. Indeterminate.

Step 2: Expand: ((x²+2xh+h²)-x²)/h = (2xh+h²)/h = 2x+h (for h≠0).

Step 3: Take the limit: lim_{h→0} (2x+h) = 2x.

Answer: **2x** — the derivative of x². This is the limit that launched calculus.

#### Chunked Example — Rationalising

Question: Compute lim_{x→0} (√(x+1)-1)/x.

Step 1: Substitute x=0: (1-1)/0 = 0/0. Indeterminate.

Step 2: Multiply numerator and denominator by the conjugate (√(x+1)+1):

```
(√(x+1)-1)/x × (√(x+1)+1)/(√(x+1)+1)
= (x+1-1)/(x(√(x+1)+1))
= x/(x(√(x+1)+1))
= 1/(√(x+1)+1)    (for x≠0)
```

Step 3: Take the limit: lim_{x→0} 1/(√(x+1)+1) = 1/(1+1) = 1/2.

Answer: **1/2**.

### Breadcrumb 4: One-Sided Limits

**Builds on:** Breadcrumb 1

x→a⁻ means "from below" (smaller values, approaching from the left on the number line).
x→a⁺ means "from above" (larger values, approaching from the right).

If the left and right limits differ, the two-sided limit **does not exist** (DNE).

#### Chunked Example

Question: f(x) = |x|/x. Compute lim_{x→0⁻} f(x) and lim_{x→0⁺} f(x). Does lim_{x→0} f(x) exist?

Step 1: Recall |x| = x when x ≥ 0, and |x| = -x when x < 0.

Step 2: For x>0 (approaching from the right): |x|/x = x/x = 1. So lim_{x→0⁺} = 1.

Step 3: For x<0 (approaching from the left): |x|/x = -x/x = -1. So lim_{x→0⁻} = -1.

Step 4: Since 1 ≠ -1, the two-sided limit does not exist.

Answer: **Left = -1, Right = 1. Two-sided limit DNE**.

#### Chunked Example — Piecewise Functions

Question: f(x) = { x+1 for x<2; 5 for x=2; x²-1 for x>2 }. Find lim_{x→2⁻} f(x), lim_{x→2⁺} f(x), and f(2).

Step 1: For x→2⁻, use f(x)=x+1: lim = 2+1 = 3.

Step 2: For x→2⁺, use f(x)=x²-1: lim = 4-1 = 3.

Step 3: f(2) = 5 (defined separately).

Step 4: The left and right limits both equal 3, so lim_{x→2} f(x) = 3. But f(2)=5 ≠ 3, so f is NOT continuous at x=2.

Answer: **lim_{x→2} f(x)=3, f(2)=5. Discontinuity at x=2**.

### Breadcrumb 5: Limits at Infinity

**Builds on:** Breadcrumb 1

Limits at infinity describe what happens to f(x) as x becomes arbitrarily large (positive or negative).

For rational functions (ratio of polynomials):
- If numerator degree < denominator degree: limit = 0.
- If numerator degree = denominator degree: limit = ratio of leading coefficients.
- If numerator degree > denominator degree: limit is ∞ or -∞ (no finite limit).

#### Chunked Example

Question: Compute lim_{x→∞} (3x²+2x)/(5x²-1).

Step 1: Both numerator and denominator are degree 2. Leading terms: 3x² and 5x².

Step 2: As x→∞, lower-order terms (2x and -1) become negligible compared to x².

Step 3: The limit approaches 3x²/5x² = 3/5.

Answer: **3/5**.

#### Chunked Example — Exponential Decay

Question: Compute lim_{x→∞} e^(-x) and lim_{x→∞} (1/x).

Step 1: e^(-x) = 1/eˣ. As x→∞, eˣ→∞, so e^(-x)→0.

Step 2: 1/x → 0 as x→∞.

Answer: **Both approach 0**.

#### Chunked Example — Horizontal Asymptotes

Question: f(x) = (2x+1)/(x-3). Find the horizontal asymptote.

Step 1: As x→∞, leading terms: 2x/x = 2. So y=2 is a horizontal asymptote.

Step 2: Check: as x→∞, (2x+1)/(x-3) → 2. As x→-∞, same.

Answer: **Horizontal asymptote at y=2**.

### Breadcrumb 6: Continuity and the Intermediate Value Theorem

**Builds on:** Breadcrumb 1, Breadcrumb 4

A function f is **continuous** at a point a if three conditions hold:
1. f(a) is defined.
2. lim_{x→a} f(x) exists (left and right limits agree).
3. lim_{x→a} f(x) = f(a).

If any condition fails, f has a **discontinuity** at a. Types:
- **Removable discontinuity** (hole): limit exists but f(a) ≠ limit or f(a) undefined.
- **Jump discontinuity**: left and right limits exist but differ.
- **Infinite discontinuity**: limit goes to ±∞ (vertical asymptote).

The **Intermediate Value Theorem (IVT)** says: if f is continuous on [a,b] and k is between f(a) and f(b), then there exists some c in [a,b] such that f(c)=k.

> [!example] Why IVT matters
> If a continuous function is positive at one point and negative at another, it must cross zero somewhere in between. This is how we know equations like cos x = x have a solution without solving them directly.

#### Chunked Example — Checking Continuity

Question: f(x)=x² on [0,2]. Is it continuous? Does f(c)=2 for some c∈[0,2]?

Step 1: f(x)=x² is a polynomial, continuous everywhere.

Step 2: f(0)=0, f(2)=4. k=2 is between 0 and 4.

Step 3: By IVT, there exists c∈[0,2] such that f(c)=2.

Step 4: Since f(x)=x², c=√2≈1.414. Indeed 1.414∈[0,2].

Answer: **Yes, c=√2**.

#### Chunked Example — Root Finding

Question: Show that f(x)=x³-x-1 has a root between 1 and 2.

Step 1: f(1)=1-1-1=-1 (negative). f(2)=8-2-1=5 (positive).

Step 2: f is a polynomial, therefore continuous.

Step 3: By IVT, since 0 is between -1 and 5, there exists c∈(1,2) with f(c)=0.

Answer: **There is a root in (1,2) by IVT**.

## Worked Examples

### Example 1 — Factoring to Remove a Hole

Question: Compute lim_{x→1} (x²-1)/(x-1).

Step 1: Substitute x=1: 0/0. Indeterminate.

Step 2: Factor: (x-1)(x+1)/(x-1) = x+1 (for x≠1).

Step 3: lim_{x→1} x+1 = 2.

Answer: **2**.

### Example 2 — Limits at Infinity with Different Degrees

Question: Compute lim_{x→∞} (4x³+2x)/(x²-1).

Step 1: Numerator degree = 3. Denominator degree = 2.

Step 2: Since numerator degree > denominator degree, the limit is infinite.

Step 3: As x→∞, 4x³/x² = 4x → ∞.

Answer: **∞ (the function grows without bound)**.

### Example 3 — CS Application: Algorithm Convergence

Question: An algorithm's error after n iterations is e(n) = 100/n². Does the algorithm converge? What is the limiting error?

Step 1: lim_{n→∞} 100/n² = 0.

Step 2: The algorithm converges to the exact solution. After 1000 iterations, error = 100/10⁶ = 0.0001.

Step 3: This analysis is how we decide stopping criteria for iterative algorithms.

Answer: **Limit = 0 (algorithm converges)**.

### Example 4 — Classifying Discontinuities

Question: Identify and classify all discontinuities of f(x) = 1/(x-2).

Step 1: At x=2, denominator = 0. f(2) is undefined.

Step 2: lim_{x→2⁺} 1/(x-2) = +∞ (approaching from the right, x-2 is positive and small).
lim_{x→2⁻} 1/(x-2) = -∞ (approaching from left, x-2 is negative and small).

Step 3: Both one-sided limits are infinite → infinite discontinuity (vertical asymptote at x=2).

Answer: **Infinite discontinuity (vertical asymptote) at x=2**.

## Why This Works

Limits formalise "approaching" without ever reaching. This is essential because calculus is built on infinitesimal quantities — the derivative is a ratio of two quantities that both approach zero, and the integral is a sum of infinitely many infinitely thin rectangles.

The epsilon-delta definition bridges intuitive "getting close" and mathematical rigour: for any desired closeness ε, we can find a δ that guarantees closeness. This lets us prove statements like "the limit exists" rather than just guessing from numerical patterns.

Continuity connects the limit to the function value, enabling the IVT — a powerful tool for proving existence without computing exact solutions. The IVT is why binary search works: if f(a) and f(b) have opposite signs, there must be a root between them.

The 0/0 indeterminate form is the gateway to derivatives. Every derivative f'(x) = lim_{h→0} (f(x+h)-f(x))/h is a 0/0 limit. Mastering these techniques now makes differentiation natural.

## Common Mistakes

> [!failure] Mistake pattern: Assuming substitution always works
> If substitution gives 0/0 or ∞/∞, you must simplify first. Do not conclude "undefined" without trying factoring, rationalising, or L'Hôpital's rule.

> [!failure] Mistake pattern: Confusing "does not exist" with "∞"
> A limit going to +∞ or -∞ is a specific type of non-existence (infinite limit). This is different from a limit not existing because left and right limits differ finitely.

> [!failure] Mistake pattern: Forgetting one-sided limits at jump discontinuities
> When a function has a jump (like |x|/x at 0), the two-sided limit does not exist. Always check both sides.

> [!failure] Mistake pattern: Assuming continuity from the existence of a limit
> Even if lim_{x→a} f(x) exists, f may not be continuous at a. Continuity requires: (1) f(a) is defined, (2) the limit exists, (3) they are equal.

## Where This Shows Up in CS

### Algorithm Convergence Analysis
```python
# We say an algorithm converges if lim_{n→∞} error(n) = 0
# Gradient descent converges when loss approaches a minimum
def gradient_descent(f_prime, x0, lr=0.01, eps=1e-6):
    x = x0
    while abs(f_prime(x)) > eps:  # gradient norm approaches 0
        x -= lr * f_prime(x)
    return x
```

### Numerical Approximation
```python
# Derivatives approximated as (f(x+h)-f(x))/h
# As h→0, the approximation improves (limit of the difference quotient)
def derivative_approx(f, x, h=1e-6):
    return (f(x+h) - f(x)) / h  # approximates f'(x) as h→0
```

### Machine Learning — Early Stopping
```python
# Training loss L(t) typically approaches a limit > 0
# Stop when |L(t) - L(t-1)| < ε (limit has been reached)
if abs(loss[-1] - loss[-2]) < 1e-6:
    break  # converged
```

### Computer Graphics — Anti-aliasing
```python
# Edge pixels are sampled at many sub-pixel positions
# The limit as samples → ∞ gives the true pixel colour
colour = sum(sample(x, y) for _ in range(256)) / 256
```
