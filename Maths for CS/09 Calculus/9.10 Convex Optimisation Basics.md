## Introduction

From [[9.9 Gradient Descent and Optimisation]], you know that gradient descent finds a minimum, but not necessarily the global one. For non-convex functions (like neural network loss landscapes), there can be many local minima, and gradient descent might get stuck in a bad one.

**Convex optimisation** studies a special class of functions where this cannot happen: **convex functions** have a single global minimum, and any algorithm that decreases the function will eventually find it.

A function f is convex if the line segment between any two points on its graph lies above the graph:
```
f(tx₁ + (1-t)x₂) ≤ t·f(x₁) + (1-t)·f(x₂)    for t ∈ [0,1]
```

This is called the **Jensen inequality** (in its simplest form). It is the definition of convexity.

Why does this matter for CS? Many important problems are convex:
- Linear regression (MSE loss).
- Support vector machines.
- Logistic regression (the negative log-likelihood is convex).
- Linear programming.

When a problem is convex, you can solve it optimally and reliably. When it is not convex, you need heuristics (and you settle for "good enough").

## New Words

- **[[convex set]]** — a set S where for any x,y∈S, the line segment between them is entirely in S.
- **[[convex function]]** — f(tx+(1-t)y) ≤ tf(x)+(1-t)f(y) for all x,y and t∈[0,1].
- **[[Jensen's inequality]]** — f(E[X]) ≤ E[f(X)] for convex f (or f(E[X]) ≥ E[f(X)] for concave f).
- **[[global minimum]]** — x* such that f(x*) ≤ f(x) for ALL x in the domain.
- **[[local minimum]]** — x* such that f(x*) ≤ f(x) for all x NEAR x*.
- **[[positive semidefinite]]** — a matrix H where xᵀHx ≥ 0 for all x. For the Hessian, this means f is convex.
- **[[Lagrangian]]** — L(x,λ) = f(x) + ∑ λᵢ·gᵢ(x), used for constrained optimisation.

> [!important] You pass this topic only when you can define all seven terms without looking.

## Breadcrumbs

### Breadcrumb 1: Convex Sets vs Convex Functions

**Builds on:** [[9.8 Multivariable Functions]] (function domain)

A **convex set** is one where you can draw a line between any two points and the entire line stays inside the set. A circle is convex. A crescent shape is not.

A **convex function** is one where the graph curves upward — the epigraph (the region above the graph) is a convex set.

#### Chunked Example — Recognising Convex Sets

Question: Which of these sets is convex?
(a) A circle (including interior).
(b) A star shape.
(c) The set {x ∈ ℝ : x ≥ 0} (the non-negative real line).

Step 1: (a) Circle: any line segment between two interior points stays inside. **Convex**.

Step 2: (b) Star: pick two points in different arms — the line segment leaves the star. **Not convex**.

Step 3: (c) Non-negative reals: the line segment between any two non-negative numbers is non-negative. **Convex**.

Answer: **(a) and (c) are convex. (b) is not**.

#### Chunked Example — Recognising Convex Functions

Question: Which of these functions is convex on all ℝ?
(a) f(x)=x². (b) f(x)=x³. (c) f(x)=|x|.

Step 1: (a) x²: f''(x)=2 ≥ 0 everywhere. **Convex**. Graph ∪-shaped.

Step 2: (b) x³: f''(x)=6x. f''(x)<0 for x<0 (concave), f''(x)>0 for x>0 (convex). **Not globally convex**.

Step 3: (c) |x|: Check Jensen: f(tx+(1-t)y) ≤ tf(x)+(1-t)f(y). Holds for all x,y. **Convex** (despite the corner at 0 — it is still convex).

Answer: **(a) and (c) are convex. (b) is not**.

### Breadcrumb 2: First and Second Order Conditions for Convexity

**Builds on:** [[9.4 Applications of Differentiation]] (second derivative test), [[9.8 Multivariable Functions]] (Hessian)

For differentiable functions:

**First-order condition**: f is convex iff for all x,y:
```
f(y) ≥ f(x) + ∇f(x)·(y-x)
```
The tangent line at any point lies **below** the graph.

**Second-order condition**: f is convex iff the Hessian H is positive semidefinite (xᵀHx ≥ 0 for all x).

In 1D: f''(x) ≥ 0 everywhere.

#### Chunked Example — Second-Order Test

Question: Is f(x,y)=x²+y² convex?

Step 1: ∇f = (2x, 2y). H = [[2,0],[0,2]].

Step 2: Check if H is positive semidefinite: xᵀHx = 2x₁² + 2x₂² ≥ 0 for all x. ✓

Step 3: Therefore f is convex. This confirms the paraboloid shape (bowl) from [[9.8 Multivariable Functions]].

Answer: **Yes. f(x,y)=x²+y² is convex**.

#### Chunked Example — First-Order Test

Question: Verify f(y) ≥ f(x)+f'(x)(y-x) for f(x)=x², x=2, y=5.

Step 1: f(5)=25. f(2)=4. f'(2)=4.

Step 2: RHS = 4+4(5-2)=4+12=16.

Step 3: 25 ≥ 16. ✓ Holds.

Answer: **The inequality holds, consistent with convexity**.

### Breadcrumb 3: Convexity Implies Global Minimum

**Builds on:** Breadcrumb 2, [[9.4 Applications of Differentiation]] (local vs global)

This is the most important property: **For a convex function, any local minimum is also a global minimum.**

Proof sketch: Suppose x* is a local minimum. For any y, the first-order condition gives:
f(y) ≥ f(x*) + ∇f(x*)·(y-x*) = f(x*) + 0 = f(x*)
since ∇f(x*)=0 at a local minimum. So f(y) ≥ f(x*) for ALL y — that is the definition of a global minimum.

#### Chunked Example — Non-Convex vs Convex

Question: f(x)=x³-3x has local max at x=-1 and local min at x=1. Why is this not globally optimisable?

Step 1: f'(x)=3x²-3=0 → x=±1. f''(x)=6x. f''(1)=6>0 (local min). f''(-1)=-6<0 (local max).

Step 2: f(1)=1-3=-2. But f(x)→-∞ as x→-∞, so the local minimum at x=1 is NOT global.

Step 3: The function is not convex (f''(x)=6x changes sign), so local does not imply global.

Answer: **Non-convex means we cannot guarantee the local minimum is global. For convex functions, this guarantee holds**.

### Breadcrumb 4: Jensen's Inequality

**Builds on:** Breadcrumb 1 (definition of convex), [[8.3 Expected Value and Variance]] (expectation)

**Jensen's inequality** applies convexity to expectations:

For convex f: f(E[X]) ≤ E[f(X)]
For concave f: f(E[X]) ≥ E[f(X)]

This is the same as the definition of convexity but with t replaced by probabilities.

#### Chunked Example — Applying Jensen

Question: f(x)=x² is convex. X takes values 0 or 2 with probability 1/2 each.

Step 1: E[X] = 0×0.5 + 2×0.5 = 1.

Step 2: f(E[X]) = 1² = 1.

Step 3: E[f(X)] = f(0)×0.5 + f(2)×0.5 = 0×0.5 + 4×0.5 = 2.

Step 4: Jensen: 1 ≤ 2. ✓ f(E[X]) ≤ E[f(X)].

Answer: **Confirmed: f(E[X]) = 1, E[f(X)] = 2. Jensen holds: 1 ≤ 2**.

#### Chunked Example — CS Application: KL Divergence

The Kullback-Leibler divergence D_KL(P||Q) = E_P[log(P/Q)] is convex in (P,Q). Jensen's inequality shows D_KL(P||Q) ≥ 0, with equality iff P=Q. This is fundamental to information theory and ML model evaluation.

### Breadcrumb 5: Constrained Optimisation and the Lagrangian

**Builds on:** Breadcrumb 1, [[9.9 Gradient Descent and Optimisation]]

Real optimisation problems often have constraints:
- Minimise f(x) subject to gᵢ(x) ≤ 0, hⱼ(x)=0.

The **Lagrangian** converts constrained optimisation into unconstrained:
```
L(x, λ, ν) = f(x) + ∑λᵢ·gᵢ(x) + ∑νⱼ·hⱼ(x)
```

For convex f with convex constraints, the solution satisfies the **KKT conditions** (necessary and sufficient).

#### Chunked Example — Constrained Minimisation

Question: Minimise f(x)=x² subject to x ≥ 1 (equivalently g(x)=1-x ≤ 0).

Step 1: Lagrangian: L(x,λ) = x² + λ(1-x), λ ≥ 0.

Step 2: KKT conditions:
- ∂L/∂x = 2x - λ = 0 → λ = 2x.
- Complementary slackness: λ(1-x)=0.
- λ ≥ 0, x-1 ≥ 0.

Step 3: If λ=0: then x=0, but x≥1 violated. So λ>0, complementary slackness gives 1-x=0 → x=1.

Step 4: Then λ = 2×1 = 2 ≥ 0. ✓

Answer: **x*=1. The constraint is active (we are at the boundary x=1)**.

## Worked Examples

### Example 1 — Proving Convexity of MSE

Question: Show that the mean squared error loss L(w) = (1/n)∑(wxᵢ+b-yᵢ)² is convex in w.

Step 1: L(w) = (1/n)∑(xᵢw + b - yᵢ)². Each term is (xᵢw + cᵢ)² where cᵢ=b-yᵢ.

Step 2: d²/dw²[(xᵢw+cᵢ)²] = 2xᵢ² ≥ 0. Each term is convex.

Step 3: Sum of convex functions is convex. So L(w) is convex.

Answer: **MSE is convex → linear regression has a unique global minimum**.

### Example 2 — Convexity of Negative Log-Likelihood for Logistic Regression

Question: Show that the negative log-likelihood for logistic regression is convex.

Step 1: For a single point: L(w) = -[y·log(σ(w·x)) + (1-y)·log(1-σ(w·x))].

Step 2: This simplifies to log(1+e^{-y·w·x}). The second derivative of log(1+e^{-z}) is σ(z)(1-σ(z)) ≥ 0.

Step 3: Therefore each term is convex, so the total loss is convex.

Answer: **Logistic regression loss is convex → guaranteed global minimum**.

## Why This Works

Convexity is the "golden ticket" of optimisation because:
1. **Any local minimum is global** — no worrying about bad local minima.
2. **Gradient descent converges to the global minimum** — with a suitable learning rate.
3. **The set of convex functions is closed under addition, scaling, and affine composition** — building convex models from simpler pieces is easy.
4. **Duality** — every convex problem has a dual problem that provides lower bounds and optimality certificates.

The second-order condition (Hessian positive semidefinite) connects to [[9.4 Applications of Differentiation]]: just as f''(x)≥0 guarantees a single minimum in 1D, H positive semidefinite guarantees a single minimum in nD.

## Common Mistakes

> [!failure] Mistake pattern: Confusing convex functions with concave functions
> Convex: ∪-shaped (smile). Concave: ∩-shaped (frown). f''(x)≥0 → convex. f''(x)≤0 → concave.

> [!failure] Mistake pattern: Assuming all functions are convex
> Most real problems are NOT convex (neural networks, mixture models, etc.). Convexity is the exception, not the rule.

> [!failure] Mistake pattern: Forgetting to check the domain
> A function might be convex on its domain, but the domain itself might not be convex. Both the function and the constraint set must be convex for the theory to apply.

> [!failure] Mistake pattern: Using Jensen's inequality backwards
> For convex f: f(E[X]) ≤ E[f(X)]. For concave f: f(E[X]) ≥ E[f(X)]. Mixing these up reverses the inequality.

### Optimisation — CVXPY (Convex Optimisation in Python)
```python
import cvxpy as cp
x = cp.Variable()
objective = cp.Minimize(x**2 + 2*x + 1)
problem = cp.Problem(objective, [x >= 0])
problem.solve()  # guaranteed global minimum
print(x.value)  # x = 0 (the constrained minimum)
```
