## Introduction

Differentiation rules are shortcuts so you do not have to use the limit definition every time. From [[9.2 Differentiation Basics]], you can differentiate x² from first principles using the limit definition. But what about sin(x²)? Or eˣ·cos x? Or (3x+1)⁵? Computing these from the definition would be painful.

The three core rules solve this:

```
Product rule:  (uv)' = u'v + uv'
Chain rule:    d/dx[f(g(x))] = f'(g(x)) · g'(x)
Quotient rule: (u/v)' = (u'v - uv')/v²
```

The chain rule is the most important rule in all of calculus for computer science. Why? Because **backpropagation in neural networks is the chain rule applied thousands of times** — computing how the loss changes with respect to every weight by multiplying gradients through every layer.

L'Hôpital's rule is a bonus: it uses derivatives to evaluate limits that would otherwise be stuck in 0/0 form.

## New Words

- **[[power rule]]** — d/dx[xⁿ] = nxⁿ⁻¹.
- **[[product rule]]** — (uv)' = u'v + uv'. "First times derivative of second plus second times derivative of first."
- **[[quotient rule]]** — (u/v)' = (u'v - uv')/v². "Low d-high minus high d-low, over low squared."
- **[[chain rule]]** — d/dx[f(g(x))] = f'(g(x)) · g'(x). "Derivative of outside, times derivative of inside."
- **[[L'Hôpital's rule]]** — for 0/0 or ∞/∞ indeterminate forms: lim f/g = lim f'/g'.

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: The Power Rule and Linearity

**Builds on:** [[9.2 Differentiation Basics]] (derivative definition, basic derivatives)

The power rule: d/dx[xⁿ] = nxⁿ⁻¹. This works for any real n (positive, negative, fractional).

Differentiation is **linear**: 
- d/dx[c·f(x)] = c·f'(x) (constants factor out)
- d/dx[f(x)+g(x)] = f'(x)+g'(x) (sum rule)

#### Chunked Example

Question: f(x) = 3x⁴ + 2x³ - x + 7. Find f'(x).

Step 1: Differentiate term by term. Power rule: 3x⁴ → 3×4x³ = 12x³.

Step 2: 2x³ → 2×3x² = 6x².

Step 3: -x = -1·x¹ → -1×1x⁰ = -1.

Step 4: Constant 7 → 0.

Step 5: f'(x) = 12x³ + 6x² - 1.

Answer: **f'(x) = 12x³ + 6x² - 1**.

### Breadcrumb 2: The Product Rule

**Builds on:** Breadcrumb 1

The product rule tells us how to differentiate the product of two functions:

```
(uv)' = u'v + uv'
```

In words: the derivative of the first times the second, plus the first times the derivative of the second.

#### Chunked Example

Question: f(x) = x²·sin x. Find f'(x).

Step 1: Identify the two factors: u = x², v = sin x.

Step 2: Compute individual derivatives: u' = 2x, v' = cos x.

Step 3: Apply the product rule: f'(x) = u'v + uv' = (2x)(sin x) + (x²)(cos x).

Answer: **f'(x) = 2x sin x + x² cos x**.

#### Chunked Example — Product of Three Functions

Question: f(x) = x·eˣ·cos x. Find f'(x). (Treat as (x·eˣ)·cos x, use product rule twice.)

Step 1: Let u = x·eˣ, v = cos x. We need u' first.

Step 2: u = x·eˣ. Use product rule: u' = (1)(eˣ) + (x)(eˣ) = eˣ(1+x).

Step 3: v' = -sin x.

Step 4: f'(x) = u'v + uv' = eˣ(1+x)·cos x + x·eˣ·(-sin x) = eˣ[(1+x)cos x - x sin x].

Answer: **eˣ[(1+x)cos x - x sin x]**.

### Breadcrumb 3: The Quotient Rule

**Builds on:** Breadcrumb 1

The quotient rule differentiates a ratio of functions:

```
(u/v)' = (u'v - uv')/v²
```

"It's low d-high minus high d-low, over low squared" — a common mnemonic. "Low" = denominator v, "high" = numerator u.

#### Chunked Example

Question: f(x) = x²/(x+1). Find f'(x).

Step 1: u = x², u' = 2x. v = x+1, v' = 1.

Step 2: f'(x) = (u'v - uv')/v² = (2x(x+1) - x²×1)/(x+1)².

Step 3: Simplify numerator: 2x²+2x - x² = x²+2x.

Answer: **f'(x) = (x²+2x)/(x+1)²**.

#### Chunked Example — Tangent of x

Question: Show that d/dx[tan x] = sec² x using the quotient rule (tan x = sin x/cos x).

Step 1: u = sin x, u' = cos x. v = cos x, v' = -sin x.

Step 2: (tan x)' = (cos x·cos x - sin x·(-sin x))/cos²x = (cos²x + sin²x)/cos²x.

Step 3: Recall sin²x + cos²x = 1. So (tan x)' = 1/cos²x = sec²x.

Answer: **d/dx[tan x] = sec² x**.

### Breadcrumb 4: The Chain Rule — Derivative of Compositions

**Builds on:** Breadcrumb 1, [[9.2 Differentiation Basics]] (function notation)

The chain rule differentiates a **composition** of functions: f(g(x)). Think of it as "outside times inside":

```
d/dx[f(g(x))] = f'(g(x)) · g'(x)
```

- f is the **outer function** (applied last).
- g is the **inner function** (applied first).
- f'(g(x)) means: evaluate the outer derivative at the inner function.
- g'(x) is the derivative of the inner function.

#### Chunked Example — Simple Chain

Question: f(x) = sin(x²). Find f'(x).

Step 1: Identify the functions. Outer: sin(u). Inner: u = x².

Step 2: Outer derivative: d/du[sin(u)] = cos(u) = cos(x²).

Step 3: Inner derivative: du/dx = 2x.

Step 4: Multiply: f'(x) = cos(x²) × 2x.

Answer: **f'(x) = 2x cos(x²)**.

#### Chunked Example — Power of a Polynomial

Question: f(x) = (3x+1)⁵. Find f'(x).

Step 1: Outer: u⁵, derivative = 5u⁴. Inner: u = 3x+1, derivative = 3.

Step 2: f'(x) = 5(3x+1)⁴ × 3 = 15(3x+1)⁴.

Answer: **f'(x) = 15(3x+1)⁴**.

#### Chunked Example — Three-Level Nested Chain

Question: f(x) = cos(e^(x²)). Find f'(x).

Step 1: Identify the three layers:
- Outermost: cos(...), derivative = -sin(...)
- Middle: e^(...), derivative = e^(...)
- Innermost: x², derivative = 2x

Step 2: Apply chain rule from outside to inside:
f'(x) = -sin(e^(x²)) × e^(x²) × 2x

Answer: **f'(x) = -2x·e^(x²)·sin(e^(x²))**.

### Breadcrumb 5: L'Hôpital's Rule

**Builds on:** [[9.1 Limits and Continuity]] (indeterminate forms 0/0), [[9.2 Differentiation Basics]] (derivatives)

For limits of the form 0/0 or ∞/∞:

```
lim_{x→a} f(x)/g(x) = lim_{x→a} f'(x)/g'(x)
```

provided the limit of f'/g' exists (or is ∞). This rule converts a difficult limit into an easier derivative ratio.

#### Chunked Example — Classic sin x / x

Question: lim_{x→0} sin x / x.

Step 1: Substitution gives 0/0. Apply L'Hôpital.

Step 2: Differentiate numerator and denominator separately: d/dx[sin x] = cos x, d/dx[x] = 1.

Step 3: lim_{x→0} cos x / 1 = 1.

Answer: **1**.

#### Chunked Example — Exponential

Question: lim_{x→0} (eˣ - 1)/x.

Step 1: Substitution: (1-1)/0 = 0/0. Apply L'Hôpital.

Step 2: d/dx[eˣ-1] = eˣ. d/dx[x] = 1.

Step 3: lim_{x→0} eˣ/1 = 1.

Answer: **1**.

## Worked Examples

### Example 1 — Product and Chain Combined

Question: f(x) = eˣ·sin(2x). Find f'(x).

Step 1: Product rule: u = eˣ (u' = eˣ), v = sin(2x) (need chain rule for v').

Step 2: v' uses chain rule: outer sin(u), inner 2x. v' = cos(2x) × 2 = 2cos(2x).

Step 3: f'(x) = eˣ·sin(2x) + eˣ·2cos(2x) = eˣ(sin 2x + 2cos 2x).

Answer: **eˣ(sin 2x + 2cos 2x)**.

### Example 2 — Chain Rule with Quotient

Question: f(x) = sin(x²+1)/(x³+2x). Find f'(x).

Step 1: Quotient rule: u = sin(x²+1), v = x³+2x.

Step 2: u' uses chain rule: outer sin, inner x²+1. u' = cos(x²+1) × 2x = 2x cos(x²+1).

Step 3: v' = 3x²+2.

Step 4: f'(x) = (u'v - uv')/v² = (2x cos(x²+1)(x³+2x) - sin(x²+1)(3x²+2))/(x³+2x)².

Answer: **(2x cos(x²+1)(x³+2x) - sin(x²+1)(3x²+2))/(x³+2x)²**.

### Example 3 — CS Application: Neural Network Gradient

Question: A neuron computes z = wx + b, then applies sigmoid activation σ(z) = 1/(1+e^(-z)). Find dσ/dw — how the output changes with weight w.

Step 1: σ'(z) = σ(z)(1-σ(z)) (derivative of sigmoid, proven using quotient rule).

Step 2: By chain rule: dσ/dw = σ'(z) × dz/dw = σ(z)(1-σ(z)) × x.

Step 3: This gradient tells us how to adjust w to reduce the loss. It is exactly what backpropagation computes.

Answer: **dσ/dw = σ(wx+b)(1-σ(wx+b)) × x**.

## Why This Works

The product rule comes from considering a tiny change Δ in both factors:

Δ(uv) ≈ (u+Δu)(v+Δv) - uv = uΔv + vΔu + ΔuΔv

As Δ→0, the ΔuΔv term vanishes (it is second-order), leaving u dv + v du.

The chain rule dy/dx = (dy/du)(du/dx) is almost obvious in Leibniz notation: you can "cancel" the du terms. This chaining is exactly how backpropagation computes gradients — starting from the loss at the output and multiplying gradients backward through every layer.

L'Hôpital's rule works because near a point where both are 0, each function is approximately its tangent line: f(x) ≈ f'(a)(x-a) and g(x) ≈ g'(a)(x-a). Their ratio is approximately f'(a)/g'(a).

## Common Mistakes

> [!failure] Mistake pattern: Using the product rule when there is only one factor
> (x²)' = 2x, not (1)x² + x²(1). The product rule is only needed when two distinct functions are multiplied.

> [!failure] Mistake pattern: Forgetting the chain rule — the most common differentiation error
> d/dx[(x²+1)³] = 3(x²+1)² × 2x = 6x(x²+1)². The 2x factor is the derivative of the inside. Students often forget it.

> [!failure] Mistake pattern: Quotient rule numerator order
> (u/v)' = (u'v - uv')/v². It is NOT (v'u - vu')/v². Remember "high d-low minus low d-high."

> [!failure] Mistake pattern: Applying L'Hôpital when the limit is NOT 0/0 or ∞/∞
> L'Hôpital only works for indeterminate forms. Do NOT use it when direct substitution gives a definite value.

## Where This Shows Up in CS

### Backpropagation — The Chain Rule in Action
```python
# The gradient of the loss w.r.t. each weight uses the chain rule
# ∂L/∂w = ∂L/∂σ · ∂σ/∂z · ∂z/∂w
gradient = loss_gradient * sigmoid_derivative(z) * input
```

### Automatic Differentiation (Autograd)
```python
# PyTorch/TensorFlow compute derivatives using these rules
# Every operation records its derivative for backpropagation
import torch
x = torch.tensor(3.0, requires_grad=True)
y = torch.sin(x**2)
y.backward()  # computes dy/dx = 2x*cos(x²)
print(x.grad)  # 2*3*cos(9) ≈ -5.88
```

### Optimisation — Gradient Descent
```python
# Gradient descent uses derivatives to minimise functions
w -= learning_rate * dw  # dw = dL/dw computed via chain rule
```
