## Introduction

Derivatives are not just abstract rules — they solve real problems. From [[9.3 Differentiation Rules]], you can differentiate almost any function. Now we put that power to work.

Differentiation answers questions like:
- Where does a function reach its maximum or minimum?
- Is a function curving upward or downward at a given point?
- How can we find the roots of a function numerically?
- How do we optimise real-world systems (cost, profit, ML loss)?

The key insight: **f'(x)=0** identifies stationary points (where the function is flat). The second derivative f''(x) tells us whether that point is a maximum (f''(x)<0), minimum (f''(x)>0), or inflection (f''(x)=0).

In computer science, these ideas power everything from training neural networks (where we find the minimum of a loss function) to root-finding algorithms (Newton's method) to game physics (velocity and acceleration).

## New Words

- **[[critical point]]** — x where f'(x)=0 or f'(x) does not exist.
- **[[stationary point]]** — x where f'(x)=0 specifically (a type of critical point).
- **[[local maximum]]** — f(c) ≥ f(x) for all x near c. Peak of a hill.
- **[[local minimum]]** — f(c) ≤ f(x) for all x near c. Bottom of a valley.
- **[[first derivative test]]** — classifies stationary points by checking sign changes of f'(x).
- **[[second derivative test]]** — classifies stationary points using f''(x): f''(c)>0 → min, f''(c)<0 → max.
- **[[convex function]]** — f''(x) ≥ 0 everywhere. Curves upward. Any local minimum is global.
- **[[concave function]]** — f''(x) ≤ 0 everywhere. Curves downward. Any local maximum is global.
- **[[Newton's method]]** — iterative algorithm to find roots using x_{n+1}=x_n - f(x_n)/f'(x_n).

## Breadcrumbs

### Breadcrumb 1: Critical Points and Stationary Points

**Builds on:** [[9.3 Differentiation Rules]] (computing derivatives), [[9.2 Differentiation Basics]]

A **critical point** occurs where f'(x)=0 or f'(x) does not exist. A **stationary point** is a critical point where f'(x)=0 exactly.

Why do we care? Because any local maximum or minimum must occur at a critical point. This is Fermat's theorem: if f has a local extremum at c and f'(c) exists, then f'(c)=0.

> [!warning] The converse is false. f'(c)=0 does NOT guarantee a maximum or minimum. Consider f(x)=x³ at x=0: f'(0)=0 but x=0 is an inflection point, not an extremum.

#### Chunked Example — Finding Critical Points

Question: f(x)=x³-3x²+1. Find all critical points.

Step 1: f'(x)=3x²-6x = 3x(x-2). Set f'(x)=0: 3x(x-2)=0.

Step 2: Solutions: x=0 and x=2. Both are stationary points.

Step 3: f(x) values: f(0)=1, f(2)=8-12+1=-3.

Answer: **Critical points: x=0 (f=1) and x=2 (f=-3)**.

### Breadcrumb 2: The First Derivative Test — Classifying Critical Points

**Builds on:** Breadcrumb 1

The first derivative test looks at how f'(x) changes sign around a stationary point:

| Sign change of f'(x) | Type |
|---|---|
| + to − | Local maximum |
| − to + | Local minimum |
| Same sign | Inflection point (not an extremum) |

#### Chunked Example — Classifying with First Derivative Test

Question: f(x)=x³-3x²+1. Classify x=0 and x=2.

Step 1: At x=0, check f'(x)=3x(x-2) on both sides:
- For x just left of 0 (e.g. x=-1): f'(-1)=3(-1)(-3)=9 > 0.
- For x just right of 0 (e.g. x=1): f'(1)=3(1)(-1)=-3 < 0.

Step 2: Sign goes + → − at x=0: **local maximum**.

Step 3: At x=2, check both sides:
- For x just left of 2 (e.g. x=1.9): f'(1.9) ≈ 3(1.9)(-0.1)=-0.57 < 0.
- For x just right of 2 (e.g. x=2.1): f'(2.1) ≈ 3(2.1)(0.1)=0.63 > 0.

Step 4: Sign goes − → + at x=2: **local minimum**.

Answer: **x=0 is a local maximum, x=2 is a local minimum**.

### Breadcrumb 3: The Second Derivative Test — An Alternative Classification

**Builds on:** Breadcrumb 1, [[9.3 Differentiation Rules]] (computing f''(x))

The second derivative f''(x) gives the **rate of change of the slope**. At a stationary point where f'(c)=0:

- f''(c) > 0: slope is increasing → local minimum (valley).
- f''(c) < 0: slope is decreasing → local maximum (peak).
- f''(c) = 0: test is inconclusive. Use the first derivative test instead.

#### Chunked Example — Using Second Derivative

Question: f(x)=x³-3x²+1. Classify with f''(x).

Step 1: f''(x)=6x-6 = 6(x-1).

Step 2: At x=0: f''(0)=-6 < 0 → local maximum.

Step 3: At x=2: f''(2)=6 > 0 → local minimum.

Step 4: Both results match the first derivative test.

Answer: **Same as before: max at x=0, min at x=2**.

### Breadcrumb 4: Convexity and Concavity

**Builds on:** Breadcrumb 3

Beyond just maxima/minima, f''(x) tells us about the **shape** of the function on intervals:

| f''(x) | Shape | Called |
|---|---|---|
| f''(x) > 0 | Curves upward (∪) | Convex |
| f''(x) < 0 | Curves downward (∩) | Concave |
| f''(x)=0 and changes sign | Inflection point | Changes shape |

A **convex** function (sometimes called "concave up") has every chord above the graph. A **concave** function (sometimes called "concave down") has every chord below the graph.

#### Chunked Example — Convexity

Question: f(x)=x³-3x²+1. Where is it convex? Concave? Any inflection points?

Step 1: f''(x)=6x-6. Set f''(x)=0: x=1.

Step 2: For x<1, f''(x)<0 (e.g. x=0: f''(0)=-6). Concave.

Step 3: For x>1, f''(x)>0 (e.g. x=2: f''(2)=6). Convex.

Step 4: At x=1, f'' changes sign. f(1)=1-3+1=-1. Inflection point at (1,-1).

Answer: **Concave on (-∞,1), convex on (1,∞). Inflection at x=1**.

### Breadcrumb 5: Newton's Method for Root Finding

**Builds on:** [[9.2 Differentiation Basics]] (tangent line), [[9.3 Differentiation Rules]]

Newton's method finds roots (solutions to f(x)=0) iteratively. Starting from an initial guess x₀, repeatedly apply:

```
x_{n+1} = x_n - f(x_n)/f'(x_n)
```

Geometrically: at the current point (xₙ, f(xₙ)), draw the tangent line (slope f'(xₙ)). Follow it down to where it crosses the x-axis. That crossing is x_{n+1}.

#### Chunked Example — Approximating √2

Question: Find √2 using Newton's method. Let f(x)=x²-2. The root is x=√2.

Step 1: f'(x)=2x. Newton's formula: x_{n+1} = x_n - (x_n²-2)/(2x_n).

Step 2: Start with x₀=1.5:
x₁ = 1.5 - (2.25-2)/3 = 1.5 - 0.25/3 = 1.5 - 0.0833 = 1.4167

Step 3: x₂ = 1.4167 - (2.007-2)/(2.8333) = 1.4167 - 0.007/2.8333 = 1.4142

Step 4: After two iterations, x₂=1.4142. Actual √2 ≈ 1.41421356... Accurate to 4 decimal places!

Answer: **√2 ≈ 1.4142 (after 2 iterations from x₀=1.5)**.

#### Chunked Example — Newton's Method in ML

In machine learning, Newton's method is too slow for high-dimensional problems (it requires the Hessian matrix — second derivatives — which is O(n²) in size). Instead, we use gradient descent (first derivative only). But Newton's method converges faster when the Hessian is tractable.

### Breadcrumb 6: Optimisation — Finding Global Maxima and Minima

**Builds on:** Breadcrumbs 1-3

For optimisation, we want the **global** (absolute) maximum/minimum of f on a given interval [a,b].

Procedure:
1. Find all critical points in (a,b).
2. Evaluate f at all critical points and at the endpoints a and b.
3. The largest value is the global max; the smallest is the global min.

#### Chunked Example — Global Optimisation

Question: f(x)=x³-3x²+1 on [-1,4]. Find global max and min.

Step 1: Critical points in (-1,4): x=0 (local max, f=1), x=2 (local min, f=-3).

Step 2: Endpoints: f(-1)=-1-3+1=-3. f(4)=64-48+1=17.

Step 3: Compare values: 17 (x=4), 1 (x=0), -3 (x=2), -3 (x=-1).

Answer: **Global max: 17 at x=4. Global min: -3 at x=2 and x=-1**.

## Worked Examples

### Example 1 — Full Function Analysis

Question: Analyse f(x)=2x³-9x²+12x-5: find critical points, classify them, determine convexity, and find global extrema on [0,3].

Step 1: Derivative: f'(x)=6x²-18x+12 = 6(x²-3x+2) = 6(x-1)(x-2).

Step 2: Stationary points: x=1, x=2. f(1)=2-9+12-5=0. f(2)=16-36+24-5=-1.

Step 3: Second derivative: f''(x)=12x-18 = 6(2x-3).
- f''(1)=12-18=-6 < 0 → local max at (1,0).
- f''(2)=24-18=6 > 0 → local min at (2,-1).

Step 4: Convexity: f''(x)=0 at x=1.5. f''(x)<0 for x<1.5 (concave), f''(x)>0 for x>1.5 (convex).

Step 5: Global on [0,3]: Evaluate f(0)=-5, f(1)=0, f(2)=-1, f(3)=54-81+36-5=4.
Global max: 4 at x=3. Global min: -5 at x=0.

### Example 2 — CS Application: Minimising Error

Question: A model predicts y = w·x. The error on a dataset is E(w) = (1/2)(wx₁-y₁)² + (1/2)(wx₂-y₂)². Find the w that minimises E.

Step 1: Data: (x₁,y₁)=(1,2), (x₂,y₂)=(3,8).
E(w) = (1/2)(w-2)² + (1/2)(3w-8)².

Step 2: E'(w) = (w-2) + 3(3w-8) = w-2+9w-24 = 10w-26.

Step 3: Set E'(w)=0: 10w-26=0 → w=2.6.

Step 4: E''(w)=10 > 0 → convex, so this is the global minimum.

Step 5: Interpretation: w=2.6 is the optimal slope. The line y=2.6x best fits these two points in a least-squares sense.

Answer: **w = 2.6 minimises the squared error**.

### Example 3 — CS Application: Loss Landscape Visualisation

```python
# Visualising the loss function L(w) = w² - 4w + 5
# Its minimum is where L'(w) = 2w - 4 = 0 → w = 2

import matplotlib.pyplot as plt

w = np.linspace(-2, 6, 100)
L = w**2 - 4*w + 5
plt.plot(w, L)
plt.axvline(2, color='r', linestyle='--', label='minimum at w=2')
```

## Why This Works

The first derivative tells you the instantaneous slope. At a maximum, the slope changes from positive (climbing up) to negative (falling down), so f'(x) goes from + to −.

The second derivative tells you how the slope itself is changing. f''(x) > 0 means the slope is becoming more positive — as you move right, the slope increases. At a minimum, the slope goes from negative to positive (increasing), so f''(x) > 0.

Convex functions (f''(x) ≥ 0) are special: they have exactly one minimum (global), and gradient descent is guaranteed to find it. This is why convex optimisation is so important in ML — problems with convex loss are "easy" to solve optimally.

Newton's method works because the tangent line approximates the function near the current point. Following the tangent to the x-axis gives a better root estimate, and repeating converges very rapidly (doubling the number of correct digits each step).

## Common Mistakes

> [!failure] Mistake pattern: Assuming f'(c)=0 implies a maximum or minimum
> f(x)=x³ at x=0: f'(0)=0 but it is an inflection point. Always classify using the first or second derivative test.

> [!failure] Mistake pattern: Confusing convex and concave
> Convex (∪): f''(x) > 0, curves upward, looks like a smile. Concave (∩): f''(x) < 0, curves downward, looks like a frown.

> [!failure] Mistake pattern: Forgetting to check endpoints for global optimisation
> The global max/min on a closed interval may occur at the endpoints, even if there are no critical points inside.

> [!failure] Mistake pattern: Applying the second derivative test when f''(c)=0
> f''(c)=0 is inconclusive. Use the first derivative test instead.

> [!failure] Mistake pattern: Newton's method with division by zero
> If f'(xₙ) ≈ 0 at some iteration, the denominator in Newton's update is near zero. The method may diverge or oscillate.

## Where This Shows Up in CS

### Gradient Descent — Finding the Minimum of a Loss Function
```python
# The fundamental ML optimisation algorithm
def gradient_descent(gradient, start, lr=0.01, steps=100):
    x = start
    for _ in range(steps):
        x -= lr * gradient(x)  # step opposite the gradient
    return x
```

### Newton's Method — Root Finding for Numerical Solvers
```python
def newton(f, df, x0, steps=10):
    x = x0
    for _ in range(steps):
        if df(x) == 0: break  # avoid division by zero
        x -= f(x)/df(x)
    return x

# Example: find sqrt(2)
f = lambda x: x**2 - 2
df = lambda x: 2*x
print(newton(f, df, 1.5))  # 1.41421356...
```
