## Introduction

So far, we have studied functions of one variable: f(x). But most real-world problems depend on many inputs:
- The loss function L(w₁, w₂, ..., wₙ) depends on all the weights in a neural network.
- The temperature T(x, y, z) at a point depends on three spatial coordinates.
- The error surface E(θ₁, θ₂) in a 2-parameter model is a 3D surface.

From [[9.3 Differentiation Rules]], you know how to differentiate f(x). Now we extend this to f(x₁, x₂, ..., xₙ).

The key tool is the **partial derivative** ∂f/∂xᵢ: the derivative of f with respect to xᵢ while treating all other variables as constants.

The **gradient** ∇f (nabla f) is the vector of all partial derivatives:
```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

The gradient points in the direction of steepest increase and is the foundation of gradient descent — the optimisation algorithm that trains neural networks.

## New Words

- **[[multivariable function]]** — a function f: ℝⁿ → ℝ that takes n real inputs and returns one real output.
- **[[partial derivative]]** — ∂f/∂xᵢ: derivative of f with respect to xᵢ, holding other variables constant.
- **[[gradient]]** — ∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ), the vector of all partial derivatives.
- **[[level curve]]** — set of points where f(x,y)=c (a contour line).
- **[[directional derivative]]** — D_ⱽ f = ∇f·v, the rate of change in direction v.
- **[[Hessian matrix]]** — H = [∂²f/∂xᵢ∂xⱼ], the matrix of second partial derivatives.
- **[[Laplacian]]** — ∇²f = ∂²f/∂x₁² + ∂²f/∂x₂² + ... + ∂²f/∂xₙ², sum of unmixed second partials.

> [!important] You pass this topic only when you can define all seven terms without looking.

## Breadcrumbs

### Breadcrumb 1: Functions of Two Variables — Visualising Surfaces

**Builds on:** [[9.2 Differentiation Basics]] (function concept), [[2.5 Cartesian Coordinates]]

A function f(x,y) maps a point in the plane to a height. The graph is a surface in 3D.

**Level curves** (contours) help visualise: they are curves where f(x,y)=c, like elevation contours on a topographic map.

#### Chunked Example — Visualising f(x,y) = x² + y²

Question: Describe f(x,y)=x²+y². Draw level curves.

Step 1: At (1,1): f=2. At (2,0): f=4. f increases as distance from origin increases.

Step 2: Level curves: x²+y²=c. These are circles of radius √c centred at the origin.

Step 3: The graph is a **paraboloid** — a 3D bowl shape with minimum at (0,0).

Answer: **f(x,y)=x²+y² is a paraboloid. Level curves are concentric circles**.

#### Chunked Example — Visualising f(x,y) = sin(x) + cos(y)

The level curves of f(x,y)=sin x + cos y form a grid-like pattern of alternating ridges and valleys. The function oscillates between -2 and 2. This is like the error surface of a neural network — full of local minima and saddle points.

### Breadcrumb 2: Partial Derivatives — One Variable at a Time

**Builds on:** [[9.3 Differentiation Rules]] (all derivative rules), [[9.2 Differentiation Basics]], Breadcrumb 1

To compute ∂f/∂x, treat y as a constant and differentiate with respect to x. To compute ∂f/∂y, treat x as a constant and differentiate with respect to y.

#### Chunked Example — Simple Partial Derivatives

Question: f(x,y) = 3x²y + 5y³. Find ∂f/∂x and ∂f/∂y.

Step 1: ∂f/∂x: treat y as constant. ∂/∂x[3x²y] = 6xy. ∂/∂x[5y³] = 0.
So ∂f/∂x = 6xy.

Step 2: ∂f/∂y: treat x as constant. ∂/∂y[3x²y] = 3x². ∂/∂y[5y³] = 15y².
So ∂f/∂y = 3x² + 15y².

Answer: **∂f/∂x = 6xy, ∂f/∂y = 3x² + 15y²**.

#### Chunked Example — Partial Derivatives with Chain Rule

Question: f(x,y) = sin(x²y). Find ∂f/∂x.

Step 1: Treat y as constant. Let u = x²y. Then f = sin(u).

Step 2: ∂f/∂x = cos(u)·∂u/∂x = cos(x²y)·(2xy).

Answer: **∂f/∂x = 2xy·cos(x²y)**.

### Breadcrumb 3: The Gradient Vector

**Builds on:** Breadcrumb 2, [[7.1 Vectors and Vector Spaces]] (vector notation)

The **gradient** ∇f is the vector of all partial derivatives:

∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)

Properties of ∇f:
- **∇f points in the direction of steepest ascent** from the current point.
- **-∇f points in the direction of steepest descent** — this is what gradient descent uses.
- ∇f is perpendicular to level curves (at the point of evaluation).
- The **directional derivative** in direction v is ∇f·v.

#### Chunked Example — Computing a Gradient

Question: f(x,y) = x²y + y³. Find ∇f at (2,1).

Step 1: ∂f/∂x = 2xy. At (2,1): 2×2×1 = 4.

Step 2: ∂f/∂y = x² + 3y². At (2,1): 4+3 = 7.

Step 3: ∇f(2,1) = (4, 7).

Interpretation: from (2,1), moving in direction (4,7) increases f fastest. The slope in that direction is |∇f| = √(4²+7²) = √65 ≈ 8.06.

Answer: **∇f(2,1) = (4, 7)**.

#### Chunked Example — Directional Derivative

Question: For f(x,y)=x²+y², find the directional derivative at (1,1) in direction v=(1,0) (i.e., moving along the x-axis).

Step 1: ∇f = (2x, 2y). At (1,1): ∇f = (2,2).

Step 2: v = (1,0). Normalise: |v| = 1 already.

Step 3: D_ⱽ f = ∇f·v = (2,2)·(1,0) = 2.

Answer: **2. Moving along the x-axis from (1,1), f increases at rate 2**.

### Breadcrumb 4: Higher-Order Partial Derivatives and the Hessian

**Builds on:** Breadcrumb 2

Second partial derivatives:
- ∂²f/∂x² = ∂/∂x(∂f/∂x) — second derivative with respect to x twice.
- ∂²f/∂y² = ∂/∂y(∂f/∂y) — second derivative with respect to y twice.
- ∂²f/∂x∂y = ∂/∂x(∂f/∂y) — mixed partial: differentiate with respect to y, then x.
- ∂²f/∂y∂x = ∂/∂y(∂f/∂x) — mixed partial: differentiate with respect to x, then y.

**Clairaut's theorem**: If the mixed partials are continuous, ∂²f/∂x∂y = ∂²f/∂y∂x (order does not matter).

The **Hessian matrix** H collects all second partials:
```
H = [∂²f/∂x₁²   ∂²f/∂x₁∂x₂  ...]
    [∂²f/∂x₂∂x₁ ∂²f/∂x₂²    ...]
    [...        ...          ...]
```

#### Chunked Example — Computing the Hessian

Question: f(x,y) = x²y + y³. Find H.

Step 1: First partials: ∂f/∂x = 2xy, ∂f/∂y = x² + 3y².

Step 2: Second partials: ∂²f/∂x² = 2y, ∂²f/∂y² = 6y, ∂²f/∂x∂y = 2x, ∂²f/∂y∂x = 2x.

Step 3: H = [[2y, 2x], [2x, 6y]].

Answer: **H = [[2y, 2x], [2x, 6y]]**.

### Breadcrumb 5: The Laplacian

**Builds on:** Breadcrumb 4

The **Laplacian** ∇²f is the sum of unmixed second partial derivatives:

∇²f = ∂²f/∂x₁² + ∂²f/∂x₂² + ... + ∂²f/∂xₙ²

It measures the "curvature" or "spread" of f at a point. Used in:
- **Heat equation**: ∂u/∂t = α∇²u (how heat diffuses).
- **Image processing**: Laplacian filters detect edges (regions of rapid intensity change).
- **Physics**: Laplace's equation ∇²φ = 0 describes electrostatic potentials.

#### Chunked Example

Question: f(x,y) = x² + y². Find ∇²f.

Step 1: ∂²f/∂x² = 2. ∂²f/∂y² = 2.

Step 2: ∇²f = 2 + 2 = 4.

Answer: **∇²f = 4**. The Laplacian is constant, indicating uniform curvature.

## Worked Examples

### Example 1 — Gradient for a Loss Function

Question: A model has loss L(w₁,w₂) = (w₁-2)² + 2(w₂+1)². Find ∇L and the direction of steepest descent at (0,0).

Step 1: ∂L/∂w₁ = 2(w₁-2). At (0,0): -4.
∂L/∂w₂ = 4(w₂+1). At (0,0): 4.

Step 2: ∇L(0,0) = (-4, 4).

Step 3: Direction of steepest descent = -∇L = (4, -4).

Step 4: Gradient descent update: (w₁,w₂) ← (0,0) - η·(4,-4) = (-4η, 4η).

Answer: **∇L = (-4,4). Steepest descent direction: (4,-4)**.

### Example 2 — CS Application: Linear Regression Gradient

Question: For a single data point (x,y), the squared error is L(w,b) = (wx+b-y)². Find ∂L/∂w and ∂L/∂b.

Step 1: ∂L/∂w = 2(wx+b-y)·x (chain rule: derivative of (·)² times derivative of inner w.r.t. w).
∂L/∂b = 2(wx+b-y)·1.

Step 2: These gradients tell us how to adjust w and b to reduce error.

Step 3: ∇L = (2x(wx+b-y), 2(wx+b-y)).

Answer: **∂L/∂w = 2x(wx+b-y), ∂L/∂b = 2(wx+b-y)**.

## Why This Works

Partial derivatives work by isolating one variable at a time. The term "partial" means exactly that — you only see part of the total change. The gradient combines these partial views into a full picture.

The directional derivative ∇f·v gives the rate of change in direction v because it projects the full gradient onto that direction. The direction of steepest ascent is where v is parallel to ∇f, maximising the dot product.

The Hessian extends the second derivative test from 9.4 to multiple dimensions: if H is positive definite (all eigenvalues > 0), the point is a local minimum. If negative definite, a local maximum. If mixed eigenvalues, a saddle point.

## Common Mistakes

> [!failure] Mistake pattern: Treating the wrong variable as constant when computing partial derivatives
> When computing ∂f/∂x, everything that is not x is treated as constant. For ∂f/∂y, everything that is not y is constant. Double-check which variable you are differentiating with respect to.

> [!failure] Mistake pattern: Confusing ∇f (gradient) with ∇·F (divergence) or ∇×F (curl)
> ∇f is the gradient (a vector). ∇·F is divergence (a scalar). ∇×F is curl (a vector). They are different operations.

> [!failure] Mistake pattern: Assuming mixed partials always commute
> Clairaut's theorem requires continuity of the mixed partials. For most well-behaved functions they are equal, but there are pathological counterexamples.

> [!failure] Mistake pattern: Forgetting that ∇f points uphill
> Gradient descent uses -∇f (the negative gradient) to go downhill. A common error is moving in the direction of ∇f (which increases the function).

## Where This Shows Up in CS

### Machine Learning — Gradient Descent
```python
# ∇L is the gradient of the loss with respect to all parameters
# w ← w - η·∇L(w) for every weight in the network
w1 -= learning_rate * dw1  # dw1 = ∂L/∂w1
w2 -= learning_rate * dw2  # dw2 = ∂L/∂w2
```

### Neural Networks — Backpropagation
```python
# Each layer's gradient is computed via the chain rule
# ∂L/∂W = ∂L/∂σ · ∂σ/∂z · ∂z/∂W
# W is a matrix — the gradient is a matrix of partial derivatives
```

### Computer Vision — Edge Detection
```python
# Sobel operators approximate partial derivatives
# Gx = ∂I/∂x (horizontal edges), Gy = ∂I/∂y (vertical edges)
# Edge magnitude = sqrt(Gx² + Gy²)
```
