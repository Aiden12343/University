## Introduction

In [[9.4 Applications of Differentiation]], you learned that the minimum of f(x) occurs where f'(x)=0. But in ML, we rarely solve f'(x)=0 directly. Instead, we **walk towards the minimum** iteratively.

**Gradient descent** is the algorithm: start at a random point, compute the gradient ∇f (the direction of steepest ascent), take a step in the opposite direction -∇f (steepest descent), and repeat.

The gradient descent update rule:
```
x ← x - η·∇f(x)
```

where η (eta) is the **learning rate** — how big a step you take.

This simple rule is the foundation of:
- Linear regression training (finding best-fit parameters).
- Neural network training (backpropagation computes the gradient).
- Deep learning (variants like Adam, RMSprop, SGD).

From [[9.8 Multivariable Functions]], you know that ∇f points uphill. Gradient descent goes downhill. If the learning rate is right, you eventually reach a minimum (hopefully the global one).

## New Words

- **[[gradient descent]]** — x ← x - η·∇f(x), iterative minimisation by stepping opposite the gradient.
- **[[learning rate]]** — η, the step size in gradient descent.
- **[[batch gradient descent]]** — computes gradient over the entire dataset at each step.
- **[[stochastic gradient descent (SGD)]]** — computes gradient using a single random sample per step.
- **[[mini-batch gradient descent]]** — computes gradient over a small random subset of data per step.
- **[[convergence]]** — when the algorithm reaches a minimum and further steps produce negligible change.
- **[[line search]]** — choosing the optimal step size along the gradient direction.
- **[[momentum]]** — adding a fraction of the previous update to accelerate convergence and escape shallow minima.

## Breadcrumbs

### Breadcrumb 1: The Gradient Descent Algorithm

**Builds on:** [[9.8 Multivariable Functions]] (gradient), [[9.4 Applications of Differentiation]] (minimisation)

The core algorithm is shockingly simple:

```
Given: function f(x), initial guess x₀, learning rate η
Repeat until convergence:
    x ← x - η·∇f(x)
Return x
```

Why -∇f? Because ∇f points in the direction of steepest **increase**. To minimise, we go opposite.

#### Chunked Example — Minimising a Quadratic

Question: Use gradient descent to minimise f(x)=x². Start at x₀=5, η=0.1. Compute steps until convergence.

Step 1: f'(x)=2x. (1D case, so gradient = derivative.)

Step 2: Update: x ← x - 0.1·(2x) = x - 0.2x = 0.8x.

Step 3: Iterations:
- x₀=5
- x₁=0.8×5=4.0
- x₂=0.8×4=3.2
- x₃=0.8×3.2=2.56
- x₄=0.8×2.56=2.048
- x₅=0.8×2.048=1.638
- ...eventually approaches 0.

Answer: **After 5 steps: x≈1.64. After ~30 steps: x≈0.01 (near minimum)**.

#### Chunked Example — Effect of Learning Rate

Question: For f(x)=x² starting at x₀=5, what happens with different η?

Step 1: Update: x ← x - η·2x = x(1-2η).

Step 2: η=0.1: xₙ = 5(0.8)ⁿ → converges to 0 (as above). **Too slow**.

Step 3: η=0.5: xₙ = 5(0)ⁿ = 0 in one step. **Perfect single step** (for this specific function).

Step 4: η=1.0: x ← x - 2x = -x. x₀=5, x₁=-5, x₂=5, ... **Oscillates, never converges**.

Step 5: η=2.0: x ← x - 4x = -3x. x₀=5, x₁=-15, x₂=45. **Diverges to ∞**.

Answer: **η too small → slow. η=0.5 → optimal (one step). η=1.0 → oscillation. η=2.0 → divergence**.

### Breadcrumb 2: Gradient Descent in Multiple Dimensions

**Builds on:** Breadcrumb 1, [[9.8 Multivariable Functions]] (gradient definition)

In multiple dimensions, the gradient is a vector and the update is component-wise:
```
w₁ ← w₁ - η·∂L/∂w₁
w₂ ← w₂ - η·∂L/∂w₂
...
wₙ ← wₙ - η·∂L/∂wₙ
```

Each parameter moves in the direction that reduces the loss.

#### Chunked Example — 2D Minimisation

Question: L(w₁,w₂) = (w₁-3)² + 2(w₂+1)². Start at (0,0), η=0.1. Compute one gradient descent step.

Step 1: ∇L = (2(w₁-3), 4(w₂+1)). At (0,0): (2×(-3), 4×1) = (-6, 4).

Step 2: Update: (w₁,w₂) ← (0,0) - 0.1·(-6,4) = (0.6, -0.4).

Step 3: New loss: L(0.6,-0.4) = (0.6-3)² + 2(-0.4+1)² = 5.76 + 2×0.36 = 6.48.
Old loss at (0,0): 9+2=11. Loss decreased from 11 to 6.48. ✓

Answer: **(w₁,w₂) = (0.6, -0.4). Loss reduced by 41% in one step**.

### Breadcrumb 3: Variants — Batch, SGD, Mini-Batch

**Builds on:** Breadcrumb 1

The difference is in how much data is used to compute the gradient at each step:

| Variant | Data used per step | Pros | Cons |
|---|---|---|---|
| Batch GD | Entire dataset | Stable, accurate gradient | Slow for large datasets |
| SGD | 1 random sample | Fast per step, escapes shallow minima | Noisy, oscillates |
| Mini-batch | Small random subset (e.g. 32, 64, 128) | Best of both | Slight overhead from batching |

Modern deep learning almost always uses **mini-batch SGD**.

#### Chunked Example — Why SGD Can Escape Local Minima

Imagine a loss surface with a shallow local minimum and a deeper global minimum. Batch GD computes the true gradient and might get stuck in the shallow minimum. SGD uses a noisy gradient from one sample — the noise can push it out of the shallow minimum and toward the global one.

### Breadcrumb 4: Learning Rate Schedules

**Builds on:** Breadcrumb 1

A fixed learning rate is rarely optimal. Common schedules:

- **Step decay**: η ← η·γ every k epochs (e.g., divide by 10 every 30 epochs).
- **Exponential decay**: η(t) = η₀·e^{-kt}.
- **Cosine annealing**: η(t) = η_min + (η₀-η_min)·(1+cos(πt/T))/2.

The intuition: take large steps early (explore) and small steps later (fine-tune).

#### Chunked Example — Step Decay

Question: η₀=0.1, γ=0.1, decay every 10 steps. What are η at steps 1, 10, 11, 20, 21?

Step 1: Steps 1-10: η=0.1.
Step 2: Steps 11-20: η=0.1×0.1=0.01.
Step 3: Steps 21-30: η=0.1×0.01=0.001.

Answer: **Step 1: 0.1. Step 10: 0.1. Step 11: 0.01. Step 20: 0.01. Step 21: 0.001**.

### Breadcrumb 5: Momentum

**Builds on:** Breadcrumb 1

Momentum adds a fraction of the previous update to the current one:

```
v ← β·v - η·∇f(x)    # velocity update
x ← x + v              # position update
```

where β is the momentum coefficient (typically 0.9).

This helps gradient descent:
- Accelerate through flat regions (where gradients are small).
- Smooth out oscillations in narrow valleys.
- Escape shallow local minima.

#### Chunked Example — Momentum vs No Momentum

For f(x,y)=x²+100y² (a narrow valley along y), gradient descent oscillates along y's steep direction. Momentum smooths the path like a ball rolling down the valley — it averages out the oscillations and converges faster.

## Worked Examples

### Example 1 — One Step of Gradient Descent

Question: Apply one step of gradient descent to minimise f(x) = x² starting at x₀ = 3 with learning rate η = 0.1. What is x₁?

Step 1: Compute the derivative: f'(x) = 2x.

Step 2: Evaluate the gradient at x₀ = 3: f'(3) = 2 × 3 = 6.

Step 3: Apply the update rule: x₁ = x₀ - η·f'(x₀) = 3 - 0.1 × 6 = 3 - 0.6 = 2.4.

Answer: **x₁ = 2.4**.

### Example 2 — Multivariable Gradient Descent Step

Question: Apply one step of gradient descent to minimise L(w₁, w₂) = (w₁ - 2)² + 3(w₂ + 1)². Start at (w₁, w₂) = (0, 0) with η = 0.2. Compute the new parameters and the new loss.

Step 1: Compute the gradient: ∇L = (2(w₁ - 2), 6(w₂ + 1)). At (0, 0): ∇L = (-4, 6).

Step 2: Update: (w₁, w₂) ← (0, 0) - 0.2·(-4, 6) = (0.8, -1.2).

Step 3: New loss: L(0.8, -1.2) = (0.8 - 2)² + 3(-1.2 + 1)² = (-1.2)² + 3(-0.2)² = 1.44 + 0.12 = 1.56. Old loss at (0, 0): (0 - 2)² + 3(0 + 1)² = 4 + 3 = 7.

Answer: **(w₁, w₂) = (0.8, -1.2), new loss = 1.56**.

### Example 3 — Diagnosing Learning Rate Behaviour

Question: For f(x) = x² starting at x₀ = 4, compute x₁ for each learning rate η = 0.05, η = 0.5, and η = 1.5. Determine whether each converges, oscillates, or diverges.

Step 1: f'(x) = 2x. Update rule: x ← x - η·2x = x(1 - 2η).

Step 2: η = 0.05: x₁ = 4(1 - 0.1) = 3.6. Since |1 - 2η| = 0.9 < 1, converges to 0.

Step 3: η = 0.5: x₁ = 4(1 - 1) = 0. Converges in one step (optimal for this function).

Step 4: η = 1.5: x₁ = 4(1 - 3) = -8, x₂ = -8(1 - 3) = 32. Since |1 - 2η| = 2 > 1, diverges to ±∞.

Answer: **η = 0.05: x₁ = 3.6 (converges). η = 0.5: x₁ = 0 (converges in one step). η = 1.5: x₁ = -8 (diverges)**.

## Why This Works

Gradient descent works because the gradient points in the direction of steepest increase. Moving opposite to it guarantees (for small enough η) that the function value decreases.

From [[9.8 Multivariable Functions]], the directional derivative D_ⱽ f = ∇f·v is maximised when v is parallel to ∇f (steepest ascent) and minimised (most negative) when v = -∇f (steepest descent).

For convex functions ([[9.10 Convex Optimisation Basics]]), gradient descent is guaranteed to converge to the global minimum. For non-convex functions (like neural networks), it finds a "good enough" local minimum — and empirically, SGD finds solutions that generalise well.

The learning rate exists because the gradient is only accurate locally. The function is approximately linear in the direction of ∇f, but only near the current point. A large step could overshoot the minimum (as the quadratic approximation fails further away).

## Common Mistakes

> [!failure] Mistake pattern: Learning rate too large → divergence
> If the loss increases instead of decreasing step over step, the learning rate is likely too large. Reduce η.

> [!failure] Mistake pattern: Learning rate too small → extremely slow convergence
> If the loss barely changes, the learning rate is too small. Increase η or use adaptive methods (Adam).

> [!failure] Mistake pattern: Forgetting to subtract the gradient
> The update is x ← x - η·∇f(x), NOT x ← x + η·∇f(x). Adding increases the function.

> [!failure] Mistake pattern: Not normalising features
> If one feature is on scale 0-1 and another is 0-100000, gradient descent will oscillate along the large-scale direction. Standardise features first.

> [!failure] Mistake pattern: Using batch GD on massive datasets
> Computing the gradient over 1 million points per step is wasteful. Use mini-batches of 32-256 instead.
