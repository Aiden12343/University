## Introduction

Machine learning is, at its core, applied linear algebra. Every dataset is a matrix. Every model is a set of matrix operations. Every training step computes gradients through matrix derivatives.

From [[7.3 Matrix Multiplication]], you know how to multiply matrices and why the inner dimensions must match. From [[7.1 Vectors and Vector Spaces]], you understand vectors as points in space. From [[7.2 Linear Transformations]], you know that matrices represent transformations.

Now we apply all of that to ML:
- **Feature matrix** X ∈ ℝ^{n×d}: n samples, d features.
- **Weight matrix** W ∈ ℝ^{d×k}: learned parameters.
- **Linear layer**: Y = XW + b.
- **Batch processing**: operate on all n samples simultaneously via a single matrix multiplication.

The insight: a CPU or GPU can multiply a 1000×1000 matrix in microseconds. By representing your entire dataset and model as matrices, you leverage this hardware to train models efficiently.

## New Words

- **[[feature matrix]]** — X ∈ ℝ^{n×d}: n samples, d features.
- **[[weight matrix]]** — W ∈ ℝ^{d×k}: learned parameters mapping input to output.
- **[[linear layer]]** — y = XW + b: affine transformation (matrix multiply + bias).
- **[[batch processing]]** — computing predictions for multiple samples simultaneously via matrix operations.
- **[[regularisation]]** — penalty term added to loss to prevent overfitting (L1: |w|, L2: ||w||²).

> [!important] You pass this topic only when you can define all five terms without looking.

## Breadcrumbs

### Breadcrumb 1: Data as Matrices

**Builds on:** [[7.1 Vectors and Vector Spaces]] (vectors as data points)

A dataset of n samples with d features each = matrix X of shape (n, d).

Each row is a d-dimensional vector representing one sample. Each column represents one feature across all samples.

#### Chunked Example

Question: 100 students took 5 tests each. What is the shape of the feature matrix? What does one row represent?

Step 1: n = 100 students (samples), d = 5 test scores (features).

Step 2: X shape: (100, 5). Each row: a vector in ℝ⁵.

Step 3: Example row: [85, 92, 78, 95, 88] (one student's five test scores).

Answer: **Shape (100, 5). Each row = one student's scores (5-dimensional vector)**.

### Breadcrumb 2: The Linear Layer

**Builds on:** [[7.3 Matrix Multiplication]] (matrix multiply rules), Breadcrumb 1

A linear layer computes: Y = XW + b.

- X ∈ ℝ^{n×d}: input (n samples, d features).
- W ∈ ℝ^{d×k}: weight matrix (d inputs → k outputs).
- b ∈ ℝ^{k}: bias vector (added to each row).
- Y ∈ ℝ^{n×k}: output (n samples, k outputs each).

#### Chunked Example

Question: X has shape (100, 10), output dimension k=3. What shapes are W, b, and Y?

Step 1: W must be (10, 3) because X(100×10) × W(10×3) → Y(100×3).

Step 2: b is (3,) — broadcast across all 100 rows.

Step 3: Y shape: (100, 3) — 100 samples, each with 3 output values.

Answer: **W(10, 3), b(3), Y(100, 3)**.

### Breadcrumb 3: Dot Products and Similarity

**Builds on:** [[7.1 Vectors and Vector Spaces]] (dot product, norm)

The dot product a·b = ∑ a_i b_i measures similarity. Cosine similarity = (a·b)/(||a|| ||b||).

In ML: word embeddings, recommendation systems, and attention mechanisms all use dot products as similarity measures.

#### Chunked Example

Question: a = [1, 2, 3], b = [4, 5, 6]. Compute dot product and cosine similarity.

Step 1: Dot: 1×4 + 2×5 + 3×6 = 4+10+18 = 32.

Step 2: Norms: ||a|| = √(1+4+9) = √14 ≈ 3.74. ||b|| = √(16+25+36) = √77 ≈ 8.78.

Step 3: cos θ = 32/(3.74×8.78) ≈ 32/32.84 ≈ 0.974.

Answer: **Dot: 32. Cosine similarity ≈ 0.974 (very similar direction)**.

### Breadcrumb 4: Softmax — Converting Scores to Probabilities

**Builds on:** Breadcrumb 1

Softmax converts a vector of real numbers (logits) into a probability distribution:
p_i = e^{z_i} / ∑ e^{z_j}

#### Chunked Example

Question: Logits z = [2.0, 1.0, 0.1]. Compute softmax probabilities. Which class is predicted?

Step 1: e² ≈ 7.39, e¹ ≈ 2.72, e^0.1 ≈ 1.11. Sum = 11.22.

Step 2: p₁ = 7.39/11.22 = 0.66. p₂ = 2.72/11.22 = 0.24. p₃ = 1.11/11.22 = 0.10.

Step 3: Class 1 has highest probability (0.66) → predicted class.

Answer: **p = [0.66, 0.24, 0.10] → class 1**.

## Worked Examples

### Example 1 — Linear Regression in Matrix Form

Question: y = Xw, X ∈ ℝ^{3×2}, y ∈ ℝ³. Find w ∈ ℝ² using the normal equation.

Step 1: X = [[1, 0], [0, 1], [1, 1]], y = [1, 1, 0].

Step 2: Normal equation: w = (XᵀX)⁻¹ Xᵀ y.

Step 3: XᵀX = [[2, 1], [1, 2]]. (XᵀX)⁻¹ = (1/3)[[2, -1], [-1, 2]].

Step 4: Xᵀy = [1×1+0×1+1×0, 0×1+1×1+1×0] = [1, 1].

Step 5: w = (1/3)[[2, -1], [-1, 2]] × [1, 1] = (1/3)[1, 1] = [1/3, 1/3].

Answer: **w = [1/3, 1/3] → model: y = (1/3)x₁ + (1/3)x₂**.

### Example 2 — L2 Regularisation (Weight Decay)

Question: Loss = ||Xw - y||² + λ||w||². What is the gradient? What does λ control?

Step 1: ∇L_w = 2Xᵀ(Xw - y) + 2λw.

Step 2: The +2λw term pulls weights toward 0 (this is "weight decay").

Step 3: Larger λ → stronger regularisation → smaller weights → simpler model.

Step 4: Without regularisation (λ=0), the model may overfit to noise in the training data.

Answer: **Gradient: 2Xᵀ(Xw - y) + 2λw. λ controls regularisation strength**.

### Example 3 — CS Application: Batch Processing

```python
import torch

# 1000 images, each 784 pixels (28×28 flattened)
X = torch.randn(1000, 784)

# Linear layer: 784 inputs → 10 outputs (one per digit)
W = torch.randn(784, 10, requires_grad=True)
b = torch.randn(10, requires_grad=True)

# Forward pass: ALL 1000 images processed simultaneously
Y = X @ W + b  # shape: (1000, 10)
```

Answer: **Single matrix multiply processes 1000 images simultaneously**.

### Example 4 — CS Application: Embedding Lookup as Matrix Operation

```python
# Word embeddings: vocabulary of 10000 words, each embedded as 300-dim vector
embeddings = torch.randn(10000, 300)  # weight matrix

# Look up word indices [3, 7, 42] — this is just indexing into rows
word_vectors = embeddings[[3, 7, 42]]  # shape: (3, 300)
# Equivalent to: one-hot × embeddings matrix
```

## Why This Works

Matrix multiplication is highly optimised — BLAS (Basic Linear Algebra Subprograms) libraries are hand-tuned for every CPU architecture, and GPUs have dedicated hardware for matrix operations.

By representing the entire dataset as a matrix, a single matrix multiply computes predictions for every sample. This is **batch processing**: instead of looping through n samples one at a time (slow), we perform one big matrix operation (fast).

The key insight: GPU matrix multiplication is ~100× faster than CPU for large matrices (thousands of elements). Deep learning would be impractical without this hardware-software alignment.

## Common Mistakes

> [!failure] Mistake pattern: Forgetting the bias term
> y = XW + b, not y = XW alone. Without bias, the decision boundary must pass through the origin.

> [!failure] Mistake pattern: Transposing incorrectly for matrix multiply
> For XW, inner dimensions must match: (n, d) × (d, k). Attempting (n, d) × (p, k) fails unless p = d.

> [!failure] Mistake pattern: Confusing rows and columns in data
> Standard: rows = samples, columns = features. Some libraries use the opposite convention — always check shapes.

> [!failure] Mistake pattern: Forgetting to flatten data
> Images arrive as (batch, channels, height, width) — e.g., (64, 3, 32, 32). Linear layers need 2D input. Flatten to (64, 3072) first.

## Where This Shows Up in CS

### Tensor Shapes in PyTorch
```python
x = torch.randn(64, 3, 32, 32)  # (batch, channels, height, width)
linear = torch.nn.Linear(32*32*3, 10)
y = linear(x.view(64, -1))  # flatten → (64, 3072)
```

### Key Operations
```text
- torch.mm(a, b): matrix multiply
- a @ b: Python @ operator (matrix multiply)
- torch.bmm(a, b): batch matrix multiply (3D tensors)
- Softmax: normalise logits to probabilities
- Cross-entropy: loss for classification
```

### GPU Acceleration
```text
- cuBLAS: NVIDIA's optimised BLAS
- cuDNN: deep neural network primitives
- TPU: Google's matrix multiply unit
- Matrix multiply is THE operation → hardware optimised
```
