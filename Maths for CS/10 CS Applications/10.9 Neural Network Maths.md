## Introduction

A **neural network** is a function composed of layers. Each layer applies a linear transformation (matrix multiply + bias) followed by a nonlinear **activation function**. Stacking layers creates a model that can learn complex patterns.

From [[10.8 Machine Learning Vectors and Matrices]], you know about linear layers and data as matrices. From [[9.8 Multivariable Functions]], you know about gradients and the chain rule. From [[9.9 Gradient Descent and Optimisation]], you know how to minimise a function using gradient descent.

Neural networks connect these ideas:
- The **forward pass** computes predictions by applying each layer in sequence.
- **Backpropagation** computes the gradient of the loss with respect to every weight by applying the chain rule from the output backward through every layer.
- **Gradient descent** updates the weights: w ← w - η·∂L/∂w.

The chain rule is the key insight: the gradient at layer ℓ depends on the gradient at layer ℓ+1. This lets us compute all gradients in a single backward pass, with cost proportional to the number of parameters.

## New Words

- **[[neuron]]** — computational unit: z = w·x + b, output a = σ(z).
- **[[activation function]]** — nonlinear function applied to neuron output (ReLU, sigmoid, tanh).
- **[[backpropagation]]** — algorithm computing gradients via chain rule from output back to input.
- **[[loss function]]** — measures prediction error (MSE for regression, cross-entropy for classification).
- **[[vanishing gradient]]** — gradients become very small in deep networks, preventing early layers from learning.

## Breadcrumbs

### Breadcrumb 1: The Single Neuron

**Builds on:** [[10.8 Machine Learning Vectors and Matrices]] (linear layer), [[9.8 Multivariable Functions]] (composition of functions)

A **neuron** computes:
```
z = w·x + b = ∑ w_i x_i + b    (weighted sum + bias)
a = σ(z)                         (activation function)
```

Common activations:
- **Sigmoid**: σ(z) = 1/(1+e^{-z}), range (0, 1). Used for binary classification output.
- **ReLU**: σ(z) = max(0, z). Most common hidden layer activation.
- **Tanh**: σ(z) = (e^z - e^{-z})/(e^z + e^{-z}), range (-1, 1).

#### Chunked Example

Question: Neuron with w = [3, -1], b = 2, input x = [1, 2], sigmoid activation. Compute output.

Step 1: z = 3×1 + (-1)×2 + 2 = 3 - 2 + 2 = 3.

Step 2: σ(3) = 1/(1+e^{-3}) ≈ 1/(1+0.05) ≈ 0.952.

Answer: **a ≈ 0.952**.

### Breadcrumb 2: The Forward Pass Through Multiple Layers

**Builds on:** Breadcrumb 1, [[7.3 Matrix Multiplication]] (matrix multiply for weights)

A multi-layer network: each layer's output becomes the next layer's input.

```
Layer 1: z_1 = XW_1 + b_1, a_1 = σ(z_1)
Layer 2: z_2 = a_1 W_2 + b_2, a_2 = σ(z_2)
...
Output: y_pred = last layer's activation
```

#### Chunked Example

Question: Input x = [1, 1]. W₁ = [[1, 0], [0, 1]], b₁ = [0, 0], ReLU activation. W₂ = [1, 1], b₂ = 0. Forward pass?

Step 1: Layer 1: z₁ = W₁x + b₁ = [[1,0],[0,1]]×[1,1] + [0,0] = [1, 1]. ReLU([1,1]) = [1, 1].

Step 2: Layer 2: z₂ = W₂·a₁ + b₂ = [1,1]·[1,1] + 0 = 2.

Answer: **Forward: [1,1] → [1,1] → 2**.

### Breadcrumb 3: Backpropagation — The Chain Rule in Action

**Builds on:** [[9.8 Multivariable Functions]] (chain rule for multivariable functions), [[9.9 Gradient Descent and Optimisation]]

Backpropagation computes ∂L/∂w for every weight using the chain rule:

```
∂L/∂w_i = (∂L/∂a) × (∂a/∂z) × (∂z/∂w_i)
```

The gradient at layer ℓ depends on the gradient at layer ℓ+1 — this is why we compute backward from the output.

#### Chunked Example — Single Neuron Gradient

Question: L = ½(a-y)², a = σ(z), z = w·x + b. Find ∂L/∂w_i.

Step 1: ∂L/∂a = (a-y). ∂a/∂z = σ(z)(1-σ(z)) (sigmoid derivative). ∂z/∂w_i = x_i.

Step 2: By chain rule: ∂L/∂w_i = (a-y) × σ(z)(1-σ(z)) × x_i.

Step 3: Interpretation: the gradient = output error × sigmoid slope × input.

Answer: **∂L/∂w_i = (a-y)σ(z)(1-σ(z))x_i**.

### Breadcrumb 4: Vanishing Gradients

**Builds on:** Breadcrumb 3

Sigmoid activation: σ'(z) ≤ 0.25. Each layer multiplies the gradient by ≤ 0.25. In a 10-layer network, the gradient at the first layer is ≤ 0.25¹⁰ ≈ 10⁻⁶ times the output gradient → effectively zero.

#### Chunked Example

Question: Sigmoid activation in a 10-layer network. Gradient at layer 1 relative to layer 10?

Step 1: Sigmoid derivative σ'(z) = σ(z)(1-σ(z)) ≤ 0.25.

Step 2: Each layer multiplies gradient by at most 0.25.

Step 3: After 10 layers: gradient × (0.25)¹⁰ ≈ gradient × 10⁻⁶.

Step 4: First layer barely learns — weights hardly change.

Step 5: Solution: ReLU activation (gradient = 1 for z > 0, 0 for z < 0 — no saturation).

Answer: **Gradient at layer 1 ≈ 10⁻⁶ × gradient at layer 10. Use ReLU to avoid this**.

## Worked Examples

### Example 1 — Cross-Entropy Loss

Question: True label y = [0, 1, 0], predicted probabilities p = [0.2, 0.7, 0.1]. Compute cross-entropy loss.

Step 1: CE = -∑ y_i log p_i = -(0×log 0.2 + 1×log 0.7 + 0×log 0.1).

Step 2: = -log(0.7) ≈ -(-0.357) = 0.357.

Step 3: Perfect prediction (p = [0, 1, 0]): CE = 0. Higher CE = worse prediction.

Answer: **CE ≈ 0.357**.

### Example 2 — Backpropagation in Code (PyTorch)

```python
x = torch.tensor([1.0, 2.0], requires_grad=True)
w = torch.tensor([3.0, -1.0], requires_grad=True)
b = torch.tensor(2.0, requires_grad=True)

z = w @ x + b  # forward pass
loss = (z - 5) ** 2  # MSE, target=5
loss.backward()  # backpropagation

print(w.grad)  # ∂loss/∂w = [-4, -8]
```

Step 1: z = 3×1 + (-1)×2 + 2 = 3. Loss = (3-5)² = 4.

Step 2: backward: ∂loss/∂z = 2(z-5) = -4. ∂z/∂w = x = [1, 2]. ∂loss/∂w = -4 × [1, 2] = [-4, -8].

Answer: **w.grad = [-4, -8]**.

### Example 3 — Why Activation Functions Matter

```python
# WITHOUT activation (linear-only network):
# Layer 1: a₁ = XW₁ + b₁
# Layer 2: a₂ = a₁W₂ + b₂ = (XW₁+b₁)W₂+b₂ = X(W₁W₂) + (b₁W₂+b₂)
# This is STILL a linear function of X! Just one linear layer.
# Nonlinear activations are ESSENTIAL for learning complex patterns.
```

## Why This Works

The forward pass computes the output by applying each layer in sequence: a composition of functions. Backpropagation computes the gradient by applying the chain rule in reverse: the gradient at layer ℓ = (gradient at layer ℓ+1) × (derivative of layer ℓ+1 w.r.t. layer ℓ).

This is efficient because each layer's gradient depends only on the next layer's gradient and its own forward values. We cache the forward values during the forward pass, then compute gradients backward in one pass.

Without activation functions (nonlinearities), stacking layers would be equivalent to a single linear layer — the whole network would collapse. Activations are what give neural networks their expressive power.

## Common Mistakes

> [!failure] Mistake pattern: Forgetting nonlinearity
> Without activation functions, the whole network collapses to a single linear layer (composition of linear functions = linear).

> [!failure] Mistake pattern: Confusing forward and backward shapes
> Forward: (n, d)×(d, k) → (n, k). Backward: gradient shapes must match parameter shapes exactly.

> [!failure] Mistake pattern: Not normalising inputs
> Large inputs → large z → sigmoid/tanh saturate → gradients vanish. Always normalise inputs to mean 0, variance 1.

> [!failure] Mistake pattern: Using sigmoid in hidden layers
> Sigmoid causes vanishing gradients in deep networks. ReLU is the standard choice for hidden layers.

## Where This Shows Up in CS

### Training Loop
```python
for epoch in range(100):
    y_pred = model(x)
    loss = loss_fn(y_pred, y_true)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

### Frameworks
```python
# PyTorch
nn.Linear(784, 256)  # fully connected
nn.ReLU()            # activation
nn.Sequential(...)   # compose layers
loss.backward()      # auto-diff

# TensorFlow/Keras
tf.keras.layers.Dense(256, activation='relu')
```
