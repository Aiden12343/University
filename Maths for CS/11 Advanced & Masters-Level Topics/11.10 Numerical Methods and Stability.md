## Introduction

**Numerical methods** provide approximate solutions to mathematical problems that cannot be solved exactly in closed form or in floating-point arithmetic. Every scientific computation — from weather forecasting to deep learning — relies on numerical algorithms.

From [[10.4 Floating Point and Rounding Error]], you understand that floating-point arithmetic introduces tiny errors that can grow. From [[9.6 Integration Techniques]], you know how to integrate analytically — numerical integration handles the rest. From [[7.10 Solving Linear Systems]], you understand Gaussian elimination.

Key concepts:
- **Condition number**: κ(A) = ||A||·||A⁻¹|| — measures how much a problem amplifies input errors.
- **LU decomposition**: factor A = LU to solve Ax = b efficiently.
- **Power iteration**: repeatedly multiply v ← Av/||Av|| to find the dominant eigenvector.
- **Runge-Kutta methods**: solve ODEs y' = f(t,y) with high-order accuracy (RK4: O(h⁵) local error).
- **Conjugate gradient**: iterative solver for symmetric positive definite (SPD) systems.

The central tension: **accuracy vs. stability vs. speed**. A faster method may be unstable; a stable method may be inaccurate for ill-conditioned problems.

## New Words

- **[[condition number]]** — κ(A) = ||A||·||A⁻¹||; large κ means the problem is ill-conditioned (small input changes cause large output changes).
- **[[LU decomposition]]** — factorisation A = LU where L is lower triangular and U is upper triangular; used to solve Ax = b in O(n²) after O(n³) factorisation.
- **[[power iteration]]** — iterative method v_{k+1} = Av_k / ||Av_k|| that converges to the dominant eigenvector.
- **[[Runge-Kutta methods]]** — family of ODE solvers; RK4 uses four function evaluations per step for fourth-order accuracy.
- **[[conjugate gradient]]** — iterative solver for Ax = b where A is SPD; converges in ≤ n steps exactly, O(n√κ) for good approximation.
- **[[pivoting]]** — row/column swaps in Gaussian elimination to improve numerical stability.

## Breadcrumbs

### Breadcrumb 1: Condition Number — Measuring Problem Sensitivity

**Builds on:** [[10.4 Floating Point and Rounding Error]] (floating-point precision, error)

The **condition number** κ(A) = ||A||·||A⁻¹|| quantifies how sensitive the solution x is to perturbations in b (for Ax = b). Rule of thumb: lose log₁₀(κ) digits of precision.

#### Chunked Example — Nearly Singular Matrix

Question: A = [[1, 1], [1, 1.0001]]. What is κ(A)?

Step 1: Eigenvalues: λ₁ ≈ 2.0001, λ₂ ≈ 0.00005. κ(A) = λ_max/λ_min ≈ 40,000.

Step 2: Double precision (53 bits ≈ 16 decimal digits). Lose log₁₀(40,000) ≈ 4.6 digits.

Step 3: Solution accurate to about 11 digits instead of 16.

Answer: **κ ≈ 40,000 → about 5 digits lost. For κ = 10¹⁰, nearly all precision is lost.**

### Breadcrumb 2: Power Iteration for Dominant Eigenvectors

**Builds on:** [[7.5 Eigenvalues and Eigenvectors]] (dominant eigenvalue, Rayleigh quotient)

**Power iteration** finds the eigenvector corresponding to the largest-magnitude eigenvalue:

1. Start with random v₀.
2. Repeat: v_{k+1} = Av_k / ||Av_k||.
3. Converges to v₁ (dominant eigenvector). Convergence rate: |λ₂/λ₁|ᵏ.

#### Chunked Example — One Step of Power Iteration

Question: A = [[2, 1], [1, 2]], starting v₀ = [1, 0].

Step 1: v₁ = A·v₀ = [2, 1]. Normalise: v₁ = [2/√5, 1/√5] = [0.894, 0.447].

Step 2: Rayleigh quotient: λ₁ ≈ v₁ᵀAv₁ = [0.894, 0.447]·[2.236, 1.789] = 2.8. True λ₁ = 3.

Step 3: After more iterations: converges linearly at rate (λ₂/λ₁) = (1/3).

Answer: **v₁ ≈ [0.894, 0.447], λ₁ ≈ 2.8. Each iteration reduces error by factor ≈ 1/3.**

## Why This Works

Numerical methods trade exactness for tractability. The key guarantees:

- **LU decomposition** solves Ax = b in O(n³) for dense matrices. With partial pivoting, it is backward stable: computed solution x̂ satisfies (A + E)x̂ = b where ||E|| ≤ O(ε)||A||.
- **Conjugate gradient** converges in ≤ n iterations (exact in exact arithmetic). The convergence rate depends on κ: each iteration reduces error by factor (√κ−1)/(√κ+1).
- **RK4** has local error O(h⁵) and global error O(h⁴). For smooth ODEs, h = 0.01 gives 8-digit accuracy.
- **Power iteration** convergence rate = |λ₂/λ₁|. For well-separated eigenvalues, fast. For close eigenvalues (λ₂ ≈ λ₁), slow — use Rayleigh quotient iteration or QR algorithm instead.

## Worked Examples

### Example 1 — Solving Ax = b with LU Decomposition

Question: A = [[2, 1], [1, 3]], b = [5, 8]. Solve via LU.

Step 1: LU: L = [[1, 0], [0.5, 1]], U = [[2, 1], [0, 2.5]].

Step 2: Solve Ly = b: y₁ = 5, 0.5·5 + y₂ = 8 → y₂ = 5.5.

Step 3: Solve Ux = y: 2.5x₂ = 5.5 → x₂ = 2.2. 2x₁ + 2.2 = 5 → x₁ = 1.4.

Answer: **x = [1.4, 2.2].**

### Example 2 — RK4 for ODE Integration

Question: dy/dt = −y, y(0) = 1, h = 0.1. Compute one RK4 step.

Step 1: f(t, y) = −y.
  k₁ = f(0, 1) = −1.
  k₂ = f(0.05, 1 − 0.05) = −0.95.
  k₃ = f(0.05, 1 − 0.0475) = −0.9525.
  k₄ = f(0.1, 1 − 0.09525) = −0.90475.

Step 2: y(0.1) = 1 + (0.1/6)(−1 − 1.9 − 1.905 − 0.90475) = 1 − 0.01667 × 5.70975 = 0.90484.

Step 3: True solution: y(0.1) = e⁻⁰·¹ = 0.904837. Match to 5 decimal places.

Answer: **RK4: y(0.1) ≈ 0.90484 — accurate to 5 decimal places with h = 0.1.**

### Example 3 — PageRank via Power Iteration

Question: Google's PageRank computes dominant eigenvector of the Google matrix.

Step 1: Google matrix G = αS + (1−α)(1/n)11ᵀ where S is the normalised adjacency matrix.

Step 2: Power iteration: v_{t+1} = Gv_t. Converges to unique stationary distribution (since G is stochastic and irreducible).

Step 3: For n = 10¹² pages, each iteration requires O(nnz(G)) ≈ 10¹³ operations (sparse multiply).

Step 4: Approximately 50 iterations suffice. Never forms G explicitly.

Answer: **PageRank = power iteration on sparse stochastic matrix. ≈50 iterations for convergence.**

### Example 4 — Conjugate Gradient Method

Question: Solve Ax = b where A is SPD using CG.

Step 1: Generate A-orthogonal search directions pₖ (conjugate directions).

Step 2: x_{k+1} = x_k + α_k p_k where α_k = r_kᵀr_k / p_kᵀAp_k (minimises along p_k).

Step 3: r_{k+1} = r_k − α_k A p_k (residual update). β_k = r_{k+1}ᵀr_{k+1} / r_kᵀr_k.

Step 4: p_{k+1} = r_{k+1} + β_k p_k (new conjugate direction).

Step 5: Exact in ≤ n steps. In practice: stop early for good approximation.

Answer: **CG: O(n√κ) for ≈ 10⁻⁶ accuracy. Exact in n steps. The method of choice for large SPD systems.**

## Common Mistakes

> [!failure] Mistake pattern: Using Gaussian elimination without pivoting
> Without partial pivoting, LU can be numerically unstable. Always use row swaps (partial pivoting) to keep ||L|| bounded.

> [!failure] Mistake pattern: Assuming all ODE solvers work for stiff equations
> Stiff ODEs (components with vastly different timescales) require implicit methods (backward Euler, BDF). Explicit RK4 requires unreasonably small h.

> [!failure] Mistake pattern: Ignoring condition number
> If κ(A) ≈ 10¹⁰ and you need 6 digits of accuracy, double precision (16 digits) is insufficient. Use arbitrary precision, preconditioning, or problem reformulation.

> [!failure] Mistake pattern: Power iteration with random starting vector fails for symmetric matrices with equal-magnitude eigenvalues
> If |λ₁| = |λ₂| (e.g., a pair of complex conjugates), power iteration oscillates. QR algorithm handles this.
