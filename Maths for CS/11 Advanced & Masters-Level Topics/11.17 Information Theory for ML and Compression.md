## Introduction

**Information theory** provides the mathematical framework for quantifying, storing, and communicating information. It underpins compression (Huffman, arithmetic coding), machine learning (cross-entropy loss, mutual information), and communication (channel capacity).

From [[8.5 Discrete Distributions]], you know about probability mass functions and expected values. From [[8.6 Continuous Distributions]], you understand density functions and differential entropy. From [[11.5 Statistical Learning Theory]], you know about model selection and generalisation.

Key quantities:
- **Entropy** H(X): average information content in bits — measures uncertainty.
- **KL divergence** D_KL(p||q): relative entropy — inefficiency of using q to approximate p.
- **Mutual information** I(X;Y): shared information between X and Y.
- **Cross-entropy** H(p,q): H(p) + D_KL(p||q) — loss function for classification.
- **Minimum Description Length (MDL)**: best model minimises total description cost.

## New Words

- **[[entropy]]** — H(X) = −∑_x p(x) log₂ p(x); the average number of bits needed to encode a sample from X; measures uncertainty.
- **[[KL divergence]]** — D_KL(p||q) = ∑ p(x) log(p(x)/q(x)); relative entropy, not symmetric (D_KL(p||q) ≠ D_KL(q||p)).
- **[[mutual information]]** — I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X); the reduction in uncertainty of X given Y.
- **[[cross-entropy]]** — H(p,q) = −∑ p(x) log q(x) = H(p) + D_KL(p||q); commonly used as a classification loss.
- **[[minimum description length (MDL)]]** — principle: the best model is the one that minimises total description length (model description + data given model).

## Breadcrumbs

### Breadcrumb 1: Entropy — Quantifying Uncertainty

**Builds on:** [[8.5 Discrete Distributions]] (probability mass, expectation)

The **entropy** of a discrete random variable X with distribution p:

```
H(X) = −∑_{x} p(x) log₂ p(x)
```

Entropy is the average number of bits required to encode a sample from X optimally. It ranges from 0 (deterministic) to log₂ n (uniform over n outcomes).

#### Chunked Example — Entropy of Fair vs Biased Coin

Question: Compute H(X) for (a) fair coin P(H)=P(T)=0.5, (b) biased coin P(H)=0.9.

Step 1: Fair: H = −(0.5 log₂ 0.5 + 0.5 log₂ 0.5) = −(−0.5−0.5) = 1 bit.

Step 2: Biased: H = −(0.9 log₂ 0.9 + 0.1 log₂ 0.1) = −(0.9×(−0.152) + 0.1×(−3.322)) = 0.137 + 0.332 = 0.469 bits.

Answer: **Fair: 1 bit. Biased (90/10): 0.469 bits (less uncertainty means fewer bits needed).**

### Breadcrumb 2: KL Divergence and Cross-Entropy

**Builds on:** Breadcrumb 1, [[8.5 Discrete Distributions]] (expectation of log-ratio)

**KL divergence** measures how many extra bits are needed to encode data from p using the distribution q:

```
D_KL(p||q) = ∑ p(x) log(p(x)/q(x))
```

Properties: D_KL(p||q) ≥ 0, equality iff p = q. Not symmetric (D_KL(p||q) ≠ D_KL(q||p)). Not a metric.

**Cross-entropy** = H(p,q) = H(p) + D_KL(p||q). Minimising cross-entropy = minimising KL divergence (since H(p) is constant for the data distribution).

#### Chunked Example — Cross-Entropy Loss

Question: True label p = [1, 0] (class 1). Prediction q = [0.7, 0.3]. Compute cross-entropy.

Step 1: H(p,q) = −∑ p_i log q_i = −1·log(0.7) − 0·log(0.3) = −log(0.7) ≈ 0.357.

Step 2: Better prediction q = [0.9, 0.1]: H(p,q) = −log(0.9) ≈ 0.105.

Step 3: Worst case q = [0.0, 1.0]: H(p,q) = −log(ε) → ∞ (if the data has probability 0 under the model, KL divergence is infinite).

Answer: **Cross-entropy = 0.357 bits. Lower is better. Infinite if the model assigns zero probability to observed data.**

## Why This Works

Information theory provides **fundamental limits**:
- **Source coding theorem**: H(X) is the minimum average bits to encode X losslessly.
- **Channel coding theorem**: I(X;Y) is the maximum rate at which data can be reliably transmitted.
- **Data processing inequality**: I(X;Y) ≥ I(X;f(Y)) — processing cannot create information.

In machine learning, maximum likelihood estimation is equivalent to minimising KL divergence:

```
argmax_θ ∏_{i=1}^{m} p_θ(x_i) = argmin_θ D_KL(p_data||p_θ)
```

The MDL principle generalises this: the best model is the one that compresses the data most effectively, balancing model complexity against goodness of fit.

## Worked Examples

### Example 1 — Mutual Information

Question: X ∈ {sunny, rainy}, P(X=sunny)=0.7. Forecast Y: P(Y=X)=0.8, P(Y≠X)=0.2. Compute I(X;Y).

Step 1: H(X) = −(0.7 log 0.7 + 0.3 log 0.3) = 0.881 bits.

Step 2: P(Y=rainy) = 0.7×0.2 + 0.3×0.8 = 0.38. P(Y=sunny) = 0.62. H(Y) = 0.959 bits.

Step 3: P(X=sunny|Y=sunny) = 0.7×0.8/0.62 = 0.903. P(rainy|sunny) = 0.097. H(X|Y=sunny) = 0.444.

Step 4: P(sunny|rainy) = 0.3×0.2/0.38 = 0.158. P(rainy|rainy) = 0.842. H(X|Y=rainy) = 0.656.

Step 5: H(X|Y) = 0.62×0.444 + 0.38×0.656 = 0.524. I(X;Y) = 0.881 − 0.524 = 0.357 bits.

Answer: **I(X;Y) = 0.357 bits. The forecast reduces uncertainty about the weather by 0.357 bits.**

### Example 2 — Huffman Coding

Question: Symbols with probabilities: A:0.4, B:0.3, C:0.2, D:0.1. Construct Huffman code.

Step 1: Sort: A(0.4), B(0.3), C(0.2), D(0.1).

Step 2: Combine lowest: C(0.2)+D(0.1) = CD(0.3). Now: A(0.4), B(0.3), CD(0.3).

Step 3: Combine B(0.3)+CD(0.3) = BCD(0.6). Now: A(0.4), BCD(0.6).

Step 4: Combine: A(0.4)+BCD(0.6) = root(1.0).

Step 5: Codes: A=0, B=10, C=110, D=111. Average length: 0.4×1+0.3×2+0.2×3+0.1×3 = 1.9 bits.

Step 6: Entropy: H = −(0.4 log 0.4+0.3 log 0.3+0.2 log 0.2+0.1 log 0.1) = 1.85 bits.

Answer: **Huffman average length 1.9 bits vs entropy 1.85 bits — near-optimal prefix code.**

### Example 3 — Information Gain in Decision Trees

Question: Dataset: 9 yes, 5 no (14 total). Feature Wind: Strong (3 yes, 3 no), Weak (6 yes, 2 no). Compute information gain.

Step 1: H(Y) = −(9/14 log(9/14) + 5/14 log(5/14)) = 0.940 bits.

Step 2: H(Y|Strong) = −(3/6 log 3/6 + 3/6 log 3/6) = 1.0 bit. H(Y|Weak) = −(6/8 log 6/8 + 2/8 log 2/8) = 0.811 bits.

Step 3: H(Y|Wind) = (6/14)×1.0 + (8/14)×0.811 = 0.429 + 0.463 = 0.892 bits.

Step 4: IG(Wind) = H(Y) − H(Y|Wind) = 0.940 − 0.892 = 0.048 bits.

Answer: **Information gain = 0.048 bits. Wind provides little predictive power in this dataset.**

### Example 4 — Variational Autoencoders and ELBO

Question: How does information theory appear in VAEs?

Step 1: VAE maximises evidence lower bound (ELBO): L = E_q[log p(x|z)] − D_KL(q(z|x)||p(z)).

Step 2: First term: reconstruction loss (cross-entropy or MSE) — measures how well z explains x.

Step 3: Second term: KL divergence between approximate posterior q(z|x) and prior p(z) — regularisation.

Step 4: This is the MDL principle: minimise bits to encode data + model complexity.

Answer: **VAE: ELBO = reconstruction (bits to code x given z) − KL (bits for z). Minimises total description length.**

## Common Mistakes

> [!failure] Mistake pattern: Using KL divergence symmetrically
> D_KL(p||q) ≠ D_KL(q||p). KL(p||q) is infinite when q has zero mass where p > 0. Use Jensen-Shannon divergence for symmetric alternatives.

> [!failure] Mistake pattern: Confusing cross-entropy with log-likelihood
> Cross-entropy = −∑ y_i log p_i. Log-likelihood = ∑ y_i log p_i. They differ by sign. Minimising cross-entropy = maximising log-likelihood.

> [!failure] Mistake pattern: Ignoring base of logarithm
> Entropy in bits (log₂) vs nats (ln). 1 nat = 1.44 bits. Always specify which base you use (bits for compression, nats for ML).

> [!failure] Mistake pattern: Confusing differential and discrete entropy
> Differential entropy h(X) = −∫ p(x) log p(x) dx can be negative! It is not the same as discrete entropy H(X) which is always ≥ 0.

## Where This Shows Up in CS

### Machine Learning
```python
# Cross-entropy loss in PyTorch
loss_fn = torch.nn.CrossEntropyLoss()
loss = loss_fn(predictions, labels)  # minimises KL divergence

# Mutual information for feature selection
from sklearn.feature_selection import mutual_info_classif
mi = mutual_info_classif(X, y)
```

### Compression
```text
- Huffman coding: optimal prefix code for known distribution
- Arithmetic coding: near-optimal for any distribution (fractional bits)
- LZW: dictionary-based (GIF, Unix compress)
- JPEG: cosine transform + Huffman
- MP3: perceptual coding + Huffman
```

### Deep Learning
```text
- VAEs: KL regularisation (ELBO objective)
- InfoNCE: mutual information for representation learning
- Entropy regularisation in RL (soft actor-critic)
- Knowledge distillation: KL between teacher and student
- MDL principle: model selection by description length
```

### NLP and Beyond
```text
- Cross-entropy loss → perplexity = 2^H
- Word embeddings: Pointwise Mutual Information (PMI) matrix factorisation
- Topic models: minimising KL divergence from data distribution
- Bioinformatics: MI for gene regulatory networks
```
