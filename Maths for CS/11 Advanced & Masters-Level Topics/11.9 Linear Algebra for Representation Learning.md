## Introduction

**Representation learning** transforms raw data (images, text, graphs) into dense vector representations that capture semantic structure. The core mathematics is linear algebra — specifically, matrix factorisation and spectral decomposition.

From [[7.5 Eigenvalues and Eigenvectors]], you understand how eigenvectors capture the "directions" of a linear transformation. From [[7.9 Singular Value Decomposition]], you know that any matrix A = UΣVᵀ decomposes into orthogonal singular vectors and singular values. From [[7.12 Matrix Decompositions]], you have seen multiple ways to factorise matrices.

The key insight: data that appears high-dimensional often lies near a low-dimensional subspace. Representing data in this subspace:
- Reduces noise and storage
- Reveals latent structure
- Improves downstream task performance

Major techniques:
- **PCA**: orthogonal projection maximising variance = truncated SVD of centred data.
- **Matrix factorisation**: approximate R ≈ PQᵀ for collaborative filtering (Netflix, Amazon).
- **Word embeddings**: map discrete words to dense ℝᵈ vectors via context prediction (word2vec, GloVe).
- **Spectral embeddings**: use eigenvectors of graph Laplacian to embed graph vertices.

## New Words

- **[[principal component analysis]]** — orthogonal projection of data onto the subspace of maximum variance; solved by eigendecomposition of covariance or SVD of centred data.
- **[[low-rank approximation]]** — approximating a matrix A by a rank-k matrix A_k = U_kΣ_kV_kᵀ, minimising ||A − A_k||_F (Eckart-Young theorem).
- **[[matrix factorisation]]** — decomposing a matrix R ≈ P·Qᵀ where P and Q are low-rank factor matrices (users × latent features, items × latent features).
- **[[word embedding]]** — a dense vector representation of a word learned from distributional context; satisfies w(king) − w(man) + w(woman) ≈ w(queen).
- **[[spectral embedding]]** — embedding graph vertices using eigenvectors of the graph Laplacian; minimises ∑W_{ij}||x_i − x_j||².
- **[[Eckart-Young theorem]]** — the rank-k SVD truncation A_k = U_kΣ_kV_kᵀ is the optimal rank-k approximation in Frobenius norm.

> [!important] You pass this topic only when you can define all six terms without looking.

## Breadcrumbs

### Breadcrumb 1: PCA via SVD — Finding the Most Important Directions

**Builds on:** [[7.9 Singular Value Decomposition]] (SVD factorisation), [[7.5 Eigenvalues and Eigenvectors]] (covariance, variance along directions)

**PCA** finds the orthogonal directions of maximum variance in data. Given centred data matrix X ∈ ℝ^{n×d} (n points, d features):

1. Centre X (subtract mean from each column).
2. Compute SVD: X = UΣVᵀ.
3. Principal components = columns of V (right singular vectors).
4. Projected data: X·V_k = U_kΣ_k ∈ ℝ^{n×k}.

#### Chunked Example — PCA on a Square Dataset

Question: Data points: [1,0], [0,1], [−1,0], [0,−1]. First principal component?

Step 1: Centred at origin. Covariance matrix = [[1,0],[0,1]] (identity).

Step 2: Both axes have equal variance. Covariance is isotropic.

Step 3: Any direction is equally good. PCA returns V = I (or any orthogonal matrix).

Answer: **Equal variance in all directions — no preferred principal component.**

#### Chunked Example — PCA for Dimensionality Reduction

Question: X ∈ ℝ^{1000×500}. Top 10 singular values contain 90% of the sum of all singular values. How much compression?

Step 1: Original: 1000 × 500 = 500,000 numbers.

Step 2: Rank-10 SVD: U₁₀ (1000×10), Σ₁₀ (10×10), V₁₀ᵀ (10×500) → 10,000 + 10 + 5,000 = 15,010.

Step 3: Compression ratio: 500,000 / 15,010 ≈ 33×.

Step 4: Retains 90% of the "energy" (variance) of the data.

Answer: **33× compression with 90% variance retained.**

### Breadcrumb 2: Matrix Factorisation for Recommendations

**Builds on:** Breadcrumb 1, [[7.12 Matrix Decompositions]] (factorisation concepts)

**Matrix factorisation** approximates the user-item rating matrix R ∈ ℝ^{m×n} as the product of two low-rank matrices: R ≈ P·Qᵀ where P ∈ ℝ^{m×k} and Q ∈ ℝ^{n×k}.

Prediction: r̂_{ui} = p_u · q_i (dot product of user and item latent vectors).

#### Chunked Example — Predicting a Rating

Question: 3 users, 4 movies, k=2 latent factors. P = [[0.5,0.5],[0.9,0.1],[0.2,0.8]], Q = [[0.6,0.4],[0.1,0.9],[0.7,0.3],[0.8,0.2]]. Predict user 1's rating for movie 3.

Step 1: p₁ = [0.5, 0.5], q₃ = [0.7, 0.3].

Step 2: r̂ = 0.5 × 0.7 + 0.5 × 0.3 = 0.35 + 0.15 = 0.5.

Answer: **Predicted rating: 0.5 (scale: 0–1).**

### Breadcrumb 3: Word Embeddings — Semantic Vector Spaces

**Builds on:** Breadcrumb 2, [[7.3 Matrix Multiplication]] (dot products for similarity)

**Word embeddings** map each word w ∈ V (vocabulary) to a dense vector v_w ∈ ℝᵈ (d ≈ 100–300). The key property: semantic relationships correspond to linear vector arithmetic.

The word2vec (skip-gram) objective: given centre word w, predict context words c in a window around w. The embedding v_w is the centre word vector; c_w is the context vector. After training, v_w captures semantic content.

#### Chunked Example — Linear Semantic Algebra

Question: Verify: vec(king) − vec(man) + vec(woman) ≈ vec(queen).

Step 1: vec(king) encodes "royal + male". vec(man) encodes "male". vec(woman) encodes "female".

Step 2: vec(king) − vec(man) = "royal" (removes male component).

Step 3: "royal" + "female" = vec(queen).

Answer: **Word embeddings capture analogies via linear vector arithmetic — a surprising emergent property.**

## Why This Works

The **Eckart-Young theorem** is the foundation: the rank-k SVD truncation minimises ||A − A_k||_F among all rank-k matrices. This means PCA gives the best possible linear projection for preserving variance.

Matrix factorisation for recommendations is SVD with missing ratings. Instead of computing SVD on the full matrix (most entries are unknown/incomplete), we minimise the squared error over observed entries only:

```
min_{P,Q} ∑_{(u,i)∈observed} (r_{ui} − p_u·q_i)² + λ(||p_u||² + ||q_i||²)
```

Word embeddings work because of the **distributional hypothesis**: words that appear in similar contexts have similar meanings. Skip-gram's objective implicitly factorises a word-context PMI (pointwise mutual information) matrix — connecting embeddings back to matrix factorisation.

## Worked Examples

### Example 1 — Computing the SVD of a 2×2 Matrix

Question: Compute the reduced SVD A = U₁σ₁v₁ᵀ of A = [[2, 2], [1, 1]].

Step 1: A has rank 1 because row 2 = ½ × row 1. Compute AᵀA = [[5, 5], [5, 5]].

Step 2: Eigenvalues of AᵀA: det([[5−λ, 5], [5, 5−λ]]) = λ(λ − 10) = 0 → λ₁ = 10, λ₂ = 0.

Step 3: Non-zero singular value σ₁ = √10. Right singular vector v₁ solves (AᵀA)v = 10v → v₁ = [1, 1]ᵀ/√2.

Step 4: Left singular vector u₁ = Av₁/σ₁ = ([[2, 2], [1, 1]] · [1, 1]ᵀ/√2) / √10 = [4, 2]ᵀ/√20 = [2/√5, 1/√5]ᵀ.

Step 5: Verify: u₁σ₁v₁ᵀ = [[2/√5], [1/√5]] · √10 · [1/√2, 1/√2] = [[2, 2], [1, 1]] = A. ✓

Answer: **σ₁ = √10, u₁ = [2/√5, 1/√5]ᵀ, v₁ = [1/√2, 1/√2]ᵀ. A has rank 1.**

### Example 2 — Truncated SVD for Word Embeddings

Question: A word co-occurrence matrix for three words is M = [[3, 1, 0], [1, 3, 0], [0, 0, 3]]. Use truncated SVD to obtain 2-dimensional embeddings for each word.

Step 1: M is symmetric, so SVD = eigendecomposition. Eigenvalues of M: det([[3−λ, 1, 0], [1, 3−λ, 0], [0, 0, 3−λ]]) = (3−λ)[(3−λ)² − 1] = 0 → λ = 4, 3, 2.

Step 2: Eigenvectors: v₁ = [1, 1, 0]ᵀ/√2 (λ = 4), v₂ = [0, 0, 1]ᵀ (λ = 3), v₃ = [1, −1, 0]ᵀ/√2 (λ = 2). Singular values sorted: σ₁ = 4, σ₂ = 3.

Step 3: Rank-2 truncated V₂ = [v₁, v₂]. U₂ = V₂ (symmetric). Word embeddings = rows of U₂Σ₂: w₁ = (4/√2, 0) = (2√2, 0), w₂ = (4/√2, 0) = (2√2, 0), w₃ = (0, 3).

Step 4: Semantic interpretation: words 1 and 2 co-occur (M₁₂ = M₂₁ = 1) → identical embeddings. Word 3 never co-occurs with them → orthogonal embedding.

Answer: **w₁ = (2√2, 0), w₂ = (2√2, 0), w₃ = (0, 3). Co-occurring words have similar embeddings.**

### Example 3 — Optimal Rank-1 Approximation via Eckart-Young

Question: Given A = [[1, 2], [2, 1], [3, 3]], find its optimal rank-1 approximation A₁ and compute ||A − A₁||_F.

Step 1: AᵀA = [[14, 13], [13, 14]]. Eigenvalues: det([[14−λ, 13], [13, 14−λ]]) = (λ − 1)(λ − 27) = 0 → λ₁ = 27, λ₂ = 1.

Step 2: Singular values: σ₁ = √27 = 3√3, σ₂ = 1. Right singular vectors: v₁ = [1, 1]ᵀ/√2 (λ₁ = 27), v₂ = [1, −1]ᵀ/√2 (λ₂ = 1).

Step 3: u₁ = Av₁/σ₁ = [[1, 2], [2, 1], [3, 3]] · [1, 1]ᵀ/(√2 · 3√3) = [3, 3, 6]ᵀ/(3√6) = [1, 1, 2]ᵀ/√6.

Step 4: Rank-1 approximation: A₁ = u₁σ₁v₁ᵀ = [[1], [1], [2]] · (3√3/√12) · [1, 1] = [[1.5, 1.5], [1.5, 1.5], [3, 3]].

Step 5: Frobenius error: ||A − A₁||_F = √((1−1.5)² + (2−1.5)² + (2−1.5)² + (1−1.5)² + (3−3)² + (3−3)²) = 1. By Eckart-Young, optimal error = σ₂ = 1.

Answer: **A₁ = [[1.5, 1.5], [1.5, 1.5], [3, 3]]. ||A − A₁||_F = 1 = σ₂.**

### Example 4 — One Step of SGD for Matrix Factorisation

Question: A user-item rating matrix R (scale 1–5) has observed entries R₁₁ = 5, R₁₂ = 3, R₂₁ = 4, R₂₂ = 2. Latent factors (k = 2) initialised as P = [[1, 0], [0, 1]], Q = [[1, 0], [0, 1]]. Perform one SGD update with η = 0.01 on entry (1, 1) using loss L = (R₁₁ − p₁·q₁)²/2.

Step 1: Prediction: r̂₁₁ = p₁·q₁ = [1, 0] · [1, 0] = 1. Error: e = 5 − 1 = 4.

Step 2: Gradients: ∂L/∂p₁ = −e·q₁ = −4[1, 0] = [−4, 0]. ∂L/∂q₁ = −e·p₁ = −4[1, 0] = [−4, 0].

Step 3: Update: p₁ ← p₁ − η·∂L/∂p₁ = [1, 0] − 0.01[−4, 0] = [1.04, 0]. q₁ ← q₁ − η·∂L/∂q₁ = [1, 0] − 0.01[−4, 0] = [1.04, 0].

Step 4: New prediction: r̂₁₁ = [1.04, 0] · [1.04, 0] = 1.0816. Error reduced from 4 to 3.9184.

Answer: **Updated factors: p₁ = (1.04, 0), q₁ = (1.04, 0). MSE on entry (1, 1) drops from 8 to 7.68.**

## Common Mistakes

> [!failure] Mistake pattern: Confusing PCA with linear regression
> PCA minimises orthogonal distance to subspace (total least squares). Linear regression minimises vertical distance (y-error only). Different objectives, different solutions.

> [!failure] Mistake pattern: Applying SVD to non-centred data
> PCA requires centring (mean subtraction). SVD on raw data finds components through the origin — usually wrong. Always centre first.

> [!failure] Mistake pattern: Interpreting latent factors as real concepts
> Matrix factorisation factors (columns of P, Q) rarely correspond to interpretable categories. They are mathematical abstractions — linear combinations of real features.

> [!failure] Mistake pattern: Overlooking that word embeddings are context-dependent
> Static embeddings (word2vec, GloVe) give one vector per word — cannot handle polysemy. Contextual embeddings (BERT, ELMo) give different vectors per context.
