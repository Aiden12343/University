# 1.1 Counting and Number Sense - Worked Examples

Theory note: [[1.1 Counting and Number Sense]]

Use these examples before attempting [[1.1 Counting and Number Sense - Practice Questions]].

> [!tip] How to use worked examples

## Example 1 - Counting Objects
Question: How many circles are shown?

```text
o  o  o  o
```

### Step 1 - Touch each object once

```text
o  o  o  o
1
```

### Step 2 - Move to the next object and say the next number

```text
o  o  o  o
1  2
```

### Step 3 - Continue until every object has exactly one number

```text
o  o  o  o
1  2  3  4
```

### Step 4 - Use the final count word
The final count word is 4.

Answer: There are **4 circles**.

## Example 2 - Finding a Counting Mistake
Question: A learner counts the boxes like this. What went wrong?

```text
[] [] [] []
1  2  2  3
```

### Step 1 - Check the counting words
The count should go:

```text
1, 2, 3, 4
```

The learner said:

```text
1, 2, 2, 3
```

### Step 2 - Identify the mistake
The number 2 was repeated.

### Step 3 - Correct the count

```text
[] [] [] []
1  2  3  4
```

Answer: There are **4 boxes**.

## Example 3 - Comparing Two Numbers
Question: Fill in the missing symbol.

```text
6 __ 8
```

### Step 1 - Put the numbers on a number line

```text
0 --- 1 --- 2 --- 3 --- 4 --- 5 --- 6 --- 7 --- 8
                              ^           ^
```

### Step 2 - Decide which number is further right
8 is further right than 6, so 8 is greater.

### Step 3 - Choose the symbol
Since 6 is smaller than 8:

```text
6 < 8
```

Answer: The missing symbol is `<`.

## Example 4 - Understanding Zero
Question: How many triangles are in the box?

```text
+---------+
|         |
|         |
+---------+
```

### Step 1 - Identify what you are counting
You are counting triangles.

### Step 2 - Look for triangles
There are no triangles in the box.

### Step 3 - Use zero
No triangles means 0 triangles.

Answer: There are **0 triangles**.

> [!important] Zero is an answer
> If there are no objects of the kind being counted, the answer is 0, not blank.

## Example 5 - Counting On
Question: You have 6 counters. You get 2 more. How many do you have now?

### Step 1 - Start from what you already know
You already have 6.

### Step 2 - Count on two more

```text
6 ... 7, 8
```

### Step 3 - Stop after two steps
You counted on 2 numbers: 7 and 8.

Answer: You now have **8 counters**.

## Example 6 - Computer Science Indexes
Question: A list contains 5 names. The first name is at index 0. What is the last index?

### Step 1 - Draw the list

```text
names: [Ana] [Bo] [Cy] [Dee] [Eli]
```

### Step 2 - Count positions from 0

```text
names: [Ana] [Bo] [Cy] [Dee] [Eli]
index:   0    1    2     3     4
```

### Step 3 - Read the final index
The last index is 4.

Answer: A list with 5 items has final index **4** when indexing starts at 0.

## Self-Check
You understand these examples when you can explain:

- why the last count word is the total
- why repeating a number breaks the count
- why 0 is a valid answer
- why `6 < 8`
- why 5 list items can end at index 4
