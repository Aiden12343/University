# 1.3 Addition and Subtraction - Worked Examples

Theory note: [[1.3 Addition and Subtraction]]

Use these before attempting [[1.3 Addition and Subtraction - Practice Questions]].

> [!tip] Worked example routine
> For every calculation, say what the operation means before calculating. Then check with the inverse operation.

## Example 1 - Addition as Combining
Question: You have 7 stickers and receive 5 more. How many stickers do you have?

### Step 1 - Identify the starting amount

```text
7 stickers
```

### Step 2 - Identify what is added

```text
5 more stickers
```

### Step 3 - Combine

```text
7 + 5 = 12
```

Answer: You have **12 stickers**.

## Example 2 - Subtraction as Taking Away
Question: You have 14 sweets and eat 6. How many are left?

### Step 1 - Start with the total

```text
14
```

### Step 2 - Take away 6

```text
14 - 6
```

### Step 3 - Calculate

```text
14 - 6 = 8
```

Answer: **8 sweets** are left.

## Example 3 - Subtraction as Difference
Question: A program took 18 steps. Another program took 11 steps. How many more steps did the first program take?

### Step 1 - Identify the two quantities

```text
18 steps
11 steps
```

### Step 2 - Difference means distance apart

```text
18 - 11
```

### Step 3 - Calculate

```text
18 - 11 = 7
```

Answer: The first program took **7 more steps**.

## Example 4 - Column Addition Without Carrying
Question:

```text
34 + 25
```

### Step 1 - Line up place values

```text
  34
+ 25
----
```

### Step 2 - Add ones

```text
4 + 5 = 9
```

### Step 3 - Add tens

```text
3 tens + 2 tens = 5 tens
```

```text
  34
+ 25
----
  59
```

Answer: `34 + 25 = 59`.

## Example 5 - Column Addition With Carrying
Question:

```text
58 + 27
```

### Step 1 - Line up place values

```text
  58
+ 27
----
```

### Step 2 - Add ones

```text
8 + 7 = 15
```

15 ones means 1 ten and 5 ones.

```text
  1
  58
+ 27
----
   5
```

### Step 3 - Add tens

```text
1 + 5 + 2 = 8
```

```text
  1
  58
+ 27
----
  85
```

Answer: `58 + 27 = 85`.

### Step 4 - Check

```text
85 - 27 = 58
```

The check works.

## Example 6 - Column Subtraction Without Borrowing
Question:

```text
76 - 42
```

### Step 1 - Line up place values

```text
  76
- 42
----
```

### Step 2 - Subtract ones

```text
6 - 2 = 4
```

### Step 3 - Subtract tens

```text
7 - 4 = 3
```

```text
  76
- 42
----
  34
```

Answer: `76 - 42 = 34`.

## Example 7 - Column Subtraction With Borrowing
Question:

```text
71 - 38
```

### Step 1 - Line up place values

```text
  71
- 38
----
```

### Step 2 - Notice the ones problem
You cannot do `1 - 8` using whole numbers.

### Step 3 - Regroup one ten

```text
71 = 6 tens + 11 ones
```

```text
  6 11
  7  1
- 3  8
------
```

### Step 4 - Subtract ones

```text
11 - 8 = 3
```

### Step 5 - Subtract tens

```text
6 - 3 = 3
```

```text
  6 11
  7  1
- 3  8
------
  3  3
```

Answer: `71 - 38 = 33`.

### Step 6 - Check

```text
33 + 38 = 71
```

The check works.

## Example 8 - CS State Update
Question: A game score starts at 120. The player gains 35 points and then loses 18 points. What is the final score?

### Step 1 - Translate the words

```text
start: 120
gain: +35
lose: -18
```

### Step 2 - Add the gain

```text
120 + 35 = 155
```

### Step 3 - Subtract the loss

```text
155 - 18 = 137
```

Answer: The final score is **137**.
