# 1.4 Multiplication and Times Tables - Worked Examples

Theory note: [[1.4 Multiplication and Times Tables]]

Use these before attempting [[1.4 Multiplication and Times Tables - Practice Questions]].

> [!tip] Worked example routine
> For each multiplication, say what the groups are. If you cannot name the groups, the calculation may not match the problem.

## Example 1 - Equal Groups
Question: There are 6 bags. Each bag has 4 marbles. How many marbles are there?

### Step 1 - Identify groups

```text
6 bags
```

### Step 2 - Identify group size

```text
4 marbles per bag
```

### Step 3 - Multiply

```text
6 x 4 = 24
```

Answer: There are **24 marbles**.

## Example 2 - Repeated Addition
Question: Write `5 x 7` as repeated addition and solve it.

### Step 1 - Read the expression
`5 x 7` means 5 groups of 7.

### Step 2 - Write repeated addition

```text
7 + 7 + 7 + 7 + 7
```

### Step 3 - Add

```text
7 + 7 = 14
14 + 7 = 21
21 + 7 = 28
28 + 7 = 35
```

Answer:

```text
5 x 7 = 35
```

## Example 3 - Array Counting
Question: How many stars are in this array?

```text
* * * * * *
* * * * * *
* * * * * *
* * * * * *
```

### Step 1 - Count rows
There are 4 rows.

### Step 2 - Count columns
There are 6 columns.

### Step 3 - Multiply rows by columns

```text
4 x 6 = 24
```

Answer: There are **24 stars**.

## Example 4 - Commutativity
Question: Use commutativity to solve `8 x 3`.

### Step 1 - Reverse the order

```text
8 x 3 = 3 x 8
```

### Step 2 - Use the easier fact

```text
3 x 8 = 24
```

Answer:

```text
8 x 3 = 24
```

## Example 5 - Multiplying by 10
Question: Calculate `43 x 10`.

### Step 1 - Think in place value
Multiplying by 10 moves digits one place left.

```text
43 -> 430
```

### Step 2 - Write the result

```text
43 x 10 = 430
```

Answer: **430**.

## Example 6 - Multiplying by 100
Question: Calculate `87 x 100`.

### Step 1 - Think in place value
Multiplying by 100 moves digits two places left.

```text
87 -> 8700
```

### Step 2 - Write the result

```text
87 x 100 = 8700
```

Answer: **8700**.

## Example 7 - Scaling
Question: A game character moves 5 pixels per frame. If the speed is scaled by 4, how many pixels per frame does it move?

### Step 1 - Identify the original amount

```text
5 pixels per frame
```

### Step 2 - Identify the scale factor

```text
4
```

### Step 3 - Multiply

```text
5 x 4 = 20
```

Answer: The character moves **20 pixels per frame**.

## Example 8 - Nested Loops
Question: A program checks every cell in a grid with 8 rows and 9 columns. How many cells does it check?

### Step 1 - Identify the grid dimensions

```text
rows = 8
columns = 9
```

### Step 2 - Multiply

```text
8 x 9 = 72
```

### Step 3 - Interpret
The program checks 72 cells.

Answer: **72 checks**.

## Self-Check
You understand these examples when you can:

- turn equal groups into multiplication
- turn multiplication into repeated addition
- count an array using rows and columns
- use commutativity without changing the total
- multiply by 10 and 100 using place value
- explain nested loops as multiplication
