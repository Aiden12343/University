# 1.6 Fractions - Worked Examples

Theory note: [[1.6 Fractions]]

Use these before attempting [[1.6 Fractions - Practice Questions]].

> [!tip] Worked example routine
> Always say what the whole is. A fraction without a clear whole is easy to misunderstand.

## Example 1 - Reading a Fraction
Question: Explain `3/10`.

### Step 1 - Read the denominator
The denominator is 10, so the whole has 10 equal parts.

### Step 2 - Read the numerator
The numerator is 3, so 3 parts are selected.

Answer: `3/10` means **3 out of 10 equal parts**.

## Example 2 - Equivalent Fractions
Question: Make an equivalent fraction to `2/5`.

### Step 1 - Choose the same multiplier for top and bottom
Use 3.

### Step 2 - Multiply numerator and denominator

```text
2 x 3 = 6
5 x 3 = 15
```

Answer:

```text
2/5 = 6/15
```

## Example 3 - Simplifying
Question: Simplify `15/20`.

### Step 1 - Find a common factor
Both 15 and 20 divide by 5.

### Step 2 - Divide top and bottom by 5

```text
15 / 5 = 3
20 / 5 = 4
```

Answer:

```text
15/20 = 3/4
```

## Example 4 - Comparing Same Denominator
Question: Which is larger, `4/9` or `7/9`?

### Step 1 - Notice the denominators match
Both fractions are ninths.

### Step 2 - Compare numerators

```text
4 < 7
```

Answer:

```text
4/9 < 7/9
```

## Example 5 - Comparing Different Denominators
Question: Which is larger, `3/4` or `2/3`?

### Step 1 - Use common denominator 12

```text
3/4 = 9/12
2/3 = 8/12
```

### Step 2 - Compare

```text
9/12 > 8/12
```

Answer:

```text
3/4 > 2/3
```

## Example 6 - Adding Same Denominator
Question:

```text
2/11 + 5/11
```

### Step 1 - Denominators match
Both fractions are elevenths.

### Step 2 - Add numerators

```text
2 + 5 = 7
```

### Step 3 - Keep denominator

```text
2/11 + 5/11 = 7/11
```

Answer: `7/11`.

## Example 7 - Adding Different Denominators
Question:

```text
1/4 + 1/6
```

### Step 1 - Find a common denominator
4 and 6 both fit into 12.

### Step 2 - Rewrite fractions

```text
1/4 = 3/12
1/6 = 2/12
```

### Step 3 - Add

```text
3/12 + 2/12 = 5/12
```

Answer: `5/12`.

## Example 8 - Multiplying Fractions
Question:

```text
3/5 x 2/7
```

### Step 1 - Multiply numerators

```text
3 x 2 = 6
```

### Step 2 - Multiply denominators

```text
5 x 7 = 35
```

Answer:

```text
3/5 x 2/7 = 6/35
```

## Example 9 - CS Pass Rate
Question: A test suite has 30 tests. 24 pass. What fraction passed, simplified?

### Step 1 - Write the fraction

```text
24/30
```

### Step 2 - Simplify
Both 24 and 30 divide by 6.

```text
24 / 6 = 4
30 / 6 = 5
```

Answer:

```text
24/30 = 4/5
```

So 4/5 of the tests passed.

## Self-Check
You understand these examples when you can:

- name the whole
- identify numerator and denominator
- create equivalent fractions
- simplify fractions
- compare by using a common denominator
- add fractions safely
- multiply fractions
- explain a CS proportion
