# 1.9 Order of Operations - Worked Examples

Theory note: [[1.9 Order of Operations]]

Use these before attempting [[1.9 Order of Operations - Practice Questions]].

> [!tip] Worked example routine
> Copy the expression exactly. Underline the next operation only. Do one operation per line.

## Example 1 - Multiplication Before Addition
Question:

```text
5 + 6 x 3
```

### Step 1 - Multiplication comes before addition

```text
6 x 3 = 18
```

### Step 2 - Add

```text
5 + 18 = 23
```

Answer:

```text
5 + 6 x 3 = 23
```

## Example 2 - Brackets First
Question:

```text
(5 + 6) x 3
```

### Step 1 - Brackets first

```text
5 + 6 = 11
```

### Step 2 - Multiply

```text
11 x 3 = 33
```

Answer:

```text
(5 + 6) x 3 = 33
```

## Example 3 - Division and Multiplication Tie
Question:

```text
48 / 6 x 4
```

### Step 1 - Work left to right

```text
48 / 6 = 8
```

### Step 2 - Continue

```text
8 x 4 = 32
```

Answer:

```text
48 / 6 x 4 = 32
```

## Example 4 - Addition and Subtraction Tie
Question:

```text
20 - 8 + 5
```

### Step 1 - Work left to right

```text
20 - 8 = 12
```

### Step 2 - Continue

```text
12 + 5 = 17
```

Answer:

```text
20 - 8 + 5 = 17
```

## Example 5 - Indices
Question:

```text
4 + 3^2
```

### Step 1 - Do the index

```text
3^2 = 9
```

### Step 2 - Add

```text
4 + 9 = 13
```

Answer:

```text
4 + 3^2 = 13
```

## Example 6 - Brackets and Indices
Question:

```text
(4 + 3)^2
```

### Step 1 - Brackets first

```text
4 + 3 = 7
```

### Step 2 - Square

```text
7^2 = 49
```

Answer:

```text
(4 + 3)^2 = 49
```

## Example 7 - Negative Numbers
Question:

```text
10 - (-2) x 4
```

### Step 1 - Multiplication first

```text
(-2) x 4 = -8
```

### Step 2 - Subtract the negative

```text
10 - (-8) = 18
```

Answer:

```text
10 - (-2) x 4 = 18
```

## Example 8 - Programming Expression
Question: A program has this expression:

```text
score = 20 + 5 * 3
```

What is `score`?

### Step 1 - Multiplication first

```text
5 * 3 = 15
```

### Step 2 - Add

```text
20 + 15 = 35
```

Answer:

```text
score = 35
```
