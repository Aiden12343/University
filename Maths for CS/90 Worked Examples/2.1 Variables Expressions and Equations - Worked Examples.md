# 2.1 Variables Expressions and Equations - Worked Examples

## Example 1 - Labelling Variables and Constants
Question: In `4x - 1 = 19`, identify the variable, the constants, and state whether this is an expression or an equation.

### Step 1 - Find the letter
The letter `x` is the [[variable]] — it stands for a number you do not know yet.

### Step 2 - Find the fixed numbers
The numbers `4`, `-1`, and `19` are [[constant]]s. They do not change when `x` changes.

### Step 3 - Check for an equals sign
There is an `=` sign, so this is an [[equation]], not an [[expression]].

Answer: Variable: **x**. Constants: **4, -1, 19**. This is an **equation**.

## Example 2 - Spot the Mistake
Question: A learner says: "`2x` means the same as `2 + x`." What is wrong?

### Step 1 - Test with a value
Let `x = 3`.

```text
2x   →  2 × 3  →  6
2 + x  →  2 + 3  →  5
```

### Step 2 - Compare the results
`6 ≠ 5`, so the two phrases do not mean the same thing.

### Step 3 - State the correct meaning
In algebra, `2x` means **2 multiplied by x**, not 2 plus x.

Answer: The mistake is treating **multiplication as addition**. `2x` means `2 × x`.

> [!important] Multiplication notation
> When a number sits next to a letter with no sign between them, it means multiply. This comes from [[1.4 Multiplication and Times Tables]].

## Example 3 - Checking a Solution
Question: Is `x = 4` a solution to `x + 9 = 14`? If not, find the correct solution.

### Step 1 - Substitute into the left side
Replace `x` with `4`:

```text
4 + 9 = 13
```

### Step 2 - Compare to the right side
The right side is `14`.

```text
13 ≠ 14
```

So `4` is not a [[solution]].

### Step 3 - Find the correct solution
Use subtraction as the inverse of addition:

```text
x = 14 - 9
x = 5
```

### Step 4 - Check

```text
5 + 9 = 14  ✓
```

Answer: **No**, `x = 4` is not a solution. The correct solution is **x = 5**.

## Example 4 - Solving and Substituting
Question: Find the solution to `n + 7 = 15`. Then find the value of `n + 2` using your answer.

### Step 1 - Estimate first
From [[1.13 Estimation and Error Checking]], `n` should be a bit less than 15. Expect a number near 8.

### Step 2 - Solve using the inverse operation

```text
n = 15 - 7
n = 8
```

### Step 3 - Check the equation

```text
8 + 7 = 15  ✓
```

### Step 4 - Substitute into the expression `n + 2`

```text
8 + 2 = 10
```

Answer: **n = 8**. The value of `n + 2` is **10**.

## Example 5 - Computer Science Application
Question: A Python function is defined as:

```python
def add_bonus(score):
    return score + 10
```

What is the value of `add_bonus(25)`? Which part is the variable, and which parts are constants?

### Step 1 - Identify the parts
- `score` is a **variable** (parameter) — it stands for different numbers each time the function is called.
- `10` is a **constant** — it never changes in this function.

### Step 2 - Substitute the argument
Calling `add_bonus(25)` means replace `score` with `25`:

```text
25 + 10 = 35
```

### Step 3 - Connect to algebra
This is the same idea as substituting into the expression `x + 10` when `x = 25`, or solving `x + 10 = 35` to get `x = 25`.

Answer: `add_bonus(25)` returns **35**. The variable is **score**; the constant is **10**.
