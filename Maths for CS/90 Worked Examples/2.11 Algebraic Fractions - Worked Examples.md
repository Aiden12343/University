# 2.11 Algebraic Fractions - Worked Examples

Theory note: [[2.11 Algebraic Fractions]]

Use these before attempting [[2.11 Algebraic Fractions - Practice Questions]].

> [!tip] Worked example routine
> Factorise, cancel, then state restrictions. When solving, multiply through by the common denominator.

## Example 1 - State a Restriction
Question: Find the restriction on `(x + 2)/(x - 7)`.

### Step 1 - Set denominator to zero

```text
x - 7 = 0
x = 7
```

Answer: **x ≠ 7**.

## Example 2 - Simplify by Factorising
Question: Simplify `(x^2 - 16)/(x + 4)`.

### Step 1 - Factorise numerator

```text
(x - 4)(x + 4)
```

### Step 2 - Cancel `(x + 4)`

```text
x - 4,   x ≠ -4
```

Answer: **x - 4**, with **x ≠ -4**.

## Example 3 - Add Algebraic Fractions
Question: Simplify `2/(3x) + 1/x`.

### Step 1 - Common denominator `3x`

```text
1/x = 3/(3x)
```

### Step 2 - Add

```text
2/(3x) + 3/(3x) = 5/(3x)
```

Answer: **5/(3x)**, **x ≠ 0**.

## Example 4 - Multiply
Question: Simplify `(2x/5) × (15/x^2)`.

### Step 1 - Multiply

```text
30x / (5x^2)
```

### Step 2 - Cancel

```text
6/x,   x ≠ 0
```

Answer: **6/x**.

## Example 5 - Solve an Equation
Question: Solve `(x - 2)/4 = 5`.

### Step 1 - Multiply by 4

```text
x - 2 = 20
x = 22
```

Answer: **x = 22**.

## Example 6 - Spot the Mistake
Question: A learner simplifies `(x + 3)/3` to `x`. Correct it.

### Step 1 - Identify error

Only factors can cancel, not added terms.

### Step 2 - Correct form

```text
(x + 3)/3 = x/3 + 1
```

Answer: Cannot simplify to **x**.

## Example 7 - CS Application: Hit Rate
Question: A cache logs `h` hits and `m` misses. Write the hit rate and restriction.

### Step 1 - Write fraction

```text
hit_rate = h / (h + m)
```

### Step 2 - State restriction

```text
h + m ≠ 0
```

Answer: **h/(h+m)** with at least one access recorded.

## Self-Check
You understand these examples when you can:

- state restrictions before simplifying
- factorise and cancel correctly
- add with a common denominator
- solve linear equations with algebraic fractions
- model a rate as a rational expression with guards
