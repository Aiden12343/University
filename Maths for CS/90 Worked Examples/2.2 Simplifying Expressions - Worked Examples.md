# 2.2 Simplifying Expressions - Worked Examples

Theory note: [[2.2 Simplifying Expressions]]

Use these examples before attempting [[2.2 Simplifying Expressions - Practice Questions]].

> [!tip] How to use worked examples

## Example 1 - Listing Terms
Question: List the terms in `4x - 7 + 2y - 3`.

### Step 1 - Split at each plus or minus
Keep the sign with the term that follows.

```text
4x   -7   2y   -3
```

### Step 2 - Name each term
There are four terms.

Answer: **4x**, **-7**, **2y**, **-3**.

## Example 2 - Finding Coefficients
Question: What is the coefficient of `x` in `5 - 3x + 2x`?

### Step 1 - Find every term containing x
The `x` terms are `-3x` and `2x`.

### Step 2 - Read each coefficient
Coefficients: **-3** and **2**.

Answer: The expression has two `x` terms with coefficients **-3** and **2**. After simplifying, the single coefficient will be -1.

## Example 3 - Collecting Like Terms
Question: Simplify `6x + 4 - 2x + 1`.

### Step 1 - Group the x terms
```text
6x - 2x + 4 + 1
```

### Step 2 - Combine the x terms
```text
(6 - 2)x = 4x
```

### Step 3 - Combine the constants
```text
4 + 1 = 5
```

Answer: **4x + 5**.

## Example 4 - Spot the Mistake
Question: A learner writes `7x - 4x = 3`. What went wrong?

### Step 1 - Check what was combined
The learner subtracted the coefficients correctly: `7 - 4 = 3`.

### Step 2 - Identify the missing part
The variable `x` was dropped.

### Step 3 - Write the correct answer
```text
7x - 4x = (7 - 4)x = 3x
```

Answer: The correct simplification is **3x**, not 3.

## Example 5 - Two Variables
Question: Simplify `3x + 2y - x + 5y + 4`.

### Step 1 - Group like terms
```text
3x - x + 2y + 5y + 4
```

### Step 2 - Combine x terms
```text
(3 - 1)x = 2x
```

### Step 3 - Combine y terms
```text
(2 + 5)y = 7y
```

### Step 4 - Keep the constant
```text
2x + 7y + 4
```

Answer: **2x + 7y + 4**.

## Example 6 - Expression Trees in CS
Question: The expression `2x + 3x + 5` is stored as a tree. What does the tree look like after simplification?

### Step 1 - Draw the original tree
```text
       +
      / \
     +   5
    / \
  2x  3x
```

### Step 2 - Combine the like-term branches
The two `x` branches merge into one.

```text
       +
      / \
     5x  5
```

### Step 3 - Connect to code
In a compiler, this is constant folding and algebraic simplification — removing redundant nodes from the tree.

Answer: After simplification, the tree has one `5x` branch and one `5` branch instead of two separate `x` branches.

## Self-Check

- why `-7` is a term in `4x - 7`
- why `7x - 4x` is `3x`, not `3`
- why `3x + 2y` cannot become one term
- how grouping terms before combining prevents sign errors
- how expression trees represent simplification in CS
