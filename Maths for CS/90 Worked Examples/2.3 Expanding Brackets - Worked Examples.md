# 2.3 Expanding Brackets - Worked Examples

Theory note: [[2.3 Expanding Brackets]]

Use these examples before attempting [[2.3 Expanding Brackets - Practice Questions]].

> [!tip] How to use worked examples
> Read the worked solution once. Then cover it and solve the same question again on paper. If you cannot repeat it, you are not ready for the practice sheet yet.

## Example 1 - Single Bracket with Positive Multiplier
Question: Expand `5(x + 3)`.

### Step 1 - Identify the outside multiplier
The multiplier is 5.

### Step 2 - Multiply into each inside term
```text
5 × x = 5x
5 × 3 = 15
```

### Step 3 - Write without brackets
```text
5x + 15
```

Answer: **5x + 15**.

## Example 2 - Single Bracket with Negative Multiplier
Question: Expand `-3(x - 2)`.

### Step 1 - Multiply -3 by the first inside term
```text
-3 × x = -3x
```

### Step 2 - Multiply -3 by the second inside term
```text
-3 × (-2) = +6
```

### Step 3 - Combine
```text
-3x + 6
```

Answer: **-3x + 6**.

## Example 3 - Expanding and Simplifying
Question: Expand and simplify `2(x + 4) + 3(x - 1)`.

### Step 1 - Expand the first bracket
```text
2(x + 4) = 2x + 8
```

### Step 2 - Expand the second bracket
```text
3(x - 1) = 3x - 3
```

### Step 3 - Combine and collect like terms
```text
2x + 8 + 3x - 3 = 5x + 5
```

Answer: **5x + 5**.

## Example 4 - Double Bracket Expansion
Question: Expand `(x + 2)(x + 5)`.

### Step 1 - Multiply each pair of terms
```text
x × x = x²
x × 5 = 5x
2 × x = 2x
2 × 5 = 10
```

### Step 2 - Collect like terms
```text
x² + 5x + 2x + 10 = x² + 7x + 10
```

Answer: **x² + 7x + 10**.

## Example 5 - Spot the Mistake
Question: A learner writes `4(x + 2) = 4x + 2`. What went wrong?

### Step 1 - Check each inside term was multiplied
The learner multiplied 4 by `x` correctly to get `4x`.

### Step 2 - Find the missed multiplication
The constant 2 was not multiplied by 4.

### Step 3 - Correct the expansion
```text
4(x + 2) = 4x + 8
```

Answer: The correct expansion is **4x + 8**. The outside multiplier must hit every inside term.

## Example 6 - Loop Unrolling Analogy
Question: The code `total = k * (a + b + c)` is "unrolled" using the distributive law. Write the expanded form.

### Step 1 - Identify the compact form
One multiplication outside brackets: `k * (a + b + c)`.

### Step 2 - Apply the distributive law
```text
k × a = ka
k × b = kb
k × c = kc
```

### Step 3 - Write as a sum (unrolled)
```text
total = k * a + k * b + k * c
```

Answer: **ka + kb + kc** — three separate multiplications instead of one grouped expression.
