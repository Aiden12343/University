# 2.4 Factorising - Worked Examples

Theory note: [[2.4 Factorising]]

Use these examples before attempting [[2.4 Factorising - Practice Questions]].

> [!tip] How to use worked examples
> Read the worked solution once. Then cover it and solve the same question again on paper. If you cannot repeat it, you are not ready for the practice sheet yet.

## Example 1 - Taking Out a Common Factor
Question: Factorise `8x + 20`.

### Step 1 - Find the HCF of 8 and 20
```text
8  = 2 × 4
20 = 2 × 10
HCF = 4
```

### Step 2 - Divide each term by 4
```text
8x ÷ 4 = 2x
20 ÷ 4 = 5
```

### Step 3 - Write the factor outside brackets
```text
4(2x + 5)
```

### Step 4 - Check by expanding
```text
4(2x + 5) = 8x + 20  ✓
```

Answer: **4(2x + 5)**.

## Example 2 - Quadratic Factorisation
Question: Factorise `x² + 8x + 15`.

### Step 1 - Find factor pairs of 15
```text
1 × 15,  3 × 5
```

### Step 2 - Find the pair that adds to 8
```text
3 + 5 = 8  ✓
```

### Step 3 - Write the brackets
```text
(x + 3)(x + 5)
```

### Step 4 - Check by expanding
```text
x² + 5x + 3x + 15 = x² + 8x + 15  ✓
```

Answer: **(x + 3)(x + 5)**.

## Example 3 - Difference of Squares
Question: Factorise `x² - 49`.

### Step 1 - Recognise two perfect squares with subtraction
```text
x² - 49 = x² - 7²
```

### Step 2 - Apply the pattern a² - b² = (a + b)(a - b)
```text
a = x,  b = 7
```

### Step 3 - Write the factors
```text
(x + 7)(x - 7)
```

### Step 4 - Check by expanding
```text
x² - 7x + 7x - 49 = x² - 49  ✓
```

Answer: **(x + 7)(x - 7)**.

## Example 4 - Spot the Mistake
Question: A learner factorises `x² + 5x + 6` as `(x + 1)(x + 6)`. What went wrong?

### Step 1 - Check the factor pair
```text
1 × 6 = 6  ✓
1 + 6 = 7  ✗  (need 5, not 7)
```

### Step 2 - Find the correct pair
```text
2 × 3 = 6  ✓
2 + 3 = 5  ✓
```

### Step 3 - Write the correct factorisation
```text
(x + 2)(x + 3)
```

Answer: The correct factorisation is **(x + 2)(x + 3)**. The factor pair must multiply to the constant **and** add to the x coefficient.

## Example 5 - Negative Middle Term
Question: Factorise `x² - 7x + 12`.

### Step 1 - Need numbers multiplying to +12 and adding to -7
Both must be negative:
```text
(-3) × (-4) = 12  ✓
(-3) + (-4) = -7  ✓
```

### Step 2 - Write the brackets
```text
(x - 3)(x - 4)
```

### Step 3 - Check
```text
x² - 4x - 3x + 12 = x² - 7x + 12  ✓
```

Answer: **(x - 3)(x - 4)**.

## Example 6 - CS Simplification
Question: The code `result = k*x + k*y + k*z` is factorised to `result = k*(x + y + z)`. Explain the benefit.

### Step 1 - Identify the common factor
`k` appears in every term.

### Step 2 - Write the factorised form
```text
k(x + y + z)
```

### Step 3 - Explain the CS benefit
- One multiplication by `k` instead of three
- Clearer intent: "scale the sum of x, y, z"
- Enables common subexpression elimination in compilers

Answer: **k(x + y + z)** — fewer operations and clearer structure for both humans and optimisers.

## Self-Check
You understand these examples when you can explain:

- why the HCF gives the neatest common-factor answer
- how to find a factor pair for a quadratic
- why `x² - 49` uses difference of squares but `x² + 49` does not
- why checking by expansion catches wrong factor pairs
- how factorising reduces repeated computation in code
