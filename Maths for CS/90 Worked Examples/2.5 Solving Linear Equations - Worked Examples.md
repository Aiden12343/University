# 2.5 Solving Linear Equations - Worked Examples

Theory note: [[2.5 Solving Linear Equations]]

Use these examples before attempting [[2.5 Solving Linear Equations - Practice Questions]].

> [!tip] Worked example routine
> For every equation, name the inverse operation before performing it. Then check by substituting back into the original equation.

## Example 1 - One-Step Addition
Question: Solve `n + 7 = 15`.

### Step 1 - Identify what was done to the unknown
3 was not added here — 7 was added to `n`.

The operation on `n` is **add 7**.

### Step 2 - Apply the inverse to both sides
The inverse of adding 7 is subtracting 7.

```text
n + 7 - 7 = 15 - 7
n = 8
```

### Step 3 - Check by substitution

```text
8 + 7 = 15  ✓
```

Answer: **n = 8**.

## Example 2 - One-Step Subtraction
Question: Solve `x - 4 = 11`.

### Step 1 - Identify the operation
4 was **subtracted** from `x`.

### Step 2 - Add 4 to both sides

```text
x - 4 + 4 = 11 + 4
x = 15
```

### Step 3 - Check

```text
15 - 4 = 11  ✓
```

Answer: **x = 15**.

## Example 3 - Two-Step Equation
Question: Solve `2x + 3 = 11`.

### Step 1 - Undo addition first
Following [[1.9 Order of Operations]] in reverse, remove the `+ 3` first.

```text
2x + 3 - 3 = 11 - 3
2x = 8
```

### Step 2 - Undo multiplication

```text
2x ÷ 2 = 8 ÷ 2
x = 4
```

### Step 3 - Check

```text
2(4) + 3 = 8 + 3 = 11  ✓
```

Answer: **x = 4**.

## Example 4 - Unknown on Both Sides
Question: Solve `5x - 3 = 2x + 9`.

### Step 1 - Collect x terms on the left
Subtract `2x` from both sides.

```text
5x - 3 - 2x = 2x + 9 - 2x
3x - 3 = 9
```

### Step 2 - Collect constants

```text
3x - 3 + 3 = 9 + 3
3x = 12
```

### Step 3 - Divide by 3

```text
x = 4
```

### Step 4 - Check both sides

```text
Left:  5(4) - 3 = 20 - 3 = 17
Right: 2(4) + 9 = 8 + 9 = 17  ✓
```

Answer: **x = 4**.

## Example 5 - Spot the Mistake
Question: A learner solves `x + 5 = 12` and writes `x = 17`. What went wrong?

### Step 1 - Test the learner's answer

```text
17 + 5 = 22 ≠ 12
```

The answer fails the check.

### Step 2 - Identify the error
The learner **added** 5 to both sides instead of **subtracting** 5.

```text
Wrong:  x + 5 + 5 = 12 + 5  →  x = 17
Right:  x + 5 - 5 = 12 - 5  →  x = 7
```

### Step 3 - State the correct solution

```text
x = 7
Check: 7 + 5 = 12  ✓
```

Answer: The learner repeated the operation instead of using the [[inverse operations|inverse operation]]. The correct answer is **x = 7**.

## Example 6 - Computer Science Application
Question: A program stores `used` bytes of memory. The constraint is `used + buffer = limit`, where `limit = 1024` and `used = 850`. Find `buffer`. Explain how this is like solving a linear equation.

### Step 1 - Write the equation

```text
850 + buffer = 1024
```

### Step 2 - Solve using subtraction (inverse of addition)

```text
buffer = 1024 - 850
buffer = 174
```

### Step 3 - Check (like an assert in code)

```text
850 + 174 = 1024  ✓
```

### Step 4 - Connect to debugging
If a program reports `used + buffer ≠ limit`, you are debugging a broken constraint — the same skill as finding where an equation fails to balance.

```python
used = 850
limit = 1024
buffer = limit - used
assert used + buffer == limit
```

Answer: **buffer = 174**. This is a [[one-step equation]] solved by [[balancing]] with [[inverse operations]].
