# 2.6 Rearranging Formulae - Worked Examples

Theory note: [[2.6 Rearranging Formulae]]

Use these examples before attempting [[2.6 Rearranging Formulae - Practice Questions]].

> [!tip] Worked example routine
> Name the subject you want, then undo each operation in reverse order of [[1.9 Order of Operations]]. Check by substituting numbers into the original formula.

## Example 1 - One-Step Multiplication
Question: Make `w` the subject of `A = l × w`.

### Step 1 - Identify the subject wanted
We need **w** alone on one side.

### Step 2 - Undo multiplication by l
Divide both sides by `l`.

```text
A/l = w
```

### Step 3 - Write with subject on the left

```text
w = A/l
```

### Step 4 - Check with numbers
Let `A = 24`, `l = 6`.

```text
w = 24/6 = 4
Original: 24 = 6 × 4  ✓
```

Answer: **w = A/l**

## Example 2 - One-Step Addition
Question: Make `u` the subject of `v = u + at`.

### Step 1 - Subtract at from both sides

```text
v - at = u
```

### Step 2 - Write with subject on the left

```text
u = v - at
```

### Step 3 - Check with numbers
Let `v = 20`, `a = 2`, `t = 3`.

```text
u = 20 - 6 = 14
Original: 20 = 14 + 6  ✓
```

Answer: **u = v - at**

## Example 3 - Two-Step Rearrangement
Question: Make `x` the subject of `y = 3x - 5`.

### Step 1 - Add 5 to both sides (undo subtraction)

```text
y + 5 = 3x
```

### Step 2 - Divide both sides by 3 (undo multiplication)

```text
(y + 5)/3 = x
```

### Step 3 - Write with subject on the left

```text
x = (y + 5)/3
```

### Step 4 - Check with numbers
Let `y = 10`.

```text
x = (10 + 5)/3 = 5
Original: 10 = 3(5) - 5 = 10  ✓
```

Answer: **x = (y + 5)/3**

## Example 4 - Spot the Mistake
Question: A learner rearranges `y = 2x + 3` to get `x = y/2 - 3`. What is wrong?

### Step 1 - Test with a value
Let `y = 7`, `x = 2` (since `2(2) + 3 = 7`).

Learner's formula: `x = 7/2 - 3 = 3.5 - 3 = 0.5 ≠ 2`.

### Step 2 - Identify the error
The learner divided by 2 **before** subtracting 3. You must subtract 3 first.

### Step 3 - Correct rearrangement

```text
y - 3 = 2x
x = (y - 3)/2
```

Check: `x = (7 - 3)/2 = 2` ✓

Answer: The mistake was undoing operations in the wrong order. Correct: **x = (y - 3)/2**.

## Example 5 - Substitute After Rearranging
Question: Make `s` the subject of `d = s × t`. Then find `s` when `d = 150` and `t = 6`.

### Step 1 - Rearrange

```text
s = d/t
```

### Step 2 - Substitute

```text
s = 150/6 = 25
```

### Step 3 - Check in original formula

```text
150 = 25 × 6  ✓
```

Answer: **s = d/t**, and **s = 25** for the given values.

## Example 6 - Computer Science Application
Question: A program converts Celsius to Fahrenheit using `F = 1.8 × C + 32`. Write a function that converts Fahrenheit to Celsius by rearranging the formula.

### Step 1 - Make C the subject
Subtract 32 from both sides:

```text
F - 32 = 1.8 × C
```

Divide both sides by 1.8:

```text
C = (F - 32)/1.8
```

### Step 2 - Implement in code

```python
def fahrenheit_to_celsius(F):
    return (F - 32) / 1.8
```

### Step 3 - Check
`F = 32` should give `C = 0`:

```text
C = (32 - 32)/1.8 = 0  ✓
```

`F = 212` should give `C = 100`:

```text
C = (212 - 32)/1.8 = 100  ✓
```

Answer: **C = (F - 32)/1.8**, implemented as shown. Rearranging lets the program answer the reverse question without a separate lookup table.
