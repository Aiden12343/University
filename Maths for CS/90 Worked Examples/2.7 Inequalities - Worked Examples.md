# 2.7 Inequalities - Worked Examples

Theory note: [[2.7 Inequalities]]

Use these examples before attempting [[2.7 Inequalities - Practice Questions]].

> [!tip] Worked example routine
> Solve the inequality one step per line. Draw a number line. Test one value inside and one outside the solution set.

## Example 1 - One-Step Inequality
Question: Solve `x + 2 > 8` and describe the [[solution set]].

### Step 1 - Subtract 2 from both sides

```text
x + 2 - 2 > 8 - 2
x > 6
```

### Step 2 - Describe the solution set
All numbers strictly greater than 6.

### Step 3 - Test
Inside: `x = 7` → `7 + 2 = 9 > 8` ✓

Outside: `x = 6` → `6 + 2 = 8 > 8` ✗ (6 is not included — strict)

Answer: **x > 6**

## Example 2 - Two-Step Inequality
Question: Solve `2x + 1 ≤ 9`.

### Step 1 - Subtract 1

```text
2x ≤ 8
```

### Step 2 - Divide by 2

```text
x ≤ 4
```

### Step 3 - Test boundary
`x = 4`: `2(4) + 1 = 9 ≤ 9` ✓ (inclusive — 4 is included)

Answer: **x ≤ 4**

## Example 3 - Flipping When Multiplying by a Negative
Question: Solve `-2x < 10`.

### Step 1 - Divide both sides by -2

Because -2 is negative, **flip** the sign.

```text
x > -5
```

### Step 2 - Test
Inside: `x = 0` → `-2(0) = 0 < 10` ✓

Outside: `x = -6` → `-2(-6) = 12 < 10` ✗

Answer: **x > -5**

> [!important] Flip rule
> This is [[flipping when multiplying by negatives]] — linked to order reversal on the number line from [[1.8 Negative Numbers]].

## Example 4 - Number Line Interval
Question: Represent `x ≤ -1` on a [[number line interval]].

### Step 1 - Identify boundary type
`≤` is **inclusive** → closed (filled) circle at -1.

### Step 2 - Identify direction
"Less than or equal to" → shade **left**.

### Step 3 - Draw

```text
<=======●
-4  -3  -2  -1   0   1   2
         ^
    closed circle, shade left
```

Answer: Closed circle at **-1**, shade all values to the **left**, including -1.

## Example 5 - Spot the Mistake
Question: A learner solves `-3x ≥ 12` and writes `x ≥ -4`. What is wrong?

### Step 1 - Test the learner's answer
Try `x = 0`:

```text
-3(0) = 0 ≥ 12  ✗
```

The answer fails immediately.

### Step 2 - Identify the error
The learner forgot to **flip** the sign when dividing by -3.

### Step 3 - Correct solution

```text
-3x ≥ 12
x ≤ -4    (sign flipped)
```

Check `x = -4`: `-3(-4) = 12 ≥ 12` ✓

Answer: The sign must flip. Correct: **x ≤ -4**.

## Example 6 - Computer Science Application
Question: A function is safe only when `0 <= index < len(items)` and `len(items) = 6`. List all valid integer values of `index`. Explain the connection to inequalities.

### Step 1 - Translate the compound inequality
`0 ≤ index` — inclusive lower bound, 0 allowed.

`index < 6` — strict upper bound, 6 excluded.

### Step 2 - List valid integers

```text
index ∈ {0, 1, 2, 3, 4, 5}
```

### Step 3 - Connect to CS
This is the standard half-open range for zero-indexed arrays:

```python
items = ['a', 'b', 'c', 'd', 'e', 'f']
# valid indexes: 0, 1, 2, 3, 4, 5
# len(items) = 6 is excluded as an index
```

Getting `<` vs `≤` wrong causes index-out-of-bounds errors.

### Step 4 - Big-O preview
Bounds like `T(n) ≤ 5n` for large `n` are inequalities describing worst-case runtime — developed fully in [[10.1 Big O Theta and Omega]].

Answer: Valid indexes: **0, 1, 2, 3, 4, 5**. The compound inequality defines a [[solution set]] that matches array bounds.
