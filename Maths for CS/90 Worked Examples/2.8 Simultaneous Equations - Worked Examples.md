# 2.8 Simultaneous Equations - Worked Examples

Theory note: [[2.8 Simultaneous Equations]]

Use these before attempting [[2.8 Simultaneous Equations - Practice Questions]].

> [!tip] Worked example routine
> Name the method first: substitution or elimination. After finding values, substitute into **both** original equations.

## Example 1 - Check a Candidate Solution
Question: Is `(2, 5)` a solution to `x + y = 7` and `2x - y = -1`?

### Step 1 - Test the first equation

```text
2 + 5 = 7   ✓
```

### Step 2 - Test the second equation

```text
2(2) - 5 = 4 - 5 = -1   ✓
```

Answer: **Yes**, `(2, 5)` is a solution.

## Example 2 - Substitution
Question: Solve.

```text
y = x + 3
4x + y = 18
```

### Step 1 - Substitute `y`

```text
4x + (x + 3) = 18
```

### Step 2 - Solve for `x`

```text
5x + 3 = 18
5x = 15
x = 3
```

### Step 3 - Find `y`

```text
y = 3 + 3 = 6
```

### Step 4 - Check both equations

```text
6 = 3 + 3        ✓
4(3) + 6 = 18    ✓
```

Answer: `x = 3`, `y = 6`.

## Example 3 - Elimination by Adding
Question: Solve.

```text
3x + 2y = 12
3x - 2y = 6
```

### Step 1 - Add the equations

```text
6x = 18
x = 3
```

### Step 2 - Back-substitute

```text
3(3) + 2y = 12
9 + 2y = 12
2y = 3
y = 1.5
```

### Step 3 - Check the second equation

```text
3(3) - 2(1.5) = 9 - 3 = 6   ✓
```

Answer: `x = 3`, `y = 1.5`.

## Example 4 - Elimination After Scaling
Question: Solve.

```text
2x + 3y = 13
4x - y = 5
```

### Step 1 - Multiply the second equation by 3

```text
12x - 3y = 15
```

### Step 2 - Add to the first equation

```text
2x + 3y = 13
12x - 3y = 15
--------------
14x = 28
x = 2
```

### Step 3 - Find `y`

```text
4(2) - y = 5
8 - y = 5
y = 3
```

Answer: `x = 2`, `y = 3`.

## Example 5 - Spot the Mistake
Question: A learner solved `x + y = 8` and `x - y = 2` and wrote `x = 4`, `y = 3`. Find the error.

### Step 1 - Check the first equation

```text
4 + 3 = 7   ✗
```

### Step 2 - Identify the mistake

The learner likely subtracted incorrectly or did not verify.

### Step 3 - Correct solution

```text
2x = 10
x = 5
y = 3
```

Answer: The correct solution is **`x = 5`, `y = 3`**. The learner forgot to check.

## Example 6 - CS Application: Screen Layout
Question: A rectangular panel must have perimeter 200 px (`2w + 2h = 200`) and width twice its height (`w = 2h`). Find `w` and `h`.

### Step 1 - Substitute `w = 2h` into the perimeter equation

```text
2(2h) + 2h = 200
4h + 2h = 200
6h = 200
h = 100/3 ≈ 33.33
w = 200/3 ≈ 66.67
```

### Step 2 - Interpret

The constraints force exact dimensions; a layout engine solves this pair before placing widgets.

Answer: `w = 200/3`, `h = 100/3` pixels (or approximately 66.67 and 33.33).

## Self-Check
You understand these examples when you can:

- verify whether a point satisfies a system
- choose substitution when a variable is already isolated
- eliminate by adding or subtracting whole equations
- scale an equation before eliminating
- spot unchecked wrong answers
- model a two-constraint CS problem as a 2×2 system
