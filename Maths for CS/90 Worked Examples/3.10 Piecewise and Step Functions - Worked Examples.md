# 3.10 Piecewise and Step Functions - Worked Examples

Theory note: [[3.10 Piecewise and Step Functions]]

> [!tip] Worked example routine
> Circle the input, find the matching interval, apply only that rule. For floor/ceiling, draw a number line when unsure.

## Example 1 - Evaluate a Piecewise Function
Question:

```text
f(x) = {  x + 2,   if x < 1
       {  x^2,     if 1 ≤ x ≤ 3
       {  10,      if x > 3
```

Find `f(-1)`, `f(2)`, and `f(5)`.

### Step 1 - Evaluate f(-1)
```text
-1 < 1  ->  use x + 2
f(-1) = -1 + 2 = 1
```

### Step 2 - Evaluate f(2)
```text
1 ≤ 2 ≤ 3  ->  use x^2
f(2) = 2^2 = 4
```

### Step 3 - Evaluate f(5)
```text
5 > 3  ->  use 10
f(5) = 10
```

Answer: **f(-1) = 1**, **f(2) = 4**, **f(5) = 10**.

## Example 2 - Boundary Point Care
Question:

```text
g(x) = {  3x,    if x ≤ 2
       {  x + 4,  if x > 2
```

Find `g(2)` and `g(2.001)`.

### Step 1 - Check x = 2
```text
2 ≤ 2  ->  true, use first rule
g(2) = 3(2) = 6
```

### Step 2 - Check x = 2.001
```text
2.001 > 2  ->  use second rule
g(2.001) = 2.001 + 4 = 6.001
```

Answer: **g(2) = 6**, **g(2.001) = 6.001**. There is a small jump at the boundary.

## Example 3 - Floor and Ceiling
Question: Evaluate `⌊7.3⌋`, `⌈7.3⌉`, `⌊-7.3⌋`, and `⌈-7.3⌉`.

### Step 1 - Floor of 7.3
```text
greatest integer ≤ 7.3 is 7
⌊7.3⌋ = 7
```

### Step 2 - Ceiling of 7.3
```text
smallest integer ≥ 7.3 is 8
⌈7.3⌉ = 8
```

### Step 3 - Floor of -7.3
```text
greatest integer ≤ -7.3 is -8
⌊-7.3⌋ = -8
```

### Step 4 - Ceiling of -7.3
```text
smallest integer ≥ -7.3 is -7
⌈-7.3⌉ = -7
```

Answer: **7**, **8**, **-8**, **-7**.

## Example 4 - Graph a Step Function
Question: Describe the graph of:

```text
h(x) = {  1,  if 0 ≤ x < 2
       {  3,  if 2 ≤ x < 4
       {  5,  if x ≥ 4
```

### Step 1 - First interval
```text
horizontal line y = 1 from x = 0 (closed) to x = 2 (open)
```

### Step 2 - Second interval
```text
horizontal line y = 3 from x = 2 (closed) to x = 4 (open)
```

### Step 3 - Third interval
```text
horizontal line y = 5 from x = 4 (closed) onwards
```

### Step 4 - Jumps
```text
jump at x = 2 from 1 (open) to 3 (closed)
jump at x = 4 from 3 (open) to 5 (closed)
```

Answer: Three horizontal **steps** at heights 1, 3, and 5 with jumps at **x = 2** and **x = 4**.

## Example 5 - Spot the Mistake
Question: A learner says `⌊-2.7⌋ = -2`. Correct the error.

### Step 1 - State the definition
```text
floor(x) = greatest integer ≤ x
```

### Step 2 - Test integers near -2.7
```text
-3 ≤ -2.7 < -2
-3 ≤ -2.7  ->  true
-2 ≤ -2.7  ->  false
```

### Step 3 - Apply definition
```text
greatest integer ≤ -2.7 is -3
⌊-2.7⌋ = -3
```

Answer: **`⌊-2.7⌋ = -3`**, not -2. Floor of negative non-integers moves **more negative**.

## Example 6 - CS Transfer: Pricing Tiers
Question: A cloud API charges £0.002 per call for the first 10 000 calls, then £0.0015 per call beyond that. Write the cost function and find the cost of 12 500 calls.

### Step 1 - Define the piecewise rule
```text
C(n) = {  0.002n,              if n ≤ 10000
       {  0.002(10000) + 0.0015(n - 10000),  if n > 10000
```

### Step 2 - Select interval for n = 12500
```text
12500 > 10000  ->  use second rule
```

### Step 3 - Calculate
```text
C(12500) = 0.002(10000) + 0.0015(2500)
         = 20 + 3.75
         = 23.75
```

Answer: **C(n)** is piecewise as above. Cost of 12 500 calls = **£23.75**.
