# 3.2 Function Notation and Mapping - Worked Examples

Theory note: [[3.2 Function Notation and Mapping]]

Use these examples before attempting [[3.2 Function Notation and Mapping - Practice Questions]].

> [!tip] Worked example routine
> Write the function name, substitute the input for x, then simplify one step per line.

## Example 1 - Evaluate f(x)
Question: If `f(x) = 4x - 3`, find `f(5)`.

### Step 1 - Substitute
Replace `x` with **5**:

```text
f(5) = 4(5) - 3
```

### Step 2 - Multiply
```text
f(5) = 20 - 3
```

### Step 3 - Subtract
```text
f(5) = 17
```

Answer: **f(5) = 17**.

## Example 2 - Find an Input from an Output
Question: If `g(x) = x + 8`, find x when `g(x) = 15`.

### Step 1 - Set up the equation
```text
x + 8 = 15
```

### Step 2 - Solve using inverse operation
```text
x = 15 - 8
x = 7
```

### Step 3 - Check
```text
g(7) = 7 + 8 = 15  ✓
```

Answer: **x = 7**.

## Example 3 - Domain Restriction
Question: What value of x is **not** allowed for `h(x) = 6/x`?

### Step 1 - Identify the restriction
Division by zero is undefined.

### Step 2 - Find when denominator is zero
```text
x = 0
```

### Step 3 - State the domain
All real numbers except **0**.

Answer: **x = 0** is excluded from the [[domain]].

## Example 4 - Spot the Mistake
Question: A learner writes `f(x) = 2x + 1` and evaluates `f(3)` as `2x + 1 = 2(3) + 1 = 7`, but then writes `f(3) = 2(3x) + 1`. What went wrong?

### Step 1 - Read the correct substitution
`f(3)` means replace **x** with **3**, not multiply x by 3 inside the expression incorrectly.

### Step 2 - Identify the error
The learner treated `f(3)` as if it meant "multiply everything by 3x" rather than substitute 3 for x.

### Step 3 - Correct evaluation
```text
f(3) = 2(3) + 1 = 7
```

Answer: **f(3) is not 2(3x) + 1**. Substitute the number 3 for x only.

## Example 5 - Is It a Function?
Question: Does this mapping define a function?

```text
  1  -->  4
  2  -->  6
  2  -->  8
  3  -->  10
```

### Step 1 - Check each input
Input **1** → one output (4) ✓
Input **2** → two outputs (6 and 8) ✗
Input **3** → one output (10) ✓

### Step 2 - Apply the rule
One input with two outputs breaks the function rule.

Answer: **No**, not a function — input **2** maps to two different outputs.

## Example 6 - CS Application
Question: In Python:

```python
def double(n):
    return 2 * n
```

What is the input, output, and function name when you call `double(9)`?

### Step 1 - Name the function
Function name: **double**

### Step 2 - Identify input
Input (argument): **n = 9**

### Step 3 - Compute output
```text
return 2 * 9 = 18
```

Answer: Function **double**, input **9**, output **18**. Same structure as `f(9) = 2(9)` in maths.
