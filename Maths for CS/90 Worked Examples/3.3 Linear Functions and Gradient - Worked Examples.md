# 3.3 Linear Functions and Gradient - Worked Examples

Theory note: [[3.3 Linear Functions and Gradient]]

Use these examples before attempting [[3.3 Linear Functions and Gradient - Practice Questions]].

> [!tip] Worked example routine
> Label m and c first. For gradient from two points, write Δy and Δx on separate lines before dividing.

## Example 1 - Read Gradient and Intercept
Question: State the gradient and y-intercept of `y = -3x + 8`.

### Step 1 - Match y = mx + c
```text
m = -3
c = 8
```

### Step 2 - Interpret
Gradient **-3** means y decreases by 3 when x increases by 1.
Y-intercept **8** at point (0, 8).

Answer: **m = -3**, **c = 8**.

## Example 2 - Gradient from Two Points
Question: Find the gradient of the line through (2, 1) and (5, 10).

### Step 1 - Find Δy
```text
10 - 1 = 9
```

### Step 2 - Find Δx
```text
5 - 2 = 3
```

### Step 3 - Divide
```text
m = 9/3 = 3
```

Answer: **Gradient = 3**.

## Example 3 - Equation from Gradient and Point
Question: A line has gradient 2 and passes through (3, 11). Find its equation.

### Step 1 - Use y = mx + c
```text
11 = 2(3) + c
11 = 6 + c
```

### Step 2 - Solve for c
```text
c = 5
```

### Step 3 - Write equation
Answer: **y = 2x + 5**.

## Example 4 - Spot the Mistake
Question: A learner finds the gradient between (1, 6) and (4, 12) as `(1-4)/(6-12) = 0.5`. What is wrong?

### Step 1 - Check formula
Gradient = **(y₂ - y₁) / (x₂ - x₁)**, not the reverse.

### Step 2 - Correct calculation
```text
m = (12 - 6) / (4 - 1) = 6/3 = 2
```

Answer: The learner swapped **rise and run**. Correct gradient is **2**.

## Example 5 - Parallel Lines
Question: Are `y = 5x - 1` and `y = 5x + 4` parallel?

### Step 1 - Compare gradients
Both have **m = 5**.

### Step 2 - Compare intercepts
-1 ≠ 4, so they are distinct lines.

### Step 3 - Conclusion
Same gradient → **parallel**.

Answer: **Yes**, parallel lines with gradients 5.

## Example 6 - CS Application
Question: A cloud provider charges £10 base plus £0.003 per API call. Write the cost model and find the cost of 5000 calls.

### Step 1 - Identify m and c
```text
c = 10  (base fee)
m = 0.003  (per call)
```

### Step 2 - Write equation
```text
cost = 0.003n + 10
```

### Step 3 - Substitute n = 5000
```text
cost = 0.003(5000) + 10 = 15 + 10 = 25
```

Answer: **cost = 0.003n + 10**; 5000 calls cost **£25**.
