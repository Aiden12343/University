## Example 1 - Recognise the Quadratic and Its Shape
Question: For `y = -3x^2 + 5x - 2`, identify a, b, c, and describe the shape.

### Step 1 - Match the standard form
Standard form is:

```text
y = ax^2 + bx + c
```

### Step 2 - Read the coefficients
```text
a = -3
b = 5
c = -2
```

### Step 3 - Use the sign of a
```text
a is negative
```

So the parabola opens downward.

### Step 4 - Use the size of a
```text
|a| = 3
```

The graph is narrower than `y = -x^2`.

Answer: **a = -3, b = 5, c = -2**. The graph is a **downward-opening parabola**.

## Example 2 - Roots from Factorised Form
Question: Find the roots of `y = (x - 7)(x + 2)`.

### Step 1 - Roots mean y = 0
```text
(x - 7)(x + 2) = 0
```

### Step 2 - Use the zero product rule
If two factors multiply to zero, one factor must be zero.

```text
x - 7 = 0
x + 2 = 0
```

### Step 3 - Solve both linear equations
```text
x = 7
x = -2
```

### Step 4 - State as x-intercepts
The graph crosses the x-axis at:

```text
(7, 0) and (-2, 0)
```

Answer: The roots are **x = 7** and **x = -2**.

## Example 3 - Factorise, Then Solve
Question: Solve `x^2 - x - 12 = 0`.

### Step 1 - Find two numbers
We need two numbers that:

```text
multiply to -12
add to -1
```

The numbers are:

```text
-4 and 3
```

### Step 2 - Factorise
```text
x^2 - x - 12 = (x - 4)(x + 3)
```

### Step 3 - Set each bracket to zero
```text
x - 4 = 0
x + 3 = 0
```

### Step 4 - Solve
```text
x = 4
x = -3
```

### Step 5 - Check one root
For x = 4:

```text
4^2 - 4 - 12 = 16 - 4 - 12 = 0
```

Answer: **x = 4** or **x = -3**.

## Example 4 - Turning Point from Roots
Question: `y = (x - 1)(x - 9)`. Find the axis of symmetry and turning point.

### Step 1 - Read the roots
```text
x = 1
x = 9
```

### Step 2 - Find the halfway x-value
```text
x = (1 + 9) / 2
x = 10 / 2
x = 5
```

### Step 3 - Write the axis
The axis of symmetry is:

```text
x = 5
```

### Step 4 - Substitute x = 5
```text
y = (5 - 1)(5 - 9)
y = 4(-4)
y = -16
```

### Step 5 - State the turning point
```text
(5, -16)
```

Answer: Axis of symmetry **x = 5**; turning point **(5, -16)**.

## Example 5 - Spot the Mistake
Question: A learner solves `x^2 - 6x = 0` by dividing both sides by x:

```text
x^2 - 6x = 0
x - 6 = 0
x = 6
```

What is wrong?

### Step 1 - Identify the risky operation
They divided by x.

### Step 2 - Explain why this loses a solution
If x could be 0, division by x is not allowed.

### Step 3 - Solve correctly by factorising
```text
x^2 - 6x = 0
x(x - 6) = 0
```

### Step 4 - Use the zero product rule
```text
x = 0
x - 6 = 0
x = 6
```

Answer: The learner lost the root **x = 0**. Correct solutions are **x = 0** and **x = 6**.

## Example 6 - CS Transfer: Nested Loop Growth
Question: A program compares every item in a list with every item in the same list.

```python
for i in range(n):
    for j in range(n):
        comparisons += 1
```

Write the comparison count as a function of n and evaluate it for n = 10.

### Step 1 - Count the outer loop
The outer loop runs:

```text
n times
```

### Step 2 - Count the inner loop
For each outer loop, the inner loop runs:

```text
n times
```

### Step 3 - Multiply
```text
comparisons = n x n
comparisons = n^2
```

### Step 4 - Substitute n = 10
```text
comparisons = 10^2
comparisons = 100
```

Answer: The function is **C(n) = n^2**. For n = 10, there are **100 comparisons**.
