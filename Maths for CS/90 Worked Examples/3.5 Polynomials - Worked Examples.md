# 3.5 Polynomials - Worked Examples

Theory note: [[3.5 Polynomials]]

Use these examples before attempting [[3.5 Polynomials - Practice Questions]].

> [!tip] Worked example routine
> Write the powers in descending order, keep every sign attached to its term, and check whether the final degree makes sense.

## Example 1 - Classify and Name the Parts
Question: For `p(x) = -4x^5 + 3x^2 - x + 7`, state whether it is a polynomial, then find its degree and leading term.

### Step 1 - Check the powers
```text
powers are 5, 2, 1, and 0
```

All are non-negative whole numbers.

### Step 2 - State whether it is a polynomial
```text
yes, it is a polynomial
```

### Step 3 - Find the highest power
```text
highest power = 5
```

### Step 4 - Read the leading term
```text
leading term = -4x^5
```

Answer: It is a **polynomial** of degree **5**, with leading term **-4x^5**.

## Example 2 - Spot What Is Not a Polynomial
Question: Which expressions are polynomials?

```text
A: 2x^3 + x - 1
B: 5/x + 4
C: x^(1/2) + x
D: 11
```

### Step 1 - Check A
```text
2x^3 + x - 1
```

Powers are 3, 1, and 0, so A is a polynomial.

### Step 2 - Check B
```text
5/x = 5x^-1
```

Negative power, so B is not a polynomial.

### Step 3 - Check C
```text
x^(1/2)
```

Fractional power, so C is not a polynomial.

### Step 4 - Check D
```text
11 = 11x^0
```

A constant is a polynomial.

Answer: **A and D** are polynomials.

## Example 3 - Add Polynomials
Question: Simplify `(5x^4 - 2x^2 + 3x - 8) + (-x^4 + 7x^2 - x + 10)`.

### Step 1 - Group like powers
```text
(5x^4 - x^4) + (-2x^2 + 7x^2) + (3x - x) + (-8 + 10)
```

### Step 2 - Combine coefficients
```text
4x^4 + 5x^2 + 2x + 2
```

### Step 3 - Check degree
Highest power is 4, so the result is degree 4.

Answer: **4x^4 + 5x^2 + 2x + 2**.

## Example 4 - Expand a Polynomial Product
Question: Expand `(2x - 1)(x^2 + 3x - 4)`.

### Step 1 - Multiply 2x by each term
```text
2x(x^2 + 3x - 4)
= 2x^3 + 6x^2 - 8x
```

### Step 2 - Multiply -1 by each term
```text
-1(x^2 + 3x - 4)
= -x^2 - 3x + 4
```

### Step 3 - Add the partial results
```text
2x^3 + 6x^2 - 8x - x^2 - 3x + 4
```

### Step 4 - Combine like terms
```text
2x^3 + 5x^2 - 11x + 4
```

Answer: **2x^3 + 5x^2 - 11x + 4**.

## Example 5 - Roots from Factorised Form
Question: Find the roots of `p(x) = x(x - 4)(x + 6)`.

### Step 1 - Roots mean p(x) = 0
```text
x(x - 4)(x + 6) = 0
```

### Step 2 - Set each factor to zero
```text
x = 0
x - 4 = 0
x + 6 = 0
```

### Step 3 - Solve each equation
```text
x = 0
x = 4
x = -6
```

### Step 4 - Interpret on the graph
The graph has x-intercepts:

```text
(0, 0), (4, 0), (-6, 0)
```

Answer: Roots are **0, 4, and -6**.

## Example 6 - Spot the Mistake
Question: A learner simplifies `x^3 + x^2` as `x^5`. What is wrong?

### Step 1 - Check whether the terms are like terms
```text
x^3 and x^2 have different powers
```

They are not like terms.

### Step 2 - State the broken rule
Only like terms can be added by combining coefficients.

### Step 3 - Correct the expression
```text
x^3 + x^2
```

It is already simplified.

Answer: The learner confused addition with multiplication. `x^3 + x^2` does **not** equal `x^5`.

## Example 7 - CS Transfer: Leading-Term Growth
Question: A program's measured operation count is `T(n) = 6n^3 + 20n^2 + 100`. What term controls growth for large n?

### Step 1 - Identify the powers
```text
3, 2, and 0
```

### Step 2 - Find the degree
```text
degree = 3
```

### Step 3 - Find the leading term
```text
6n^3
```

### Step 4 - Connect to CS language
For large n, the cubic term dominates smaller powers.

Answer: Growth is controlled by **6n^3**, so the model has **cubic** leading-term behaviour.
