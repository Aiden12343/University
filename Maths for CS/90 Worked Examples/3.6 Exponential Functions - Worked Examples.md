# 3.6 Exponential Functions - Worked Examples

> [!tip] Worked example routine
> Identify `a`, identify `b`, decide growth or decay, then make a table or substitute the requested input.

## Example 1 - Recognise Exponential Functions
Question: Which functions are exponential?

```text
A: y = 6 * 2^x
B: y = x^6
C: y = 12 * 0.75^x
D: y = 4x + 2
```

### Step 1 - Look for x in the exponent
```text
A has 2^x
C has 0.75^x
```

### Step 2 - Reject x as the base
```text
B has x^6, so x is the base, not the exponent
```

### Step 3 - Reject linear form
```text
D has x to power 1
```

Answer: **A and C** are exponential functions.

## Example 2 - Build a Growth Table
Question: Make a table for `y = 5 * 3^x` for x = 0, 1, 2, 3.

### Step 1 - Start at x = 0
```text
y = 5 * 3^0
y = 5 * 1
y = 5
```

### Step 2 - Multiply by the growth factor
The growth factor is 3.

```text
x = 1: y = 15
x = 2: y = 45
x = 3: y = 135
```

### Step 3 - Write the table
```text
x    0    1    2     3
y    5   15   45   135
```

Answer: The values are **5, 15, 45, 135**.

## Example 3 - Exponential Decay
Question: A file compression estimate keeps 70% of the previous size each pass. A file starts at 1000 MB. Write a model and estimate the size after 4 passes.

### Step 1 - Convert 70% to a decay factor
```text
70% = 0.7
```

### Step 2 - Write the model
```text
S(t) = 1000 * 0.7^t
```

### Step 3 - Substitute t = 4
```text
S(4) = 1000 * 0.7^4
S(4) = 1000 * 0.2401
S(4) = 240.1
```

Answer: The estimated size after 4 passes is **240.1 MB**.

## Example 4 - Read Model Parameters
Question: For `P(t) = 800 * 1.06^t`, identify the initial value, growth factor, and percentage growth per step.

### Step 1 - Match the form
```text
P(t) = a * b^t
```

### Step 2 - Read the initial value
```text
a = 800
```

### Step 3 - Read the growth factor
```text
b = 1.06
```

### Step 4 - Convert to percentage
```text
1.06 = 1 + 0.06
0.06 = 6%
```

Answer: Initial value **800**, growth factor **1.06**, growth **6% per step**.

## Example 5 - Spot the Mistake
Question: A learner models doubling from 10 as:

```text
y = 10 + 2x
```

They say the values are 10, 12, 14, 16. What is wrong?

### Step 1 - Interpret doubling
Doubling means multiply by 2 each step.

### Step 2 - Identify the learner's model
```text
y = 10 + 2x
```

This adds 2 each step, so it is linear.

### Step 3 - Write the correct model
```text
y = 10 * 2^x
```

### Step 4 - List the correct values
```text
x = 0: 10
x = 1: 20
x = 2: 40
x = 3: 80
```

Answer: The learner used repeated addition instead of repeated multiplication.

## Example 6 - Compare Polynomial and Exponential Growth
Question: Compare `n^3` and `2^n` at n = 5 and n = 12.

### Step 1 - Evaluate at n = 5
```text
n^3 = 5^3 = 125
2^n = 2^5 = 32
```

At n = 5, `n^3` is larger.

### Step 2 - Evaluate at n = 12
```text
n^3 = 12^3 = 1728
2^n = 2^12 = 4096
```

At n = 12, `2^n` is larger.

### Step 3 - Explain
Exponential growth eventually overtakes fixed-degree polynomial growth.

Answer: `n^3` is larger at 5, but `2^n` is larger at 12.

## Example 7 - CS Transfer: Binary Choices
Question: A brute-force search checks every on/off setting for 8 switches. How many settings are possible?

### Step 1 - Count choices per switch
Each switch has:

```text
2 choices
```

### Step 2 - Count switches
```text
n = 8
```

### Step 3 - Use the exponential model
```text
settings = 2^8
settings = 256
```

Answer: There are **256 possible settings**.
