# 3.7 Logarithms - Worked Examples

Theory note: [[3.7 Logarithms]]

Use these examples before attempting [[3.7 Logarithms - Practice Questions]].

> [!tip] Worked example routine
> Translate every log into an exponent statement, solve the power question, then translate back if needed.

## Example 1 - Evaluate Simple Logs
Question: Evaluate `log_2(64)`.

### Step 1 - Translate the log
```text
log_2(64) means: 2^? = 64
```

### Step 2 - List powers of 2
```text
2^1 = 2
2^2 = 4
2^3 = 8
2^4 = 16
2^5 = 32
2^6 = 64
```

### Step 3 - Read the power
```text
? = 6
```

Answer: **log_2(64) = 6**.

## Example 2 - Convert Between Forms
Question: Rewrite `log_7(49) = 2` in exponential form.

### Step 1 - Identify the base
```text
base = 7
```

### Step 2 - Identify the power
```text
power = 2
```

### Step 3 - Identify the result
```text
result = 49
```

### Step 4 - Write the exponential statement
```text
7^2 = 49
```

Answer: **7^2 = 49**.

## Example 3 - Solve an Exponential Equation
Question: Solve `3^x = 81`.

### Step 1 - Use the inverse operation
```text
x = log_3(81)
```

### Step 2 - Use powers of 3
```text
3^1 = 3
3^2 = 9
3^3 = 27
3^4 = 81
```

### Step 3 - State x
```text
x = 4
```

Answer: **x = 4**.

## Example 4 - Use Log Laws
Question: Simplify `log_2(32) - log_2(4)`.

### Step 1 - Use the quotient law
```text
log_2(32) - log_2(4) = log_2(32 / 4)
```

### Step 2 - Divide inside the log
```text
32 / 4 = 8
```

### Step 3 - Evaluate
```text
log_2(8) = 3
```

Answer: **3**.

## Example 5 - Spot the Mistake
Question: A learner says:

```text
log_2(8 + 8) = log_2(8) + log_2(8) = 6
```

What is wrong?

### Step 1 - Identify the claimed rule
The learner treated a log of a sum like a sum of logs.

### Step 2 - State the correct rule
There is a product law:

```text
log_b(xy) = log_b(x) + log_b(y)
```

There is no matching addition law for `log_b(x + y)`.

### Step 3 - Evaluate correctly
```text
log_2(8 + 8) = log_2(16)
log_2(16) = 4
```

Answer: The correct value is **4**, not 6.

## Example 6 - Binary Search Depth
Question: A sorted list has 4096 items. About how many halving steps does binary search need?

### Step 1 - Write the log question
```text
steps = log_2(4096)
```

### Step 2 - Use powers of 2
```text
2^10 = 1024
2^11 = 2048
2^12 = 4096
```

### Step 3 - State the number of steps
```text
steps = 12
```

Answer: About **12 halving steps**.

## Example 7 - CS Transfer: Bits and Outcomes
Question: How many bits are needed to identify one item out of 256 equally likely choices?

### Step 1 - Use base 2
Bits count binary choices, so use:

```text
log_2(256)
```

### Step 2 - Use powers of 2
```text
2^8 = 256
```

### Step 3 - Interpret
```text
8 binary yes/no choices identify 256 outcomes
```

Answer: **8 bits**.
