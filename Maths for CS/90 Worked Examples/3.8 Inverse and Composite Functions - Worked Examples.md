# 3.8 Inverse and Composite Functions - Worked Examples

Theory note: [[3.8 Inverse and Composite Functions]]

Use these examples before attempting [[3.8 Inverse and Composite Functions - Practice Questions]].

> [!tip] Worked example routine
> For composites, work inside out. For inverses, write y, solve for x, swap back, then check by composition.

## Example 1 - Evaluate a Composite
Question: If `f(x) = 3x - 2` and `g(x) = x + 5`, find `f(g(4))`.

### Step 1 - Do the inside function
```text
g(4) = 4 + 5 = 9
```

### Step 2 - Feed the result into f
```text
f(9) = 3(9) - 2
```

### Step 3 - Calculate
```text
27 - 2 = 25
```

Answer: **f(g(4)) = 25**.

## Example 2 - Compare Composition Order
Question: For `f(x) = 2x` and `g(x) = x + 3`, find `f(g(x))` and `g(f(x))`.

### Step 1 - Find f(g(x))
```text
f(g(x)) = f(x + 3)
= 2(x + 3)
= 2x + 6
```

### Step 2 - Find g(f(x))
```text
g(f(x)) = g(2x)
= 2x + 3
```

### Step 3 - Compare
```text
2x + 6 != 2x + 3
```

Answer: **f(g(x)) = 2x + 6**, but **g(f(x)) = 2x + 3**. Order matters.

## Example 3 - Find a Linear Inverse
Question: Find the inverse of `f(x) = 4x - 7`.

### Step 1 - Write y
```text
y = 4x - 7
```

### Step 2 - Add 7
```text
y + 7 = 4x
```

### Step 3 - Divide by 4
```text
x = (y + 7) / 4
```

### Step 4 - Write inverse notation
```text
f^-1(x) = (x + 7) / 4
```

Answer: **f^-1(x) = (x + 7) / 4**.

## Example 4 - Check an Inverse
Question: Check that `f(x) = 5x + 1` and `h(x) = (x - 1)/5` are inverses.

### Step 1 - Check f(h(x))
```text
f(h(x)) = 5((x - 1)/5) + 1
= x - 1 + 1
= x
```

### Step 2 - Check h(f(x))
```text
h(f(x)) = ((5x + 1) - 1) / 5
= 5x / 5
= x
```

### Step 3 - Interpret
Both compositions give the identity function.

Answer: **Yes**, they are inverses.

## Example 5 - Spot the Mistake
Question: A learner says the inverse of `f(x) = 2x + 8` is `f^-1(x) = 2x - 8`. What is wrong?

### Step 1 - Identify the original operations
```text
multiply by 2
then add 8
```

### Step 2 - Undo in reverse order
```text
subtract 8
then divide by 2
```

### Step 3 - Write the correct inverse
```text
f^-1(x) = (x - 8) / 2
```

### Step 4 - Check
```text
f((x - 8)/2) = 2((x - 8)/2) + 8
= x - 8 + 8
= x
```

Answer: The learner did not undo in reverse order. Correct inverse: **(x - 8)/2**.

## Example 6 - One-to-One Check
Question: Explain why `f(x) = x^2 + 1` does not have a full inverse over all real numbers.

### Step 1 - Choose two different inputs
```text
x = 2 and x = -2
```

### Step 2 - Evaluate both
```text
f(2) = 2^2 + 1 = 5
f(-2) = (-2)^2 + 1 = 5
```

### Step 3 - Apply the one-to-one rule
Different inputs gave the same output.

Answer: It is **not one-to-one**, so it cannot have a full inverse over all real numbers.

## Example 7 - CS Transfer: Encode and Decode
Question: A toy encoder is `encode(x) = x + 13`. Find a decoder and check the round trip.

### Step 1 - Identify the operation
```text
add 13
```

### Step 2 - Undo it
```text
subtract 13
```

### Step 3 - Write decoder
```text
decode(x) = x - 13
```

### Step 4 - Check round trip
```text
decode(encode(x)) = decode(x + 13)
= x + 13 - 13
= x
```

Answer: **decode(x) = x - 13**, and the round trip returns the original input.
