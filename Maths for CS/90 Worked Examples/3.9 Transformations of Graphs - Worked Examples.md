# 3.9 Transformations of Graphs - Worked Examples

Theory note: [[3.9 Transformations of Graphs]]

Use these examples before attempting [[3.9 Transformations of Graphs - Practice Questions]].

> [!tip] Worked example routine
> For each question, name the parent graph, list the transformations in order, then track one reference point through every step.

## Example 1 - Vertical Translation
Question: Describe the transformation from `y = x^2` to `y = x^2 - 6`.

### Step 1 - Compare formulas
```text
parent:  y = x^2
new:     y = x^2 - 6
```

### Step 2 - Locate the change
```text
-6 is outside the function
```

### Step 3 - Apply the vertical rule
```text
subtract 6 from every y-value
translate down 6 units
```

### Step 4 - Check a point
```text
(0, 0) on parent  ->  (0, -6) on new graph
```

Answer: **Translation down 6 units**.

## Example 2 - Horizontal Translation
Question: Describe the transformation from `y = x^2` to `y = (x + 4)^2`.

### Step 1 - Rewrite the inside expression
```text
(x + 4) = (x - (-4))
```

### Step 2 - Apply the horizontal rule
```text
inside change: x - (-4)
translate left 4 units
```

### Step 3 - Check the vertex
```text
parent vertex: (0, 0)
new vertex:    (-4, 0)
```

Answer: **Translation left 4 units**.

## Example 3 - Reflection and Vertical Stretch Combined
Question: Describe the transformation from `y = x^2` to `y = -2x^2`.

### Step 1 - Identify the outside multiplier
```text
a = -2
```

### Step 2 - Split into stretch and reflection
```text
vertical stretch, scale factor 2
reflection in the x-axis (because a is negative)
```

### Step 3 - Track a point
```text
(1, 1) on parent  ->  (1, -2) on new graph
```

Answer: **Vertical stretch by factor 2** and **reflection in the x-axis**.

## Example 4 - Combined Transformations
Question: Describe all transformations from `y = x^2` to `y = 3(x - 2)^2 + 1`.

### Step 1 - Horizontal translation
```text
(x - 2)^2  ->  translate right 2
```

### Step 2 - Vertical stretch
```text
3(...)     ->  vertical stretch, factor 3
```

### Step 3 - Vertical translation
```text
+ 1        ->  translate up 1
```

### Step 4 - Track the vertex
```text
(0, 0)  ->  (2, 0)  ->  (2, 0) after stretch at vertex x-value  ->  (2, 1)
```

Answer: **Right 2**, **vertical stretch factor 3**, **up 1**. New vertex: **(2, 1)**.

## Example 5 - Spot the Mistake
Question: A learner says `y = f(x + 5)` translates the graph right 5 units. Correct the error.

### Step 1 - Rewrite the inside expression
```text
f(x + 5) = f(x - (-5))
```

### Step 2 - Apply the horizontal rule
```text
inside x - (-5) means shift left 5, not right
```

### Step 3 - Test with a point
```text
On y = x^2, vertex (0, 0)
On y = (x + 5)^2, vertex (-5, 0)  ->  moved left
```

Answer: **`f(x + 5)` translates left 5 units**, not right. The inside sign works opposite to naive reading.

## Example 6 - CS Transfer: Normalise a Feature
Question: Exam scores range from 40 to 100. Write a formula mapping score `s` to the interval [0, 1] and name the transformations used.

### Step 1 - Translate so minimum becomes 0
```text
s - 40
```

This is a horizontal translation on the input axis (or shift the data left by 40).

### Step 2 - Stretch to fit length 1
```text
(s - 40) / (100 - 40) = (s - 40) / 60
```

Division by 60 is a vertical compression with scale factor `1/60`.

### Step 3 - Verify endpoints
```text
s = 40  ->  0/60 = 0
s = 100 ->  60/60 = 1
```

Answer: **`normalised = (s - 40) / 60`**. Uses **translation** (subtract 40) then **vertical compression** (divide by 60).
