# 4.10 Geometry for Computer Graphics - Worked Examples

Theory note: [[4.10 Geometry for Computer Graphics]]

Use these examples before attempting [[4.10 Geometry for Computer Graphics - Practice Questions]].

## Example 1 - Translation
Question: A triangle has vertices (1, 1), (3, 1), (2, 4). Translate it by vector (4, 2).

### Step 1 - Add translation to each vertex
A': (1+4, 1+2) = (5, 3)
B': (3+4, 1+2) = (7, 3)
C': (2+4, 4+2) = (6, 6)

Answer: Translated triangle: **(5, 3), (7, 3), (6, 6)**.

## Example 2 - Scaling
Question: A square has corners (1, 1), (3, 1), (3, 3), (1, 3). Scale by factor 2 about the origin.

### Step 1 - Multiply each coordinate by 2
(1,1)→(2,2), (3,1)→(6,2), (3,3)→(6,6), (1,3)→(2,6).

Answer: Scaled square: **(2, 2), (6, 2), (6, 6), (2, 6)**.

## Example 3 - Rotation
Question: Rotate point (4, 0) by 90° about the origin. cos 90° = 0, sin 90° = 1.

### Step 1 - Apply rotation formula
x' = x cos θ - y sin θ = 4×0 - 0×1 = 0.
y' = x sin θ + y cos θ = 4×1 + 0×0 = 4.

Answer: Rotated point: **(0, 4)**.

## Example 4 - Coordinate Space Transformation
Question: A model vertex at (2, 0, 0) in model space. The model matrix translates by (10, 5, 0). Where is the vertex in world space?

### Step 1 - Model to world
Add translation to model vertex: (2+10, 0+5, 0+0) = (12, 5, 0).

Answer: World space position: **(12, 5, 0)**.

## Example 5 - Spot the Mistake
Question: A student first rotates a point (5, 0) by 90°, then translates by (3, 0). Their answer is (0, 8). The correct answer should be (3, 5). What did they do wrong?

### Step 1 - Check the student's process
Rotate (5, 0) by 90°: (0, 5).
Translate by (3, 0): (0+3, 5+0) = (3, 5).

The student got (0, 8). They seem to have translated before rotating.

### Step 2 - Reverse order check
Translate first: (5+3, 0+0) = (8, 0).
Then rotate: (0, 8). That matches the student's answer!

Answer: The student applied translation **before** rotation, but the correct order is rotation first, then translation. Transformation order matters.

## Example 6 - CS Transfer: Diffuse Lighting
Question: A surface normal N = (0, 0, 1). Light direction L = (1, 1, 1). Normalise L and compute diffuse brightness.

### Step 1 - Normalise L
|L| = √(1+1+1) = √3 ≈ 1.732.
L̂ = (1/1.732, 1/1.732, 1/1.732) ≈ (0.577, 0.577, 0.577).

### Step 2 - Compute dot product
N·L̂ = 0×0.577 + 0×0.577 + 1×0.577 = 0.577.

### Step 3 - Diffuse brightness
max(0.577, 0) = 0.577.

Answer: Diffuse brightness = **0.577** (about 58% of maximum).
