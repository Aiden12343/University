## Example 1 - Find Hypotenuse Given Two Legs
Question: A right triangle has legs 9 cm and 12 cm. Find the hypotenuse.

### Step 1 - Identify the sides
The hypotenuse c is unknown. Legs a = 9, b = 12.

### Step 2 - Apply Pythagoras
c² = a² + b² = 9² + 12².

### Step 3 - Square each number
9² = 81.
12² = 144.

### Step 4 - Add
81 + 144 = 225.

### Step 5 - Take square root
c = √225 = 15.

Answer: The hypotenuse is **15 cm**.

Check: 9² + 12² = 81 + 144 = 225 = 15². ✓

---

## Example 2 - Find a Leg Given Hypotenuse and One Leg
Question: A right triangle has hypotenuse 26 cm and one leg 10 cm. Find the other leg.

### Step 1 - Identify the sides
c = 26, a = 10. Find b.

### Step 2 - Rearrange Pythagoras
b² = c² - a².

### Step 3 - Substitute
b² = 26² - 10².

### Step 4 - Square each number
26² = 676.
10² = 100.

### Step 5 - Subtract
676 - 100 = 576.

### Step 6 - Take square root
b = √576 = 24.

Answer: The other leg is **24 cm**.

Check: 10² + 24² = 100 + 576 = 676 = 26². ✓

## Example 3 - Distance Between Two Points
Question: Find the distance between (-1, 3) and (5, 11).

### Step 1 - Find the differences
Δx = 5 - (-1) = 5 + 1 = 6.
Δy = 11 - 3 = 8.

### Step 2 - Apply distance formula
d² = 6² + 8² = 36 + 64 = 100.

### Step 3 - Take square root
d = √100 = 10.

Answer: The distance is **10 units**.

> [!tip] Negative differences are fine
> (x₂ - x₁) can be negative, but squaring makes it positive. That is why (3 - (-1))² and ((-1) - 3)² both give 16.

## Example 4 - Converse: Check for Right Angle
Question: A triangle has sides 11 cm, 60 cm, 61 cm. Is it right-angled?

### Step 1 - Identify the largest side (candidate hypotenuse)
61 cm is the largest.

### Step 2 - Check if a² + b² = c²
11² + 60² = 121 + 3600 = 3721.
61² = 3721.

### Step 3 - Compare
3721 = 3721.

Answer: Yes, it is a right-angled triangle.

## Example 5 - Spot the Mistake
Question: A student solves: "Right triangle, c = 20, a = 16. Find b."

Student writes:
```text
b² = a² + c² = 16² + 20² = 256 + 400 = 656
b = √656 ≈ 25.6
```

What is wrong?

### Step 1 - Check which formula was used
The student used b² = a² + c² (addition).

### Step 2 - Determine the correct formula
When finding a leg, use subtraction: b² = c² - a².

### Step 3 - Fix the calculation
b² = 20² - 16² = 400 - 256 = 144.
b = √144 = 12.

Answer: The student should have subtracted, not added. The correct answer is **12 cm**.

> [!failure] Rule to remember
> The hypotenuse c is always the largest number. If your answer for a leg is larger than c, you added instead of subtracted.

## Example 6 - CS Transfer: Euclidean Distance in kNN
Question: A machine learning dataset has two features (x, y). A new point P = (4, 5) needs classification. Training points:
- A: (1, 1) label "red"
- B: (5, 3) label "blue"

Using k=1 (nearest neighbour), which label does P get?

### Step 1 - Compute distance to A
Δx = 4 - 1 = 3, Δy = 5 - 1 = 4.
d_A² = 3² + 4² = 9 + 16 = 25.
d_A = 5.

### Step 2 - Compute distance to B
Δx = 4 - 5 = -1, Δy = 5 - 3 = 2.
d_B² = (-1)² + 2² = 1 + 4 = 5.
d_B = √5 ≈ 2.236.

### Step 3 - Compare distances
d_B ≈ 2.236 < d_A = 5. B is closer.

Answer: P is classified as **blue** (the nearest neighbour is B).

> [!tip] kNN in production
> Real kNN uses higher dimensions (many features). The formula extends to n dimensions: d = √(Σ(xᵢ - yᵢ)²). This is called the **Euclidean norm** or L2 distance.
