# 4.8 Vectors Basics - Worked Examples

Theory note: [[4.8 Vectors Basics]]

Use these examples before attempting [[4.8 Vectors Basics - Practice Questions]].

## Example 1 - Find the Vector Between Two Points
Question: Find the vector from A(2, 5) to B(7, 9).

### Step 1 - Subtract A from B
v = (7-2, 9-5).

### Step 2 - Compute
v = (5, 4).

Answer: The vector is **(5, 4)** — 5 units right, 4 units up.

## Example 2 - Find the Magnitude
Question: Find |v| for v = (6, 8).

### Step 1 - Apply Pythagoras
|v| = √(6² + 8²).

### Step 2 - Compute
|v| = √(36 + 64) = √100 = 10.

Answer: |v| = **10**.

## Example 3 - Add Two Vectors
Question: a = (2, 3), b = (5, 1). Find a + b.

### Step 1 - Add x-components
2 + 5 = 7.

### Step 2 - Add y-components
3 + 1 = 4.

### Step 3 - Combine
(7, 4).

Answer: **a + b = (7, 4)**.

## Example 4 - Scalar Multiplication
Question: v = (3, 2). Compute 3v and -2v.

### Step 1 - 3v
3×(3, 2) = (9, 6).

### Step 2 - -2v
-2×(3, 2) = (-6, -4).

Answer: **3v = (9, 6)**, **-2v = (-6, -4)**.

## Example 5 - Find a Unit Vector
Question: Find the unit vector of v = (3, 4).

### Step 1 - Find the magnitude
|v| = √(9 + 16) = 5.

### Step 2 - Divide by magnitude
v̂ = (3/5, 4/5) = (0.6, 0.8).

Answer: The unit vector is **(0.6, 0.8)**.

Check: |v̂| = √(0.36 + 0.64) = √1 = 1. ✓

## Example 6 - CS Transfer: Player Movement
Question: A player at (10, 20) presses right (x+1) and up (y+1) simultaneously. What is the player's new position and speed?

### Step 1 - Determine the movement vector
Movement = (1, 1).

### Step 2 - Add to position
New position = (10+1, 20+1) = (11, 21).

### Step 3 - Compute speed (magnitude)
Speed = √(1² + 1²) = √2 ≈ 1.414 units/frame.

Answer: New position: **(11, 21)**, speed: **≈1.414 units/frame**.
