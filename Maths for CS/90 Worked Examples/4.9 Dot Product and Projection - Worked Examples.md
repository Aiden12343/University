# 4.9 Dot Product and Projection - Worked Examples

Theory note: [[4.9 Dot Product and Projection]]

Use these examples before attempting [[4.9 Dot Product and Projection - Practice Questions]].

## Example 1 - Compute the Dot Product
Question: a = (2, 3), b = (4, 5). Find a·b.

### Step 1 - Multiply x-components
2 × 4 = 8.

### Step 2 - Multiply y-components
3 × 5 = 15.

### Step 3 - Add
8 + 15 = 23.

Answer: **a·b = 23**.

## Example 2 - Dot Product with Geometric Formula
Question: |a| = 7, |b| = 4, angle = 60°. Find a·b.

### Step 1 - Recall formula
a·b = |a||b|cos θ.

### Step 2 - cos 60° = 0.5
a·b = 7 × 4 × 0.5 = 28 × 0.5 = 14.

Answer: **a·b = 14**.

## Example 3 - Find the Angle Between Vectors
Question: a = (1, 0), b = (1, 1). Find the angle between them.

### Step 1 - Compute dot product
a·b = 1×1 + 0×1 = 1.

### Step 2 - Compute magnitudes
|a| = 1, |b| = √(1+1) = √2.

### Step 3 - Find cos θ
cos θ = 1 / (1 × √2) = 1/√2 ≈ 0.707.

### Step 4 - Take inverse cos
θ = cos⁻¹(0.707) = 45°.

Answer: The angle is **45°** (π/4 rad).

## Example 4 - Compute Projection
Question: a = (4, 0), b = (3, 4). Find the projection of b onto a.

### Step 1 - Compute a·b
a·b = 4×3 + 0×4 = 12.

### Step 2 - Compute |a|²
|a|² = 4² + 0² = 16.

### Step 3 - Scalar projection
s = 12/16 = 3/4.

### Step 4 - Vector projection
proj_a(b) = s × a = (3/4)(4, 0) = (3, 0).

Answer: Projection = **(3, 0)**. Perpendicular component = (3, 4) - (3, 0) = (0, 4).

## Example 5 - Spot the Mistake
Question: A student says "a·b = 0 means both vectors are zero."

### Step 1 - Check the definition
a·b = 0 means the vectors are orthogonal (perpendicular).

### Step 2 - Counterexample
a = (1, 0), b = (0, 1): neither is zero, but a·b = 0.

Answer: The student confused "zero dot product" with "zero vectors." a·b = 0 means **orthogonal**, not zero.

## Example 6 - CS Transfer: Lighting Calculation
Question: Surface normal N = (0, 1, 0). Light direction L = (1, 1, 0). Normalise L and compute diffuse brightness.

### Step 1 - Normalise L
|L| = √(1+1+0) = √2 ≈ 1.414.
L̂ = (1/1.414, 1/1.414, 0) ≈ (0.707, 0.707, 0).

### Step 2 - Compute dot product
N·L̂ = 0×0.707 + 1×0.707 + 0×0 = 0.707.

### Step 3 - Apply diffuse formula
brightness = max(0.707, 0) = 0.707.

Answer: Diffuse brightness = **≈0.707** (about 71% of maximum).
