## Example 1 - Vocabulary in Context
**Question:** Explain differentiation basics using [[derivative]], [[gradient function]], and [[tangent]].

**Worked solution:**
1. A [[derivative]] is: the instantaneous rate of change of a function with respect to its input.
2. [[gradient function]] means: the rule f'(x) that gives the derivative at every point x in the domain.
3. [[tangent]] means: a straight line that touches a curve at exactly one point locally and has the same slope as the curve there.
4. Together, these ideas let you the **derivative** measures how fast a function's output changes when the input ...
5. This matters because derivatives drive optimisation, graphics motion, and ml training.
