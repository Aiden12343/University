# 10.1 Big O Theta and Omega - Practice Questions

Theory note: [[10.1 Big O Theta and Omega]]

Do these on paper first. Check [[10.1 Big O Theta and Omega - Answers]] only after making a serious attempt.

## Vocabulary
1. Define Big O.
2. Define Big Theta.
3. Define Big Omega.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Prove that f(n) = 5n² + 3n + 10 is O(n²) using the formal definition. Find constants c and n₀.

6. Prove that f(n) = n² − 50n is Ω(n²) using the formal definition. Find constants c and n₀.

7. Is f(n) = 5n² + 3n + 10 also Θ(n²)? Justify your answer using your results from Q5 and Q6.

8. A nested loop has an outer loop running n times and an inner loop running n − i times (for i from 0 to n−1). Determine the Big O complexity and derive it step by step.

## Error Checking
9. A student claims 3n² + 100n is O(n) because for n = 1 we get 3(1)² + 100(1) = 103 ≤ 103(1), so with c = 103 and n₀ = 1 the definition is satisfied. Identify the exact error in this reasoning.

10. Verify that f(n) = 100n² + 50n + 10 is O(n²) by checking the bound for n = 1, then finding c and n₀ that satisfy the formal definition for all n ≥ n₀.

## CS Transfer
11. A database query plan uses a nested loop join (O(n²)) on two tables each with 10⁶ rows. A hash join would be O(n). Calculate the time difference at 10⁹ operations per second. Explain why algorithm choice matters at scale.

12. Write a one-paragraph answer: why can we ignore constants and lower-order terms when comparing algorithm scalability?
