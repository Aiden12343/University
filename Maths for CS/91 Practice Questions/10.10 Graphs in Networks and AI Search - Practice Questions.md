## Vocabulary
1. Define state graph.
2. Define network graph.
3. Define heuristic.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. For the undirected graph with vertices {1, 2, 3, 4} and edges 1−2, 2−3, 3−4, 1−4, write the adjacency matrix and the adjacency list representation.

6. Perform BFS traversal starting from vertex 1 on the graph from Q5. List the order of visitation and state the shortest path from 1 to 3 in terms of number of edges.

7. Apply Dijkstra's algorithm on the weighted graph: A−B: 6, A−C: 2, B−C: 1, B−D: 4, C−D: 7. Find the shortest distance from A to D and the path taken.

8. For A* search, define f(n) = g(n) + h(n). Explain what each term represents and why an admissible heuristic (h(n) never overestimates) guarantees optimality.

## Error Checking
9. A student attempts topological sort on a graph with edges 1→2, 2→3, 3→1 and claims the result is [1, 2, 3]. Identify the exact mistake and explain why topological sort requires a DAG.

10. Verify the shortest path from A to D in the graph from Q7 by enumerating all possible paths and confirming that A→C→B→D has the minimum total weight.

## CS Transfer
11. A package manager (like apt or pip) needs to install a library with dependencies that themselves have dependencies. Explain how topological sort ensures all dependencies are installed before the packages that depend on them.

12. Write a one-paragraph answer comparing BFS (queue, level-order) with DFS (stack, depth-first) and the situation where each is appropriate.
