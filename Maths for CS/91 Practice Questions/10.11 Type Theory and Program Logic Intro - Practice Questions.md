# 10.11 Type Theory and Program Logic Intro - Practice Questions

Theory note: [[10.11 Type Theory and Program Logic Intro]]

Do these on paper first. Check [[10.11 Type Theory and Program Logic Intro - Answers]] only after making a serious attempt.

## Vocabulary
1. Define type.
2. Define proposition as type.
3. Define inference rule.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. What is the type of the lambda term λx : Int. λy : Int. x + y in the simply typed lambda calculus?

6. Under the Curry-Howard correspondence, give a λ-term that proves the proposition A → (B → A). Explain how the term corresponds to a proof.

7. The term λx : A. λy : B. y has type A → B → B. What proposition does this prove under Curry-Howard? Write the proposition and explain why it is a tautology.

8. Determine the type that Haskell would infer for the function `f g x y = g (x y)`. Show your reasoning step by step.

## Error Checking
9. A student claims that the type `Int → Bool` means "a function that takes a Bool and returns an Int." Identify the mistake and give the correct interpretation.

10. Verify that `Maybe a = Nothing | Just a` is a sum type corresponding to logical OR. Explain why the type system forces a programmer to handle both the Nothing and Just cases.

## CS Transfer
11. In Rust, a function with type `fn(T) -> U` guarantees that given a value of type T it produces a value of type U. Explain how this relates to the Curry-Howard correspondence and how types catch bugs at compile time before the program runs.

12. Write a one-paragraph answer explaining how type inference (Hindley-Milner) lets a compiler deduce types without explicit annotations, and why this catches bugs early.

Pass target: 85%. Definitions must be perfect.
