## Vocabulary
1. Define best case.
2. Define average case.
3. Define worst case.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Binary search on a sorted array of n = 4096 elements. How many comparisons are needed in the worst case? Show your working.

6. Analyse the runtime of the following code as a function of n:
   ```
   total = 0
   for i in range(n):
       for j in range(n):
           total += arr[i][j]
   ```
   Determine the Big O complexity.

7. Change the inner loop in Q6 to `for j in range(i):`. Determine the new runtime complexity and show the complete derivation.

8. Explain why Python's list.append achieves O(1) amortised time, using the doubling strategy in your explanation.

## Error Checking
9. A student claims that quick sort is O(n log n) in all cases and therefore always faster than merge sort. Identify the exact mistake in this statement.

10. Verify that merge sort has O(n log n) worst-case complexity. Under what conditions does quick sort's worst case O(n²) occur, and how likely is it with a random pivot?

## CS Transfer
11. Database hash joins achieve O(m + n) average complexity versus nested loop joins at O(m × n). For two tables each with 10⁵ rows, calculate the number of operations each approach requires and state the speedup factor.

12. Write a one-paragraph answer explaining why amortised analysis gives a more accurate picture than worst-case analysis for dynamic array operations.
