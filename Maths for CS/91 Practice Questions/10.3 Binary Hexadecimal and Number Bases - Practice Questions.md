# 10.3 Binary Hexadecimal and Number Bases - Practice Questions

Theory note: [[10.3 Binary Hexadecimal and Number Bases]]

Do these on paper first. Check [[10.3 Binary Hexadecimal and Number Bases - Answers]] only after making a serious attempt.

## Vocabulary
1. Define binary.
2. Define hexadecimal.
3. Define bit.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Convert the binary number 1101101₂ to decimal. Show your working using place values.

6. Convert the decimal number 156₁₀ to binary using repeated division by 2. Show all remainder steps.

7. Convert the binary number 1101101₂ to hexadecimal. Then convert your hex result back to decimal to verify.

8. Compute −12 in 8-bit two's complement. Show the steps: write 12 in binary, invert the bits, and add 1.

## Error Checking
9. A student converts decimal 42 to binary and gets 1010100₂. Identify the exact mistake and give the correct answer.

10. Verify that 101101₂ = 45₁₀ by converting 45₁₀ back to binary using repeated division.

## CS Transfer
11. An IP address 192.168.1.1 is stored as a 32-bit number. Convert each octet to binary, concatenate them, and express the result as a single hexadecimal value (as seen in network packet headers).

12. Write a one-paragraph answer explaining why hexadecimal is used instead of raw binary when displaying memory addresses or colour codes.

Pass target: 85%. Definitions must be perfect.
