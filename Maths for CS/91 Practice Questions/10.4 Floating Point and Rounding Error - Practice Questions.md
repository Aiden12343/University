# 10.4 Floating Point and Rounding Error - Practice Questions

Theory note: [[10.4 Floating Point and Rounding Error]]

Do these on paper first. Check [[10.4 Floating Point and Rounding Error - Answers]] only after making a serious attempt.

## Vocabulary
1. Define floating point.
2. Define mantissa.
3. Define exponent.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Using a = 10¹⁵, b = 1, evaluate (a + b) + (−a) compared with a + (b + (−a)). Show why one gives 0 and the other gives 1, and state which algebraic property fails in floating point.

6. Evaluate √(x + 1) − √x for x = 10¹⁵ using both the direct formula and the rearranged form 1/(√(x + 1) + √x). Explain which result is more accurate and why.

7. In double precision, machine epsilon ε ≈ 2.22 × 10⁻¹⁶. Explain why 1.0 + ε/2 == 1.0 evaluates to True in double precision, but 1.0 + ε != 1.0.

8. Explain why Kahan summation reduces error from O(nε) to O(ε) + O(nε²). Describe the role of the compensation term c.

## Error Checking
9. A student writes `if x == 0.1:` to check whether a user entered 0.1. Identify the exact mistake and provide the correct approach using a tolerance.

10. Verify that √(1000 + 1) − √1000 does not suffer from catastrophic cancellation by computing it directly and comparing with the rearranged form (the difference should be small enough that double precision handles it).

## CS Transfer
11. During neural network training, the loss becomes NaN after a few iterations. Explain how floating-point overflow causes this and describe one technique (gradient clipping or mixed precision) to prevent it.

12. Write a one-paragraph answer explaining why financial software uses the `Decimal` type instead of double-precision floating point.

Pass target: 85%. Definitions must be perfect.
