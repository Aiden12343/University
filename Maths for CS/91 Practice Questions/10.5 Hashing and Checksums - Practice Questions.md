## Vocabulary
1. Define hash function.
2. Define collision.
3. Define checksum.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Insert keys 23, 47, 15, 38, 62 into a hash table of size m = 7 using h(k) = k mod 7. Show which keys collide and place them using chaining.

6. For the hash table in Q5, compute the load factor λ and the average successful search time (1 + λ/2).

7. Change the table size from m = 7 to m = 11 and rehash the same five keys using h(k) = k mod 11. Compare the load factor and the number of collisions with Q5.

8. Explain why choosing m as a power of 2 (e.g., m = 8) for h(k) = k mod m can produce poor hash distributions. What type of m is better?

## Error Checking
9. A student claims that cryptographic hashes can be "decrypted" to recover the original message. Identify the exact mistake and explain what preimage resistance means.

10. Verify Git's content-addressable storage principle: explain why two identical files produce the same SHA-1 hash and how this enables deduplication.

## CS Transfer
11. A database index on `user_id` uses a hash index. Explain why `SELECT * FROM users WHERE user_id = 42` is O(1) but `SELECT * FROM users WHERE user_id > 42` cannot use the hash index and must fall back to a sequential scan or B-tree.

12. Write a one-paragraph answer explaining why collisions are inevitable in hashing (reference the pigeonhole principle) and how load factor affects hash table performance.
