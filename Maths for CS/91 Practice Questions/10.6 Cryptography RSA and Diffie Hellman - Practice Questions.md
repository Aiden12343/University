## Vocabulary
1. Define public key.
2. Define private key.
3. Define RSA.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Compute 7⁵ mod 13 using repeated squaring. List the successive squares and the final multiplication.

6. For Diffie-Hellman with p = 13, g = 2, Alice's secret a = 5, and Bob's secret b = 9, compute A = gᵃ mod p, B = gᵇ mod p, and the shared secret s.

7. Generate RSA keys with primes p = 7, q = 13. Compute n, φ(n), choose a valid e (coprime with φ(n)), and find d. State the public and private keys.

8. Using the RSA keys from Q7, encrypt the message m = 5 to obtain ciphertext c = mᵉ mod n. Then decrypt c to verify you recover m = 5.

## Error Checking
9. A student says RSA with p = 2, q = 7 is secure because n = 14 and factoring 14 is hard. Identify the exact mistake (consider the minimum recommended prime size and the ease of factoring small numbers).

10. Verify that encryption and decryption work: with public key (55, 3) and private key d = 27, encrypt m = 8, then decrypt the result and confirm you get back m = 8.

## CS Transfer
11. When you visit an HTTPS website, the browser performs a TLS handshake. Explain how Diffie-Hellman is used for key agreement and how RSA is used for authentication in this process.

12. Write a one-paragraph answer explaining why the security of RSA relies on factoring being hard and why quantum computers threaten this assumption.

Pass target: 85%. Definitions must be perfect.
