## Vocabulary

2. Define error correction.
3. Define finite field.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Compute the Hamming distance between the binary strings 1011011 and 1001101. Count and list the differing bit positions.

6. A code has minimum distance d_min = 7. How many errors can it detect? How many can it correct? Show the formulas.

7. Add even parity to the data bits 1101011. Then simulate a single-bit error (flip any one bit) at the receiver and show how parity detects it. Explain why an even number of bit flips would go undetected.

8. A Reed-Solomon code has 2t = 26 parity symbols. How many symbol errors can it correct? If each symbol is one byte (8 bits), what is the maximum number of bit errors it can correct when all errors are in distinct symbols?

## Error Checking
9. A student claims a code with d_min = 5 can correct up to 3 errors. Identify the exact mistake using the formula t = ⌊(d_min − 1)/2⌋.

10. Verify the correction capacity: a Hamming code with d_min = 3 corrects 1 error. Explain why a code with d_min = 4 can detect up to 3 errors but still only corrects 1 error.

## CS Transfer
11. A QR code on a product package is partially damaged (a corner is torn). Explain how the finder patterns (three large squares) and Reed-Solomon error correction enable the scanner to still decode the data.

12. Write a one-paragraph answer explaining the trade-off between error correction strength and data capacity, using QR code levels L (7%), M (15%), Q (25%), and H (30%) as examples.
