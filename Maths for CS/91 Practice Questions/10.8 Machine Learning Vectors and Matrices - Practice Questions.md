## Vocabulary
1. Define feature vector.
2. Define weight vector.
3. Define matrix multiplication.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A dataset has 200 grayscale images, each 28 × 28 pixels. What is the shape of the feature matrix X if each image is flattened into a row? What does one row represent?

6. A linear layer takes input X of shape (200, 784) and produces output of dimension 10. Determine the shapes of weight matrix W and bias vector b, and the shape of the output Y = XW + b.

7. Compute the dot product and cosine similarity between vectors a = [2, 0, 3] and b = [1, 4, 1]. Show each step including the norms.

8. Convert logits z = [1.5, 0.5, −0.5, −1.5] to probabilities using softmax. Show the exponentials, the sum of exponentials, and the resulting probability vector.

## Error Checking
9. A student writes a linear layer as Y = XW (without a bias term) and wonders why the model always outputs 0 when the input is the zero vector. Identify the mistake and explain why the bias term is necessary.

10. Verify the normal equation for linear regression: given X = [[1, 0], [0, 1], [1, 1]] and y = [1, 1, 0], compute w = (XᵀX)⁻¹ Xᵀy and confirm that w = [1/3, 1/3].

## CS Transfer
11. When training a neural network on colour images, the input tensor has shape (64, 3, 32, 32). Explain why the data must be flattened before passing through a linear layer, and state the flattened shape.

12. Write a one-paragraph answer explaining why representing data as matrices (rows = samples, columns = features) enables efficient batch processing on GPUs.
