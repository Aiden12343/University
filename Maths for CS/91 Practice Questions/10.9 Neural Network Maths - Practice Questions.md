Do these on paper first. Check [[10.9 Neural Network Maths - Answers]] only after making a serious attempt.

## Vocabulary
1. Define neuron.
2. Define activation function.
3. Define weight.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A neuron has weights w = [2, −1, 3], bias b = 1, input x = [1, 0, 2], and sigmoid activation. Compute the output a = σ(w·x + b).

6. For the neuron in Q5, the target output is y = 0. Compute the binary cross-entropy loss L = −[y log a + (1 − y) log(1 − a)].

7. Change the activation in Q5 from sigmoid to ReLU (σ(z) = max(0, z)). Recompute the neuron output. How does the derivative of ReLU compare with sigmoid for positive inputs?

8. Explain the chain rule for backpropagation in a single neuron: given L = ½(a − y)², a = σ(z), z = w·x + b, derive ∂L/∂wᵢ in terms of the output error (a − y), the sigmoid derivative, and the input xᵢ.

## Error Checking
9. A student builds a 5-layer neural network using sigmoid activations in all hidden layers and observes that the first layer's weights barely change during training. Identify the exact cause (vanishing gradients) and the correct fix.

10. Verify that stacking two linear layers without activation functions collapses to a single linear layer: expand (XW₁ + b₁)W₂ + b₂ into X(W₁W₂) + (b₁W₂ + b₂) and explain why this means nonlinear activations are essential.

## CS Transfer
11. In PyTorch, a model computes predictions and calls `.backward()`. Explain what happens during this backward pass with respect to the chain rule, and state how gradients flow from the output layer back to the input layer.

12. Write a one-paragraph answer explaining why activation functions must be nonlinear and what happens to a network's expressive power without them.

Pass target: 85%. Definitions must be perfect.
