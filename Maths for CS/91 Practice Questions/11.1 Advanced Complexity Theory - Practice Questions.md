## Vocabulary
1. Define reduction.
2. Define NP-complete.
3. Define co-NP.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Construct a reduction from CLIQUE to INDEPENDENT SET. Given G = (V,E) with V = {1,2,3,4} and E = {(1,2),(2,3),(3,4),(1,4),(2,4)}, and k = 3. What is the corresponding INDEPENDENT SET instance on the complement graph Ḡ? Does G have a 3-clique?

6. For the graph G in Q5, use the complement graph Ḡ to determine whether an independent set of size k = 3 exists. Show each step of checking the complement.

7. Change the instance: let G' = (V,E') with E' = {(1,2),(2,3),(3,4),(1,3)}. Repeat the reduction for k = 3. Does G' have a 3-clique?

8. Explain why the reduction CLIQUE ≤ₚ INDEPENDENT SET is valid. Specifically, why does G contain a k-clique if and only if Ḡ contains an independent set of size k?

## Error Checking
9. A student claims to have proven Vertex Cover is NP-complete by showing VERTEX-COVER ≤ₚ SAT. The student writes: "Since SAT is NP-complete and we reduced VC to SAT, VC must be NP-complete." Identify the exact error — is the reduction direction correct for proving NP-hardness?

10. The correct reduction 3SAT ≤ₚ Independent Set constructs a graph with 3m vertices and sets k = m. For φ = (x₁ ∨ ¬x₂ ∨ x₃) ∧ (¬x₁ ∨ x₂ ∨ ¬x₃), verify that the constructed graph has an independent set of size 2. List the vertices in the independent set and confirm no edges connect them.

## CS Transfer
11. RSA cryptography relies on integer factoring being hard. Factoring is in NP (given factors, verify the product) but is not believed to be NP-complete — it lies in NP ∩ co-NP. Explain why this classification matters: if factoring were NP-complete, what would that imply for cryptography? Give one concrete consequence.

12. The P vs NP question asks whether every problem with efficiently verifiable solutions can also be solved efficiently. State the current status of this question. Describe one concrete impact on optimisation if P = NP were proven true.
