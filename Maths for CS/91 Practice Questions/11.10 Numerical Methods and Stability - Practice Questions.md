## Core Skill
5. Compute the condition number κ(A) for A = [[1, 1], [1, 1.0001]] given eigenvalues λ₁ = 2.0001 and λ₂ ≈ 0.00005. How many decimal digits of accuracy are lost when solving Ax = b in double precision (53 bits ≈ 16 decimal digits)?

6. Apply one step of power iteration to A = [[2, 1], [1, 2]] starting from v₀ = [1, 0]. Compute v₁ = Av₀, normalise it, and estimate the dominant eigenvalue λ₁ using the Rayleigh quotient v₁ᵀAv₁.

7. Repeat Q6 with starting vector v₀ = [0, 1]. After one iteration, which starting vector gives a better estimate of the true dominant eigenvalue λ₁ = 3?

8. For the LU decomposition A = [[2, 1], [1, 3]] = LU where L = [[1, 0], [0.5, 1]] and U = [[2, 1], [0, 2.5]], explain why solving Ly = b then Ux = y yields the solution to Ax = b. Verify with b = [5, 8].

## Error Checking
9. A student computes one RK4 step for dy/dt = −y, y(0) = 1 with h = 0.2. They write: k₁ = f(0, 1) = −1, k₂ = f(0.1, 1 + 0.2×(−1)) = f(0.1, 0.8) = −0.8, k₃ = f(0.1, 1 + 0.2×(−0.8)) = f(0.1, 0.84) = −0.84. Identify the mistake in their computation of k₂ and k₃.

10. Verify the RK4 result from the worked example: y(0.1) ≈ 0.90484 with h = 0.1 for dy/dt = −y, y(0) = 1, by comparing it to the analytic solution y(t) = e^−t at t = 0.1. Compute the absolute error.

## CS Transfer
11. Google's PageRank algorithm applies power iteration to the Google matrix G = αS + (1−α)(1/n)11ᵀ for n ≈ 10¹² pages. If α = 0.85, estimate the number of iterations needed for convergence given the subdominant eigenvalue of G is approximately α, convergence rate ≈ (λ₂/λ₁)ᵏ, and target relative error < 10⁻⁸.

12. In the conjugate gradient method for SPD systems, the condition number κ(A) determines both the convergence rate (error reduces by factor (√κ−1)/(√κ+1) per iteration) and the maximum attainable accuracy in floating point. Explain why an ill-conditioned system (κ ≈ 10¹⁰) may converge slowly and produce inaccurate results even when using CG.
