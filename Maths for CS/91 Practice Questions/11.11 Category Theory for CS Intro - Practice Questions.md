# 11.11 Category Theory for CS Intro - Practice Questions

Theory note: [[11.11 Category Theory for CS Intro]]

Do these on paper first. Check [[11.11 Category Theory for CS Intro - Answers]] only after making a serious attempt.

## Vocabulary
1. Define category.
2. Define object.
3. Define morphism.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. In the category Set, let A = {1, 2}, B = {a, b}, C = {x, y}. Given f: A → B with f(1) = a, f(2) = b and g: B → C with g(a) = x, g(b) = y, compute g ∘ f and verify that composition is associative with h: C → {z} where h(x) = z, h(y) = z.

6. Verify the List functor preserves the identity law: compute fmap id [1, 2, 3] and show it equals id [1, 2, 3].

7. Repeat Q6 with the list ['a', 'b', 'c'] in place of [1, 2, 3] and confirm the identity law still holds.

8. For the naturality square η_Y ∘ F(f) = G(f) ∘ η_X, explain why both paths must give the same result for every morphism f, using the head: [X] → Maybe X natural transformation as a concrete example.

9. A student defines a functor F that maps every set to a fixed set {p, q} and every function f: X → Y to the constant function F(f): {p, q} → {p, q} where F(f)(p) = p and F(f)(q) = q for all f. Explain why this is NOT a functor by showing it fails to preserve composition.

10. Verify the Maybe monad right unit law μ ∘ η_T = id_T on the inputs Nothing and Just 7, where η(x) = Just x and μ(Nothing) = Nothing, μ(Just Nothing) = Nothing, μ(Just (Just x)) = Just x.

11. In Haskell, the Maybe functor maps f: a → b to fmap f: Maybe a → Maybe b. Explain how fmap preserves composition: fmap (g ∘ f) = fmap g ∘ fmap f, and why this corresponds to the second functor law.

12. The universal property of the product states that for any object C with morphisms f: C → A and g: C → B, there exists a unique h: C → A × B such that π₁ ∘ h = f and π₂ ∘ h = g. Explain how this universal property guarantees that (a, b) paired with fst and snd in Haskell uniquely determines any function producing a pair.

Pass target: 85%. Definitions must be perfect.
