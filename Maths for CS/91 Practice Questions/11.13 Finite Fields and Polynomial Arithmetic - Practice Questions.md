# 11.13 Finite Fields and Polynomial Arithmetic - Practice Questions

Theory note: [[11.13 Finite Fields and Polynomial Arithmetic]]

Do these on paper first. Check [[11.13 Finite Fields and Polynomial Arithmetic - Answers]] only after making a serious attempt.

## Vocabulary
1. Define finite field.
2. Define polynomial modulo.
3. Define irreducible polynomial.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Find the multiplicative inverse of 5 in GF(7) by checking which element x ∈ {1, …, 6} satisfies 5x ≡ 1 (mod 7).

6. In GF(8) with irreducible polynomial m(x) = x³ + x + 1, multiply a(x) = x + 1 by b(x) = x² and reduce the result modulo m(x).

7. Change the multiplier in Q6 from b(x) = x² to b(x) = x. Compute (x+1) × x in GF(8) with the same irreducible polynomial m(x) = x³ + x + 1.

8. Show that x³ + x + 1 is irreducible over GF(2) by verifying it has no roots in GF(2) and explaining why any degree-3 reducible polynomial over GF(2) must have a linear factor.

9. A student claims that GF(4) = {0, 1, 2, 3} with addition and multiplication modulo 4 is a finite field. Identify the element that lacks a multiplicative inverse and explain why this violates the field axioms.

10. Verify that 3 is a primitive element of GF(7) by computing 3¹, 3², 3³, 3⁴, 3⁵, 3⁶ modulo 7 and showing these generate all six non-zero elements.

11. AES SubBytes computes the multiplicative inverse of each byte in GF(2⁸) then applies an affine transformation. Explain why the inverse alone provides nonlinearity (confusion) and why the additional affine transform is necessary to prevent algebraic attacks that exploit the inverse's mathematical structure.

12. In Shamir's secret sharing over GF(p), a secret s is encoded as P(0) = s where P is a random degree (t−1) polynomial. Explain why any t shares (points on P) suffice to reconstruct s via Lagrange interpolation, while t−1 shares provide zero information about s.

Pass target: 85%. Definitions must be perfect.
