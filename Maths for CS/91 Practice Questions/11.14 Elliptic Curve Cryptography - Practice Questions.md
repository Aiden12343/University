## Vocabulary
1. Define elliptic curve.
2. Define group law.
3. Define scalar multiplication.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. On the elliptic curve E: y² = x³ − 2x + 1 over ℝ with P = (0, 1) and Q = (2, 1), compute P + Q using the algebraic addition formula: slope m = (y_Q − y_P)/(x_Q − x_P), x_R = m² − x_P − x_Q, y_R = m(x_P − x_R) − y_P.

6. Compute 5P using the double-and-add algorithm on the curve from Q5, showing the binary expansion of 5 and each doubling/addition step.

7. Check whether the point P = (1, 0) lies on the curve y² = x³ − 2x + 1. If it does not, explain why not, and then test P = (1, 1) as an alternative.

8. Explain why P + O = P, P + (−P) = O, and why P + P requires the doubling formula (tangent line) instead of the secant line formula used for distinct points.

9. A student computes P + Q on E: y² = x³ + x + 1 over GF(7) with P = (0, 1) and Q = (0, 6). They compute the slope m = (6−1)/(0−0) = 5/0 and conclude the slope is undefined, so P + Q = O (point at infinity). Is this conclusion correct? If not, identify the error.

10. Verify that P = (0, 1) and R = (0, 6) from the worked example on E: y² = x³ + x + 1 over GF(7) satisfy the curve equation and that P + R = O, confirming they are additive inverses.

11. In ECDSA, nonce k must be unique and random. If two signatures (r, s₁) and (r, s₂) are produced with the same k for different messages m₁, m₂, show how an attacker can recover the private key d using the formula d = (s₁ − s₂)⁻¹(k·s₁ − H(m₁)) mod n.

12. ECC achieves equivalent security to RSA with much smaller key sizes (256-bit ECC ≈ 3072-bit RSA). Explain why: the best classical algorithm for ECDLP is Pollard rho with O(√n) complexity (n the group order), while RSA's security relies on integer factorisation where NFS has subexponential complexity. Describe how Shor's algorithm threatens both.
