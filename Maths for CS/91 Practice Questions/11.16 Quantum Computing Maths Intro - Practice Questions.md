# 11.16 Quantum Computing Maths Intro - Practice Questions

Theory note: [[11.16 Quantum Computing Maths Intro]]

Do these on paper first. Check [[11.16 Quantum Computing Maths Intro - Answers]] only after making a serious attempt.

## Vocabulary
1. Define qubit.
2. Define superposition.
3. Define unitary matrix.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Apply the Hadamard gate H = (1/√2)[[1, 1], [1, −1]] to |0⟩ = [1, 0]ᵀ. Compute H|0⟩ and then apply H again to verify H²|0⟩ = |0⟩.

6. Apply the CNOT gate (|00⟩→|00⟩, |01⟩→|01⟩, |10⟩→|11⟩, |11⟩→|10⟩) to the 2-qubit state |00⟩, then apply H ⊗ I to the resulting state.

7. Repeat Q6 with input state |10⟩ instead of |00⟩. Compare the final state with the result from Q6.

8. Verify that the Hadamard gate H is unitary by computing H† = H (since H is real and symmetric) and showing H†H = I.

9. A student claims that |+⟩ = (|0⟩ + |1⟩)/√2 and a 50/50 probabilistic mixture of |0⟩ and |1⟩ are physically identical. Explain why this is wrong: apply H to both cases and show that H|+⟩ = |0⟩ (deterministic) whereas applying H to a mixture gives a 50/50 mixture of H|0⟩ and H|1⟩, which is not purely |0⟩.

10. Verify that applying the Hadamard gate to |+⟩ = (|0⟩ + |1⟩)/√2 gives back |0⟩ by computing H|+⟩ explicitly using matrix multiplication.

11. Shor's algorithm factors N = 15 using order finding: for a = 2 coprime with 15, the order r = 4 since 2⁴ = 16 ≡ 1 mod 15. Compute the nontrivial factors p = gcd(2² + 1, 15) and q = gcd(2² − 1, 15). Verify that p × q = 15.

12. Grover's search algorithm finds a marked element in an unsorted database of N items using O(√N) queries to the oracle, while classical search requires O(N). Explain why O(√N) is optimal for quantum search and contrast this quadratic speedup with Shor's exponential speedup for factoring.

Pass target: 85%. Definitions must be perfect.
