## Core Skill
5. Compute the entropy H(X) = −∑ p(x) log₂ p(x) for a binary random variable with P(X=1) = 0.9. Compare this to the entropy of a fair coin (1 bit).

6. Compute the cross-entropy loss H(p,q) = −∑ p_i log₂ q_i where p = [1, 0, 0] is the true one-hot label and q = [0.7, 0.2, 0.1] is the predicted distribution over 3 classes.

7. Change the prediction in Q6 to q = [0.9, 0.05, 0.05] and recompute the cross-entropy. Which prediction is better and why?

8. Using the identity H(p,q) = H(p) + D_KL(p||q), explain why minimising cross-entropy is equivalent to minimising KL divergence when the data distribution p is fixed.

9. A student computes D_KL(p||q) for p = [0.5, 0.5] and q = [0.5, 0.5] and gets 0. Another student computes D_KL(p||q) for p = [1, 0] and q = [0.9, 0.1] and claims D_KL(p||q) = D_KL(q||p). Which student is correct? For the second student, identify why KL divergence is not symmetric.

10. For the Huffman code in the worked example (A:0.4, B:0.3, C:0.2, D:0.1), verify the entropy H = 1.85 bits and the average code length L = 1.9 bits satisfy the source coding theorem: H ≤ L < H + 1.

11. In decision tree learning, information gain IG(Feature) = H(Y) − H(Y|Feature) measures predictive power. For a dataset with 9 yes and 5 no outcomes, compute H(Y). If Wind splits into Strong (3 yes, 3 no) and Weak (6 yes, 2 no), compute H(Y|Wind) and the information gain IG(Wind).

12. The ELBO in variational autoencoders L = E_q[log p(x|z)] − D_KL(q(z|x)||p(z)) decomposes into a reconstruction term and a regularisation term. Explain how this embodies the Minimum Description Length principle: the reconstruction measures bits to code x given z, and the KL measures bits for z under the prior, so maximising ELBO minimises total description length.
