## Vocabulary
1. Define randomised algorithm.
2. Define Las Vegas algorithm.
3. Define Monte Carlo algorithm.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Use Freivalds' algorithm to verify whether A × B = C for A = [[1,2],[3,4]], B = [[5,0],[0,5]], and claimed product C = [[5,10],[15,20]]. Use the random vector r = [1, 0]ᵀ. Show each step and state whether the product is correct.

6. Given n = 100 jobs assigned uniformly at random to m = 10 machines, let L₁ be the number of jobs on machine 1. Compute E[L₁]. Then use the Chernoff bound P(L₁ ≥ (1+δ)μ) ≤ (e^δ/(1+δ)^{1+δ})^{μ} to bound P(L₁ ≥ 20).

7. Now double the number of machines to m = 20 while keeping n = 100. Recompute E[L₁] and bound P(L₁ ≥ 20) using the Chernoff bound. How does the bound change?

8. Explain why the Chernoff bound is applicable to the load balancing analysis. Specifically, why can each job's machine assignment be treated as a sum of independent random variables, and why is the union bound over all machines a valid step?

## Error Checking
9. A student writes: "Miller-Rabin with base a = 2 tells me 341 is prime because 2³⁴⁰ mod 341 = 1. Therefore 341 is definitely prime." Identify the exact error. (Hint: 341 = 11 × 31 is a Fermat pseudoprime to base 2.)

10. A Monte Carlo algorithm answers a decision problem correctly with probability p = 0.55. Using the Chernoff bound on majority voting: P(error after k trials) ≤ exp(−k(1−2ε)²/2), verify that k = 600 independent trials reduces error probability below 10⁻⁶.

## CS Transfer
11. In machine learning, Stochastic Gradient Descent (SGD) picks a random training example at each step rather than computing the full gradient. Explain why this is a Monte Carlo approach and how averaging over many steps serves as amplification to make it effective despite noisy gradient estimates.

12. Randomised algorithms trade certainty for speed. Give one concrete scenario in distributed systems where a randomised consensus or leader election protocol is preferred over a deterministic one, and explain the role of probability in the guarantee.
