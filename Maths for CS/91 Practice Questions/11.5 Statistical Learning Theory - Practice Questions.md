## Vocabulary

## Core Skill
5. A hypothesis class H has |H| = 1000. You train on m = 500 samples and achieve training error 0.15. Using δ = 0.05, compute the PAC generalisation gap: gap = √((ln|H| + ln(1/δ))/(2m)). What is the upper bound on test error?

6. Using the bound from Q5, suppose you require gap ≤ 0.05 with confidence δ = 0.01. What minimum sample size m is needed for |H| = 1000?

7. Now suppose the hypothesis class is larger: |H| = 10,000. Recompute the sample size needed for gap ≤ 0.05 with δ = 0.01. How many additional samples are needed compared to Q6?

8. Explain why the PAC bound uses ln|H| rather than |H|. Why is this logarithmic dependence crucial for machine learning with large hypothesis classes?

## Error Checking
9. A student trains two models: Model A with VC dimension d = 10, Model B with d = 100. Both achieve training error 0.05 on m = 1000 samples. The student claims: "Both have the same training error, so they will have similar test error." Identify the mistake. Compute the PAC bound gap = √((d + ln(1/δ))/m) for each model with δ = 0.05 to quantify the difference.

10. A classifier with VC dimension d = 15 achieves training error 0.08 on m = 800 samples. Compute the test error upper bound using error_test ≤ error_train + √((d + ln(1/δ))/m) with δ = 0.05. Verify the result by also applying the finite-hypothesis bound treating d ≈ log₂|H|.

## CS Transfer
11. In deep learning, overparameterised networks with millions of parameters often generalise well despite having enormous VC dimension. Explain briefly what implicit regularisation is and how it reconciles this observation with classical PAC learning guarantees.

12. The bias-variance trade-off decomposes test error as Bias² + Variance + Irreducible Error. State which component increases and which decreases as model complexity grows, and explain why the optimal model complexity lies at the intersection of the two curves.
