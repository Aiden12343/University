## Core Skill
5. Given the Bayesian network A → B → C → D with all binary variables and CPTs: P(A=1)=0.5; P(B=1|A=1)=0.8, P(B=1|A=0)=0.2; P(C=1|B=1)=0.7, P(C=1|B=0)=0.4; P(D=1|C=1)=0.9, P(D=1|C=0)=0.1. Compute P(D=1) by variable elimination in the order A, C, B.

6. For the Bayesian network in Q5, compute P(B=1 | D=1) using the chain rule and Bayes' theorem. Show each marginalisation step.

7. Modify the CPTs so that P(B=1|A=1) = 0.5 and P(B=1|A=0) = 0.5 (B is independent of A). Recompute P(D=1) and P(B=1|D=1). How do the results change from Q5 and Q6?

8. Explain why the factorisation P(A,B,C,D) = P(A)P(B|A)P(C|B)P(D|C) makes variable elimination efficient. How many numbers would the full joint distribution require for 4 binary variables, and how many does this factorisation use?

## Error Checking
9. A student states: "In the Bayesian network A → B ← C, variables A and C are dependent unconditionally because there is a path between them through B." Identify the exact error. Apply the d-separation rules for v-structures to determine the correct relationship.

10. For an MRF with two binary variables X₁, X₂ and potential ψ(x₁,x₂) = [[3,2],[2,4]] (ψ(0,0)=3, ψ(0,1)=2, ψ(1,0)=2, ψ(1,1)=4), compute the partition function Z and P(X₁=1). Verify that X₁ and X₂ are not independent by comparing P(X₁=1, X₂=1) with P(X₁=1)P(X₂=1).

## CS Transfer

12. Treewidth determines the complexity of exact inference in PGMs. State the treewidth of a chain-structured graph (e.g., an HMM) and explain why inference is tractable for trees but potentially exponential for grid-structured graphs.
