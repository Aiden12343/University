## Core Skill
5. Determine the strong convexity parameter μ for f(x) = 3x² + 2x + 1. Given gradient Lipschitz constant L = 6 and initial suboptimality f(x₀) − f(x*) = 10, compute how many GD iterations are needed to reach ε = 10⁻⁶ using the bound exp(−μk/L)·(f(x₀) − f(x*)) ≤ ε.

6. Apply the KKT conditions to minimise f(x) = (x − 1)² subject to the constraint x ≥ 3. Write the Lagrangian, find the optimal x* and λ*, and verify that complementary slackness holds.

7. Change the constraint to x ≥ 0 and repeat Q6. How does the optimal solution differ from Q6?

8. Explain why the KKT stationarity condition ∂L/∂x = 0 together with complementary slackness λ·g(x) = 0 is necessary for optimality in constrained optimisation. Use the example from Q6 to illustrate.

## Error Checking
9. A student writes the Adam update as: m_k = β₁·m_{k−1} + (1−β₁)·g_k and w_{k+1} = w_k − η·m_k/(√v_k + ε). Identify the two exact errors: (a) the missing second moment update for v_k, and (b) the missing bias correction. Explain why bias correction is critical in early steps.

10. For f(x) = ½xᵀAx − bᵀx with A = [[4,0],[0,1]] and b = [1,1], compute the Newton update from w₀ = [0,0]ᵀ using w₁ = w₀ − (∇²f)⁻¹∇f. Show that it reaches the exact minimum in one step. Verify by computing ∇f and ∇²f.

## CS Transfer
11. In deep learning, Adam is the default optimiser for training large neural networks. Explain one key advantage of Adam's per-parameter adaptive learning rates over standard SGD, and state one known failure mode of Adam (e.g., on certain simple convex functions).

12. Compare sublinear convergence O(1/k) with linear convergence O(exp(−μk/L)). If an optimisation algorithm achieves rate O(1/k) and needs ε = 10⁻⁸, roughly how many iterations are required? What about a linear rate with μ/L = 0.1? State the practical significance of this difference for training large models.
