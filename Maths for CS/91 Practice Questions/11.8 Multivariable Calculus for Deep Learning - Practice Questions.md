## Core Skill
5. Compute the Jacobian J_f for f(x) = Wx + b where W = [[1,2,3],[4,5,6]] and x ∈ ℝ³, b ∈ ℝ². State the dimensions of J_f and write its entries.

6. For h(x) = g(f(x)) where f: ℝ² → ℝ³ with f(x) = Wx and W = [[1,0],[0,1],[1,1]], and g: ℝ³ → ℝ with g(z) = z₁² + z₂² + z₃², compute J_h at x = [1,1]ᵀ using the chain rule J_h = J_g(f(x)) · J_f(x).

7. Change g to g(z) = z₁z₂ + z₂z₃. Recompute J_h at x = [1,1]ᵀ.

8. Explain each step of the chain rule in matrix form for h = g∘f. Show the dimensions of J_g(f(x)) and J_f(x) and how the matrix multiplication J_h = J_g(f(x)) · J_f(x) validates the composition.

## Error Checking
9. A student computes the gradient of MSE loss L = ½||Wx − y||² and writes ∇_W L = x(Wx − y)ᵀ. Identify the exact dimensional error. Write the correct gradient and verify its dimensions.

10. For cross-entropy loss with softmax, the gradient is ∇_z L = softmax(z) − one_hot(y). Verify that this gradient has the same shape as z and that its components sum to 0. For z = [1, 2, 0.5] and true class y = 1, compute the gradient vector explicitly.

## CS Transfer
11. In deep learning, backpropagation computes gradients for millions of parameters efficiently. Explain why reverse-mode automatic differentiation is exponentially more efficient than forward-mode for scalar-output functions like neural network training losses.

12. State the dimensions of the Hessian matrix for a function f: ℝⁿ → ℝ. If a network has n = 10⁷ parameters, explain why storing the full Hessian is infeasible and how Hessian-vector products (HVPs) circumvent this storage problem.
