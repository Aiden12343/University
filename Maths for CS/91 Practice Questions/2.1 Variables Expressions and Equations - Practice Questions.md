## A. Vocabulary

2. What is a [[constant]]?
3. What is an [[expression]]?
4. What is an [[equation]]?

6. In one sentence, explain the difference between an expression and an equation.

## B. Identify the Parts
7. In `x + 3 = 11`, list the variable and the constants.
8. In `2n + 5 = 17`, list the variable and the constants.
9. In `3t - 2 = 10`, list the variable and the constants.
10. Which are expressions and which are equations?

```text
(a) 4x + 1
(b) 4x + 1 = 9
(c) 15
(d) y = y + 0
```

11. Is `2x + 5` an expression or an equation? Explain in one sentence.
12. Is `x + 3 = 11` an expression or an equation? Explain in one sentence.

## C. Spot the Mistake
13. A learner writes: "`x + 3` is an equation because it has a variable." What is wrong?
14. A learner says: "`3x = 3 + x`." What is wrong? Test with `x = 2`.
15. A learner solves `x + 5 = 12` and writes `x = 17`. What went wrong?
16. A learner checks `x = 2` for `5x = 10` by writing `5 + 2 = 10`. What is the mistake?

## D. Substitution and Solving
17. If `x = 4`, find the value of `x + 3`.
18. If `n = 5`, find the value of `n + 2`.
19. If `x = 6`, find the value of `2x + 1`.
20. Solve `x + 3 = 11`. Check your answer.
21. Solve `n + 7 = 15`. Check your answer.
22. Solve `t + 4 = 20`. Check your answer.
23. Is `x = 5` a solution to `x + 4 = 7`? Show your working.
24. Is `x = 2` a solution to `5x = 10`? Show your working.

## E. Computer Science Transfer
25. In the code `lives = 3`, is `lives` a variable or a constant? Explain.
26. In `def double(n): return 2 * n`, what does `n` represent when you call `double(7)`?
27. A program checks `used + buffer = limit`. Name the mathematical object this models and explain in one sentence.
28. Explain why checking a solution by substitution is like testing code with sample input.
