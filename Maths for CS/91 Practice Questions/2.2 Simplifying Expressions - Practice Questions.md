## B. Core Skill — Identify Parts

9. What is the coefficient of `x` in `8x + 2`?
10. What is the coefficient of `x` in `5 - 2x`?
11. Which are like terms: `4x`, `4y`, `4`, `-2x`?

18. Simplify `7a + 4b - 2a + b - 3`.

## D. Spot the Mistake
21. A learner writes `6x + 2x = 8`. What is wrong?
22. A learner writes `3x + 4y = 7xy`. What is wrong?
23. Correct this simplification: `5x - 2x = 3`.
24. A learner writes `4 - 2x + x = 4 - x = 3x`. Identify both errors.

## E. Mixed
25. Simplify `2x + 3 - x + 7 - 4`.
26. Check `4x + 1 - x + 2` simplifies to `3x + 3` using `x = 2`.
27. Check `7x - 3 + 2x + 1` simplifies to `9x - 2` using `x = 0`.
28. Write an expression with three terms that simplifies to `5x + 1`.
29. Explain why `x` and `3` are not like terms.
30. Simplify `6x + 0 - 2x + 5`.

## F. Computer Science Transfer
31. Draw the expression tree for `2x + 3x + 1` before and after simplification.
32. In Python, `a + a` is rewritten as `2*a` by some optimisers. What algebraic idea is this?
33. Why might a compiler simplify `x + x + x` to `3*x`?
34. Give one reason expression simplification matters in query optimisation.
35. Write one sentence explaining why this topic belongs in a Computer Science maths course.
