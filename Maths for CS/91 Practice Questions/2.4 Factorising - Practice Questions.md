# 2.4 Factorising - Practice Questions

Theory note: [[2.4 Factorising]]

Answers: [[2.4 Factorising - Answers]]

> [!warning] Practice rule
> Try every question on paper before checking the answers. If you only read the answers, you are training recognition, not recall.

## A. Vocabulary
1. What is a [[common factor]]?
2. What is a [[factor pair]]?
3. What is [[quadratic factorisation]]?
4. State the [[difference of squares]] pattern.
5. Why is [[checking by expansion]] important?
6. Is 3 a common factor of `6x + 9`? Explain.

## B. Core Skill — Common Factor
7. Factorise `6x + 12`.
8. Factorise `10x - 15`.
9. Factorise `8x + 20`.
10. Factorise `9x - 6`.
11. Factorise `12x + 18`.
12. Factorise `5x² + 10x` (take out the HCF).
13. Factorise `4x - 8`.

## C. Core Skill — Quadratic Factorisation
14. Factorise `x² + 5x + 6`.
15. Factorise `x² + 8x + 15`.
16. Factorise `x² + 9x + 20`.
17. Factorise `x² - 5x + 6`.
18. Factorise `x² - 8x + 15`.
19. Factorise `x² + 2x - 8`.
20. Factorise `x² - x - 6`.

## D. Core Skill — Difference of Squares
21. Factorise `x² - 4`.
22. Factorise `x² - 25`.
23. Factorise `x² - 1`.
24. Factorise `4x² - 9`.
25. Can `x² + 16` be factorised using difference of squares? Explain.

## E. Spot the Mistake
26. A learner writes `8x + 12 = 4(8x + 12)`. Correct it.
27. A learner writes `x² + 7x + 12 = (x + 2)(x + 5)`. Correct it.
28. A learner writes `x² - 9 = (x + 3)(x + 3)`. Correct it.
29. A learner stops at `6x + 9 = 3(6x + 9)`. Correct it.

## F. Mixed and CS Transfer
30. Factorise `3x + 3y + 3z`.
31. Check `(x + 5)(x + 2)` by expanding. Does it equal `x² + 7x + 10`?
32. Rewrite `a*b + a*c + a*d` in factorised form.
33. Why does factorising help compilers perform common subexpression elimination?
34. Give one connection between factorising and cryptography.
35. Write one sentence explaining why factorising belongs in a Computer Science maths course.

Pass target: 90%. You should get at least 32 out of 35 correct before taking [[2.4 Factorising - Mastery Test]].
