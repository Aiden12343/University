# 2.7 Inequalities - Practice Questions

Theory note: [[2.7 Inequalities]]

Answers: [[2.7 Inequalities - Answers]]

> [!warning] Practice rule
> Draw a number line for every inequality. Test at least one value from your solution set before checking the answers.

## A. Vocabulary
1. Name the four [[inequality symbols]] and what each means.
2. What is a [[solution set]]?
3. What is a [[number line interval]]?
4. What is the difference between [[strict vs inclusive]] boundaries?
5. When does [[flipping when multiplying by negatives]] apply?
6. In one sentence, explain how solving inequalities relates to [[2.5 Solving Linear Equations]].

## B. Solve Simple Inequalities
7. Solve `x + 3 > 10`.
8. Solve `x - 4 ≤ 5`.
9. Solve `2x < 14`.
10. Solve `3x ≥ 18`.
11. Solve `x + 7 < 2`.
12. Solve `5x - 2 > 13`.
13. Solve `2x + 4 ≤ 16`.
14. Solve `4x - 1 < 11`.

## C. Negative Coefficient (Flip the Sign)
15. Solve `-x > 4`.
16. Solve `-2x ≤ 10`.
17. Solve `-3x > 15`.
18. Solve `-4x ≥ -20`.
19. Solve `6 - 2x < 12`.
20. Solve `5 - x ≤ 1`.

## D. Number Line Representation
21. Draw a number line for `x > 3`.
22. Draw a number line for `x ≤ -2`.
23. Draw a number line for `x ≥ 0`.
24. Draw a number line for `x < -4`.
25. For `x ≥ -1`, is -1 in the solution set? Is -2?

## E. Spot the Mistake
26. A learner writes `-2x > 6` → `x > -3`. Explain the error and solve correctly.
27. A learner uses an open circle for `x ≤ 5`. What is wrong?
28. A learner shades right for `x < 2`. What is wrong?
29. A learner gives `x = 4` as the answer to `x + 1 ≤ 5`. Explain why this is incomplete.
30. A learner writes `x > 5` and includes 5 in the test list. Why is that incorrect?

## F. Computer Science Transfer
31. Write an inequality for "age must be at least 18."
32. Write a compound inequality for valid array indexes: `0 <= index < length`.
33. If `length = 8`, list all valid integer indexes.
34. Explain in one sentence why `index < length` uses strict less-than, not `≤`.
35. Give one example of how Big-O uses inequalities to bound runtime (preview of [[10.1 Big O Theta and Omega]]).

Pass target: 90%. You should get at least 32 out of 35 correct before taking [[2.7 Inequalities - Mastery Test]].
