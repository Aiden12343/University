## Section B - Core Skills
7. For `f(x) = 2x` if `x < 0` and `f(x) = x + 1` if `x ≥ 0`, find `f(-3)` and `f(4)`.
8. For `g(x) = x^2` if `x ≤ 2` and `g(x) = 2x + 1` if `x > 2`, find `g(2)` and `g(3)`.
9. For `h(x) = 5` if `x < 1`, `h(x) = x` if `1 ≤ x ≤ 4`, and `h(x) = -1` if `x > 4`, find `h(0.5)`, `h(2)`, and `h(10)`.
10. Evaluate `⌊6.2⌋` and `⌈6.2⌉`.
11. Evaluate `⌊-6.2⌋` and `⌈-6.2⌉`.
12. Evaluate `⌊0⌋` and `⌈0⌉`.
13. Evaluate `⌊-0.3⌋` and `⌈-0.3⌉`.
14. A step function has `f(x) = 2` on `[0, 3)` and `f(x) = 6` on `[3, 7)`. Find `f(1)`, `f(2.99)`, and `f(3)`.
15. A step function has `f(x) = -1` for `x < 0` and `f(x) = 1` for `x ≥ 0`. Describe the graph.
16. Write a piecewise definition for: "return x when x is between 0 and 5 inclusive, otherwise return 0."
17. For `p(x) = 3x - 1` if `x < 2` and `p(x) = 7` if `x ≥ 2`, find `p(1.5)` and `p(2)`.
18. Is `f(x) = ⌊x⌋` a step function? Explain briefly.

## Section C - Mistake-Spotting
For each question, write the mistake, correction, and reason.

19. A learner uses `f(x) = x^2` at `x = 1` when the rule is `f(x) = x^2` for `x < 1` and `f(x) = 5` for `x ≥ 1`.
20. A learner says `⌊-4.1⌋ = -4`.
21. A learner says `⌈-4.1⌉ = -5`.
22. A learner draws a closed dot at `x = 2` for the rule `f(x) = 3` when `x < 2`.
23. A learner writes overlapping intervals `x ≤ 3` and `x ≥ 3` without specifying which rule wins at 3.

## Section D - Mixed Practice
24. Write the piecewise rule for absolute value: `|x| = x` if `x ≥ 0` and `|x| = -x` if `x < 0`. Find `|-5|` using it.
25. Graph description: `f(x) = 1` on `[0, 2)`, `f(x) = 4` on `[2, 5)`. What is `f(2)`? Is the dot at `(2, 1)` open or closed?
26. Solve: `⌊x⌋ = 3`. What interval does x belong to?
27. Solve: `⌈x⌉ = 3`. What interval does x belong to?
28. A file needs `⌈5001 / 4096⌉` pages. How many?
29. Express `⌈x⌉` in terms of `-⌊-x⌋`.
30. For `f(x) = { 2x, x < 1; x + 3, x ≥ 1 }`, is there a jump at `x = 1`? Find both one-sided values.
31. Write conditions covering all real numbers without overlap for three rules: `x < 0`, middle, `x > 5`.

## Section E - CS Transfer
32. Write a Python if/else chain for: free if `items == 0`, £2 if `items ≤ 5`, else £2 + 0.5 × (items - 5).
33. An API charges 1 credit per call up to 1000 calls, then 0.5 credits per extra call. Write `credits(n)` piecewise.
34. Why does array index `floor(x / bucket_size)` create a step function?
35. A program uses `Math.ceil(total / 10)` for pagination. What does this compute in words?
36. Give one example where using floor instead of ceiling causes a bug in memory allocation.

## Stretch
37. Define `f(x) = x - ⌊x⌋` (fractional part). Find `f(3.7)`, `f(-1.3)`, and describe the graph on `[0, 3)`.
