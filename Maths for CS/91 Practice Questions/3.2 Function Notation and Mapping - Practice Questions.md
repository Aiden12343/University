# 3.2 Function Notation and Mapping - Practice Questions

Theory note: [[3.2 Function Notation and Mapping]]

Answers: [[3.2 Function Notation and Mapping - Answers]]

> [!warning] Practice rule
> Try every question on paper before checking the answers. If you only read the answers, you are training recognition, not recall.

## A. Vocabulary
1. What is a [[function]]?
2. What is an [[input]]?
3. What is an [[output]]?
4. What is the [[domain]]?
5. What is the [[range]]?
6. In one sentence, explain why a rule that gives two outputs for one input is not a function.

## B. Core Skills
7. If `f(x) = 3x + 2`, find `f(4)`.
8. If `g(x) = x - 7`, find `g(10)`.
9. If `h(x) = x^2`, find `h(5)`.
10. If `f(x) = 2x + 1`, find `f(0)`.
11. If `f(x) = 5x - 1`, find x when `f(x) = 14`.
12. If `g(x) = x + 3`, find x when `g(x) = 11`.
13. For `f(x) = 1/(x-2)`, which value of x is not in the domain?
14. For `f(x) = x + 4`, can the output be 9? Show working.
15. Write the coordinates `(x, f(x))` when `f(x) = x + 2` and x = 1, 2, 3.
16. Does this table define a function?

```text
x | y
--+--
1 | 2
2 | 4
3 | 6
```

17. Does this table define a function?

```text
x | y
--+--
1 | 2
1 | 5
2 | 4
```

18. If `f(x) = 2x`, is 20 in the range? Explain.

## C. Spot the Mistake
19. A learner says `f(x)` means `f` times `x`. Explain why this is wrong.
20. A learner evaluates `f(3)` for `f(x) = x^2 + 1` and writes `3x^2 + 1`. What is wrong?
21. A learner says the domain of `f(x) = x + 5` is "only positive numbers." Correct them.
22. A learner maps input 4 to both 7 and 9 and calls it a function. Explain the error.

## D. Mixed Practice
23. If `f(x) = 3x - 2` and `g(x) = x + 1`, find `f(2)` and `g(2)`.
24. Create a mapping diagram for `f(x) = x + 3` with inputs 0, 1, 2.
25. For `f(x) = 2x + 1`, list three outputs in the range when x = 0, 1, 2.
26. Explain the difference between domain and range using `f(x) = x^2`.
27. Write a function rule whose domain excludes x = 5.
28. If `f(x) = -x + 10`, find `f(3)` and `f(-2)`.

## E. Computer Science Transfer
29. In `def greet(name): return "Hello, " + name`, identify the function name, input, and output for `greet("Ada")`.
30. Explain why a hash function must be deterministic (same input → same output).
31. Why does checking `if x == 0` before dividing matter for `return 1/x` in code?
32. Write one sentence linking `f(n)` in Big-O notation to function notation from this topic.

Pass target: 90%. You should get at least 27 out of 32 correct before taking [[3.2 Function Notation and Mapping - Mastery Test]].
