# 3.5 Polynomials - Practice Questions

Theory note: [[3.5 Polynomials]]

Answers: [[3.5 Polynomials - Answers]]

> [!tip] Paper-first rule
> For each polynomial, first write the powers you can see. This prevents most degree, coefficient, and leading-term mistakes.

## How to Use This Practice
Work in order.

Use this checklist beside each algebra question:

```text
terms:
coefficients:
degree:
leading term:
root check if needed:
```

## Section A - Vocabulary
1. Define [[polynomial]].
2. Define [[degree]].
3. Define [[coefficient]].
4. Define [[root]].
5. Define [[leading term]].
6. Give one expression that is not a polynomial and explain why.

## Section B - Core Skills
7. Is `3x^4 - 2x + 1` a polynomial?
8. Is `4/x + 2` a polynomial?
9. Is `sqrt(x) + x^2` a polynomial?
10. Find the degree of `7x^6 - x^2 + 5`.
11. Find the leading term of `-2x + 9x^5 - 3`.
12. List the coefficients in `4x^3 - x^2 + 8x - 6`.
13. Simplify `(2x^3 + x - 4) + (5x^3 - 3x + 9)`.
14. Simplify `(6x^2 - 4x + 1) - (2x^2 + x - 7)`.
15. Expand `x(x^2 + 4x - 3)`.
16. Expand `(x + 2)(x^2 - x + 5)`.
17. Find the roots of `x(x - 3)(x + 4) = 0`.
18. Find the roots of `p(x) = x^2(x - 5)`.

## Section C - Mistake-Spotting
For each question, write the mistake, the correction, and the rule.

19. A learner says `x^2 + x^3 = x^5`.
20. A learner says `10x^2 + 3x^7` has degree 2 because 10 is the largest coefficient.
21. A learner says `1/x + 4` is a polynomial because it has x in it.
22. A learner lists the coefficient of `-x^4` as 1.
23. A learner expands `(x + 1)(x^2 + 2)` as `x^3 + 2`.

## Section D - Mixed Practice
24. Rewrite `3x - 8 + 2x^4 - x^2` in descending powers, then state its degree.
25. Add `(x^4 - 3x^2 + 2x) + (-2x^4 + x^2 - 5)`.
26. Expand `(2x + 3)(x^2 - x + 1)`.
27. Factorise `x^3 - 9x` and find its roots.
28. Is x = 2 a root of `p(x) = x^3 - 5x + 2`? Show substitution.
29. Which term dominates `12n^5 - 30n^3 + 100n` for large n?

## Section E - CS Transfer
30. A program has operation count `T(n) = 4n^2 + 12n + 9`. What term dominates for large n?
31. Is `T(n) = 3n^3 + n` closer to linear, quadratic, or cubic growth for large n?
32. In one sentence, explain why polynomial leading terms matter in Big-O analysis.
33. Name one CS use of polynomial arithmetic outside Big-O.
34. A Reed-Solomon-style code treats data as polynomial values. Why might extra values help recover damaged data?

## Stretch
35. Find the degree, leading term, and roots of `p(x) = x^4 - 5x^2`.

## Self-Check Before Marking
- Did you keep negative signs attached to coefficients?
- Did you combine only like powers?
- Did you use every term when expanding brackets?
- Did you identify roots as x-values?
- Did your CS answer name a concrete algorithm, code, curve, or data process?
