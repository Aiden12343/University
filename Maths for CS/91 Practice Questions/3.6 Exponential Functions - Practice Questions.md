## How to Use This Practice
For each model, write:

```text
initial value:

```

## Section A - Vocabulary
1. Define [[exponential growth]].
2. Define [[growth factor]].
3. Define [[decay factor]].
4. Define [[base]].
5. Define [[asymptote]].
6. Explain the difference between repeated addition and repeated multiplication.

## Section B - Core Skills
7. Is `y = 4 * 2^x` exponential?
8. Is `y = x^4` exponential?
9. Is `y = 20 * 0.6^x` growth or decay?
10. For `y = 9 * 3^x`, state the initial value and growth factor.
11. For `A(t) = 500 * 0.8^t`, state the initial value and decay factor.
12. Find y for `y = 2^x` when x = 5.
13. Find y for `y = 3 * 2^x` when x = 4.
14. Find A for `A(t) = 100 * 0.5^t` when t = 3.
15. Make a table for `y = 4^x` for x = 0, 1, 2, 3.
16. Make a table for `y = 16 * 0.5^x` for x = 0, 1, 2, 3.
17. What is the y-intercept of `y = 11 * 2^x`?
18. What is the horizontal asymptote of `y = 7 * 0.3^x`?

## Section C - Mistake-Spotting
For each question, write the mistake, correction, and reason.

19. A learner says `x^3` is exponential because it has a power.
20. A learner models tripling from 5 as `y = 5 + 3x`.
21. A learner says `100 * 0.5^x` reaches zero at x = 2.
22. A learner says the y-intercept of `y = 6 * 4^x` is 0.
23. A learner says `n^5` must eventually beat `2^n` because 5 is bigger than 2.

## Section D - Mixed Practice
24. Write a model for a quantity that starts at 40 and doubles each step.
25. Write a model for a quantity that starts at 900 and keeps 90% each step.
26. A value starts at 12 and triples each round. What is it after 4 rounds?
27. A value starts at 200 and halves each round. What is it after 5 rounds?
28. Compare `n^2` and `2^n` at n = 6 and n = 10.
29. Explain why the graph of `y = 2^x` is not a straight line.

## Section E - CS Transfer
30. How many bit strings of length 10 are possible?
31. A recursive tree branches into 3 calls per level for 4 levels. How many leaves are possible?
32. A retry delay follows `D(a) = 2^a` seconds. What is the delay at attempt 6?
33. Why can exponential-time brute force become infeasible quickly?
34. Name one CS situation that uses exponential decay.

## Stretch
35. A model is `P(t) = 1200 * 1.15^t`. Find P(3), then explain what 1.15 means.

## Self-Check Before Marking
- Did you check whether x is in the exponent?
- Did you identify b > 1 as growth and 0 < b < 1 as decay?
- Did you use `b^0 = 1` for y-intercepts?
- Did you avoid saying decay reaches zero exactly?
- Did your CS answer name a specific process or algorithm?
