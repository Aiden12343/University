> Draw arrows for function chains. For inverse questions, write the original operations and undo them in reverse order.

## How to Use This Practice

```text

```


## Section A - Vocabulary
1. Define [[inverse function]].
2. Define [[composition]].
3. Define [[identity function]].
4. Define [[one-to-one]].
5. Define [[nested function]].
6. Explain why `f^-1(x)` does not mean `1/f(x)` in this topic.

## Section B - Core Skills
7. If `f(x)=x+2` and `g(x)=3x`, find `f(g(4))`.
8. If `f(x)=x^2` and `g(x)=x-1`, find `f(g(5))`.
9. For `f(x)=2x+1` and `g(x)=x+4`, find `f(g(x))`.
10. For `f(x)=2x+1` and `g(x)=x+4`, find `g(f(x))`.
11. Find the inverse of `f(x)=x+6`.
12. Find the inverse of `f(x)=x-9`.
13. Find the inverse of `f(x)=2x+3`.
14. Find the inverse of `f(x)=5x-4`.
15. Check that `f(x)=x+10` and `h(x)=x-10` are inverses.
16. Check that `f(x)=3x` and `h(x)=x/3` are inverses.
17. Is `f(x)=x^2` one-to-one over all real numbers?
18. Is `f(x)=x+1` one-to-one?

## Section C - Mistake-Spotting
For each question, write the mistake, correction, and reason.

19. A learner calculates `f(g(2))` by doing f first.
20. A learner says `f(g(x))` always equals `g(f(x))`.
21. A learner says the inverse of `f(x)=4x+1` is `4x-1`.
22. A learner says `f^-1(x)` means `1/f(x)`.
23. A learner says `x^2` has a full inverse over all real numbers because square root undoes square.

## Section D - Mixed Practice
24. For `f(x)=x-2` and `g(x)=x^2+1`, find `f(g(x))`.
25. For `f(x)=x-2` and `g(x)=x^2+1`, find `g(f(x))`.
26. Find the inverse of `f(x)=(x+7)/2`.
27. Check whether `f(x)=2x-5` and `h(x)=(x+5)/2` are inverses.
28. State the execution order of `store(validate(parse(input)))`.
29. Give two different inputs showing `f(x)=x^2-3` is not one-to-one over all real numbers.

## Section E - CS Transfer
30. A pipeline is `send(compress(encode(data)))`. What runs first?
31. If `decrypt(encrypt(message)) = message`, what function property is being shown?
32. A toy encoder is `encode(x)=x+21`. Write a decoder.
33. Why is one-to-one behaviour important for decoding?
34. Name one useful CS function that is not meant to be easily inverted.

## Stretch
35. If `f(x)=3x+2` and `g(x)=x^2`, find `f(g(x))`, `g(f(x))`, and explain why they differ.

## Self-Check Before Marking
- Did you work from the inside outward?
- Did you undo inverse operations in reverse order?
- Did you check inverse claims using composition?
- Did you identify one-to-one failures with two different inputs?
- Did your CS answer name a concrete pipeline, codec, or security transform?
