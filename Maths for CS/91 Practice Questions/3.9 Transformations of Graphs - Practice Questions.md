# 3.9 Transformations of Graphs - Practice Questions

Theory note: [[3.9 Transformations of Graphs]]

Answers: [[3.9 Transformations of Graphs - Answers]]

> [!tip] Paper-first rule
> For each question, write: parent graph → transformation list → check point. Track one known point through every step.

## How to Use This Practice
For translation questions, write:

```text
inside or outside change?
direction:
check point:
```

For stretch questions, write:

```text
vertical or horizontal?
scale factor:
reflect? yes/no
```

## Section A - Vocabulary
1. Define [[translation]].
2. Define [[reflection]].
3. Define [[stretch]].
4. Define [[scale factor]].
5. Define [[transformation]].
6. State the rule: outside change affects which coordinate?

## Section B - Core Skills
7. Describe the transformation from `y = x^2` to `y = x^2 + 7`.
8. Describe the transformation from `y = x^2` to `y = x^2 - 3`.
9. Describe the transformation from `y = x^2` to `y = (x - 5)^2`.
10. Describe the transformation from `y = x^2` to `y = (x + 2)^2`.
11. Describe the transformation from `y = x^2` to `y = -x^2`.
12. Describe the transformation from `y = x^2` to `y = (-x)^2`.
13. Describe the transformation from `y = x^2` to `y = 4x^2`.
14. Describe the transformation from `y = x^2` to `y = 0.5x^2`.
15. Describe the transformation from `y = x^2` to `y = (3x)^2`.
16. Describe all transformations in `y = 2(x + 1)^2 - 4`.
17. Describe all transformations in `y = -0.5(x - 3)^2 + 2`.
18. The point `(2, 5)` lies on `y = f(x)`. Where is it on `y = f(x - 1) + 3`?
19. The point `(4, -1)` lies on `y = f(x)`. Where is it on `y = 2f(x)`?
20. The point `(6, 3)` lies on `y = f(x)`. Where is it on `y = f(2x)`?

## Section C - Mistake-Spotting
For each question, write the mistake, correction, and reason.

21. A learner says `f(x - 4)` shifts the graph left 4 units.
22. A learner says `f(3x)` stretches the graph horizontally by factor 3.
23. A learner says `-f(x)` and `f(-x)` always produce the same graph.
24. A learner applies `f(x) + 2` and moves every point right 2 units.
25. A learner says `y = -2f(x)` only stretches vertically and does not reflect.

## Section D - Mixed Practice
26. Start with `y = |x|`. Write the equation after: up 3, then reflect in the x-axis.
27. Start with `y = x^2`. Write the equation after: right 2, then vertical stretch by 3.
28. Write the transformation sequence for `y = -3(x - 1)^2 + 4` starting from `y = x^2`.
29. The vertex of `y = x^2` is `(0, 0)`. Find the vertex of `y = 2(x + 3)^2 - 5`.
30. Which transformation moves `(1, 4)` to `(1, 7)`? Which moves it to `(4, 4)`?
31. Does `y = (-x)^2` differ from `y = x^2`? Explain briefly.
32. Describe the effect of `y = f(0.5x)` on the width of a graph.

## Section E - CS Transfer
33. A sprite at `(10, 8)` is drawn with offset `(3, -2)`. What are the screen coordinates?
34. Write a formula to map pixel value `p` from range [0, 255] to [0, 1].
35. A CSS rule is `transform: scale(2) translateY(10px)`. Does the order matter compared with translate then scale? Explain in one sentence.
36. Why is subtracting the mean in data preprocessing a translation?
37. Name the transformations in `(x - min) / (max - min)` when normalising data.

## Stretch
38. Point `(2, 8)` is on `y = f(x)`. Find its image under `y = -2f(x - 3) + 1`.

## Self-Check Before Marking
- Did you distinguish inside (horizontal) from outside (vertical) changes?
- Did you remember that `f(bx)` compresses when |b| > 1?
- Did you check at least one point after describing a transformation?
- Did your CS answers name concrete objects (sprite, pixel, feature vector)?
