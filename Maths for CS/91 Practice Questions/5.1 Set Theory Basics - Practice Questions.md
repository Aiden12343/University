# 5.1 Set Theory Basics - Practice Questions

Theory note: [[5.1 Set Theory Basics]]

Do these on paper first. Check [[5.1 Set Theory Basics - Answers]] only after making a serious attempt.

## Vocabulary
1. Define set.
2. Define element.
3. Define membership.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Let U = {x ∈ ℕ | x ≤ 15}. Write A = {x ∈ U | x is odd} in roster notation and find |A|.

6. Using U and A from Q5, determine whether 7 ∈ A, 14 ∈ A, and 2 ∉ A. Give a reason for each answer.

7. Let B = {x ∈ U | x is a prime number}. List B in roster notation, find |B|, and state whether B is finite or infinite.

8. Explain why {1, 2, 3, 2} = {1, 2, 3} as sets, citing the specific property of sets that justifies this.

## Error Checking
9. A student writes: "The set {x | x < 10} written in roster notation is {1, 2, 3, 4, 5, 6, 7, 8, 9}." Identify the exact mistake and write the correct roster form.

10. A classmate claims |{∅, {∅}, ∅}| = 3. Verify whether this is correct by first removing any duplicate elements and then computing the cardinality.

## CS Transfer
11. A database table stores user IDs {101, 102, 103, 104}. In one sentence, explain why this collection is a mathematical set rather than an ordered list, naming one property of sets that applies.

12. In one paragraph, explain how the requirement that sets be "well-defined" relates to a boolean data type in programming (where every value is either true or false).

Pass target: 85%. Definitions must be perfect.
