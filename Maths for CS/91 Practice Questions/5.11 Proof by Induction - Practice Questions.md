# 5.11 Proof by Induction - Practice Questions

Theory note: [[5.11 Proof by Induction]]

Do these on paper first. Check [[5.11 Proof by Induction - Answers]] only after making a serious attempt.

## Vocabulary
1. Define base case.
2. Define inductive step.
3. Define induction hypothesis.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Prove by induction that for all n ≥ 1, 1 + 3 + 5 + ... + (2n − 1) = n² (the sum of the first n odd numbers).

6. Prove by induction that 6ⁿ − 1 is divisible by 5 for all n ≥ 1.

7. Prove by induction that 2ⁿ > n for all n ≥ 1. (This is an inequality proof — carefully justify each inequality in the inductive step.)

8. Explain why an induction proof requires both a base case and an inductive step. Use the domino analogy and describe what goes wrong if you omit each part.

## Error Checking
9. A student writes part of an induction proof that "7ⁿ − 2ⁿ is divisible by 5":
   Base: n = 1 → 7¹ − 2¹ = 5, divisible by 5. ✓
   Inductive step: 7^{k+1} − 2^{k+1} = 7·7^k − 2·2^k
   = (5 + 2)·7^k − 2·2^k
   = 5·7^k + 2·7^k − 2·2^k
   = 5·7^k + 2(7^k − 2^k)
   The student stops here. Identify the missing step needed to complete the proof.

10. A classmate says: "I tested 1 + 2 + 3 + ... + n = n(n+1)/2 for n = 1, 2, 3, 4 and it worked, so it must be true for all n." Explain why this is not an induction proof and state the two essential components of a proper induction proof that are missing.

## CS Transfer
11. A recursive factorial function is defined as: factorial(0) = 1, factorial(n) = n × factorial(n−1). In one sentence, identify which part of the function corresponds to the base case and which to the inductive step of an induction proof that factorial(n) = n!.

12. In one paragraph, explain why mathematical induction is the natural method for proving recursive algorithms correct, connecting the inductive hypothesis to the recursive call and the base case to the algorithm's termination condition.

Pass target: 85%. Definitions must be perfect.
