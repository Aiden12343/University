# 5.2 Subsets Unions and Intersections - Practice Questions

Theory note: [[5.2 Subsets Unions and Intersections]]

Do these on paper first. Check [[5.2 Subsets Unions and Intersections - Answers]] only after making a serious attempt.

## Vocabulary
1. Define subset.
2. Define proper subset.
3. Define union.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Let A = {2, 4, 6, 8, 10}, B = {1, 2, 3, 4, 5, 6}, C = {4, 6}. Determine whether each statement is true or false: (a) C ⊆ A (b) C ⊆ B (c) A ⊆ B (d) ∅ ⊆ A (e) B ⊆ A.

6. Using A and B from Q5, compute A ∪ B and A ∩ B. Write each in roster notation.

7. Let U = {x ∈ ℕ | x ≤ 12}. Using A and B from Q5, find A' (the complement of A relative to U). Then determine whether A and B are disjoint, justifying your answer.

8. Explain why {2, 4, 6} ⊆ {1, 2, 3, 4, 5, 6} is true but {2, 4, 6} ∈ {1, 2, 3, 4, 5, 6} is false. Reference the definitions of subset (⊆) and element (∈).

## Error Checking
9. A student writes: "A = {1, 2, 3}, B = {2, 3, 4}. A ∪ B = {1, 2, 2, 3, 3, 4} and A ∩ B = {2, 3}." Identify the exact mistake in the union result and write the correct A ∪ B.

10. A classmate claims that A ∪ B always contains more elements than A ∩ B. Verify or refute this claim by computing both A ∪ B and A ∩ B for A = {1, 2, 3} and B = {1, 2, 3}.

## CS Transfer
11. In SQL, the query `SELECT name FROM rock UNION SELECT name FROM nineties` corresponds to which set operation? In one sentence, describe what the result contains.

12. In one paragraph, explain how the set operations ∪ (union) and ∩ (intersection) correspond to the logical operators OR and AND used in programming conditionals.

Pass target: 85%. Definitions must be perfect.
