# 5.3 Venn Diagrams and Cardinality - Practice Questions

Theory note: [[5.3 Venn Diagrams and Cardinality]]

Do these on paper first. Check [[5.3 Venn Diagrams and Cardinality - Answers]] only after making a serious attempt.

## Vocabulary
1. Define Venn diagram.
2. Define cardinality.
3. Define overlap.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. In a survey of 60 people, 35 like chocolate (C), 28 like vanilla (V), and 15 like both. Apply the inclusion-exclusion principle to compute |C ∪ V|.

6. Using the data from Q5, find how many people like neither chocolate nor vanilla. Then verify by listing the four disjoint region counts (C-only, V-only, both, neither) and checking that they sum to 60.

7. Let U = {n ∈ ℕ | n ≤ 20}. Let A = {multiples of 3 in U} and B = {multiples of 5 in U}. Compute |A|, |B|, and |A ∩ B|. Then use inclusion-exclusion to find |A ∪ B|, and the complement formula to find |(A ∪ B)'|.

8. Explain why the inclusion-exclusion formula includes subtracting |A ∩ B| rather than adding it. Use the idea that |A| + |B| counts the overlap region twice.

## Error Checking
9. A student writes: "|A| = 12, |B| = 7, |A ∪ B| = 19, therefore |A ∩ B| = 0." Identify the hidden assumption in this reasoning and explain why it might be wrong.

10. A classmate claims that |A ∪ B| = |A| + |B| is always true. Test this claim by computing |A ∪ B| and |A| + |B| for A = {1, 2, 3, 4} and B = {3, 4, 5}, and state whether the claim holds.

## CS Transfer
11. A search engine query returns 120 pages containing "python", 80 pages containing "java", and 30 pages containing both. In one sentence, state how many pages contain at least one of the two terms and name the set operation used to compute this.

12. In one paragraph, explain how the inclusion-exclusion principle prevents double-counting in database queries that combine conditions with OR, relating it to the formula |A ∪ B| = |A| + |B| − |A ∩ B|.
