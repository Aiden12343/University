# 5.4 Infinity and Countability - Practice Questions

Theory note: [[5.4 Infinity and Countability]]

Do these on paper first. Check [[5.4 Infinity and Countability - Answers]] only after making a serious attempt.

## Vocabulary
1. Define infinite set.
2. Define countable.
3. Define uncountable.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Show that the set of integers ℤ = {..., −2, −1, 0, 1, 2, ...} is countable by providing an explicit listing (a₁, a₂, a₃, ...). What is the 8th term in your sequence?

6. Show that the set of perfect squares S = {1, 4, 9, 16, 25, ...} has the same cardinality as ℕ by defining a bijection f: ℕ → S.

7. Suppose someone claims to have listed all real numbers between 0 and 1 as follows:
   r₁ = 0.500000...
   r₂ = 0.250000...
   r₃ = 0.125000...
   r₄ = 0.062500...
   r₅ = 0.031250...
   Use Cantor's diagonal argument to construct a number not in this list.

8. Explain why adding the new number from Q7 back into the list does not fix Cantor's argument — that is, why the argument still proves uncountability.

## Error Checking
9. A student argues: "The rational numbers ℚ and the real numbers ℝ are both infinite, so they must have the same cardinality." Identify the mistake and state which set is strictly larger.

10. A classmate claims the set of even numbers E = {2, 4, 6, ...} is half the size of ℕ because it contains only the even naturals. Verify or refute this by describing a bijection between E and ℕ.

## CS Transfer
11. A computer program is a finite string over a finite alphabet. In one sentence, state whether the set of all possible programs is countable or uncountable, and give the reason.

12. In one paragraph, explain why the fact that there are uncountably many functions from ℕ to {0, 1} but only countably many programs proves that most problems cannot be solved algorithmically.

Pass target: 85%. Definitions must be perfect.
