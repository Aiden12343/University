# 5.5 Propositional Logic - Practice Questions

Theory note: [[5.5 Propositional Logic]]

Do these on paper first. Check [[5.5 Propositional Logic - Answers]] only after making a serious attempt.

## Vocabulary
1. Define proposition.
2. Define truth value.
3. Define and.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Let P = T, Q = F, R = T. Evaluate the compound proposition (P ∧ ¬Q) ∨ (¬R ∧ Q), showing each step.

6. Let P = "the file is open", Q = "the system is locked", R = "the user is admin". Translate into propositional logic: (a) The file is open and the system is not locked. (b) The file is open or the user is admin.

7. Using P, Q, R from Q6, write an English sentence for the compound proposition (P ∨ Q) ∧ ¬R.

8. Explain why the order of operations matters by evaluating both ¬P ∧ Q and ¬(P ∧ Q) with P = T, Q = F, and showing they produce different truth values.

## Error Checking
9. A student writes: "¬(P ∧ Q) ≡ ¬P ∧ ¬Q." Identify the mistake and give the correct equivalence from De Morgan's laws.

10. A classmate claims that (P ∧ Q) ∨ (P ∧ ¬Q) ≡ P. Verify whether this is correct by simplifying the left-hand side using logical equivalences (distributivity, complement, identity).

## CS Transfer
11. A login condition is written as: if (loggedIn && !banned) || isAdmin. Identify which logical connectives (∧, ∨, ¬) correspond to &&, ||, and !, and express the condition as a propositional logic formula.

12. In one paragraph, explain how truth tables guarantee that a boolean expression in code will behave predictably for all possible input values, relating this to the 2ⁿ rows needed for n variables.

Pass target: 85%. Definitions must be perfect.
