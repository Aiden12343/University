## Vocabulary
1. Define truth table.
2. Define case.
3. Define tautology.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Build a complete truth table for (P ∧ Q) ∨ ¬P. Include columns for P, Q, P ∧ Q, ¬P, and the final expression.

6. Using the truth table from Q5, classify the proposition (P ∧ Q) ∨ ¬P as a tautology, contradiction, or contingency. Justify your answer.

7. Build a truth table with columns for P, Q, P ∨ Q, ¬(P ∨ Q), ¬P, ¬Q, and ¬P ∧ ¬Q to verify whether ¬(P ∨ Q) ≡ ¬P ∧ ¬Q.

8. Explain why a truth table with 5 atomic propositions must have exactly 32 rows, referencing binary counting and powers of 2.

## Error Checking
9. A student builds a truth table for P ∧ Q with only 3 rows: TT → T, TF → F, FF → F. Identify the missing row (FT) and explain why ignoring it could lead to incorrect conclusions.

10. A classmate claims that since P ∨ ¬P is a tautology, the compound proposition (P ∨ ¬P) ∧ Q must also be a tautology. Test this claim by evaluating the expression when Q = F, and state whether the claim holds.

## CS Transfer
11. A login condition is: (username != "" AND password != "") OR remember_token. State how many atomic propositions it contains and how many rows a complete truth table would require.

12. In one paragraph, explain why exhaustive truth-table testing of a boolean condition provides stronger guarantees than testing a few specific cases, and how the 2ⁿ growth of rows limits this approach in practice.
