# 5.7 Implication and Equivalence - Practice Questions

Theory note: [[5.7 Implication and Equivalence]]

Do these on paper first. Check [[5.7 Implication and Equivalence - Answers]] only after making a serious attempt.

## Vocabulary
1. Define implication.
2. Define converse.
3. Define inverse.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Write the truth table for P → Q (include columns for P, Q, and P → Q). Then state the converse, inverse, and contrapositive of: "If a number is divisible by 6, then it is divisible by 3." Indicate which (if any) is logically equivalent to the original.

6. Using the implication from Q5, answer: (a) Is being divisible by 6 sufficient for being divisible by 3? (b) Is being divisible by 3 necessary for being divisible by 6? Explain each answer in one sentence.

7. Given the premises "If the server is running, then the website loads" and "The website did not load", state the conclusion you can draw and name the inference rule (modus ponens or modus tollens) that justifies it.

8. Explain why P → Q is considered true when P is false (vacuously true). Use the equivalence P → Q ≡ ¬P ∨ Q to support your explanation.

## Error Checking
9. A student argues: "P → Q is true and Q is true, therefore P must be true." Identify the name of this fallacy and give a concrete counterexample using specific propositions.

10. A classmate claims that P → Q and Q → P are logically equivalent. Verify or refute this by building a truth table row for (T, F) and showing that the two columns differ.

## CS Transfer
11. A foreign key constraint in a database says: "If a record in the Orders table references CustomerID X, then X must exist in the Customers table." Express this as an implication A → B and identify which of A or B is the necessary condition.

12. In one paragraph, explain why confusing → (implication) with ↔ (biconditional) in a program specification can introduce bugs — specifically, how "if" when "iff" is intended may allow unintended edge cases.

Pass target: 85%. Definitions must be perfect.
