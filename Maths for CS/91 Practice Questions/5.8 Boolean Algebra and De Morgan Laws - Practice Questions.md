# 5.8 Boolean Algebra and De Morgan Laws - Practice Questions

Theory note: [[5.8 Boolean Algebra and De Morgan Laws]]

Do these on paper first. Check [[5.8 Boolean Algebra and De Morgan Laws - Answers]] only after making a serious attempt.

## Vocabulary
1. Define Boolean variable.
2. Define Boolean expression.
3. Define De Morgan law.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Simplify the Boolean expression (A ∧ B) ∨ (A ∧ ¬B) using the laws of Boolean algebra. Show each step and name the law used (distributive, complement, identity).

6. Apply De Morgan's laws step by step to fully expand and simplify ¬((A ∨ B) ∧ ¬C). Write the final expression.

7. Simplify the Boolean expression (x ∨ y) ∧ (x ∨ ¬y) using the distributive, complement, and identity laws. State the simplified result.

8. Explain why the De Morgan law ¬(x ∧ y) = ¬x ∨ ¬y holds. Reference the truth table of x ∧ y and describe how negation distributes and the operator flips from AND to OR.

## Error Checking
9. A student writes: "¬(x ∧ y) = ¬x ∧ ¬y." Identify the error and state the correct De Morgan law.

10. A classmate claims that x ∨ (x ∧ y) simplifies to x ∧ y. Verify or refute this by applying the absorption law or by building a truth table and comparing the final columns.

## CS Transfer
11. A database query contains the condition: NOT (age > 65 OR status = 'retired'). Rewrite this condition using De Morgan's first law so that NOT applies to each sub-condition individually, and state the rewritten form.

12. In one paragraph, explain how simplifying Boolean expressions reduces the number of logic gates in a circuit and why this matters for chip manufacturing cost and power consumption.

Pass target: 85%. Definitions must be perfect.
