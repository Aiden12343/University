# 6.1 Sequences and Series - Practice Questions

Theory note: [[6.1 Sequences and Series]]

Do these on paper first. Check [[6.1 Sequences and Series - Answers]] only after making a serious attempt.

## Vocabulary
1. Define sequence.
2. Define term.
3. Define series.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. An arithmetic sequence has first term a₁ = 7 and common difference d = 4. Find a₂₀ and the sum S₂₀ of the first 20 terms.

6. A geometric sequence has first term a₁ = 64 and common ratio r = ½. Find a₈ and determine whether the infinite series converges. If so, find S∞.

7. For each sequence, determine whether it is arithmetic, geometric, or neither. Then find the indicated term.
   (a) 2, 5, 10, 17, ... find a₅
   (b) 81, 27, 9, 3, ... find a₇
   (c) 100, 93, 86, 79, ... find a₁₂

8. A nested loop runs i = 1 to n and j = 1 to i, performing one operation per iteration. Use the arithmetic series formula to find the total number of operations when n = 100.

## Error Checking
9. A student writes: "For the arithmetic sequence 3, 7, 11, 15, ..., the 10th term is a₁₀ = 3 + 10 × 4 = 43." Identify the mistake and give the correct value.

10. For the geometric series 1 + 2 + 4 + 8 + ... + 128, compute the sum using the formula Sₙ = a₁(1−rⁿ)/(1−r). Then verify by directly adding all terms.

## CS Transfer
11. In binary search, the search range halves each step. Starting with n = 1024 items, write the sequence of range sizes for each step until the range size is 1. Identify which type of sequence this is and explain why.

12. Sequences are called the "discrete version of functions" because aₙ = f(n) where n ∈ ℕ. Give one example from CS (such as array indexing, loop iteration, or algorithm analysis) where viewing a sequence as a function on natural numbers is useful.

Pass target: 85%. Definitions must be perfect.
