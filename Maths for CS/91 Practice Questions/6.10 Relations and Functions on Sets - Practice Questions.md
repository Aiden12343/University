# 6.10 Relations and Functions on Sets - Practice Questions

Theory note: [[6.10 Relations and Functions on Sets]]

Do these on paper first. Check [[6.10 Relations and Functions on Sets - Answers]] only after making a serious attempt.

## Vocabulary
1. Define relation.
2. Define reflexive.
3. Define symmetric.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Let A = {1, 2, 3} and R = {(1,1), (2,2), (3,3), (1,2), (2,1)}. Check whether R is reflexive, symmetric, and transitive. Is R an equivalence relation?

6. Determine which of the following relations from {1, 2, 3} to {a, b} are functions. For each, explain why or why not.
   R₁ = {(1,a), (2,a), (3,a)}
   R₂ = {(1,a), (2,b)}
   R₃ = {(1,a), (1,b), (2,a)}
   R₄ = {(1,a), (2,b), (3,a)}

7. Consider f: {1, 2, 3} → {a, b, c, d} defined by f(1)=a, f(2)=b, f(3)=c. Is f injective? Is f surjective? Is f bijective? Explain each answer.

8. Given f(x) = x + 1 and g(x) = 2x, compute (g∘f)(3) and (f∘g)(3). Are the two results equal? What does this show about function composition?

## Error Checking
9. A student says: "The relation R = {(1,2), (2,3)} on A = {1, 2, 3} is transitive because there are no violations of the rule aRb ∧ bRc ⇒ aRc." Explain why R is NOT transitive and state which ordered pair must be added to make it transitive.

10. For A = {1, 2} and B = {a, b}, list all 4 possible ordered pairs in A × B. Then count how many subsets of A × B exist (i.e., how many possible relations from A to B). Verify your count against 2^(|A×B|).

## CS Transfer
11. In a university database, a student can enrol in many courses and a course can have many students. Explain why this "Enrolled" relationship is a relation (not a function) and why a function (each input has exactly one output) would be insufficient to model this scenario.

12. Explain why every function is a relation but not every relation is a function. Give one CS example where a non-function relation is needed (e.g., many-to-many relationships in databases, social network friendships, or web page links).

Pass target: 85%. Definitions must be perfect.
