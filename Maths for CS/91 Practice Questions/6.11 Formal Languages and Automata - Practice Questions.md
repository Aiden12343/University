# 6.11 Formal Languages and Automata - Practice Questions

Theory note: [[6.11 Formal Languages and Automata]]

Do these on paper first. Check [[6.11 Formal Languages and Automata - Answers]] only after making a serious attempt.

## Vocabulary
1. Define alphabet.
2. Define string.
3. Define language.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Design a DFA over alphabet {0, 1} that accepts strings where the number of 1s is even. Give the 5-tuple (Q, Σ, δ, q₀, F) and test the strings "110", "101", and "0".

6. Consider the DFA: Q = {q₀, q₁}, Σ = {0,1}, δ(q₀,0)=q₀, δ(q₀,1)=q₁, δ(q₁,0)=q₀, δ(q₁,1)=q₁, F = {q₁}. Simulate the DFA on input "0101". List the state after each symbol and state whether the string is accepted.

7. Write a regular expression over {0,1} for the set of strings that contain at least one 0. Then write a regex for strings that start and end with the same symbol (both 0 and 1, length at least 1).

8. Given the context-free grammar S → aSb | ε, derive the string "aaabbb" step by step (show each sentential form). What language does this grammar generate?

## Error Checking
9. A student draws a DFA with transitions: q₀ with 0 → q₀, q₀ with 1 → q₁, q₁ with 0 → q₀, but q₁ has no transition for input 1. Identify the mistake (what rule of DFA design is violated?) and explain how to fix it.

10. For the DFA in question 6 (strings ending with 1), run the string "100" through the automaton step by step. Then run "101" through and verify both results match the acceptance condition.

## CS Transfer
11. In a compiler, the lexer uses a DFA (derived from regular expressions) to tokenise source code (e.g., recognising identifiers matching [a-zA-Z][a-zA-Z0-9]*). Explain why a DFA is sufficient for tokenisation but parsing nested structures (matching parentheses, nested if-statements) requires a context-free grammar (pushdown automaton) with a stack.

12. Explain the difference between a DFA and an NFA. Why can every NFA be converted to an equivalent DFA (subset construction), and why might the resulting DFA require exponentially more states?

Pass target: 85%. Definitions must be perfect.
