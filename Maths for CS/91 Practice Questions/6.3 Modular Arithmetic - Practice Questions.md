# 6.3 Modular Arithmetic - Practice Questions

Theory note: [[6.3 Modular Arithmetic]]

Do these on paper first. Check [[6.3 Modular Arithmetic - Answers]] only after making a serious attempt.

## Vocabulary
1. Define modulus.
2. Define remainder.
3. Define congruence.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Compute 157 mod 12. Then determine whether 157 ≡ 1 (mod 12). Show the quotient–remainder division for both checks.

6. Compute (48 × 35) mod 11 by first reducing each factor modulo 11, then multiplying, then reducing the result. Verify by computing the full product 48 × 35 and then taking mod 11.

7. Compute 3¹² mod 7 using repeated squaring. Write out the powers 3¹, 3², 3⁴, 3⁸ modulo 7, then combine them to get 3¹².

8. A hash table has 13 buckets using h(k) = k mod 13. Compute the bucket index for each key: 27, 41, 15, 10, 32.

## Error Checking
9. A student writes: "−17 mod 5 = −2 because −17 ÷ 5 = −3 remainder −2." Identify the mistake about the remainder range and give the correct value of −17 mod 5.

10. Compute (24 + 37) mod 10 using the reduction-first method: reduce each term modulo 10, add, and reduce again. Then compute the direct sum (24 + 37) mod 10 to verify the answer matches.

## CS Transfer
11. Using repeated squaring, compute 5⁷ mod 11. Show all intermediate steps (5¹, 5², 5⁴) and write 7 as a sum of powers of 2.

12. Explain why modular arithmetic is called "clock arithmetic." Give one CS example (hashing, cryptography, or circular buffers) where reducing numbers modulo m before operating prevents large intermediate values.

Pass target: 85%. Definitions must be perfect.
