# 6.4 Counting Rules - Practice Questions

Theory note: [[6.4 Counting Rules]]

Do these on paper first. Check [[6.4 Counting Rules - Answers]] only after making a serious attempt.

## Vocabulary
1. Define addition rule.
2. Define multiplication rule.
3. Define case split.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. How many 4-digit PIN codes are possible (digits 0–9, digits may repeat)? Then, using the product rule, how many 4-digit PINs have no repeated digits?

6. A password consists of exactly 4 lowercase letters (26 letters, 5 vowels: a, e, i, o, u). Use the complement rule to find how many passwords contain at least one vowel.

7. How many 8-bit binary strings either start with a 1 or end with 00? Solve using inclusion-exclusion: count those that start with 1, those that end with 00, and subtract the overlap.

8. How many 3-digit numbers (from 100 to 999) have at least one digit equal to 7? Use the complement rule: count numbers with no 7 first (remember the leading digit cannot be 0).

## Error Checking
9. A student says: "A restaurant has 4 starters and 6 mains. Choosing a starter OR a main gives 4 × 6 = 24 options." Identify the mistake (which rule should be used instead?) and give the correct count.

10. Count the number of 4-digit numbers that are even and have no repeated digits. Split into two cases (last digit 0 vs last digit 2,4,6,8) and add the results. Verify the method makes sense by checking that each counted number satisfies all constraints.

## CS Transfer
11. A function has 3 boolean inputs. How many test cases are needed to cover all possible input combinations? If each test case runs in 0.1 seconds, how long does it take to run all tests? (Use the product rule.)

12. Explain why the product rule corresponds to the Cartesian product |A × B| = |A| × |B|. Give one CS example (password security, testing, or search spaces) where counting rules estimate the size of a search space without enumerating.

Pass target: 85%. Definitions must be perfect.
