# 6.6 Recurrence Relations - Practice Questions

Theory note: [[6.6 Recurrence Relations]]

Do these on paper first. Check [[6.6 Recurrence Relations - Answers]] only after making a serious attempt.

## Vocabulary
1. Define recurrence.
2. Define initial condition.
3. Define recursive definition.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Given T(1) = 1, T(n) = T(n−1) + 2n for n > 1, compute T(4) by building up from the base case step by step.

6. Given T(1) = 2, T(n) = 3T(n−1) for n > 1, use the iteration method (expand 3 steps, find the pattern, then write a closed form) to find T(n).

7. Solve T(n) = 4T(n/2) + n using the Master Theorem. Identify a, b, and f(n), compute log_b a, compare f(n) to n^(log_b a), and state which case applies and the Θ class.

8. Compute the Fibonacci numbers F₀ through F₈ where F₀ = 0, F₁ = 1, and Fₙ = Fₙ₋₁ + Fₙ₋₂ for n ≥ 2.

## Error Checking
9. A student solves T(n) = 2T(n/2) + n and writes: "n^(log₂2) = n¹ = n, and f(n) = n = O(n¹), so this is Master Theorem Case 1 and T(n) = Θ(n)." Identify the mistake (which case actually applies?) and give the correct Θ class.

10. Given T(1) = 1 and T(n) = T(n−1) + 3 for n > 1, verify that the closed form T(n) = 3n − 2 is correct by checking T(1), T(2), and T(3).

## CS Transfer
11. Merge sort has recurrence T(n) = 2T(n/2) + n, T(1) = 1. Use the Master Theorem to find its complexity class. Then explain why naive recursive Fibonacci (T(n) = T(n−1) + T(n−2) + 1) is Θ(2ⁿ) and why storing computed values (dynamic programming) improves this to O(n).

12. Explain why every recurrence relation needs at least one base case. Why does the Master Theorem not apply to recurrences of the form T(n) = T(n−1) + n?

Pass target: 85%. Definitions must be perfect.
