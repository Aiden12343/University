# 6.7 Graph Theory Basics - Practice Questions

Theory note: [[6.7 Graph Theory Basics]]

Do these on paper first. Check [[6.7 Graph Theory Basics - Answers]] only after making a serious attempt.

## Vocabulary
1. Define graph.
2. Define vertex.
3. Define edge.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. An undirected graph has V = {A, B, C, D} and E = {A−B, A−C, B−C, B−D}. Find the degree of each vertex and verify the Handshaking Lemma: sum of degrees = 2|E|.

6. For the directed graph with edges A→B, A→C, B→C, C→A, compute the indegree and outdegree of each vertex. Which vertex has the highest total degree?

7. Convert the undirected graph with vertices {A, B, C, D} and edges {A−B, B−C, C−D, A−C} into (a) an adjacency list and (b) an adjacency matrix.

8. In the undirected graph with edges A−B, B−C, C−D, A−C:
   (a) Is there a path from D to A? If so, give one.
   (b) Is the graph connected?
   (c) Does the graph contain a cycle?

## Error Checking
9. A student says: "In an undirected graph with edges A−B and B−C, the degree of B is 1 because B is only directly connected to A." Identify the mistake and give the correct degree of B.

10. For the graph with V = {A, B, C, D} and E = {A−B, B−C, C−D, A−C}, write the adjacency matrix. Then convert your matrix back to an edge list to verify it matches the original edges.

## CS Transfer
11. Four web pages form a directed graph: A links to B and C, B links to C, C links to A, and D links to no one. Draw the directed graph and compute indegree and outdegree for each vertex.

12. Explain why adjacency lists use O(V+E) memory while adjacency matrices use O(V²) memory. For a social network with millions of users where each user has ~100 friends on average, which representation is more efficient and why?
