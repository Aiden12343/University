# 6.8 Trees and Traversal - Practice Questions

Theory note: [[6.8 Trees and Traversal]]

Do these on paper first. Check [[6.8 Trees and Traversal - Answers]] only after making a serious attempt.

## Vocabulary
1. Define tree.
2. Define root.
3. Define leaf.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A tree has 15 vertices. How many edges does it have? Explain which tree property gives this answer.

6. Consider the rooted tree: A is the root, with children B and C. B has children D and E. C has child F. List: (a) the root, (b) leaves, (c) parent of D, (d) children of B.

7. For the binary tree: root A has left child B and right child C; B has left D and right E; C has right F (no left child). Write the preorder, inorder, and postorder traversals.

8. Using the same tree as question 7, find the depth of node E and the height of the tree (longest path from root to a leaf, measured in edges).

## Error Checking
9. A student says: "A connected graph with 6 vertices and 5 edges is definitely a tree." Identify what additional condition is needed and give a counterexample (a connected graph with 6 vertices and 5 edges that is not a tree).

10. For the expression tree where the root is ×, left child is + (with children A and B), and right child is − (with children C and D), write the postorder traversal. Then write the preorder traversal and explain why postorder corresponds to Reverse Polish Notation used in stack-based calculators.

## CS Transfer
11. A Binary Search Tree contains the keys 50 (root), 30 (left of 50), 70 (right of 50), 20 (left of 30), 40 (right of 30), 60 (left of 70), 80 (right of 70). Perform an inorder traversal and explain why the result is the sorted order of keys.

12. Explain why a tree with n vertices always has exactly n−1 edges. Give one CS application where tree traversal is essential (e.g., listing files in a directory tree, evaluating arithmetic expressions, or printing BST keys in order).

Pass target: 85%. Definitions must be perfect.
