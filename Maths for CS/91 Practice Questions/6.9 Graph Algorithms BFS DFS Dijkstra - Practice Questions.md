## Vocabulary
1. Define breadth-first search.
2. Define depth-first search.
3. Define shortest path.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. For the undirected graph with edges A−B, A−C, B−D, B−E, C−F, run BFS starting from A. List the visit order and the distance from A for each node.

6. For the same graph (A−B, A−C, B−D, B−E, C−F), run DFS starting from A assuming neighbours are processed in alphabetical order. List the visit order.

7. For the weighted graph: A−B (weight 4), A−C (weight 2), B−C (weight 1), B−D (weight 5), C−D (weight 3), run Dijkstra's algorithm from source A. After each extraction from the priority queue, record the distances. State the shortest path from A to D and its total weight.

8. Using BFS on the graph A−B, A−C, B−D, B−E, C−F, find the shortest path from A to F. List each step of the BFS parent tracking and the final path.

## Error Checking
9. A student says: "BFS and DFS produce the same visit order on any graph." Consider the line graph A−B−C−D. Run BFS and DFS both starting from A, and show they give different visit orders, demonstrating the claim is false.

10. For the weighted graph from question 7, there are two possible paths from A to D: A−B−D and A−C−D. Compute the total weight of each path and verify that Dijkstra's answer (A−C−D, weight 5) is indeed the shortest.

## CS Transfer
11. GPS navigation uses Dijkstra's algorithm on road networks where edge weights represent travel time. Explain why BFS (which finds the fewest edges) is not sufficient and why Dijkstra requires all edge weights to be non-negative.

12. Explain why BFS uses a queue (FIFO) while DFS uses a stack (LIFO). How do these data structures produce the different exploration patterns of BFS (level-by-level) vs DFS (deep-first)?
