# 7.10 Orthogonality and Least Squares - Practice Questions

Theory note: [[7.10 Orthogonality and Least Squares]]

Do these on paper first. Check [[7.10 Orthogonality and Least Squares - Answers]] only after making a serious attempt.

## Vocabulary
1. Define orthogonal.
2. Define projection.
3. Define least squares.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Determine whether u = [2, 1, -1] and v = [1, 2, 4] are orthogonal by computing their dot product.
6. Project b = [7, 5]ᵀ onto a = [2, 1]ᵀ using the formula proj_a(b) = ((b·a)/(a·a)) × a.
7. Fit a line y = mx + c to the points (1, 3), (2, 5), (3, 8) using the normal equation AᵀAx = Aᵀb. Set up A and b, compute AᵀA and Aᵀb, then solve for [c, m]ᵀ.
8. Apply Gram-Schmidt to v₁ = [1, 2]ᵀ, v₂ = [3, 1]ᵀ to obtain an orthonormal basis. Show each step: normalise the first, project and subtract, then normalise the second.

## Error Checking
9. A student claims that Q = [[1, 0, 0], [0, 1, 0], [0, 0, 2]] is an orthogonal matrix because the columns are orthogonal. Check whether the columns are orthonormal (unit length) and determine whether Q satisfies QᵀQ = I.
10. A classmate fits a line to (0, 1), (1, 2), (2, 4) using the normal equation. They check that AᵀA = [[3, 3], [3, 5]] and compute its determinant as 3×5 - 3×3 = 15 - 9 = 6 ≠ 0, then conclude a unique least squares solution exists. Verify the correctness of their reasoning.

## CS Transfer
11. In linear regression with data points (1, 3), (2, 4), (3, 6), the least squares solution gives the best-fit line y = 1.5x + 1.667. Use this line to predict the y-value when x = 4. What is the residual for the point (3, 6)?
12. In 3D computer graphics, the camera coordinate system uses an orthonormal basis {right, up, look}. Explain why using an orthonormal basis (rather than any arbitrary basis) makes it easier to compute the camera transformation matrix Q, and why Q⁻¹ = Qᵀ is computationally convenient.
