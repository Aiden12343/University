## Vocabulary
1. Define LU decomposition.
2. Define QR decomposition.
3. Define SVD.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Find the LU decomposition of A = [[4, 3], [2, 7]] by performing one Gaussian elimination step and recording the multiplier in L.
6. Compute the QR decomposition of A = [[1, 0], [1, 1], [0, 1]] by applying Gram-Schmidt to its columns to obtain Q and computing R = QᵀA.
7. A = [[3, 0], [0, 1], [0, 0]] has SVD with σ₁ = 3, σ₂ = 1. What is its rank? What is the best rank-1 approximation?
8. A matrix has singular values σ₁ = 8, σ₂ = 2, σ₃ = 0.01. Compute its condition number κ = σ_max / σ_min, and explain how many decimal digits of accuracy would be lost.

## Error Checking
9. A student writes the LU decomposition of [[2, 1], [1, 3]] as L = [[1, 0.5], [0, 1]], U = [[2, 1], [0, 2.5]]. Identify the mistake in L (what shape should L be, and where does the multiplier go?).
10. A classmate claims that for any matrix A, the SVD factors U and V are the same matrix. Using the diagonal matrix D = [[3, 0], [0, 1]], verify whether U = V holds and explain the role of U versus V in the SVD.

## CS Transfer
11. In image compression via SVD, a grayscale image of size 200×300 has singular values σ₁ = 5000, σ₂ = 200, σ₃ = 15, σ₄ = 3, ..., σ₂₀₀ ≈ 0. To achieve a compression ratio of about 10× (store only 10% of the data), how many singular values should you keep? What fraction of the total energy (sum σᵢ²) would be retained by keeping the first two singular values?
12. In a recommendation system using matrix factorisation, a user-movie ratings matrix R (users × movies) is approximated as R ≈ UΣVᵀ using the top k singular values. Explain why the Eckart-Young theorem guarantees this is the optimal rank-k approximation, and how this relates to predicting a user's rating for a movie they have not yet watched.
