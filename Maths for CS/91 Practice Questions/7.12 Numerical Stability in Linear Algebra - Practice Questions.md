# 7.12 Numerical Stability in Linear Algebra - Practice Questions

## Vocabulary
1. Define floating-point error.
2. Define condition number.
3. Define stability.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. In double precision (ε ≈ 2.2×10⁻¹⁶), compute (1 + 10⁻¹⁶) - 1 and explain why the result is not 10⁻¹⁶.
6. A matrix has σ_max = 500 and σ_min = 0.05. Compute κ(A) = σ_max / σ_min and estimate how many decimal digits of accuracy are lost when solving Ax = b.
7. A = [[1, 1], [1, 1.00001]]. Compute det(A) and estimate κ(A). Classify it as well-conditioned or ill-conditioned.
8. For a least squares problem with κ(A) = 10⁸, compare the expected accuracy of the normal equation versus QR decomposition. State how many digits each method loses and which is preferred.

## Error Checking
9. A student claims that solving Ax = b using the normal equation (AᵀAx = Aᵀb) is always better than QR because the normal equation is a simpler formula. For κ(A) = 10⁶, explain why the normal equation loses about 12 digits while QR loses only about 6, and identify which is more stable.
10. A classmate solves Ax = b and gets a tiny residual r = b - Ax ≈ 10⁻¹⁴. They conclude the solution x is highly accurate. Explain why a tiny residual does not guarantee accuracy for ill-conditioned problems, and what role κ(A) plays.

## CS Transfer
11. In ridge regression, the matrix (AᵀA + λI) is used instead of AᵀA. If A has singular values σ₁ = 10, σ₂ = 5, σ₃ = 0.001, compute κ(AᵀA) and κ(AᵀA + λI) for λ = 1. Explain how adding λ improves the condition number and why this matters numerically.
12. In 3D reconstruction from images (Structure from Motion), the system matrix often has a condition number exceeding 10¹². Explain why double-precision floating point (≈ 16 decimal digits) cannot produce reliable results for such a problem, and discuss what practical steps (regularization, preconditioning, higher precision) could help.
