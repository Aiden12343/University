# 7.3 Matrix Multiplication - Practice Questions

Theory note: [[7.3 Matrix Multiplication]]

Do these on paper first. Check [[7.3 Matrix Multiplication - Answers]] only after making a serious attempt.

## Vocabulary
1. Define dot product row by column.
2. Define inner dimension.
3. Define composition.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A = [[2, -1], [3, 4]] and B = [[1, 0], [-2, 3]]. Compute AB.
6. A = [[2, -1], [0, 3], [1, 4]] and v = [2, -3]ᵀ. Compute Av.
7. A = [[0, 1], [1, 0]] and B = [[1, 2], [3, 4]]. Compute AB and BA and explain why they differ.
8. Verify that (AB)C = A(BC) for A = [[1, 2], [0, 1]], B = [[2, 0], [1, 3]], C = [[1, 1], [0, -1]] by computing both sides.

## Error Checking
9. A student computes [[1, 2], [3, 4]] × [[5, 6], [7, 8]] as [[1×5, 2×6], [3×7, 4×8]] = [[5, 12], [21, 32]]. Identify the exact mistake and state the correct name for what they actually computed.
10. A classmate claims AB = BA for A = [[1, 2], [3, 4]] and B = [[0, 1], [1, 0]]. Verify whether this claim is correct by computing both products.

## CS Transfer
11. A neural network layer has weight matrix W = [[1, -2, 3], [0, 4, -1]] (2 output neurons, 3 input neurons) and input vector x = [2, 1, -1]ᵀ. Compute the layer output z = Wx.
12. A 3D graphics vertex v = [x, y, z, 1]ᵀ is transformed by a rotation matrix R (4×4) then a translation matrix T (4×4). Explain why the combined transformation is T(Rv) rather than R(Tv), and state which matrix product gives the single transformation matrix that applies translation after rotation.

Pass target: 85%. Definitions must be perfect.
