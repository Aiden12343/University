# 7.4 Identity and Inverse Matrices - Practice Questions

Theory note: [[7.4 Identity and Inverse Matrices]]

Do these on paper first. Check [[7.4 Identity and Inverse Matrices - Answers]] only after making a serious attempt.

## Vocabulary
1. Define identity matrix.
2. Define inverse matrix.
3. Define singular matrix.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A = [[3, -1, 2], [0, 4, 1]]. Verify AI = A by multiplying A by the correct identity matrix and stating what size identity matrix you used.
6. Use the 2×2 inverse formula to find A⁻¹ for A = [[3, 2], [5, 4]]. Verify your answer by showing A × A⁻¹ = I.
7. Find the inverse of B = [[6, 3], [2, 1]] or explain why it does not exist.
8. Given A⁻¹ = [[2, 1], [5, 3]], recover A using the fact that A = (A⁻¹)⁻¹ and the 2×2 formula.

## Error Checking
9. A student writes that the inverse of [[a, b], [c, d]] is [[-a, -b], [-c, -d]]. Identify the exact mistake and write the correct formula.
10. A classmate claims that for A = [[2, 1], [5, 3]] and B = [[0, 1], [1, 0]], the inverse of the product AB is A⁻¹B⁻¹. Verify whether this is correct by computing (AB)⁻¹ and A⁻¹B⁻¹ and comparing.

## CS Transfer
11. In 3D computer graphics, a camera position is recovered as camera_matrix = inv(view_matrix). If view_matrix = [[1, 0, 0, 2], [0, 1, 0, 3], [0, 0, 1, 4], [0, 0, 0, 1]], explain why this matrix is invertible (what is its determinant?) and comment on what the inverse represents geometrically.
12. The normal equation for linear regression is β = (XᵀX)⁻¹Xᵀy. Explain why XᵀX must be invertible for this equation to work, and what it means if XᵀX is singular.

Pass target: 85%. Definitions must be perfect.
