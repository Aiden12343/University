# 7.5 Determinants - Practice Questions

Theory note: [[7.5 Determinants]]

Do these on paper first. Check [[7.5 Determinants - Answers]] only after making a serious attempt.

## Vocabulary
1. Define determinant.
2. Define area scale.
3. Define volume scale.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Compute det(A) for A = [[2, -3], [1, 5]] using ad - bc. Is A invertible?
6. Compute det(B) for B = [[2, 1, 0], [3, -1, 2], [1, 0, 3]] using Sarrus rule.
7. For A = [[2, 4], [3, d]], find the value of d such that det(A) = 0 (making A singular).
8. If det(A) = 4 and det(B) = 0.5, find det(AB) and det(A⁻¹). Also find det(2A) for a 3×3 matrix A.

## Error Checking
9. A student computes det([[1, 2], [3, 4]]) as 1×4 + 2×3 = 4 + 6 = 10. Identify the exact mistake and compute the correct determinant.
10. A classmate claims that if det(A) = 2 and det(B) = 3, then det(AB) = 5 (because 2 + 3 = 5). Verify whether this is correct by computing the product rule, and if wrong, state the correct relationship.

## CS Transfer
11. In computer graphics, the determinant of a transformation matrix tells you whether it is invertible and how it scales area. A transformation matrix M = [[2, 0], [1, 3]] maps a unit square. Compute det(M) and state: (a) whether M is invertible, (b) by what factor area is scaled, (c) whether orientation is preserved.
12. In machine learning, a covariance matrix Σ must be invertible for the multivariate Gaussian density to be defined. If Σ = [[4, 2], [2, 1]], compute det(Σ) and explain why this covariance matrix would cause numerical problems.

Pass target: 85%. Definitions must be perfect.
