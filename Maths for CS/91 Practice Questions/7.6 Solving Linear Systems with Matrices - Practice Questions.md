## Vocabulary
1. Define linear system.
2. Define augmented matrix.
3. Define row operation.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Write the system 4x - y = 9, 2x + 5y = -3 as Ax = b.
6. Solve the system 3x + 5y = 1, 2x + 4y = 0 using the inverse method (x = A⁻¹b).
7. Solve using Gaussian elimination: x + y + z = 6, 2x - y + z = 3, x + 2y - z = 2. Show the augmented matrix and each row operation.
8. For the system 2x + 3y - z = 5, x - 2y + 4z = -1, 3x + y - 2z = 7: write the augmented matrix [A | b], then explain why the system has a unique solution without solving it (consider shape and invertibility).

## Error Checking
9. A student performs this row operation: R₂ = 2R₂ - R₁ on the augmented matrix [[1, 1 | 3], [2, -1 | 0]]. Identify the exact mistake (is this an allowed elementary row operation?) and describe what operation should have been used instead.
10. A classmate claims the system 2x + 4y = 10, x + 2y = 5 has a unique solution because every linear system has exactly one solution. Verify by attempting Gaussian elimination and commenting on the rank of the coefficient matrix.

## CS Transfer
11. In computer graphics, solving for camera position uses linear systems. If we have the matrix equation [[1, 2], [3, 4]] [x, y]ᵀ = [5, 11]ᵀ, solve for [x, y]ᵀ using the inverse method. What does the solution represent geometrically?
12. In linear regression, the normal equation β = (XᵀX)⁻¹Xᵀy requires solving a linear system. Explain why computing (XᵀX)⁻¹ and then multiplying by Xᵀy is less numerically stable than using np.linalg.solve, and why Gaussian elimination (via LU decomposition) is preferred in practice.
