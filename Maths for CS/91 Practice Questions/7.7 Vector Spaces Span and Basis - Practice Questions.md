# 7.7 Vector Spaces Span and Basis - Practice Questions

Theory note: [[7.7 Vector Spaces Span and Basis]]

Do these on paper first. Check [[7.7 Vector Spaces Span and Basis - Answers]] only after making a serious attempt.

## Vocabulary
1. Define vector space.
2. Define span.
3. Define basis.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Is the set S = {[x, y, z]ᵀ | x + y - z = 0} a subspace of ℝ³? Check all three conditions.
6. What is span{[1, -1]ᵀ, [-2, 2]ᵀ}? Describe the set geometrically and state its dimension.
7. Test whether [1, 2, 1], [2, 1, 0], [0, 3, 2] are linearly independent by solving c₁v₁ + c₂v₂ + c₃v₃ = 0.
8. Determine whether {[2, 1], [1, 3]} is a basis for ℝ². Check both spanning and independence.

## Error Checking
9. A student claims that {[1, 0, 0], [0, 1, 0], [1, 1, 0]} is a basis for ℝ³ because it contains three vectors and ℝ³ has dimension 3. Identify the exact mistake (check linear independence).
10. A classmate claims that S = {[x, y]ᵀ | x + y = 1} is a subspace of ℝ² because it is a line. Check whether S contains the zero vector and whether it is closed under addition, then state your conclusion.

## CS Transfer
11. In PCA (Principal Component Analysis) for dimensionality reduction, a dataset in ℝ¹⁰⁰ (100 features per sample) is projected onto the top 3 principal components. Explain in vector-space terms what this means: what are the original space, the new basis vectors, and the dimension of the reduced space?
12. In computer graphics, a model's local coordinate system uses basis vectors {[1, 0, 0], [0, 1, 0], [0, 0, 1]} in model space. To transform to world space, we use a different basis. Explain why the set of all points reachable by linear combinations of the basis vectors forms a vector space, and why a 3D model with a fixed scale cannot be represented without the origin at (0,0,0).
