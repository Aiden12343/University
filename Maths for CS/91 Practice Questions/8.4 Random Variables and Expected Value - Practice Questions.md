## Vocabulary
1. Define random variable.
2. Define expected value.
3. Define variance.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Let X be the value from a fair six-sided die. Compute E[X] using the formula E[X] = Σ x × P(X=x).

6. A lottery ticket costs $5. You win $100 with probability 0.02, win $10 with probability 0.10, and win nothing otherwise. Compute the expected winnings E[X]. Is buying the ticket a good deal? Show your reasoning.

7. Roll two fair dice. Let X = value on die 1, Y = value on die 2. Use linearity of expectation to compute E[X + Y]. Check your answer by also computing E[2X] directly.

8. A fair six-sided die has μ = 3.5. Compute E[X²] and use it to find Var(X) = E[X²] - μ². Then compute the standard deviation σ.

## Error Checking
9. A student says: "E[X] = 3.5 for a fair die, so the most common roll is 3.5." Identify the mistake and explain what E[X] actually represents.

10. Compute E[X²] and (E[X])² for the die from Q5. Show that they are different, and explain why this difference is related to the definition of variance.

## CS Transfer
11. In randomised quicksort, the expected running time is O(n log n). Explain why the expected value (not the worst case) is often the more useful metric when analysing randomised algorithms.

12. Explain why linearity of expectation holds even for dependent variables. Give a concrete CS example where this property is useful despite dependence between random variables.
