## Vocabulary
1. Define Bernoulli.
2. Define binomial.
3. Define geometric.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A fair coin is flipped 5 times. Let X = number of heads. Assuming X ∼ Bin(5, 0.5), compute P(X = 3) using the binomial formula P(X=k) = C(n,k) × pᵏ × (1-p)ⁿ⁻ᵏ.

6. A website receives an average of λ = 3 visits per minute, modelled as Poisson. Compute P(X = 0) and P(X ≥ 1) for visits in one minute.

7. A factory produces chips with a 5% defect rate. You sample 20 chips. Assuming X ∼ Bin(20, 0.05), compute P(≤ 1 defective) = P(X=0) + P(X=1).

8. A multiple-choice test has 10 questions, each with 4 options. You guess every answer. Let X = number correct. Find E[X] and Var(X) for this Binomial distribution. Then compute P(X ≥ 7) by summing P(X=7) through P(X=10).

## Error Checking
9. A student writes: "X ∼ Bin(20, 0.5), so Var(X) = np = 20 × 0.5 = 10." Identify the mistake and give the correct formula and answer for Var(X).

10. Compute the mean and variance of a Bernoulli(0.3) random variable. Then verify that for a Binomial(10, 0.3), E[X] = 10 × E[Bernoulli] and Var(X) = 10 × Var(Bernoulli).

## CS Transfer
11. Explain why the Binomial distribution requires independent trials. Give a concrete example from computing (e.g., drawing from a dataset without replacement) where the Binomial model would fail.

12. Explain when you would use a Poisson distribution instead of a Binomial. A server gets 15,000 requests with a per-request failure probability of 0.001 — which distribution is more practical and why?
