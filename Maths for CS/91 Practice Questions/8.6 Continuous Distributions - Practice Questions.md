# 8.6 Continuous Distributions - Practice Questions

Theory note: [[8.6 Continuous Distributions]]

Do these on paper first. Check [[8.6 Continuous Distributions - Answers]] only after making a serious attempt.

## Vocabulary
1. Define continuous variable.
2. Define density.
3. Define normal distribution.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. X is uniformly distributed on [0, 10] with PDF f(x) = 0.1 for 0 ≤ x ≤ 10. Compute P(2 ≤ X ≤ 5) as an area under the PDF. Then find the CDF F(7) = P(X ≤ 7).

6. IQ scores follow a normal distribution: IQ ∼ N(100, 15²). Use the empirical rule (68-95-99.7) to find the percentage of people with IQ between 85 and 115, and between 70 and 130.

7. For the IQ distribution N(100, 15²), compute the z-score for an IQ of 110. Then use the empirical rule to find P(IQ ≤ 110).

8. A server's response times follow N(200, 30²) ms. A single request takes 290 ms. Compute its z-score and determine whether it should be flagged as an outlier using the empirical rule.

## Error Checking
9. A student says: "X is uniform on [0, 0.1], so f(0.05) = 10, which means P(X = 0.05) = 10." Identify the exact mistake in interpreting the PDF.

10. For a normal distribution N(μ, σ²), compute the z-score formula for a given x. Then verify that if x = μ + 2σ, the empirical rule says approximately 95% of values lie below this point (actually 97.5%).

## CS Transfer
11. Explain how the Central Limit Theorem allows A/B testing to rely on normal distributions even when the underlying user behaviour (e.g., click or no-click) is far from normal.

12. Explain why P(X = a) = 0 for any specific value a in a continuous distribution, and why this means we must always think about intervals and areas rather than point probabilities.
