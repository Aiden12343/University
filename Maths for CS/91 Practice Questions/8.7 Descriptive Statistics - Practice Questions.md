# 8.7 Descriptive Statistics - Practice Questions

Theory note: [[8.7 Descriptive Statistics]]

Do these on paper first. Check [[8.7 Descriptive Statistics - Answers]] only after making a serious attempt.

## Vocabulary
1. Define mean.
2. Define median.
3. Define mode.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Given the dataset {2, 3, 3, 5, 7}, compute the mean, median, and mode.

6. The same dataset plus an outlier: {2, 3, 3, 5, 7, 100}. Compute the mean and median. Which measure of centre better represents a typical value? Explain why.

7. For the dataset {2, 4, 4, 4, 5, 5, 7, 9}, find the range, the interquartile range (IQR), the sample variance s², and the sample standard deviation s.

8. A company has 10 employees with salaries ($K): {35, 38, 40, 42, 45, 48, 52, 55, 60, 200}. Compute the mean, median, and IQR. Compare the mean and median — what does the difference tell you about the shape (skew) of the distribution?

## Error Checking
9. A student says: "The dataset {1, 2, 3, 4, 100} has mean = 22, so the typical employee earns $22K." Identify the mistake and state which measure of centre would be more appropriate.

10. Compute the five-number summary (min, Q1, median, Q3, max) for {2, 3, 3, 5, 7}. Then check that Q3 - Q1 equals the IQR computed manually.

## CS Transfer
11. In machine learning, many algorithms (e.g., k-NN, SVM, neural networks) perform better when features are standardised: z = (x - μ)/σ. Explain why this pre-processing step uses descriptive statistics and what problem it solves.

12. Explain why the five-number summary (min, Q1, median, Q3, max) and a box plot reveal information that a single number like the mean cannot capture.

Pass target: 85%. Definitions must be perfect.
