# 8.8 Correlation and Regression - Practice Questions

Theory note: [[8.8 Correlation and Regression]]

Do these on paper first. Check [[8.8 Correlation and Regression - Answers]] only after making a serious attempt.

## Vocabulary
1. Define correlation.
2. Define linear regression.
3. Define slope.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. Match each correlation coefficient to its description: r = 0.95, r = -0.50, r = 0.10, r = -0.90. (Options: strong positive, moderate negative, very weak, strong negative)

6. Five students' hours studied (x) and exam scores (y): x = [1, 2, 3, 4, 5], y = [50, 55, 65, 70, 75]. Use the formulas b = r × (sᵧ / sₓ) and a = ȳ - b × x̄ to find the regression line ŷ = a + bx. Given: r ≈ 0.991, sₓ ≈ 1.581, sᵧ ≈ 10.369.

7. From Q6, r ≈ 0.991. Compute R² = r² and interpret what this says about how well hours studied explain exam scores.

8. For the regression line ŷ = 43.5 + 6.5x from Q6, compute the residuals for the student who studied 1 hour (actual y=50) and the student who studied 5 hours (actual y=75). What should the residuals sum to approximately?

## Error Checking
9. A student says: "Ice cream sales and drowning deaths have r = 0.9, so eating ice cream causes drowning." Identify the mistake and explain what lurking variable might explain the correlation.

10. From the data in Q6, manually compute the residual for x=2 (y=55, ŷ=56.5). Then verify the least squares property by checking that this residual squared, plus others, sums to a smaller number than any other line would produce.

## CS Transfer
11. In machine learning, R² is often used to evaluate linear regression models. Explain what R² = 0.72 means in terms of variance explained, and state what the correlation between predicted and actual values would be.

12. Explain why extrapolation — predicting Y for an X value outside the observed data range — is dangerous in regression analysis. Give a concrete CS example.

Pass target: 85%. Definitions must be perfect.
