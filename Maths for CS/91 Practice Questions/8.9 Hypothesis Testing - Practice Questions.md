# 8.9 Hypothesis Testing - Practice Questions

Theory note: [[8.9 Hypothesis Testing]]

Do these on paper first. Check [[8.9 Hypothesis Testing - Answers]] only after making a serious attempt.

## Vocabulary
1. Define null hypothesis.
2. Define alternative hypothesis.
3. Define p-value.
4. Write one sentence explaining the difference between two of the new words.

## Core Skill
5. A coin is flipped 20 times and lands heads 15 times. Test whether the coin is biased towards heads. State H₀ and H₁, compute the p-value (using X ∼ Bin(20, 0.5)), and make a decision at α = 0.05.

6. A manufacturer claims light bulbs last μ₀ = 1000 hours (σ = 50). A sample of 40 bulbs has mean x̄ = 985 hours. Test whether the bulbs fall short. Compute the z-test statistic and the p-value (one-tailed). Use α = 0.05.

7. From the light bulb data in Q6 (x̄ = 985, σ = 50, n = 40), compute the 95% confidence interval for the mean using the formula x̄ ± 1.96 × (σ/√n). Does it include the claimed mean of 1000? What does this suggest?

8. In a medical test, the null hypothesis is "patient is healthy." Define Type I error (false positive) and Type II error (false negative) in this context, and describe a real consequence of each.

## Error Checking
9. A student writes: "p = 0.03 from a hypothesis test, so there is a 3% chance that the null hypothesis is true." Identify the exact mistake: what does the p-value actually measure?

10. For the light bulb test in Q6, verify that the test statistic z = (x̄ - μ₀) / (σ/√n) = -1.897. Then confirm that the one-tailed p-value P(Z < -1.897) ≈ 0.029 leads to rejecting H₀ at α = 0.05.

## CS Transfer
11. In A/B testing, two versions of a webpage are compared. Explain why hypothesis testing is used, what the null hypothesis is in this context, and what "statistically significant at α = 0.05" means for the decision to launch the new version.

12. Explain the multiple testing problem: if you run 100 hypothesis tests at α = 0.05, how many false positives do you expect by chance? Describe how the Bonferroni correction addresses this.
