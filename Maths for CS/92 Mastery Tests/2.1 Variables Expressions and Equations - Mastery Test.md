## Section B - Identify the Parts
7. In `x + 9 = 14`, list the variable and the constants.
8. Which are expressions and which are equations?

```text
(a) 3x
(b) 3x = 12
(c) 8
(d) a + b = c
```

9. In `3t - 2 = 10`, state whether it is an expression or an equation, and list the variable.
10. List the variable and constants in `4x - 1 = 19`.

## Section C - Spot the Mistake
11. A learner says "`2x` means `2 + x`." Explain why this is wrong using `x = 3`.
12. A learner writes "`x + 3` is an equation." What is wrong?
13. A learner solves `x + 5 = 12` and writes `x = 17`. Identify the mistake.
14. A learner checks `x = 2` for `5x = 10` by writing `5 + 2 = 10`. What went wrong?

## Section D - Solve and Substitute
15. Solve `x + 5 = 12`. Check your answer.
16. Solve `n + 7 = 15`. Check your answer.
17. If `x = 3`, find the value of `x + 7`.

20. Is `x = 2` a solution to `5x = 10`? Show substitution working.

## Section E - Computer Science Transfer
