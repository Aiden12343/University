## Section A - Definitions
Each answer must be in your own words.

1. What is a [[function]]?
2. What is an [[input]]?
3. What is an [[output]]?
4. What is the [[domain]]?
5. What is the [[range]]?
6. What rule must every function satisfy about inputs and outputs?

## Section B - Evaluate and Solve
7. If `f(x) = 4x - 1`, find `f(3)`.
8. If `g(x) = x + 6`, find `g(-2)`.
9. If `h(x) = x^2 + 2`, find `h(4)`.
10. If `f(x) = 2x + 5`, find x when `f(x) = 17`.
11. Write coordinates for `f(x) = x + 1` at x = 0, 2, 4.

## Section C - Spot the Mistake
12. A learner writes `f(x) = f × x`. Explain the error.
13. A learner says `(x, y)` with two y-values for x = 3 is still a function. Explain why not.
14. A learner uses x = 0 in `f(x) = 5/x`. What went wrong?

## Section D - Domain, Range, and Tables
15. State the domain of `f(x) = 1/(x + 2)`.
16. For `f(x) = x^2`, can the output be -4? Explain.
17. Does this table define a function? Explain.

```text
x | f(x)
--+-----
2 |  7
3 |  9
2 |  11
```

18. Draw or describe a mapping for `f(x) = 2x` with inputs 1, 2, 3.

## Section E - Computer Science Transfer
19. In `def scale(x): return 0.5 * x`, what is `scale(20)`?
20. Name the input and output when calling `hash("data")`.
21. Explain why pure functions (same input → same output) are easier to test.
22. Why is domain checking like input validation in APIs?
23. Write one sentence linking function notation to algorithm runtime `T(n)`.
24. Give an example of a CS function whose domain excludes certain values.
25. Explain why a vending machine is a good everyday model of a function.
