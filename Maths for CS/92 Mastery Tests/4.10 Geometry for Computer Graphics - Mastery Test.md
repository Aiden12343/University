Answers: [[4.10 Geometry for Computer Graphics - Answers]]

## Section A - Definitions (6 marks)
1. What is model space?
2. What is screen space?
3. What does translation do?
4. What does scaling do to coordinates?
5. What does rotation preserve?
6. What is a normal vector used for?

## Section B - Translation and Scaling (4 marks)
7. Translate (3, 5) by (7, 2).
8. Triangle (1,1), (3,1), (2,4) translated by (4, 0). New vertices?
9. Scale (2, 3) by factor 5.
10. Square (0,0), (1,0), (1,1), (0,1) scaled by 4. New corners?

## Section C - Rotation (3 marks)
11. Rotate (6, 0) by 90°.
12. Rotate (0, 5) by 180°.
13. Rotate (2, 0) by 60°. cos 60° = 0.5, sin 60° = √3/2 ≈ 0.866.

## Section D - Lighting (3 marks)
14. N = (0, 1, 0), L = (1, 1, 0) normalised. Compute diffuse.
15. N = (0, 0, 1), L = (0, 1, 1) normalised. Compute diffuse.
16. Why must L be normalised before computing dot product with N?

## Section E - CS Transfer (9 marks)
17. A model vertex at (2, 0, 0) in model space. World position (10, 5, 0). World vertex position?
18. A camera at z = -10 sees object at z = 30. Camera-space z?
19. A button scales 2×. Original size (40, 20). New size?
20. A game object rotates 90°/s. After 3 seconds, total rotation in radians?
21. Why does transformation order matter?
22. In the graphics pipeline, what does the projection matrix do?
23. Explain how diffuse lighting uses the dot product.
24. A 2D point (4, 3) is rotated 90° then translated by (5, 5). Where does it end?

## Marking
Total: 25 marks. Pass: 23/25 + 6/6 Section A.
