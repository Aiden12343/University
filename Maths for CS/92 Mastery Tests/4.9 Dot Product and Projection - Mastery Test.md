# 4.9 Dot Product and Projection - Mastery Test

Theory note: [[4.9 Dot Product and Projection]]

Answers: [[4.9 Dot Product and Projection - Answers]]

Pass mark: 90%. Full marks on Section A required.

> [!danger] Test condition
> Do without notes. Use paper.

## Section A - Definitions (6 marks)
1. What is the dot product of two vectors?
2. Is the result a scalar or vector?
3. What does a·b = 0 mean?
4. Write the geometric formula for a·b.
5. What is projection?
6. What is a normal vector?

## Section B - Compute Dot Products (4 marks)
7. a = (2, 3), b = (5, 6). Find a·b.
8. a = (1, 0, 0), b = (0, 1, 0). Find a·b.
9. |a| = 6, |b| = 5, θ = 60°. Find a·b.
10. a = (4, 1), b = (2, -3). Find a·b.

## Section C - Angles and Orthogonality (4 marks)
11. a = (1, 0), b = (1, √3). Find θ.
12. Are (3, 4) and (4, -3) orthogonal?
13. a·b = 20, |a| = 5, |b| = 8. Find cos θ.
14. Find k so (4, k) ⟂ (3, -6).

## Section D - Projection (3 marks)
15. a = (6, 0), b = (4, 3). Find proj_a(b).
16. a = (2, 0), b = (5, 5). Find proj_a(b).
17. a = (1, 0, 0), b = (2, 3, 4). Find proj_a(b).

## Section E - CS Transfer (8 marks)
18. Surface normal N = (0, 1), light L = (1, 1) normalised. Diffuse brightness?
19. Two ML vectors have dot = 0.99, |a| = 1, |b| = 1. What is cos θ?
20. Work = force·displacement. F = (8, 0), d = (3, 4). Find work.
21. In Unity, facing = (1, 0), to-target = (3, 4). Is target in front? (Dot > 0?)
22. Light L = (0, 1, 1) normalised, N = (0, 0, 1). Compute diffuse.
23. Explain why dot = 0 means orthogonal (not "no result").
24. Cosine similarity between two vectors is -0.5. Are they similar or opposite?

## Marking
Total: 25 marks. Pass: 23/25 + 6/6 Section A.
