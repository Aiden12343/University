2. Opposites are numbers the same distance from zero on opposite sides, such as 8 and -8.
3. Adding a negative moves left on the number line.
4. Subtracting a negative moves right on the number line.
5. Absolute value is distance from zero.
6. Distance is not negative, so absolute value is never negative.

### G. Computer Science Transfer
40. Examples: `temperature = -4`, `offset = -3`, `balance = -20`, `x = -12`.
41. Example: `x = -6` or `y = -10`.
42. A negative offset can mean moving left, down, backward, earlier, or toward a smaller index/value.
43. Programs may need values below zero for coordinates, losses, balances, sensor readings, offsets, or differences.
44. Position `-6` means 6 units in the negative direction. Distance `|-6|` means 6 units away, ignoring direction.

### H. Error Checking
45. `-10` is further left than `-2`, so `-10 < -2`.
46. Absolute value is distance from zero, so `|-5| = 5`.
47. Adding `-9` moves left. Correct: `4 + (-9) = -5`.
48. Subtracting a negative moves right. Correct: `4 - (-9) = 13`.
