# 10.1 Big O Theta and Omega - Answers

Practice note: [[10.1 Big O Theta and Omega - Practice Questions]]
Theory note: [[10.1 Big O Theta and Omega]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- Big O: define it in one sentence and include a tiny example.
- Big Theta: define it by saying what it measures, names, or transforms.
- Big Omega: connect it to the main idea: Classify algorithm growth rates.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Complexity notation predicts how programs scale.

It should also explain what would go wrong in software if the concept were misunderstood.
