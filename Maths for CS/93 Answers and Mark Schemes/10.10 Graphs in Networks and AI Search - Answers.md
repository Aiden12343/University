## Vocabulary Answers
- state graph: define it in one sentence and include a tiny example.
- network graph: define it by saying what it measures, names, or transforms.
- heuristic: connect it to the main idea: Apply graph theory to real CS systems.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Routing, AI planning, compilers, and package managers use graphs.

It should also explain what would go wrong in software if the concept were misunderstood.
