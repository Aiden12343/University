## Vocabulary Answers
- type: define it in one sentence and include a tiny example.
- proposition as type: define it by saying what it measures, names, or transforms.
- inference rule: connect it to the main idea: See types and programs as mathematical objects.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Advanced programming languages and proof assistants rely on type theory.

It should also explain what would go wrong in software if the concept were misunderstood.
