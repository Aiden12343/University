These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- binary: define it in one sentence and include a tiny example.
- hexadecimal: define it by saying what it measures, names, or transforms.
- bit: connect it to the main idea: Represent numbers in bases used by computers.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Computer memory and machine instructions are built from binary.

It should also explain what would go wrong in software if the concept were misunderstood.
