# 10.5 Hashing and Checksums - Answers

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- hash function: define it in one sentence and include a tiny example.
- collision: define it by saying what it measures, names, or transforms.
- checksum: connect it to the main idea: Use maths to map data to compact fingerprints.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Hash tables, file integrity, and security use hashing.

It should also explain what would go wrong in software if the concept were misunderstood.
