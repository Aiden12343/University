These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- public key: define it in one sentence and include a tiny example.
- private key: define it by saying what it measures, names, or transforms.
- RSA: connect it to the main idea: Use number theory for secure communication.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Modern security depends on mathematical hardness assumptions.

It should also explain what would go wrong in software if the concept were misunderstood.
