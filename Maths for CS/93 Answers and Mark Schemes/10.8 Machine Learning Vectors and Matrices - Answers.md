## Vocabulary Answers
- feature vector: define it in one sentence and include a tiny example.
- weight vector: define it by saying what it measures, names, or transforms.
- matrix multiplication: connect it to the main idea: Connect ML models to vector and matrix operations.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Most ML libraries are built on linear algebra.

It should also explain what would go wrong in software if the concept were misunderstood.
