## Vocabulary Answers
- neuron: define it in one sentence and include a tiny example.
- activation function: define it by saying what it measures, names, or transforms.
- weight: connect it to the main idea: Understand weights, activations, layers, and loss.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Neural networks are compositions of matrix operations and nonlinear functions.

It should also explain what would go wrong in software if the concept were misunderstood.
