These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- reduction: define it in one sentence and include a tiny example.
- NP-complete: define it by saying what it measures, names, or transforms.
- co-NP: connect it to the main idea: Go beyond basic P and NP into reductions and hierarchy ideas.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Complexity theory explains what efficient computation may or may not achieve.

It should also explain what would go wrong in software if the concept were misunderstood.
