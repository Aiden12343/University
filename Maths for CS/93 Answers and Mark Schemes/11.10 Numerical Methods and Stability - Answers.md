These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- iteration: define it in one sentence and include a tiny example.
- convergence: define it by saying what it measures, names, or transforms.
- stability: connect it to the main idea: Approximate solutions while managing error.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Scientific computing and ML depend on stable numerical approximations.

It should also explain what would go wrong in software if the concept were misunderstood.
