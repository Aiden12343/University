These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- category: define it in one sentence and include a tiny example.
- object: define it by saying what it measures, names, or transforms.
- morphism: connect it to the main idea: Study structure-preserving maps at a beginner level.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Functional programming and semantics borrow ideas from category theory.

It should also explain what would go wrong in software if the concept were misunderstood.
