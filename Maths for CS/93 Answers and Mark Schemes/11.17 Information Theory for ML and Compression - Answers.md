## Vocabulary Answers
- KL divergence: define it in one sentence and include a tiny example.
- cross entropy: define it by saying what it measures, names, or transforms.
- mutual information: connect it to the main idea: Use entropy and divergence in advanced data systems.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Modern ML losses and compression theory share information-theoretic roots.

It should also explain what would go wrong in software if the concept were misunderstood.
