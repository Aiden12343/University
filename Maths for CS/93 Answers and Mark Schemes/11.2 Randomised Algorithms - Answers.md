## Vocabulary Answers
- randomised algorithm: define it in one sentence and include a tiny example.
- Las Vegas algorithm: define it by saying what it measures, names, or transforms.
- Monte Carlo algorithm: connect it to the main idea: Use randomness to design efficient algorithms.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Randomisation helps hashing, primality tests, sampling, and distributed systems.

It should also explain what would go wrong in software if the concept were misunderstood.
