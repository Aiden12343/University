These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- matching: define it in one sentence and include a tiny example.
- flow network: define it by saying what it measures, names, or transforms.
- cut: connect it to the main idea: Study deeper graph structure and algorithms.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Advanced graph theory supports networks, compilers, logistics, and verification.

It should also explain what would go wrong in software if the concept were misunderstood.
