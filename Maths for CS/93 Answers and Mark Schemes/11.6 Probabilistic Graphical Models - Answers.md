## Vocabulary Answers
- Bayesian network: define it in one sentence and include a tiny example.
- Markov random field: define it by saying what it measures, names, or transforms.
- conditional independence: connect it to the main idea: Represent uncertain systems with graph structure.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: PGMs support diagnosis, NLP, robotics, and causal modelling.

It should also explain what would go wrong in software if the concept were misunderstood.
