## Practice Answers

### A. Vocabulary
1. A variable is a letter or symbol that stands for a number that is unknown or can change.
2. A constant is a fixed number that does not change, such as `3` or `-5`.
3. An expression is a maths phrase made from numbers, variables, and operations, without an equals sign.
4. An equation is a statement that two expressions are equal, using an equals sign.
5. A solution is the value of the variable that makes an equation true.
6. An expression is a phrase with no equals sign; an equation is a full statement claiming two sides are equal.

### B. Identify the Parts
7. Variable: `x`. Constants: `3`, `11`.
8. Variable: `n`. Constants: `2`, `5`, `17`.
9. Variable: `t`. Constants: `3`, `-2`, `10`.
10. Expressions: **(a) 4x + 1**, **(c) 15**. Equations: **(b) 4x + 1 = 9**, **(d) y = y + 0**.
11. `2x + 5` is an **expression** because it has no equals sign.
12. `x + 3 = 11` is an **equation** because it uses `=` to claim both sides are equal.

### C. Spot the Mistake
13. Having a variable does not make something an equation. `x + 3` has no equals sign, so it is an **expression**.
14. With `x = 2`: `3x = 6` but `3 + x = 5`. So `3x ≠ 3 + x`. The mistake is treating multiplication as addition.
15. The learner added 5 to both sides incorrectly. Correct working: `x = 12 - 5`, so **x = 7**.
16. `5x` means `5 × x`, not `5 + x`. Correct check: `5(2) = 10` ✓.

### D. Substitution and Solving
17. `4 + 3 = 7`
18. `5 + 2 = 7`
19. `2(6) + 1 = 12 + 1 = 13`
20. `x = 11 - 3 = 8`. Check: `8 + 3 = 11` ✓.
21. `n = 15 - 7 = 8`. Check: `8 + 7 = 15` ✓.
22. `t = 20 - 4 = 16`. Check: `16 + 4 = 20` ✓.
23. `3 + 4 = 7` ✓. Yes, **x = 5** is a solution.
24. `5(2) = 10` ✓. Yes, **x = 2** is a solution.

### E. Computer Science Transfer
25. `lives` is a **variable** — it names a storage location whose value can change during the program.
26. When you call `double(7)`, `n` stands for **7**, and the function returns `2 × 7 = 14`.
27. This models an **equation** — it states that memory used plus buffer equals the limit.
28. Substitution tests whether a value makes an equation true, just as sample input tests whether code produces the expected output.
