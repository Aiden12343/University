## Practice Answers

### A. Vocabulary
1. A term is one part of an expression, separated by plus or minus signs.
2. A coefficient is the number multiplying a variable in a term.
3. Like terms have exactly the same variable part.
4. To simplify means to rewrite an expression in a shorter equivalent form, usually by collecting like terms.
5. Substitute the same value into both the original and simplified forms; if the results match, the simplification is likely correct.
6. The coefficient of `x` is **5**.

### B. Core Skill — Identify Parts
7. Terms: `3x`, `7`, `-2`.
8. Terms: `x`, `-4`, `2y`, `-1`.
9. Coefficient: **8**.
10. Coefficient: **-2**.
11. Like terms: `4x` and `-2x` (both are `x` terms). `4y` is not like either. `4` is a constant.

### C. Core Skill — Simplify
12. **8x**
13. **5x**
14. `4x - x + 7 + 2` = **3x + 9**
15. `6x - 2x + 1 + 4` = **4x + 5**
16. `9x - 4x - 5 + 3` = **5x - 2**
17. `3x - x + 2y + y` = **2x + 3y**
18. `7a - 2a + 4b + b - 3` = **5a + 5b - 3**
19. `x + x + x + 5` = **3x + 5**
20. `10 - 4 - 3x + 2x` = **6 - x**

### D. Spot the Mistake
21. The variable `x` was dropped. Correct answer: **8x**.
22. Unlike terms cannot be combined into one term. Correct answer stays **3x + 4y**.
23. Correct: `5x - 2x = **3x**`.
24. First error: `4 - 2x + x` should be `4 - x`, not `4 - x` then wrongly combined. Second error: `4 - x` cannot become `3x`. Correct simplification: **4 - x**.

### E. Mixed
25. `2x - x + 3 + 7 - 4` = **x + 6**
26. Original: `4(2) + 1 - 2 + 2 = 8 + 1 - 2 + 2 = 9`. Simplified: `3(2) + 3 = 6 + 3 = 9`. ✓
27. Original: `7(0) - 3 + 2(0) + 1 = -3 + 1 = -2`. Simplified: `9(0) - 2 = -2`. ✓
28. Any valid answer, e.g. `3x + 2x + 1` or `7x - 2x + 1`.
29. `x` has a variable part; `3` is a constant with no variable. They are different kinds of term.
30. `6x - 2x + 5` = **4x + 5**.

### F. Computer Science Transfer
31. Before: root `+`, left branch `+` with children `2x` and `3x`, right branch `1`. After: root `+`, left branch `5x`, right branch `1`.
32. Collecting like terms / algebraic simplification.
33. Fewer operations at runtime; cleaner intermediate representation; easier further optimisation.
34. Merging redundant filter conditions, combining repeated column calculations, or simplifying boolean expressions.
35. A good answer mentions expression trees, compiler optimisation, symbolic maths, or reducing redundant computation.

## Mastery Test Answers

1. A term is one part of an expression, separated by plus or minus signs.
2. A coefficient is the number multiplying a variable in a term.
3. Like terms have exactly the same variable part.
4. To simplify means to rewrite an expression in a shorter equivalent form without changing its value.
5. Substitution means replacing a variable with a number and calculating the result.
6. Terms: `5x`, `-2`, `3y`, `-4`.
7. Coefficient: **-4**.
8. `6x - 2x + 3 + 1` = **4x + 4**.
9. `9x - 5x - 4 + 2` = **4x - 2**.
10. `4x - x + 3y + 2y + 5` = **3x + 5y + 5**.
11. `8 - 1 - 3x + 2x` = **7 - x**.
12. Correct: `5x - 3x = **2x**`. The variable was dropped.
13. No. `2x` and `3y` have different variable parts and must stay as two terms.
14. Original: `5(4) + 2 - 4 + 3 = 20 + 2 - 4 + 3 = 21`. Simplified: `4(4) + 5 = 16 + 5 = 21`. ✓
15. Possible answers: dropping the variable after combining coefficients; combining unlike terms; sign errors when grouping.
16. `6x - 1`.
17. `4a + 3b - 4`.
18. Any valid four-term expression simplifying to `2x + 6`, e.g. `5x + 3 - 3x + 3`.
19. Grouping puts like terms together so signs stay attached to the correct term and you combine one type at a time.
20. `3x + 2x + 5 = 5x + 5`. If `3x + 5 = 20`, then `3x = 15`, so `x = 5`. Check: `5(5) + 5 = 30` — note the original equation was `3x + 5 = 20`, giving `x = 5`; the combined form `5x + 5 = 30` is a different expression. Accept answers that recognise `3x + 5 = 20` gives `x = 5`.
21. Before: `+` with children `3x` and `4x`. After: single node `7x`.
22. An expression tree (or abstract syntax tree).
23. To reduce the number of operations and simplify further analysis or optimisation.
24. Compiler constant folding, SymPy symbolic simplification, SQL query optimisation, shader code generation.
25. A good answer mentions fewer nodes in expression trees, faster evaluation, or cleaner generated code.

## Mark Scheme
- Section A (Definitions): 5 marks (1 each; all required to pass)
- Section B (Identify and Simplify): 6 marks
- Section C (Mistakes and Checking): 4 marks
- Section D (Mixed): 5 marks
- Section E (CS Transfer): 5 marks

Total: 25 marks.

Pass requires 23 out of 25 overall and 5 out of 5 on definitions.

Common wrong answers:
- `7x - 4x = 3` instead of `3x` — deduct 1 mark per occurrence
- Combining unlike terms — deduct full marks for that question
- Forgetting negative coefficients in `7 - 4x` — accept if learner identifies `-4`
