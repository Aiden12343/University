## Practice Answers

### A. Vocabulary
1. `a(b + c) = ab + ac`
2. A single bracket has one multiplier outside one pair of brackets, e.g. `3(x + 2)`.
3. A double bracket is two bracketed expressions multiplied together, e.g. `(x + 2)(x + 3)`.
4. The area model uses a rectangle split into sub-rectangles to show expansion as length × width.
5. Signs must be applied to every inside term; negative multipliers flip signs correctly.
6. `2x + 2`.

### B. Core Skill — Single Brackets
7. **3x + 12**
8. **10x - 5**
9. **-2x - 6**
10. **-x + 5**
11. **4x + 8y - 4**
12. `2x + 6 + 5` = **2x + 11**
13. `3x - 6 - 2x - 2` = **x - 8**
14. **-8 + 4x**
15. **x² + 3x**

### C. Core Skill — Double Brackets
16. **x² + 5x + 4**
17. **x² + 5x + 6**
18. **x² + 3x - 10**
19. **x² + 6x - 7**
20. **x² - 5x + 6**
21. Four regions: `x²`, `3x`, `2x`, `6`. Total: **x² + 5x + 6**.

### D. Spot the Mistake
22. Correct: **5x + 10**.
23. Correct: **-3x + 3**.
24. Missing the `x` terms (`5x`); constant should be 6 not 6 alone — actually `x² + 6` missed both middle terms and used wrong constant (should be x² + 5x + 6).
25. Correct: **-x - 4**.

### E. Mixed
26. `2x + 2 + 3x + 6` = **5x + 8**
27. `4x - 4 - 2x - 6` = **2x - 10**
28. `x² + 2x + 2x + 4` = **x² + 4x + 4**
29. Before: `3(2 + 1) = 9`. After: `6 + 3 = 9`. ✓
30. Expanding removes brackets; simplifying collects like terms to give the cleanest form.

### F. Computer Science Transfer
31. **scale * r + scale * g + scale * b**
32. Fewer loop-control overheads; enables instruction-level parallelism; easier for the compiler to optimise.
33. The distributive law.
34. Constant folding, common subexpression elimination, or preparing for further algebraic simplification.
35. A good answer mentions loop unrolling, compiler optimisation, symbolic algebra, or making implicit multiplications explicit.

## Mastery Test Answers

1. The distributive law says a(b + c) = ab + ac — multiply the outside term into each inside term.
2. A single bracket has one multiplier outside one pair of brackets.
3. A double bracket is two bracketed expressions multiplied together.
4. A rectangle diagram split into sub-rectangles to visualise expansion.
5. Careful use of positive and negative signs when multiplying terms.
6. **4x + 20**
7. **-3x + 6**
8. **6x - 8**
9. **-x - 6**
10. `3x + 6 + 2x - 2` = **5x + 4**
11. **x² + 6x + 8**
12. **x² + 4x - 5**
13. **x² - x - 6**
14. Four labelled regions: `x²`, `3x`, `x`, `3`. Total: **x² + 4x + 3**.
15. Correct: **6x + 6**. The 6 must multiply both terms.
16. Correct: **-2x + 8**. `-2 × (-4) = +8`.
17. `5x + 5 - 3x + 6` = **2x + 11**
18. **x² + 6x + 9**
19. The minus in front applies to both terms: `-(x - 4) = -1 × x + (-1) × (-4) = -x + 4`.
20. Left: `2(3 + 1) = 8`. Right: `2(3) + 2 = 8`. ✓
21. **ka + kb**
22. Unrolling a `for i in range(3)` loop into three explicit statements.
23. To reveal structure for further simplification, pattern matching, or equivalence checking.
24. Expanded: `total = n * x + n * y + n * z` — each inside term gets multiplied by n.
25. A good answer mentions loop unrolling, compiler transforms, or symbolic expansion tools.
