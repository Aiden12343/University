## Practice Answers

### A. Vocabulary
1. A formula is an equation linking two or more quantities using letters and operations.
2. The subject is the single variable written alone on one side of the formula.
3. To isolate a letter means to get it alone on one side by undoing other operations.
4. An inverse operation undoes another operation, such as subtraction undoing addition.
5. To substitute means to replace a letter with a number and calculate.
6. Rearranging is solving the formula for a different letter using the same balancing and inverse-operation steps.

### B. One-Step Rearrangements
7. `w = A/l`
8. `t = d/s`
9. `s = d/t`
10. `m = F/a`
11. `a = F/m`
12. `b = A/h`
13. `h = A/b`
14. `r = C/(2π)`

### C. Two-Step Rearrangements
15. `u = v - at`
16. `t = (v - u)/a`
17. `x = (y - 1)/2`
18. `x = (y + 4)/3`
19. `x = (y - 2)/5`
20. `C = (5/9)(F - 32)` or equivalent `(F - 32) × 5/9`

### D. Substitute and Check
21. `t = 3`. Check: `120 = 40 × 3`.
22. `u = 20`. Check: `30 = 20 + 10`.
23. `x = 4`. Check: `11 = 2(4) + 3`.
24. `w = 5`. Check: `45 = 9 × 5`.
25. `s = 25`. Check: `200 = 25 × 8`.

### E. Spot the Mistake
26. They divided before subtracting. Correct: `x = (y - 3)/2`.
27. Moving `at` across the equals sign changes sign. Correct: `u = v - at`.
28. `s` is multiplied by `t` in the original, so divide: `s = d/t`, not multiply.
29. A mistake in rearrangement may still pass a self-consistent wrong formula; the original is the ground truth.
30. Division by zero is undefined; `s = 0` makes `t = d/s` invalid.

### F. Computer Science Transfer
31. `def celsius_from_fahrenheit(F): return (F - 32) * 5 / 9`
32. `inches = pixels / dpi`; e.g. `inches = pixels / dpi`
33. `time_per_item = total_time / count`
34. It computes the wrong value because operations are undone in the wrong order.
35. Programs often need to compute different variables from the same relationship (e.g. reverse conversions, solve for rate or time).

## Mastery Test Answers

### Section A - Definitions
1. A formula is an equation connecting quantities with letters.
2. The subject is the variable isolated on one side of the formula.
3. To isolate means to get the subject alone by inverse operations.
4. An inverse operation undoes another (e.g. division undoes multiplication).
5. To substitute is to replace letters with numbers and evaluate.
6. Rearranging applies the same balancing and inverse steps as solving an equation, but for a named letter.

### Section B - Make the Subject
7. `t = d/s`
8. `u = v - at`
9. `x = (y - 3)/4`
10. `x = (y + 7)/2`
11. `m = E/c²`
12. `C = (5/9)(F - 32)`

### Section C - Substitute and Check
13. `t = 180/45 = 4`. Check: `180 = 45 × 4`.
14. `x = (19 - 3)/4 = 4`. Check: `19 = 4(4) + 3`.
15. `s = 240/8 = 30`. Check: `240 = 30 × 8`.

### Section D - Spot the Mistake
16. Divided before subtracting. Correct: `x = (y - 2)/3`.
17. `m` is multiplied by `a`, so `m = F/a`, not `F × a`.
18. The original formula validates the relationship; checking only the rearranged form can hide algebraic errors.

### Section E - CS Transfer
19. `def time_from_distance_speed(distance, speed): return distance / speed`
20. `x = (y - c) / m`
21. You must subtract 32 before scaling; dividing first applies operations in the wrong order.
22. Good answers: implementing reverse formulas, graphics, physics, unit conversion, performance calculations.
23. Learner-created response.

## Common Wrong Answers
- `y = 2x + 3` → `x = y/2 + 3`: undo addition before division.
- `v = u + at` → `u = v + at`: sign error when moving `at`.
- `d = st` → `s = dt`: multiplication rearranges to division, not more multiplication.
