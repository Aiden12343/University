## Practice Answers

### A. Vocabulary
1. Two or more equations using the same unknowns that must all be true together. (1 mark)
2. Replace one unknown with an expression from another equation. (1 mark)
3. Add or subtract equations to remove one unknown. (1 mark)
4. The `(x, y)` pair where both equations are satisfied — where two lines cross. (1 mark)
5. A system with at least one valid solution. (1 mark)
6. Otherwise you are mixing different quantities under the same name. (1 mark)

### B. Substitution
7. `x = 3`, `y = 5` (1 mark)
8. `y = 3`, `x = 6` (1 mark)
9. `x = 4`, `y = 1` (1 mark)
10. `b = 2`, `a = 5` (1 mark)
11. `x = 3`, `y = 9` (1 mark)

### C. Elimination

15. `x = 3`, `y = 13/3` or `4.333...` (1 mark)
16. `x = 3`, `y = 2.2` or `11/5` (1 mark)

## Mastery Test Answers
1. Two or more equations with the same unknowns that must all hold at once.
2. Express one unknown using another and substitute into the second equation.
3. Combine equations to cancel one unknown.
4. The shared solution point of two equations / crossing point of two lines.
5. A system that has one or more valid solutions.
6. `x = 4`, `y = 5`
7. `y = 3`, `x = 9`
8. `x = 2`, `y = 1`
9. `x = 7`, `y = 4`
10. `x = 2`, `y = 4`
11. `x = 3`, `y = 2.6` or `13/5`
12. `x = 3`, `y = 2`
13. No — fails `x + y = 5`.
14. Infinitely many.
15. None.
16. `(3, 5)`
17. Correct: add equations → `6x = 18`, `x = 3`, then `y = 2`.
18. `w = 60`, `h = 40`
19. `s = 125`, `r = 375`
20. Good answers: impossible user constraints, conflicting API limits, unsatisfiable linear program.
21. `x + y = 12`, `5x + 9y = 84`
22. `x = 6`, `y = 6`
23. Algebra slips can satisfy one equation only.
24. When coefficients of one variable are already equal or opposite.
25. Good answers mention constraints, intersections, layouts, resource limits, or linear models in software.

## Mark Scheme
- Practice: 35 marks total (1 mark each).
- Mastery Section A: 5 marks (1 each; all required to pass).
- Mastery Sections B–E: 20 marks (1 each).
- Mastery total: 25 marks. Pass: 23/25 with 5/5 on Section A.

Common wrong answers:
- `(3, 2)` for `x + y = 6`, `x - y = 2` — fails the sum equation.
- Forgetting to multiply **every term** when scaling an equation.
