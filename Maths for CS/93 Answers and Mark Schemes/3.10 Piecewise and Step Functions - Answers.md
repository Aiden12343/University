## Practice Questions - Answers

### Section A - Vocabulary
1. A [[piecewise rule]] defines a function with different formulas on different input intervals.
2. An [[interval]] is a continuous range of input values, often written with inequalities.
3. A [[step function]] is piecewise constant — flat on each interval with jumps at boundaries.
4. The [[floor function]] ⌊x⌋ is the greatest integer less than or equal to x.
5. The [[ceiling function]] ⌈x⌉ is the smallest integer greater than or equal to x.
6. A **closed** endpoint includes the boundary value (filled dot); an **open** endpoint excludes it (hollow dot).

### Section C - Mistake-Spotting
19. At x = 1, the rule is `x ≥ 1`, so use `f(x) = 5`, not `x^2`. `f(1) = 5`.
20. `⌊-4.1⌋ = -5`, not -4. Greatest integer ≤ -4.1 is -5.
21. `⌈-4.1⌉ = -4`, not -5. Smallest integer ≥ -4.1 is -4.
22. `x < 2` excludes 2, so the dot at (2, 3) must be **open**.
23. Intervals must be defined so exactly one rule applies. Specify: e.g. `x < 3` and `x ≥ 3`, with one rule using `≤` at 3 on one side only.

## Common Wrong Answers
- Using the wrong interval at boundary points (`<` vs `≤`).
- Floor of negative numbers going toward zero instead of more negative.
- Confusing floor and ceiling on negative inputs.
- Open/closed dot errors at interval endpoints.
- Overlapping or gapped piecewise definitions.
