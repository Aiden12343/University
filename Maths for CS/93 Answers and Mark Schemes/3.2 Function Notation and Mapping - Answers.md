## Practice Answers

### A. Vocabulary
1. A function is a rule assigning exactly one output to each allowed input.
2. An input is the value fed into a function (often x).
3. An output is the value returned for a given input (often f(x) or y).
4. The domain is the set of all allowed input values.
5. The range is the set of all possible output values.
6. A function requires one input → one output; two outputs for the same input breaks the rule.

### B. Core Skills
7. `f(4) = 3(4) + 2 = 14`
8. `g(10) = 10 - 7 = 3`
9. `h(5) = 25`
10. `f(0) = 1`
11. `5x - 1 = 14` → `x = 3`
12. `x + 3 = 11` → `x = 8`
13. **x = 2** (denominator zero)
14. `x + 4 = 9` → `x = 5`. Yes, output 9 is possible.
15. **(1, 3), (2, 4), (3, 5)**
16. Yes — each x has one y.
17. No — x = 1 has two y-values.
18. `f(x) = 10` when x = 5. Yes, 20 is in the range.

### C. Spot the Mistake
19. `f(x)` names the output when input is x; it is not multiplication by x.
20. Substitute 3 for x: `3^2 + 1 = 10`, not `3x^2 + 1`.
21. Domain is all real numbers unless restricted; negatives are allowed.
22. Input 4 cannot map to two outputs in a function.

### D. Mixed Practice
23. `f(2) = 4`, `g(2) = 3`
24. 0→3, 1→4, 2→5
25. Outputs: 1, 3, 5
26. Domain: all reals; range: y ≥ 0 (outputs never negative).
27. Example: `f(x) = 1/(x - 5)` excludes x = 5.
28. `f(3) = 7`, `f(-2) = 12`

### E. Computer Science Transfer
29. Function: **greet**; input: **"Ada"**; output: **"Hello, Ada"**
30. Deterministic hashing ensures the same data always maps to the same digest for lookup and integrity checks.
31. x = 0 causes division by zero — domain check prevents crash.
32. `T(n)` treats input size n as the input to a runtime function, same input-output structure.
