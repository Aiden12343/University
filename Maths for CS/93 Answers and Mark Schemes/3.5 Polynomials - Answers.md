## Practice Questions - Answers

### Section A - Vocabulary
1. A [[polynomial]] is a sum of terms with non-negative whole-number powers of a variable.
2. The [[degree]] is the highest power of the variable with a non-zero coefficient.
3. A [[coefficient]] is the number multiplying a variable or variable-power term.
4. A [[root]] is an input value that makes the polynomial equal zero.
5. The [[leading term]] is the highest-degree term in standard descending order.
6. Example: `1/x + 2` is not a polynomial because `1/x = x^-1`, which has a negative power.

### Section B - Core Skills
7. Yes. Powers are 4, 1, and 0.
8. No. `4/x = 4x^-1`, which has a negative power.
9. No. `sqrt(x) = x^(1/2)`, which has a fractional power.

11. Reorder as `9x^5 - 2x - 3`, so leading term is **9x^5**.

### Section C - Mistake-Spotting
19. They combined unlike terms. `x^2` and `x^3` have different powers, so `x^2 + x^3` is already simplified.
20. Degree is about highest power, not largest coefficient. The degree is **7**.
21. `1/x` equals `x^-1`; negative powers are not allowed in polynomials.
22. The coefficient of `-x^4` is **-1**, not 1.
23. They failed to distribute both terms:

```text
(x + 1)(x^2 + 2)
= x^3 + 2x + x^2 + 2
= x^3 + x^2 + 2x + 2
```

### Section D - Mixed Practice
24. Descending powers:

```text
2x^4 - x^2 + 3x - 8
```

Degree: **4**.

25. Add like terms:

```text
(x^4 - 2x^4) + (-3x^2 + x^2) + 2x - 5
= -x^4 - 2x^2 + 2x - 5
```

26. Expand:

```text
(2x + 3)(x^2 - x + 1)
= 2x^3 - 2x^2 + 2x + 3x^2 - 3x + 3
= 2x^3 + x^2 - x + 3
```

27. Factorise:

```text
x^3 - 9x
= x(x^2 - 9)
= x(x - 3)(x + 3)
```

Roots:

```text
x = 0, x = 3, x = -3
```

28. Substitute x = 2:

```text
p(2) = 2^3 - 5(2) + 2
= 8 - 10 + 2
= 0
```

Yes, x = 2 is a root.

29. The dominant term is **12n^5** because it has the highest power.

### Section E - CS Transfer
30. Dominant term: **4n^2**.
31. It is closest to **cubic growth** for large n because `3n^3` is the leading term.
32. Leading terms matter in Big-O because smaller powers become less important as input size grows.
33. Examples: Reed-Solomon error correction, CRC checks, interpolation, curve fitting, Bezier graphics, numerical approximation.
34. Extra polynomial values give redundancy; if some values are damaged, enough remaining values can reconstruct the original polynomial and therefore the data.

35. Factorise:

```text
p(x) = x^4 - 5x^2
= x^2(x^2 - 5)
```

Degree: **4**.

Leading term: **x^4**.

Roots:

```text
x^2 = 0  gives  x = 0
x^2 - 5 = 0  gives  x^2 = 5
x = sqrt(5) or x = -sqrt(5)
```

Roots: **0, sqrt(5), -sqrt(5)**.

## Common Wrong Answers
- Treating any expression with x as a polynomial: check powers.
- Dropping negative signs from coefficients: keep the sign attached.
- Combining unlike terms: only equal powers combine.
- Thinking largest coefficient means highest degree: degree uses exponent size.
- Forgetting roots are x-values, not y-values.
