## Practice Questions - Answers

### Section A - Vocabulary
1. [[exponential growth]] is increase by multiplying by the same factor each step.
2. A [[growth factor]] is the multiplier greater than 1 used each step.
3. A [[decay factor]] is the multiplier between 0 and 1 used each step.
4. The [[base]] is the number raised to a power.
5. An [[asymptote]] is a line a graph approaches but does not reach.
6. Repeated addition adds the same amount each step; repeated multiplication multiplies by the same factor each step.

## Common Wrong Answers
- Calling `x^k` exponential: x must be in the exponent.
- Adding the factor instead of multiplying by it.
- Saying decay reaches zero exactly.
- Forgetting `b^0 = 1` when finding y-intercepts.
- Comparing growth types only with tiny input values.
