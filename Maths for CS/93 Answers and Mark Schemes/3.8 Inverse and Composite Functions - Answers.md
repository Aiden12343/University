## Practice Questions - Answers

### Section A - Vocabulary
1. An [[inverse function]] undoes another function.
2. [[composition]] means applying one function to the result of another.
3. The [[identity function]] returns every input unchanged.
4. [[one-to-one]] means different inputs always give different outputs.
5. A [[nested function]] is a function written inside another function.
6. In this topic, `f^-1(x)` means the inverse function, not the reciprocal `1/f(x)`.

### Section C - Mistake-Spotting
19. In `f(g(2))`, g happens first because it is inside. Then f uses that result.
20. Composition order does not always commute. Example: if `f(x)=2x` and `g(x)=x+3`, then `f(g(x))=2x+6` but `g(f(x))=2x+3`.
21. Correct inverse:

```text
y = 4x + 1
y - 1 = 4x
x = (y - 1)/4
f^-1(x) = (x - 1)/4
```

22. `f^-1(x)` means inverse function, not reciprocal.
23. Over all real numbers, `x^2` is not one-to-one because `2` and `-2` both map to `4`. Square root only gives one branch unless the domain is restricted.

### Section E - CS Transfer
30. `encode(data)` runs first, then `compress(...)`, then `send(...)`.
31. It shows an inverse-function round trip: decode undoes encode.
32.

```text
decode(x) = x - 21
```

33. One-to-one behaviour matters because the decoder must know exactly which original input produced the encoded output.
34. Examples: cryptographic hash, checksum, lossy image compression, rounding, many-to-one classification.

35.

```text
f(g(x)) = f(x^2)
= 3x^2 + 2
```

```text
g(f(x)) = g(3x + 2)
= (3x + 2)^2
= 9x^2 + 12x + 4
```

They differ because composition order changes which output is fed into which function.

## Common Wrong Answers
- Doing the outside function first in composition.
- Assuming composition order does not matter.
- Treating inverse notation as reciprocal notation.
- Undoing operations in the wrong order.
- Ignoring one-to-one failures when claiming an inverse.
