### D. Rotation
13. x' = 5×0 - 0×1 = 0, y' = 5×1 + 0×0 = 5. Result: (0, 5)

### E. Spot the Mistake
16. Yes, correct: (2+4, 3+1) = (6, 4)
17. The student added instead of multiplying. Correct: (3×2, 4×2) = (6, 8)
18. The student got (0, -4), which is rotation by -90°. Correct for +90°: (0, 4)

### F. CS Transfer
19. (3+10, 0+5, 0+0) = (13, 5, 0)
20. Camera-space z = 20 - (-10) = 30. Actually, if camera is at z=-10 looking towards z=+∞, the relative position is 30-(-10) = 40. More precisely, camera at -10, object at 20, so camera-space z = 30.
21. |L| = √2, L̂ = (0.707, 0.707). N·L̂ = 0.707. Diffuse = 0.707
22. (80×2, 30×2) = (160, 60) pixels
23. Rotation formulas use cos and sin, which preserve x²+y² for any point
24. 45 × 2 = 90°. Radians: 90 × π/180 = π/2
25. L·N measures how aligned the light direction is with the surface normal. Higher value = more light.
