# 4.9 Dot Product and Projection - Answers

Theory note: [[4.9 Dot Product and Projection]]

## Practice Answers
### A. Vocabulary
1. A scalar operation: sum of products of corresponding components
2. Scalar (a single number)
3. The vectors are orthogonal (perpendicular)
4. a·b = |a||b|cos θ
5. The component of one vector along the direction of another
6. A vector perpendicular to a surface

### B. Compute Dot Product
7. a·b = 2×3 + 3×4 = 6 + 12 = 18
8. a·b = 2×0 + 0×5 = 0
9. a·b = 1×2 + 1×3 + 1×4 = 9
10. a·b = 0×1 + 1×0 + 0×1 = 0

### C. Angles
11. a·b = 5×3×cos30° = 15×0.866 = 12.99
12. cos θ = 12/(4×6) = 12/24 = 0.5
13. a·b = 0, so θ = 90°
14. a·b = 4, |a|=√8≈2.828, |b|=2, cos θ=4/(5.656)=0.707, θ=45°

### D. Orthogonality
15. 2×3 + 3×(-2) = 6-6 = 0. Yes, orthogonal.
16. 1×0 + 0×1 + 0×0 = 0. Yes, orthogonal.
17. 4×1 + 1×(-4) = 4-4 = 0. Yes, orthogonal.
18. 3×2 + k×(-6) = 0 → 6 - 6k = 0 → k = 1

### E. Projection
19. a·b = 20, |a|² = 25. s = 20/25 = 0.8. proj = 0.8×(5,0) = (4, 0)
20. a·b = 18, |a|² = 9. s = 2. proj = 2×(3,0) = (6, 0)
21. a·b = 3, |a|² = 1. s = 3. proj = (3, 0, 0)

### F. Spot the Mistake
22. Dot product is a scalar, not a vector. Correct: 2×4 + 3×1 = 8+3 = 11.
23. No. a·b = 0 means a ⟂ b. Example: (1,0)·(0,1) = 0, neither vector is zero.

### G. CS Transfer
24. |L| = √2 ≈ 1.414, L̂ = (0.707, 0.707). N·L̂ = 0×0.707 + 1×0.707 = 0.707. max(0.707, 0) = 0.707
25. 0.98 is very close to 1, so the vectors are very similar (almost parallel)
26. Direction = (3-0, 4-0) = (3,4). Facing·Direction = (1,0)·(3,4) = 3 > 0. Yes, in front.
27. |L| = √(0+1+1) = √2 ≈ 1.414, L̂ = (0, 0.707, 0.707). N·L̂ = 0.707. Brightness = 0.707
28. W = (10,0)·(5,3) = 50 + 0 = 50 J
