Practice note: [[5.1 Set Theory Basics - Practice Questions]]
Theory note: [[5.1 Set Theory Basics]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- set: define it in one sentence and include a tiny example.
- element: define it by saying what it measures, names, or transforms.
- membership: connect it to the main idea: Group objects and describe membership precisely.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Sets model collections, database results, permissions, and types.

It should also explain what would go wrong in software if the concept were misunderstood.
