# 5.4 Infinity and Countability - Answers

Practice note: [[5.4 Infinity and Countability - Practice Questions]]
Theory note: [[5.4 Infinity and Countability]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- infinite set: define it in one sentence and include a tiny example.
- countable: define it by saying what it measures, names, or transforms.
- uncountable: connect it to the main idea: Compare sizes of infinite sets carefully.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Countability helps explain limits of computation and data representation.

It should also explain what would go wrong in software if the concept were misunderstood.
