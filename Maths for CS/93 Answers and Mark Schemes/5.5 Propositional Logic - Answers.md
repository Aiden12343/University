These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- proposition: define it in one sentence and include a tiny example.
- truth value: define it by saying what it measures, names, or transforms.
- and: connect it to the main idea: Build true-or-false statements from smaller statements.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Program conditions and circuit logic are propositional logic.

It should also explain what would go wrong in software if the concept were misunderstood.
