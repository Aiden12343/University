# 5.6 Truth Tables - Answers

Practice note: [[5.6 Truth Tables - Practice Questions]]
Theory note: [[5.6 Truth Tables]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- truth table: define it in one sentence and include a tiny example.
- case: define it by saying what it measures, names, or transforms.
- tautology: connect it to the main idea: List all possible truth cases systematically.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Truth tables test conditionals, Boolean expressions, and digital circuits.

It should also explain what would go wrong in software if the concept were misunderstood.
