# 5.9 Direct Proof and Counterexample - Answers

Practice note: [[5.9 Direct Proof and Counterexample - Practice Questions]]
Theory note: [[5.9 Direct Proof and Counterexample]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- theorem: define it in one sentence and include a tiny example.
- assumption: define it by saying what it measures, names, or transforms.
- conclusion: connect it to the main idea: Prove a claim directly or disprove it with one example.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Algorithm correctness begins with proof habits.

It should also explain what would go wrong in software if the concept were misunderstood.
