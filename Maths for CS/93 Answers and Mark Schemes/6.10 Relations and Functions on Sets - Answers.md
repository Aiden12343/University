## Vocabulary Answers
- relation: define it in one sentence and include a tiny example.
- reflexive: define it by saying what it measures, names, or transforms.
- symmetric: connect it to the main idea: Describe links between elements and special relation properties.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Databases, type relations, ordering, and program semantics use relations.

It should also explain what would go wrong in software if the concept were misunderstood.
