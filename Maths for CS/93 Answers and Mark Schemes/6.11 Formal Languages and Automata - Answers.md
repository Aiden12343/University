# 6.11 Formal Languages and Automata - Answers

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- alphabet: define it in one sentence and include a tiny example.
- string: define it by saying what it measures, names, or transforms.
- language: connect it to the main idea: Model patterns and machines that recognise strings.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Compilers, parsers, regex engines, and protocol checkers use automata.

It should also explain what would go wrong in software if the concept were misunderstood.
