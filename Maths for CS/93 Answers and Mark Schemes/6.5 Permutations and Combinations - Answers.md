# 6.5 Permutations and Combinations - Answers

Practice note: [[6.5 Permutations and Combinations - Practice Questions]]
Theory note: [[6.5 Permutations and Combinations]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- permutation: define it in one sentence and include a tiny example.
- combination: define it by saying what it measures, names, or transforms.
- factorial: connect it to the main idea: Count arrangements and selections.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Passwords, scheduling, testing combinations, and probability use these counts.

It should also explain what would go wrong in software if the concept were misunderstood.
