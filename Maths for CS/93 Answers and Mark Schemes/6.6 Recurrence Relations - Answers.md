# 6.6 Recurrence Relations - Answers

Practice note: [[6.6 Recurrence Relations - Practice Questions]]
Theory note: [[6.6 Recurrence Relations]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- recurrence: define it in one sentence and include a tiny example.
- initial condition: define it by saying what it measures, names, or transforms.
- recursive definition: connect it to the main idea: Define values using previous values.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Recursive algorithms are described by recurrence relations.

It should also explain what would go wrong in software if the concept were misunderstood.
