## Vocabulary Answers
- graph: define it in one sentence and include a tiny example.
- vertex: define it by saying what it measures, names, or transforms.
- edge: connect it to the main idea: Represent connected objects using vertices and edges.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Networks, maps, dependency graphs, and social graphs are graph structures.

It should also explain what would go wrong in software if the concept were misunderstood.
