These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- tree: define it in one sentence and include a tiny example.
- root: define it by saying what it measures, names, or transforms.
- leaf: connect it to the main idea: Study connected acyclic graphs and ways to visit them.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: File systems, syntax trees, DOM trees, and search structures are trees.

It should also explain what would go wrong in software if the concept were misunderstood.
