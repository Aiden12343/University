## Vocabulary Answers
- matrix: define it in one sentence and include a tiny example.
- row: define it by saying what it measures, names, or transforms.
- column: connect it to the main idea: Read matrices by rows, columns, and dimensions.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Matrices store images, datasets, transformations, and systems of equations.

It should also explain what would go wrong in software if the concept were misunderstood.
