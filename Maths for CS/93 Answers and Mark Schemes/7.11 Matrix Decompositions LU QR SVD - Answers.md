## Vocabulary Answers
- LU decomposition: define it in one sentence and include a tiny example.
- QR decomposition: define it by saying what it measures, names, or transforms.
- SVD: connect it to the main idea: Break matrices into useful simpler pieces.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: SVD powers compression, search, PCA, and recommender systems.

It should also explain what would go wrong in software if the concept were misunderstood.
