## Vocabulary Answers
- dot product row by column: define it in one sentence and include a tiny example.
- inner dimension: define it by saying what it measures, names, or transforms.
- composition: connect it to the main idea: Multiply matrices as composed linear operations.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Matrix multiplication powers graphics, neural networks, and scientific computing.

It should also explain what would go wrong in software if the concept were misunderstood.
