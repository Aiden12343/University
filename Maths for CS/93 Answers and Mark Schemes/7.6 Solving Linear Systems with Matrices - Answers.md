## Vocabulary Answers
- linear system: define it in one sentence and include a tiny example.
- augmented matrix: define it by saying what it measures, names, or transforms.
- row operation: connect it to the main idea: Use matrix methods to solve many equations at once.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Simulation, optimisation, graphics, and ML often solve linear systems.

It should also explain what would go wrong in software if the concept were misunderstood.
