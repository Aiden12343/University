# 7.7 Vector Spaces Span and Basis - Answers

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- vector space: define it in one sentence and include a tiny example.
- span: define it by saying what it measures, names, or transforms.
- basis: connect it to the main idea: Describe spaces made from vectors and their building blocks.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Embeddings, graphics, and data representations depend on vector spaces.

It should also explain what would go wrong in software if the concept were misunderstood.
