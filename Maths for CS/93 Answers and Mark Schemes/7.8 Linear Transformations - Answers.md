These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- linear transformation: define it in one sentence and include a tiny example.
- rotation: define it by saying what it measures, names, or transforms.
- scaling: connect it to the main idea: Treat matrices as operations that move vectors.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: 3D graphics pipelines are chains of linear transformations.

It should also explain what would go wrong in software if the concept were misunderstood.
