These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- event: define it in one sentence and include a tiny example.
- outcome: define it by saying what it measures, names, or transforms.
- sample space: connect it to the main idea: Measure how likely events are.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Reliability, ML predictions, simulations, and randomised algorithms use probability.

It should also explain what would go wrong in software if the concept were misunderstood.
