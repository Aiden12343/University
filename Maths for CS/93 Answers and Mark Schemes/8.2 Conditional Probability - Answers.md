## Vocabulary Answers
- conditional probability: define it in one sentence and include a tiny example.
- given: define it by saying what it measures, names, or transforms.
- joint probability: connect it to the main idea: Update probability when extra information is known.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Spam filters, risk models, and diagnostics use conditional probability.

It should also explain what would go wrong in software if the concept were misunderstood.
