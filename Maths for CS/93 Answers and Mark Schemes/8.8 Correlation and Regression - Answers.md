# 8.8 Correlation and Regression - Answers

Practice note: [[8.8 Correlation and Regression - Practice Questions]]
Theory note: [[8.8 Correlation and Regression]]

These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- correlation: define it in one sentence and include a tiny example.
- linear regression: define it by saying what it measures, names, or transforms.
- slope: connect it to the main idea: Measure relationships and fit simple predictive lines.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: Regression is a first model for prediction and data analysis.

It should also explain what would go wrong in software if the concept were misunderstood.
