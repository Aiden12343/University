These are model answer patterns, not scripts to memorise.

## Vocabulary Answers
- null hypothesis: define it in one sentence and include a tiny example.
- alternative hypothesis: define it by saying what it measures, names, or transforms.
- p-value: connect it to the main idea: Use sample data to judge claims carefully.

## Core Skill Answers
A correct solution should:

1. State the problem clearly.
2. Use the correct definition or rule.
3. Show one step per line.
4. Keep notation consistent.
5. Check the answer.

## CS Transfer Answer
A strong answer should say: A/B testing and performance comparisons need hypothesis testing.

It should also explain what would go wrong in software if the concept were misunderstood.
