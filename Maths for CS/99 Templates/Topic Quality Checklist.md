# Topic Quality Checklist

Use this before marking any topic bundle as complete. Derived from Module 01 (1.1–1.13).

## Topic Note
- [ ] Tags present (`#maths/...`, `#cs/...`)
- [ ] Position in the Course: Prerequisites, Used later in, mastery threshold (90% / 100% New Words)
- [ ] Plain-English Idea: one paragraph, no unexplained jargon
- [ ] New Words: exactly 5 linked glossary terms
- [ ] ≥5 Concept sections, each with one micro-idea only
- [ ] Each Concept has ≥1 Obsidian callout (`tip`, `example`, `warning`, `important`, or `failure`)
- [ ] Each Concept has a Chunked Example (Question → Steps → Answer)
- [ ] ≥2 backward wiki-links in Concept body text (not just header)
- [ ] Why This Works cites earlier breadcrumbs
- [ ] Common Mistakes: 4–6 items with fixes
- [ ] Where This Shows Up in CS: named programming objects
- [ ] Checkpoint Questions: 8–10
- [ ] Mini-Quiz: 10 questions
- [ ] Pass Gate lists exact next topic
- [ ] Related Notes: backward, forward, assessment links

## Worked Examples
- [ ] 4–6 examples, escalating difficulty
- [ ] Every step on its own line
- [ ] ≥1 CS transfer example
- [ ] ≥1 spot-the-mistake example
- [ ] Links to theory note and practice questions

## Practice Questions
- [ ] Sections A–E (Vocabulary → Core → Mistakes → Mixed → CS)
- [ ] 25–35 questions total
- [ ] Paper-first rule callout

## Mastery Test
- [ ] Section A: Definitions (100% required)
- [ ] Sections B–D: Core skills
- [ ] Section E: CS transfer (3–5 questions)
- [ ] 25 marks total; pass 90% (85% from Module 05+)
- [ ] Decision checkboxes (Pass / Review / Restart)

## Answers
- [ ] Full worked solutions, not just final answers
- [ ] Mark allocation per question
- [ ] Common wrong answer notes where helpful

## Glossary (5 terms per topic)
- [ ] One-sentence plain-English definition
- [ ] First introduced in: [[topic]]
- [ ] Builds on: [[prior term or topic]]
- [ ] Used in CS: one sentence
